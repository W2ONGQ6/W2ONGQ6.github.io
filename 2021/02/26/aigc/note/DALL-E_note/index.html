Zero-Shot Text-to-Image Generation

DALL-E: 零样本文生图

核心信息

  • 标题: Zero-Shot Text-to-Image Generation
  • 标题翻译: 零样本文本到图像生成
  • 作者: Aditya Ramesh, Mikhail Pavlov, Gabriel Goh, Scott Gray, Chelsea Voss, Alec Radford, Mark Chen, Ilya Sutskever
  • 机构: OpenAI
  • 发表时间: 2021 年 2 月
  • 发表渠道: ICML 2021
  • arXiv: 2102.12092
  • 论文链接: https://arxiv.org/abs/2102.12092
  • 代码 / 项目: https://github.com/openai/DALL-E
  • 论文类型: 文生图生成模型（自回归 Transformer）

原文摘要翻译

文本到图像的生成传统上聚焦于在固定的小规模数据集上寻找更好的建模假设。这种假设可能涉及复杂的工程结构、辅助损失函数或训练阶段中包含的辅助信息（如目标部件标签或分割掩码）。本文描述了一个简单的方法，基于一个自回归 Transformer，在大规模文本-图像对数据上进行训练。给定文本和一组图像标记序列后，我们只需以自回归方式对标记进行建模。数据充足时，该方法在零样本条件下即可完成多种任务，包括概念组合、风格迁移、地理事实知识等。在 MS-COCO 数据集上的人类评审中，我们的 120 亿参数模型生成的样本优于此前任务特定模型，如 DF-GAN 和 DM-GAN。

创新点

1. 将图像离散化为 Token 序列，统一文图模态

核心思想: 训练一个离散变分自编码器（dVAE），将 256x256 的 RGB 图像压缩为 32x32 的离散 token 网格，每个 token 来自 8192 个码本条目。这使得连续图像被转化为与文本完全相同的离散符号序列，文图生成问题变成了标准的序列到序列（seq2seq）建模问题。

为什么重要: 在 DALL-E 之前，文生图的主流方法是 GAN 配合文本编码器，需要针对图像模态设计专门的生成架构。DALL-E 的做法——把图像当作”另一种语言”——消除了模态差异，使得为语言模型开发的所有基础设施（大规模训练、稀疏注意力、分布式训练等）可以直接应用于图像生成。这条”万物皆 token”的技术路线最终演化为 GPT-4V/4o 等多模态大模型的基础范式。

2. 12B 参数的稀疏 Transformer 架构

核心思想: 使用 64 层、每层 62 个注意力头的稀疏 Transformer，总参数量 120 亿。稀疏注意力模式在文本 token 和图像 token 之间使用了不同的连接策略——文本 token 可以关注所有之前的文本 token，图像 token 可以关注所有文本 token 和图像的局部区域。这种设计大幅降低了自回归生成的计算复杂度（从完全的 O(N^2) 降到近似 O(N*√N)）。

为什么重要: 12B 参数在当时是图像生成领域前所未有的规模（此前最大的图像生成模型参数量通常在百万到亿级别）。稀疏注意力的使用使得模型能够处理文本（最长 256 token）和图像（1024 token）拼接而成的长序列，同时保持训练效率。这证明了”规模越大，能力越强”的定律在文生图领域同样成立。

3. 大规模数据驱动的零样本泛化

核心思想: 使用约 2.5 亿图文对进行训练（远超此前学术数据集的规模，如 MS-COCO 仅 10 万级），不做任何任务特定的微调。模型在训练中从未见过明确的”风格迁移”或”图像类比”训练样本，但这些能力从数据中涌现出来。

为什么重要: 这标志着文生图研究从”在特定数据集上精心设计任务专属方案”转向了”大规模预训练 + 零样本泛化”的范式。这一范式是 GPT-3 在 NLP 领域成功经验向视觉生成的直接迁移，为后续 DALL-E 2、Stable Diffusion 等模型的训练哲学奠定了思想基础。

4. 涌现的多种生成能力

核心思想: DALL-E 展示了此前需要专门模型才能实现的能力：概念组合（”鳄梨形状的扶手椅”）、风格迁移（”以梵高风格画的猫”）、图像类比推理、地理事实知识（”旧金山金门大桥的照片”）、时序推理（”一天中不同时刻的同一场景”）等。

为什么重要: 这些能力不是显式设计的产物，而是模型在大规模数据上训练后自然涌现的。这证明了 Transformer 的灵活表征能力足以学习到视觉概念的语义组合规则，使得”用语言指挥图像生成”这一理想变得切实可行。

一句话总结

DALL-E 通过训练 120 亿参数的稀疏 Transformer 对 2.5 亿图文对进行自回归建模，首次证明足够大的模型在大规模数据上训练后可以在零样本条件下从文本描述直接生成多样化、语义合理的图像，开创了”大规模预训练 + 零样本文生图”的新范式。

研究问题

核心挑战

在 DALL-E 之前，文生图面临两个根本性困难：

  1. 模态鸿沟: 文本是离散的、结构化的符号序列，图像是连续的、高维的像素矩阵。如何将两者映射到统一的建模空间？

  2. 数据与泛化: 传统文生图模型（如 StackGAN、DF-GAN）在 MS-COCO 等特定数据集上训练，严重受限于标注数据的规模和多样性，泛化到新概念组合的能力极弱。

DALL-E 的关键洞察

把图像当作另一种语言: 如果能把图像转换为离散 token 序列，就可以用处理文本完全相同的方式处理图像——用 Transformer 做自回归建模。这从根本上消除了模态差异。

数据与任务定义

训练数据

  • 规模: 约 2.5 亿对图文对（来自互联网抓取，未公开具体数据源）
  • 预处理: 文本截断至 256 token（BPE 编码），图像缩放至 256x256 分辨率
  • dVAE 训练数据: 来自 ImageNet 的图像（用于训练图像离散化编码器）

评估方式

  • 零样本人类评估: 在 MS-COCO 上，请人类评审者比较 DALL-E 和此前最先进的专用模型生成的图像质量
  • 定性展示: 通过精心设计的 prompt 展示概念组合、风格迁移、类比推理等能力
  • 可控生成: 通过消融实验评估不同温度、不同 reranking 策略对生成质量的影响

关键设计选择

参数 值 原因
图像分辨率 256x256 dVAE 编码后的 token 网格为 32x32，共 1024 token
dVAE 码本大小 8192 在重建质量与序列长度之间平衡
文本编码 BPE (16384 词汇表) 与语言模型一致，降低 token 序列长度
稀疏注意力模式 行+列+头卷积 使 1024 图像 token 的复杂度从 O(N^2) 降至 O(N*√N)
推理后处理 CLIP + DALL-E reranking 用 CLIP 对 512 个候选排序，选出最佳图像

方法主线

整体架构

DALL-E 是一个两阶段系统：

  1. 阶段一（dVAE）: 训练一个离散 VAE，用于图像的编码（连续 RGB -> 离散 token 网格）和解码（离散 token 网格 -> 连续 RGB）
  2. 阶段二（Transformer）: 训练一个 120 亿参数的自回归 Transformer，对拼接的文本 token 和图像 token 序列进行联合建模

机制流程

步骤 1: 图像离散化（dVAE 训练）

  • 输入: RGB 图像 X（256x256x3）
  • 操作:
    • 编码器将图像编码为 32x32 的连续特征图
    • 通过查找 8192 大小的码本将每个位置的特征向量量化为最近的码本向量索引
    • 输出 32x32=1024 个离散 token（每个 token 是 0~8191 的整数）
    • 解码器从量化后的特征图重建原始图像
  • 输出: 一个能可靠编码/解码图像的 dVAE 模型，以及每张训练图像对应的 1024 个 token
  • 训练目标: 最小化 ELBO（证据下界），包括重建误差和码本学习损失

步骤 2: 文本-图像序列构建

  • 输入: 文本描述 T 和图像的 1024 个 token
  • 操作:
    • 用 BPE 分词器将文本编码为最长 256 个 token
    • 将文本 token 和图像 token 拼接为一个长序列：[text_1, …, text_m, image_1, …, image_1024]
    • 序列总长度最多为 256 + 1024 = 1280 token
  • 输出: 拼接后的统一 token 序列

步骤 3: 自回归 Transformer 训练

  • 输入: 拼接后的文本-图像 token 序列
  • 操作:
    • 对于文本区域：使用标准因果注意力（每个文本 token 关注所有之前的文本 token）
    • 对于图像区域：使用稀疏注意力（每个图像 token 关注所有文本 token + 图像 token 中特定位置的子集）
    • 稀疏注意力模式：行注意力（关注同一行的所有图像 token）+ 列注意力（关注同一列的所有图像 token）+ 头卷积注意力
    • 逐 token 预测下一个 token 的概率分布
  • 输出: 训练好的 12B 参数 Transformer
  • 训练目标: 交叉熵损失，最大化正确 token 的对数概率

步骤 4: 推理生成

  • 输入: 文本 prompt（训练时未见过的描述）
  • 操作:
    • 将文本编码为 token 序列
    • 从起始 token 开始，逐 token 自回归生成 1024 个图像 token
    • 在每一步从模型输出的概率分布中采样下一个 token
    • 生成 512 个候选图像（使用不同温度或采样策略）
    • 用 CLIP 对 512 个候选图像进行 reranking（按 CLIP 计算的图文相似度排序）
    • 选出 CLIP 得分最高的图像
  • 输出: dVAE 解码后的 RGB 图像

稀疏注意力细节

DALL-E 的 Transformer 使用了三种注意力模式的组合：

  • 行注意力: 每个图像 token 关注所有文本 token + 同一行（row）的所有图像 token
  • 列注意力: 每个图像 token 关注所有文本 token + 同一列（column）的所有图像 token
  • 头卷积注意力: 在注意力头的维度上使用一维卷积来模拟更灵活的注意力模式

这种设计使得 1024 个图像 token 的注意力复杂度从 O(1024²) ≈ 1M 降至 O(1024 × (1024^(1/2) + 1024^(1/2))) ≈ 65K，大幅降低了内存和计算需求。

涌现能力定性展示

DALL-E 展示了多种零样本能力：

深度分析

为什么选择自回归而非 GAN

DALL-E 选择自回归 Transformer 而非当时更主流的 GAN 有以下深层原因：

  1. 训练稳定性: GAN 面临模式坍塌、训练不收敛等根本性问题，尤其在处理多样化输出时。自回归 Transformer 的极大似然训练天然稳定。
  2. 规模化能力: Transformer 的可扩展性已被 GPT 系列充分验证。将模型从 1B 扩大到 12B，性能持续提升——而 GAN 在此规模上的训练极为困难。
  3. 与文本的统一: 自回归生成与 GPT 等语言模型的范式完全一致，文本和图像可以采用完全相同的建模方式。

dVAE 设计的权衡

dVAE 的码本大小（8192）是一个关键设计参数：

  • 太小: 码本表达能力不足，重建质量差，信息损失大
  • 太大: 每个 token 有太多可能取值，自回归预测的搜索空间过大
  • 8192: 对 256x256 图像，32x32 的 token 网格配合 8192 码本可实现较好的重建质量（PSNR 约 28-30），同时保持每个 token 的预测分布足够集中

码本大小还直接影响后续 Transformer 的”词汇表”大小——8192 加上文本的 16384 个 BPE token，总词汇量约 24000，仍然可控。

自回归速度瓶颈

DALL-E 的推理需要自回归生成 1024 个图像 token，每个 token 需要一次完整的前向传播——即使使用 KV 缓存，单张图生成仍需约 1024 次前向传播。这导致：

  • 单张图像生成时间：约 2-5 分钟（取决于硬件）
  • 512 张候选 + CLIP reranking：总时间可能超过 1 小时
  • 这一速度瓶颈直接决定了 DALL-E 不适合交互式应用

这也是后续 DALL-E 2、Stable Diffusion 转向扩散模型的核心原因之一——扩散模型可通过单次前向传播（或少数几步去噪）完成生成。

稀疏注意力的真正作用

DALL-E 的稀疏注意力不仅是工程优化——它还引入了有益的归纳偏置。行/列注意力模式隐式地编码了图像的二维结构，使模型天然理解”相邻像素更相关”这一空间规律。这类似于 CNN 的平移等变归纳偏置，但以更灵活的方式嵌入 Transformer 架构中。

DALL-E 的核心贡献是”概念验证”——证明了大规模的 Transformer + 大规模数据可以解决文生图问题。它开辟的道路比它自身的结果更重要。

局限

1. 推理速度极慢

问题: 自回归生成 1024 个 token 需要 1024 次前向传播，单张图生成分钟级。这是 DALL-E 无法产品化的根本原因。

影响: 限制了交互式应用场景，也使得大规模用户服务不可行。

2. 图像保真度有限

问题: 256x256 的分辨率在 2021 年就已经不够用，dVAE 的压缩-重建过程会损失细节。生成的图像常有模糊、块状伪影等问题。

影响: 无法满足高分辨率、高质量图像需求。

3. 缺乏精确的空间控制

问题: DALL-E 通过自然语言描述来指定图像内容，但无法进行精确的空间定位（如”把树放在左上角”）。文本描述的模糊性导致生成结果的随机性。

影响: 限制了在专业设计等领域的使用。

4. 封闭生态

问题: OpenAI 未开源 DALL-E 的模型权重、训练代码和数据集，外部研究者无法复现或改进。

影响: 虽然论文发表后学术社区广泛讨论了其方法，但无法基于 DALL-E 进行二次开发。

5. 文本理解深度不足

问题: DALL-E 使用简单的 BPE 文本编码，缺乏对复杂语义关系（否定、计数、空间关系）的深层理解。复杂的 prompt 常常产生不准确的结果。

影响: “把三只猫放在两只狗旁边”这类涉及计数的 prompt 经常失败。

可复用洞见

1. “万物皆 Token”的统一范式

洞见: 将不同模态（文本、图像、音频等）统一表示为离散 token 序列，可以用同一套自回归 Transformer 架构处理所有模态。

后续应用:

  • Make-A-Scene: 用 token 表示语义分割图
  • VideoPoet: 用统一的 token 空间处理视频、音频、图像、文本
  • 多模态 LLM (GPT-4V, Gemini): 图像 token + 文本 token 统一处理

2. 大规模数据 + 大模型 = 涌现能力

洞见: 当模型和数据规模足够大时，不需要专门的任务设计，Transformer 就可以涌现出概念组合、风格迁移、类比推理等复杂能力。

后续应用: 这一原则贯穿了整个生成式 AI 的发展——从 DALL-E 到 GPT-4 到 Sora，每次能力突破都伴随着规模的跨越。

3. CLIP Reranking 的实用价值

洞见: 对于有高方差输出的生成模型，用另一个评价模型（CLIP）对候选结果排序是廉价且有效的质量提升手段。

后续应用:

  • DALL-E 2 继承了这一策略
  • 扩散模型的 classifier-free guidance 可以视为在采样过程中隐式地实现类似目标
  • 在线服务中，生成多个候选再进行审美筛选是标准操作

4. 稀疏注意力中的结构化归纳偏置

洞见: 在 Transformer 中使用结构化的稀疏注意力模式（如行+列+卷积）既能降低计算复杂度，又能引入对数据结构的先验知识。

后续应用:

  • Axial Attention（轴注意力）在图像和视频 Transformer 中被广泛采用
  • Video Diffusion Models 的空间-时间因式分解注意力继承了类似思想

我的笔记

历史地位的再审视

DALL-E 经常因为后续工作的光芒而被低估。但回顾来看，它是文生图领域最关键的”0 到 1”突破：

  • 之前: 人们普遍认为高质量文生图需要复杂的多阶段架构、辅助损失函数和专门的数据标注
  • 之后: 人们意识到大规模 Transformer + 大规模数据就够了

这一认知转换的影响远超 DALL-E 自身——它直接催生了 2021-2022 年整个生成式 AI 赛道的爆发。

对研究范式的启示

DALL-E 的成功本质上是科研思路的重大转变：

  1. 从”巧妙的架构”到”足够大的规模”: 类似 NLP 领域的 BERT/GPT 经验——当规模足够大时，架构细节的重要性下降
  2. 从”任务专属”到”通用预训练”: 不再为每个能力设计专门的模块，而是相信大规模预训练可以覆盖各种下游任务
  3. 从”小数据精调”到”大数据涌现”: 2.5 亿图文对 > 10 万 COCO 标注——数据的量级差异改变了模型的行为模式

与 GPT 系列的类比

DALL-E 之于图像生成，如同 GPT-1/GPT-2 之于 NLP：

类比维度 NLP 视觉生成
范式开创者 GPT-1/GPT-2 DALL-E
证明规模可行 GPT-3 DALL-E 2 / Imagen
开源民主化 LLaMA Stable Diffusion
多模态统一 GPT-4V 仍在发展中

这种跨领域的对称性暗示着：文生图的发展轨迹可能继续跟随 NLP 的脚步——从规模到效率、从单模态到多模态、从生成到理解。

后续问题

1. 自回归与扩散的终极竞争

问题: 自回归和扩散模型到底哪个更适合图像生成？VAR (NeurIPS 2024 Best Paper) 证明自回归可以超越扩散，但扩散模型目前仍然是主流。这两种范式的优劣边界在哪里？

研究方向: 在更大规模上比较自回归和扩散的 scaling law、在不同任务类型上的表现差异。

2. 更好的图像 Tokenizer

问题: dVAE 的压缩率和重建质量都不够理想。是否有更好的图像离散化方法？

研究方向: VQ-VAE-2、VQGAN、MAGVIT-v2 等方法在重建质量和压缩效率上的进展值得关注。

3. 从”生成”到”理解”

问题: DALL-E 证明了 Transformer 可以从文本生成图像，但它是否能真正”理解”图像的内容？这关系到多模态 LLM 的底层架构选择。

研究方向: 比较”统一 token + 自回归” vs “专用编码器 + 交叉注意力”两种多模态融合策略的深度理解能力。
