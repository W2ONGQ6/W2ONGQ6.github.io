LLM in a Flash: Efficient Large Language Model Inference with Limited Memory

核心信息

  • 标题: LLM in a Flash: Efficient Large Language Model Inference with Limited Memory
  • 作者: Apple ML Research
  • 发表时间: 2023年12月
  • arXiv: 2312.11514
  • 论文类型: 系统工程论文

原文摘要翻译

通过将模型参数存储在闪存中并利用激活稀疏性最小化数据传输，在内存远小于模型大小的设备上实现高效 LLM 推理。核心创新包括利用 ReLU/GLU 激活稀疏性减少读取权重数量、以及窗口化数据传输策略优化闪存 I/O。

创新点

1. 激活稀疏性驱动的读取优化

利用前馈层中 ReLU/GLU 激活的 90%+ 稀疏性，只从闪存读取对应非零激活的权重行。

2. 窗口化+行打包数据布局

将随机读取转化为批量顺序读取，优化闪存 I/O 效率。

3. 苹果设备端 AI 的技术基础

将闪存确立为可行的 LLM 推理存储介质，支撑了 Apple Intelligence 的设备端 AI。

一句话总结

LLM in a Flash 利用激活稀疏性和闪存优化，使 LLM 可在内存受限设备上高效推理，是 Apple 设备端 AI 的技术基础。
