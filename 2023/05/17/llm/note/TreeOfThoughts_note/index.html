Tree of Thoughts: Deliberate Problem Solving with Large Language Models

核心信息

  • 标题: Tree of Thoughts: Deliberate Problem Solving with Large Language Models
  • 标题翻译: 思维树：大语言模型的审慎问题求解
  • 作者: Shunyu Yao, Dian Yu, Jeffrey Zhao, Izhak Shafran, Thomas L. Griffiths, Yuan Cao, Karthik Narasimhan
  • 机构: Princeton University, Google DeepMind
  • 发表时间: 2023年5月
  • 发表渠道: NeurIPS 2023
  • arXiv: 2305.10601
  • 论文链接: https://arxiv.org/abs/2305.10601
  • 论文类型: 方法论论文

原文摘要翻译

语言模型越来越多地被用于解决各种任务中的通用问题，但它们在推理过程中仍然局限于 token 级别的从左到右的决策过程。这意味着它们在需要探索、策略性前瞻或初始决策起关键作用的任务中可能表现不佳。为了克服这些限制，我们提出了一种新的语言模型推理框架——思维树（Tree of Thoughts, ToT），它将经典 AI 中的规划搜索技术与现代语言模型相结合。ToT 允许语言模型在”思维”的树结构上进行探索，并通过考虑多种不同的推理路径和自我评估选择来进行审慎决策。实验表明 ToT 显著提升了语言模型在三个需要非平凡规划或搜索的任务上的问题解决能力。在 24 点游戏中，CoT 的 GPT-4 仅解决 4% 的任务，而 ToT 达到 74% 的成功率。

创新点

1. 将经典搜索算法与 LLM 深度结合

ToT 将 LLM 推理视为在”思维空间”中进行树搜索的过程。每个节点是一个”思维”（中间推理文本），LLM 负责两个核心操作：(a) 生成候选思维，(b) 评估每个思维的价值。这是首个将 BFS/DFS 搜索范式有机融入 LLM 推理的工作，标志着从”线性链”到”搜索树”的范式跃迁。

2. LLM 作为启发式评估器

ToT 让 LLM 同时充当思维生成器和启发式评估器。LLM 对每个候选思维打分或投票，引导搜索朝向有希望的方向。这种”自我评估”机制让 LLM 能在没有外部验证器的情况下进行审慎搜索。

3. 任务自适应搜索策略

不同任务使用不同搜索策略：24 点游戏用 BFS（广度优先+剪枝），创意写作用 DFS（深度优先探索完整故事线），迷你填字游戏用迭代 BFS。这种灵活性展示了 ToT 框架的通用性。

一句话总结

Tree of Thoughts 将经典 AI 的树搜索范式引入 LLM 推理，让模型在思维空间中探索多条路径并自我评估选择，在需要规划和搜索的任务上将 GPT-4 成功率从 4% 提升到 74%。

方法主线

机制流程

  1. 思维分解: 输入问题 → LLM 将问题分解为可逐步推进的”思维单元”
  2. 思维生成: 从当前状态出发 → LLM 生成 k 个候选下一思维
  3. 状态评估: 对每个候选思维 → LLM 进行价值评估，判断导向正确解的概率
  4. 搜索与剪枝: 保留最有价值的 b 个思维（BFS）或深度优先探索（DFS）→ 重复直到找到解

搜索策略

  • BFS (24 点游戏): 每层生成 5 个候选，保留 top-3，最多 4 层
  • DFS (创意写作): 每段落生成多个候选，选择最优者继续，可回溯
  • 迭代 BFS (填字游戏): 逐行填充，每行多个候选，BFS 剪枝

核心实验

24 点游戏

方法 成功率
IO prompt (GPT-4) 7.3%
CoT (GPT-4) 4.0%
CoT-SC (k=100, GPT-4) 9.0%
ToT (b=5, GPT-4) 74.0%

最引人注目的结果：CoT-SC 即使采样 100 条路径也仅有 9%，而 ToT 通过智能搜索达到 74%。证明了”盲目采样更多路径”≠”智能搜索”。

局限性与批判

  • API 调用成本高：每步需多次 LLM 调用，总量可能是 CoT 的 10-100 倍
  • 评估质量是关键瓶颈：LLM 自我评估不准确则搜索朝错误方向进行
  • 任务设计依赖人工：思维分解方式、搜索策略、评估 prompt 需手工设计
  • 可扩展性有限：搜索空间随深度指数增长

关键要点

  • 范式跃迁：LLM 推理从”线性生成”走向”树搜索”
  • LLM 双角色：同时作为思维生成器和启发式评估器
  • 搜索 > 采样：ToT 74% vs CoT-SC (k=100) 9%
  • 为 o1/R1 等推理时搜索范式提供了理论基础
