Any-to-Any Generation via Composable Diffusion (CoDi)

Any-to-Any Generation via Composable Diffusion (CoDi)

核心信息

  • 标题: Any-to-Any Generation via Composable Diffusion
  • 作者: Microsoft Azure AI
  • 发表时间: 2023年5月
  • arXiv: 2305.11846
  • 论文类型: 方法论论文

原文摘要翻译

CoDi 是首个能够从任意输入模态组合生成任意输出模态组合的生成模型。通过可组合的扩散模型架构，CoDi 可以同时处理文本、图像、视频和音频，实现如”文本+图像→视频+音频”的交叉模态生成。

创新点

1. Any-to-Any 生成范式

突破单模态到单模态的限制，支持同步多模态输入和多模态输出。例如从文本+图像生成视频+音频。

2. 可组合扩散架构

通过桥接对齐（Bridging Alignment）和潜在扩散模型将不同模态对齐到共享空间，使模态可以自由组合。

3. 模态交叉生成

首次展示文本+图像→视频+音频等复杂交叉模态生成任务。

一句话总结

CoDi 是首个实现 any-to-any 多模态生成的扩散模型，支持文本/图像/视频/音频的任意组合输入和输出。
