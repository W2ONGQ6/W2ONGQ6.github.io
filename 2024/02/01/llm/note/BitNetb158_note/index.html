The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits

BitNet b1.58: 1比特LLM时代的到来——所有大语言模型本质上都是1.58比特

核心信息

  • 标题: The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits
  • 标题翻译: 1比特LLM时代的到来：所有大语言模型本质上都是1.58比特
  • 作者: Shuming Ma, Hongyu Wang, Lingxiao Ma, Lei Wang, Wenhui Wang, Shaohan Huang, Lifeng Dong, Ruiping Wang, Jilong Xue, Furu Wei
  • 机构: 微软亚洲研究院 (Microsoft Research Asia), 中国科学院

原文摘要翻译

我们提出BitNet b1.58，一种每个参数被限制为三值{-1, 0, 1}的大语言模型。这相当于每个参数1.58比特（$\log_2(3) \approx 1.58$）。BitNet b1.58保留了原始1比特BitNet的所有优势，包括新的计算范式——矩阵乘法仅需整数加减法，几乎不需要乘法运算——同时通过引入显式的零值大幅提升了建模能力。从零开始训练的三元LLM在规模扩展时，其困惑度和零样本任务性能可与全精度LLaMA媲美。具体而言，3B BitNet b1.58在困惑度上匹敌3B LLaMA，在端到端任务上匹敌同等规模的StableLM-3B，而延迟降低2.97倍、内存减少3.87倍。在7B和13B规模上，内存优势继续扩大到4.9倍和5.9倍，能耗降低至原来的1/70以下。我们的结果开创了一个新的缩放定律范式——1比特LLM不仅是可行的，而且在高能效和低成本方面具有变革性潜力。

创新点

1. 三值权重{-1, 0, 1}：每参数1.58位的表示

核心思想: BitNet b1.58的权重不是连续的浮点数，而是约束在三个整数值{-1, 0, 1}之间。$\log_2(3) \approx 1.58$ bits/per weight是这个离散空间的信息容量。推理时，权重存储为2 bits（实际上可以用更紧凑的编码），矩阵乘法简化为：
$$y = \sum_i w_i x_i$$
其中$w_i \in {-1, 0, 1}$，所以每个乘法退化为”加$x_i$”、”减$x_i$”或”跳过（加0）”。这从根本上消除了浮点乘法。

为什么重要: 乘法是现代处理器的能耗大户。FP32乘法约3.7pJ，而INT加法约0.1pJ——差距约37倍。对于LLM推理（几乎全是矩阵乘法），将乘法转化为ADD/SUB/SKIP意味着推理能耗降低数十倍。5nm制程下分析显示，BitNet b1.58的MatMul能耗仅为FP16的1/71.4。

2. 零值的显式建模意义

核心思想: 与原始1比特BitNet（仅{-1, +1}）相比，b1.58引入了显式的零值。零值不仅是表示能力的增强（从2个选项增加到3个），更是引入了显式的特征稀疏性和特征过滤机制。

为什么重要: 从特征学习的角度，权重为0意味着该特征被”过滤掉”——这是一个显式的特征选择操作。原始{-1, +1}无法表示”忽略此特征”，导致了信息表示的瓶颈。1.58位的额外0.58 bits换来了质变的表示能力——这是b1.58优于纯1位BitNet的核心原因。

3. LLaMA兼容架构的从零训练

核心思想: BitNet b1.58不是将现有LLM量化到三值，而是从随机初始化开始，使用LLaMA兼容架构（RMSNorm、SwiGLU激活、旋转位置编码RoPE）直接从零训练三元模型。训练中使用STE（Straight-Through Estimator）处理离散权重的不可微性。

为什么重要: 这从根本上区别于GPTQ/AWQ等后训练量化方法。从零训练的BitNet b1.58是”天生量化”的——网络从初始化阶段就学会了在{-1, 0, 1}空间中表示信息。这不只是压缩，而是一种新的模型范式，类似于稀疏网络或二值网络从零训练的思路，但针对LLM规模做了适配。

4. 定义新的LLM缩放定律

核心思想: BitNet b1.58展示了三值LLM的缩放行为与全精度LLM不同——在较小规模下（<3B）可能与FP16有差距，但随着规模增长，差距缩小甚至消失。这定义了新的帕累托前沿：在延迟-精度和能耗-精度空间上，三值LLM开辟了全新的效率区间。

为什么重要: 传统的LLM缩放定律（Kaplan et al., 2020; Hoffmann et al., 2022）基于浮点计算。BitNet b1.58的新缩放定律意味着：如果目标是高效率部署，最经济的方案可能不是量化已有浮点模型，而是从头训练一个更大的三元模型——用更少的计算和内存代价换取相同的推理质量。

一句话总结

BitNet b1.58通过将LLM的每个权重约束在{-1, 0, 1}（每参数1.58位），将矩阵乘法简化为纯整数加减法和选择性跳过，从零训练的3B三元模型在性能上匹敌全精度LLaMA 3B，同时实现2.97倍加速、3.87倍内存节省和71.4倍MatMul能耗降低，开创了以整数量化为中心的新LLM缩放定律。

研究问题

核心问题

当前LLM的规模增长面临着功耗和硬件成本的指数级增长。量化和稀疏化是对现有浮点模型的”事后修补”——它们从FP16/FP32模型出发，试图在推理阶段减少比特宽度。

BitNet b1.58提出的激进问题是：如果从一开始就抛弃浮点表示，LLM能否在{-1, 0, 1}的离散空间中学到等价的知识？ 这不是压缩问题，而是一个表示学习问题——三值权重网络是否有足够的表示容量来学习语言？

关键难题

  1. 训练不可微性: 离散权重的梯度为0或不存在，无法直接用反向传播
  2. 表示容量: 每参数1.58位是否能编码语言所需的细粒度模式？
  3. 缩放行为: 离散权重网络是否遵循与浮点网络相同的缩放定律？

关键洞察

语言建模的”压缩”本质意味着：成功预测下一个token的关键在于编码模式（patterns）而非存储精确值（exact values）。三值可能足以捕捉模式——额外的精度位数可能主要用于编码噪声而非信号。

数据与任务定义

实验设置

  • 模型规模: 700M, 1.3B, 3B, 7B, 13B参数（部分为推论）
  • 训练数据: 大规模语料（与LLaMA训练设置可比）
  • 架构: LLaMA兼容（RMSNorm, SwiGLU, RoPE, Pre-Norm）
  • 硬件: NVIDIA GPU（训练需模拟量化，推理可原生整数运算）
  • 对比方法: LLaMA（FP16）、StableLM-3B、原始BitNet（{-1, +1}）

评估任务

  • 语言建模: Perplexity
  • 零样本常识推理: 标准7项任务
  • 能耗分析: 基于5nm和7nm制程的芯片级建模
  • 延迟和吞吐量: 理论与模拟

绝对均值量化（AbsMean Quantization）

BitNet b1.58的核心训练机制：

前向传播（将连续权重映射到三值）:
$$\tilde{W} = \text{RoundClip}\left(\frac{W}{\gamma + \epsilon}, -1, 1\right)$$

其中$\gamma = \frac{1}{nm}\sum_{i,j}|W_{i,j}|$是权重矩阵的平均绝对值，$\text{RoundClip}(x, a, b) = \max(a, \min(b, \lfloor x \rceil))$。

反向传播（STE梯度通过）:
$$\frac{\partial L}{\partial W} = \frac{\partial L}{\partial \tilde{W}}$$

即直接将量化权重的梯度复制到连续权重的梯度——忽略量化函数的不可微性。

核心机制

机制流程


Figure 2: 来源—原论文。

步骤1: 权重初始化与缩放

步骤输入: 随机初始化的连续权重$W$（标准正态分布或均匀分布）
步骤操作:

  • 在每次前向传播前，计算$\gamma = \text{mean}(|W|)$（当前层的权重范数估计）
  • 缩放权重：$W_{\text{scaled}} = W / \gamma$，使得缩放后的权重有统一的分布尺度
  • 这样，RoundClip函数可以将权重自然地分散到{-1, 0, 1}上
    步骤输出: 缩放后的连续权重，准备进行三值量化

步骤2: 三值量化与STE前向

步骤输入: $W_{\text{scaled}}$，激活输入$X$
步骤操作:

  • 将每个权重四舍五入到最近的整数并裁剪到[-1, 1]:
    $$\tilde{W}{i,j} = \text{clamp}(\text{round}(W{\text{scaled}, i,j}), -1, 1)$$
  • 得到离散权重$\tilde{W} \in {-1, 0, 1}^{m \times n}$
  • 前向计算：$Y = X \tilde{W}^T$（仅包含加法、减法和跳过操作）
  • 记录$\tilde{W}$用于后续反向传播
    步骤输出: 层输出$Y$，量化权重$\tilde{W}$

步骤3: STE反向传播与零值梯度

步骤输入: 输出梯度$\partial L/\partial Y$，连续权重$W$
步骤操作:

  • STE直接将$\tilde{W}$的梯度复制到$W$：
    $$\frac{\partial L}{\partial W} = \frac{\partial L}{\partial \tilde{W}} \cdot \mathbb{I}_{|\tilde{W}| \leq 1}$$
  • 梯度裁剪：如果$W_{\text{scaled}}$的值超出[-1, 1]（即$\tilde{W}$被裁剪到边界），对应的梯度被置零
  • 权重更新：$W \leftarrow W - \eta \cdot \partial L/\partial W$（常规SGD/Adam更新）
    步骤输出: 更新后的连续权重$W$

步骤4: 推理时的整数乘法

步骤输入: 量化权重$\tilde{W} \in {-1, 0, 1}$，输入激活$X$（可量化为INT8）
步骤操作:

  • 矩阵乘法分解为：
    $$Y_{i,k} = \sum_{j: \tilde{W}{k,j}=1} X{i,j} - \sum_{j: \tilde{W}{k,j}=-1} X{i,j}$$
    零值权重的对应项被跳过
  • 可使用高效的popcount和SIMD指令实现（如在CPU上通过AVX-512的vpternlogd指令）
  • 在专用硬件上，可直接用加法器阵列（无需乘法器）实现
    步骤输出: 层输出（与FP16计算相比无浮点乘法）

深度分析


Figure 5: 来源—原论文。

零值的双重角色

零值在BitNet b1.58中扮演了两个不同但互补的角色：

  1. 特征过滤（Feature Filtering）: 权重为0意味着跳过对应特征，等效于一种软的特征选择。在多轮训练后，网络学会了哪些特征连接是必要的（非零权重）和哪些是冗余的（零权重）。

  2. 稀疏性（Sparsity）: 零值权重天然产生计算稀疏性——对应的乘法-加法操作可以完全跳过。在BitNet b1.58中，训练后的零值比例通常在30-50%之间，这意味着30-50%的乘法可以被跳过（额外加速）。

这种双重角色是b1.58位宽选择（1.58而非2.0或1.0）的精妙之处：刚好引入了零值，但不过度增加表示位宽。

训练中的量化感知机制

BitNet b1.58的训练可以理解为一种强正则化的量化感知训练（QAT）。在每次前向传播中：

  • 连续权重被强制投影到{-1, 0, 1}
  • 反向传播通过STE恢复连续权重
  • 连续权重”记忆”了离散表示之外的细微调整方向

长期来看，连续权重$W$扮演了”蓄水池”角色——它们积累了比离散三值更丰富的梯度信号，在下一轮前向传播中指导新的离散化决策。这类似于最近邻嵌入训练中的”codebook + residuals”模式。

缩放行为分析

论文暗示了一种新的缩放特性：

  • 在较小规模（<3B），三值模型有容量限制（参数数量的信息容量仅为FP16的1/10），与全精度模型的差距存在但不大
  • 随着规模增长，差距缩小——因为FP16模型的额外精度主要用于表示冗余信息而非额外的有效模式
  • 在某个拐点（可能在10-20B），三值模型可能以显著更低的成本实现同等的泛化性能

这与”模型压缩随规模更友好”的观察（GPTQ中的规模降退化现象）一致，但将这一趋势推到了极致的1.58位——比GPTQ的4位激进得多。

硬件设计的范式转变

BitNet b1.58的最大影响可能不在软件而在硬件。当前的GPU和TPU设计围绕FP16/BF16乘法器构建——面积大、功耗高。如果LLM可以用{-1, 0, 1}权重运行：

  • 无需浮点乘法器: 用更小的加法器阵列替代，芯片面积节省50%+
  • 内存带宽需求降低3-6倍: 每权重仅需2位存储
  • 片上缓存效率提升: 更小的权重 = 更大的模型可完全驻留在片上SRAM

这意味着专为三值DNN设计的ASIC可以以消费级芯片的成本和功耗提供数据中心级的LLM推理能力。

局限

1. 完整预训练的成本

BitNet b1.58需要从零训练，训练成本与浮点LLaMA相当（或更高，因为STE训练收敛可能更慢）。对于已有大量FP16 LLM的现状，这不切实际——你需要为每一个模型规模训练一个新的三值版本。

2. 3B以上的实验验证有限

论文中7B和13B的结果来自推论/模拟，而非实际训练。三值训练的收敛性和最终质量在10B+规模上尚未通过实际训练验证。从3B到70B的缩放外推是乐观假设。

3. 训练中的计算模拟

训练过程中，前向传播简化了计算（ADD/SUB 替代 MUL），但反向传播仍需要全精度梯度累积。此外，当前GPU训练时需模拟三值运算（实际的INT加速仅对推理有效），训练加速有限。

4. 精度上限的物理限制

1.58位的表示容量有硬上限：每参数仅能区分3种状态。对于需要细粒度数值精度的任务（如数学计算、精确代码生成），三值表示可能存在最终的性能天花板，即使无限增加模型规模也无法突破。

5. 微调与适配的不确定性

能否在BitNet b1.58基础上进行指令微调（SFT）？能否应用RLHF？微调过程中的分布变化是否会破坏三值权重学到的特征结构？这些都没有在论文中探索。

可复用洞见

1. “表示精度”和”信息精度”是不同的概念

BitNet b1.58最深刻的洞见是：FP16的16位表示精度远超语言建模任务所需的信息精度。自然语言的预测性信息密度可能远低于16位/参数——3个离散值已经能编码大部分有用模式。

如何应用: 在设计表示方案时，区分”数值精度”和”信息精度”。在很多AI任务中，后者远低于前者，存在巨大的压缩空间。

2. 零值是离散表示中的关键维度

从2值（{-1, +1}）到3值（{-1, 0, +1}），增加的1个选项（0）带来了质的飞越。这在数学上意味着$\log_2 3$ bits的信息容量而非$\log_2 2 = 1$ bit——多了58%。这种”小增量、大飞跃”的设计模式——在离散表示中增加一个具有特殊语义的值——值得在其他离散化场景中借鉴。

如何应用: 在设计离散表示时，考虑引入带有特殊语义的额外离散值（如显式的”无连接”、”无贡献”），而非仅增加分辨率。

3. 从训练而非推理侧解决硬件问题

BitNet b1.58的思路是：与其优化硬件以适应模型（添加稀疏矩阵支持、混合精度单元等），不如让模型适应简单的硬件（整数加法器）。这种”简约硬件”的哲学与RISC的设计理念一脉相承。

如何应用: 在AI-硬件协同设计中，优先考虑简化模型的计算范式（如去乘加），使通用简单硬件能以高效率运行，而非为复杂模型设计复杂硬件。

我的笔记

对后续研究的启发

  1. 训练一个真正的大规模BitNet b1.58: 3B只是起点。训练10-70B的三值LLM将是验证该范式的终极测试。

  2. 专用硬件的机会: BitNet b1.58使LLM推理芯片的设计从”如何更高效地做乘法”变为”如何更高效地做加法”。这完全改变了ASIC的设计空间和成本结构。

  3. 与MoE的结合: BitNet b1.58 + Mixture of Experts是天然的组合：三值权重降低了每个expert的存储，使在同样内存预算下容纳更多expert成为可能。

实际应用前景

  • 短期（1-2年）: BitNet b1.58更多是概念验证和研究方向，缺乏足够的规模验证和工程生态
  • 中期（3-5年）: 如果大规模训练验证成功并出现专用推理芯片，可能成为边缘AI的默认LLM范式
  • 长期: “天生量化”的训练范式可能取代”训练+后量化”的现状，尤其当能效成为AI部署的首要考量时

对实践的启示

  1. 如果资源允许，训练3B的BitNet b1.58作为实验平台的可行性已获验证
  2. 不要期待当前的GPU硬件能从BitNet b1.58中获得巨大加速——整数加速需要专门的软件内核
  3. BitNet b1.58的代码和检查点在内存受限场景（手机、嵌入式）中潜力最大

后续问题

1. 70B+规模的实际训练验证

论文中3B的实际训练和7B/13B的推论需要弥合。在大规模训练中，STE估计的梯度偏差是否会累积并影响收敛？三值训练是否需要特殊的优化器或学习率调度？

2. 指令微调与对齐的兼容性

BitNet b1.58的离散表示是否支持SFT/RLHF/DPO等微调方法？微调过程中，连续的”影子权重”和离散的前向权重之间的关系如何演变？

3. 多模态扩展

视觉-语言模型和语音-语言模型需要处理比纯文本更丰富的信号模式。三值权重在视觉编码器中的表现如何？在跨模态注意力中能保持足够的表示能力吗？

4. 训练中的稀疏性演化

零值的比例在训练过程中如何变化？它是单调递增（网络持续发现可过滤的特征）还是收敛到一个稳定比例？能否控制零值比例来主动调节计算稀疏度？

5. 与KV Cache量化的交互

如果权重已经是三值，KV cache的量化策略是否也需要重新考虑？当前KV cache量化的许多策略（如8位/4位cache）是否仍然适用于BitNet b1.58的推理？
