Sora: Creating Video from Text

Sora: 从文本创建视频

1. 一句话总结

Sora 是一个大规模视频生成扩散 Transformer，通过将视频表示为时空补丁（spacetime patches），在多样化时长、分辨率和宽高比的视频数据上进行联合训练，展示了对物理世界运动规律、长期一致性和三维空间理解的涌现能力，将视频生成长度从数秒推升至最长一分钟，标志着视觉生成模型从”帧生成”全面迈入”世界模拟”阶段。

2. 研究背景与动机

2.1 视频生成的核心挑战

在 Sora 之前，视频生成面临几个根本性的技术瓶颈：

  1. 时序一致性：如何在数秒甚至一小时的连续帧之间保持物体、动作、光照的高度一致性？大多数模型只能生成几秒的视频。
  2. 物理规律理解：模型如何理解重力、碰撞、流体运动等物理现象，使生成的视频看起来”真实”而非”荒谬”？
  3. 多样化格式：训练数据中的视频有着不同的分辨率、宽高比和帧率——如何处理这种多样性而不损失信息？
  4. 长程依赖：如何建模跨越几十秒甚至一分钟的因果依赖关系？一个动作在视频开端的影响可能在 30 秒后才展现。

2.2 前 Sora 时代的视频生成

方法 典型时长 主要局限
Video Diffusion Models (VDM) 2-5 秒 固定分辨率，生成质量有限
Make-A-Video (Meta) 5 秒 时序一致性差，高动态场景崩塌
Imagen Video (Google) 5.6 秒 级联模型复杂，无法处理长视频
Video LDM (Stability AI) 3-5 秒 帧数固定，多样性受限于分辨率
AnimateDiff 2-4 秒 基于预训练图像模型的运动模块，物理理解有限

所有先前的方法都在”几秒”时间尺度上挣扎，且视频长度、分辨率和宽高比都受限于固定设定。

2.3 核心研究问题

Sora 试图回答几个根本问题：

  1. 视频能否被表示为”时空补丁”，就像文本可以被表示为 token、图像可以被表示为 patch 一样？
  2. 大规模 Transformer 训练能否让模型涌现出对物理世界的基本理解，而不仅仅是学习表面关联？
  3. 是否可能训练一个统一的视觉模型来处理任意分辨率、宽高比和时长的视频，就像 LLM 可以处理任意长度的文本一样？

3. 方法论

3.1 核心表示：时空补丁（Spacetime Patches）

Sora 最根本的创新在于视频的表示方式。

从文本 Token 到视觉 Patch 的类比：

  • LLM 将文本切分为 token 序列进行训练，token 是不可再分的语义单元
  • ViT（Vision Transformer）将图像切分为 2D patch 序列
  • Sora 将视频切分为 3D 时空补丁序列——每个补丁是视频的一个小立方体（时间x高度x宽度）

补丁化的实现（逐步骤详述）：

Step 1: 视频编码压缩——将原始视频 (T_frames × H × W × 3) 通过训练好的视频压缩网络映射到低维潜空间 (T’ × h × w × c)，压缩率约 4-8x
Step 2: 时空补丁提取——从压缩潜空间中沿时间-空间维度切分 3D 立方体 patch (t_patch × h_patch × w_patch)
Step 3: 序列化——将三维网格展平为 1D 序列 [patch_1, patch_2, …, patch_M]
Step 4: Patch Token 投影——每个补丁通过线性层投影为 Transformer 可处理的 embedding 向量（维度 d）
Step 5: 位置编码——添加可学习的位置编码以保留时空位置信息

为什么这很重要：

  • 补丁化是 Sora 能处理任意分辨率、宽高比和时长的唯一原因。不需要固定输入尺寸——就像 BERT 可以通过 padding 处理不同长度的句子但 Sora 更优雅地不需要 padding。
  • 补丁大小控制着压缩率：更小的补丁保留更多细节但需要处理更多 token；更大的补丁更高效但可能丢失细节。
  • 与 LLM 处理 token 的方式完全一致——这使 Sora 可以直接复用 LLM 的 Transformer 架构和大规模训练经验。

3.2 架构：视频扩散 Transformer

Sora 使用扩散模型 + Transformer 的组合架构：

扩散过程：

  • 前向过程：在潜空间中向干净视频潜变量逐步添加高斯噪声
  • 反向过程：训练一个 DiT（Diffusion Transformer）从噪声中预测干净潜变量
  • 条件机制：通过交叉注意力将文本条件（caption，由 DALL-E 3 风格的描述器生成）注入去噪过程

Transformer 架构设计：

  • 基于 DiT（Peebles & Xie, 2023）的设计哲学：”用 Transformer 替代 U-Net”，基于可扩展性和长程建模能力的考量
  • 与 U-Net 不同，Transformer 可以自然地处理可变长度的输入序列。这对于视频的多样化格式处理至关重要
  • 自注意力层在所有 token（空间上近邻和远距离的 patch token）之间建模关系
  • 交叉注意力层将文本条件的语义信息注入到视觉 token 中

文本条件嵌入：

  • Sora 使用了一个重新描述的文本编码流程：LLM 先将用户简短 prompt 扩展为详细的视频描述，编码后的文本嵌入作为生成条件
  • 这与 DALL-E 3 的做法相似——使用 GPT 重新描述用户的简短 prompt 为更详细的描述

Sora 核心技术堆栈：

3.3 原生多样化训练

Sora 的一个关键设计决策是在原生分辨率和宽高比上训练，而非将所有视频裁剪为统一尺寸。

[!figure] Figure 3: 原生多样化训练 vs 传统固定尺寸训练的对比
建议位置：3.3节之后
放置原因：直观对比传统方法（所有视频裁剪到 256x256 → 信息丢失）和 Sora 方法（保持原生分辨率 → Patch 数量变化 → Transformer 天然适应），解释为什么 Sora 能生成任意宽高比的视频
当前状态：图表占位
图表元素：

  • 左半（传统方法）：三种源视频 (16:9电影, 1:1方形, 9:16竖屏) → 全部裁剪/缩放到 256x256 → 模型学到 “方形世界”
  • 右半（Sora方法）：三种源视频分别保持原生尺寸 → Patchify 得到不同数量的 Patch Tokens (e.g., 480, 256, 240) → Transformer 处理变长序列 → 推断时可生成任意比例
  • 底部标注涌现优势：更好的构图、多样化的输出格式、同一模型支持所有宽高比

传统方法的局限：

  • 将所有视频裁剪/缩放到固定分辨率（如 256x256），丢失了大量视觉信息
  • 宽屏视频（如电影 21:9）和竖屏视频（如手机视频 9:16）被强行压缩
  • 模型学到的”世界”是一个固定尺寸的小窗口

Sora 的多样化训练：

  • 直接使用视频的原生宽高比和分辨率进行训练
  • 由于补丁机制，不同比例的视频产生不同数量的 patch token——Transformer 天然可以处理
  • 这使 Sora 能够：
    • 生成宽屏电影（如 1920x800）
    • 生成竖屏短视频（如 1080x1920）
    • 生成方形视频
    • 在同一模型内处理所有格式

多样化训练的涌现优势：

  • 模型学到了更好的构图原则（宽屏适合风景，竖屏适合人物），因为在训练中看到了各种格式的样本
  • 用户可以在推理时指定目标宽高比，获得最佳构图
  • 这是大语言模型早已做到（任意长度文本）但在视频领域首次实现的能力

3.4 长视频生成的扩展能力

训练时的长视频处理：

  • Sora 可以处理长达一分钟的视频（远超此前模型的 2-5 秒）
  • 具体来说是训练在持续时间不等的视频片段上

推理时的扩展：

  • 通过训练中的多样化时长学习，Sora 可以在推理时生成远长于训练片段的视频
  • 这类似于 LLM 的外推能力——训练在 2048 上下文但推理时可以处理更长的序列

长程一致性：

  • 论文展示了 Sora 能够”记住”视频开头的人物、物体和场景，即使中间经历了视角切换、遮挡或场景变换
  • 例如：一条被咬过的汉堡在一分钟后仍然保持着被咬过的痕迹——展现了持续性物体跟踪能力
  • 这与之前的模型形成鲜明对比，后者在几秒后就会”忘记”并改变物体状态

Sora 在完全没有显式 3D 建模的情况下，展示了对三维空间的理解：

  • 多镜头一致性：当相机围绕场景旋转时，物体保持正确的 3D 位置和遮挡关系
  • 透视投影：远小近大的透视规律被保持
  • 前后景分离：前景物体的运动方式与背景不同，自然地创造了纵深感

这暗示了 Sora 的内部表示中蕴含了某种隐式的 3D 世界模型——不需显式的 NeRF 或三维重建。

4.2 物理交互的模拟

Sora 展示了对多种物理现象的理解：

  • 刚体和软体运动：物体碰撞、下落、弹跳的物理规律基本正确
  • 流体模拟：液体的流动、飞溅、扩散
  • 布料模拟：衣服、窗帘等软材料的自然褶皱和摆动
  • 光影效果：光源变化、阴影、反射的一致性
  • 粒子系统：雪花飘落、尘土飞扬等大规模粒子运动

4.3 物体持久性（Object Permanence）

Sora 最令人印象深刻的涌现能力之一是物体持久性：

  • 当一个物体被暂时遮挡（经过一棵树后面），Sora 在物体重新出现时保持了它的外观和运动状态
  • 当一个角色离开画面后再次出现，其衣着、发型、体态保持一致
  • 视频中”虚拟拍摄”的多镜头切换之间，场景元素保持高度一致

4.4 摄像机运动

Sora 还可以模拟多样的摄像机运动：

  • 推拉镜头（dolly zoom）
  • 平移跟随（tracking shot）
  • 环绕拍摄（orbit shot）
  • 特写到全景的转换

这些镜头语言不是被编程出来的——它们从训练数据中自然学习而来，并可以通过 prompt 引导。

4.5 模拟数字世界

Sora 也能生成数字化、游戏化的场景：

  • Minecraft 风格的体素世界，具有正确的方块物理和游戏逻辑
  • 模型在生成 Minecraft 视频时，甚至展现了对玩家视角移动、方块颜色一致性、HUD 元素等的理解
  • 这表明 Sora 不仅可以模拟物理世界，也可以模拟规则定义的人造世界

5.2 训练规模效应

与 LLM 类似，Sora 展示了强烈的规模效应：

  • 随着训练计算的增加，视频质量、时序一致性和物理理解能力持续提升
  • 没有任何饱和的迹象——更多的计算 = 更好的视频 = 更强的涌现能力
  • 这暗示着视频生成可能也遵循类似语言模型的缩放定律

5.3 图像生成能力

由于视频可视为一系列连续的图像帧，Sora 也具备图像生成能力：

  • 通过仅使用一帧（时间维度上的单个 “frame” patch），Sora 可以生成高质量的单张图像
  • 生成的图像展现了多物体组合、复杂场景构造能力
  • 支持图像编辑、图像扩展（outpainting）、图像插值等任务

5.4 视频编辑能力

Sora 支持多种视频编辑任务：

  • 时间插值：在两个给定的关键帧之间生成平滑的过渡动画
  • 前向/后向扩展：给定初始几帧，向前或向后继续生成视频
  • 风格迁移：通过文本引导改变视频风格
  • 主题保持：在编辑中保持人物或物体的外观一致性

7. 创新点与贡献

7.1 核心创新

  1. 时空补丁表示：将视频统一表示为 3D 补丁序列，使得视频可以像语言一样被 Transformer 建模。这是 Sora 架构哲学中最根本的创新。

  2. 原生多样化训练：首次在视频生成中实现原生分辨率/宽高比训练，突破了此前所有模型的固定尺寸限制。

  3. 大规模涌现的物理理解：证明了纯数据驱动的 Transformer 可以达到对三维空间、物理交互、物体持久性的基本理解——无需显式的物理引擎、3D 几何建模或世界模型。

  4. 一分钟长视频：将视频生成的实用长度从 2-5 秒推升到 1 分钟，跨越了一个数量级。这不仅要求更好的生成质量，更要求模型有实际的”记忆”和时序推理能力。

  5. 统一框架：Sora 的架构同时支持视频生成、图像生成、视频编辑、时间插值等多种任务，无需为每种任务设计专门模型。

7.2 对 AI 研究的深远影响

  1. 世界模拟器的可能性：Sora 证明了当前的深度学习方法可以通过足够的数据和计算来学习世界运行的规律（物理、空间、持久性），而不仅仅是表面的视觉模式。

  2. 视觉模型的”GPT 时刻”：Sora 之于视频的意义类似于 GPT 之于文本——一个足够大的通用架构 + 足够多的数据 + 足够强的计算 = 涌现出远超预期的能力。

  3. 从生成到理解：Sora 的 3D 空间理解和物理模拟能力暗示，生成能力可能是理解能力的副产品——模型为了更好地生成而学会了更深入地理解世界。

8. 局限性与后续工作

8.1 已知局限（论文中承认）

  1. 因果逻辑错误：Sora 有时会生成物理上不合理的场景。例如一个人跑步的画面中，脚下的地面纹理会反向移动。或者杯子掉落时摔碎后重新愈合。

  2. 复杂物理交互：在复杂的多物体交互场景（如碰撞后碎片轨迹、多个角色互相推搡）中，物理一致性容易崩塌。

  3. 左右方向混淆：模型对空间方向的判断（如左右区分）有时出错——这暴露了缺乏真实 3D 理解。

  4. 长视频一致性退化：虽然 1 分钟远超此前方法，但在接近 1 分钟的时间尺度上，场景元素仍然可能出现不一致（如一件衣服的颜色突然变化）。

  5. 计算成本高：训练和推理都需要巨大的计算资源，目前不是面向普通用户的实用产品。

  6. 生成内容的可控性有限：虽然文本控制有效，但对镜头运动的精确控制、对特定物体运动的约束等仍然困难。

8.2 未公开的细节

Sora 的技术报告没有公开以下关键细节：

  • 模型的具体参数量和架构规格
  • 训练数据的确切规模和来源
  • 训练计算量
  • 视频编码器和解码器的设计
  • 推理时的具体采样策略

这使得外部研究者无法完全复现或验证该方法。

10. 对世界模型的深远启示

Sora 最深刻的意义不在于视频生成本身，而在于它对构建 AI 世界模型 的启示：

  1. “学习物理”不需要物理引擎：足够的数据和 Transformer 可以从观测数据中隐式学习物理规律。这与神经科学中”大脑通过观测学习世界规律”的理念一致。

  2. 生成 = 理解的路径：通过学会”生成逼真的视频”，模型被迫学习世界的底层结构和规律。好生成是好理解的副产品。

  3. 尺度是一切：Sora 的涌现能力强烈依赖于训练规模。小规模模型的视频生成仅仅是像素预测，但大规模模型的视频生成变成了世界模拟。

  4. 通用架构的价值：Sora 使用了与 LLM 相同的 Transformer 架构核心（尽管在扩散框架中），验证了”统一的通用架构可以处理跨模态数据”的思想。

11. 实现建议与技巧

11.1 架构设计原则

  • 补丁化是核心：将视频视为时空补丁序列，避免对特定分辨率和时长的依赖
  • Transformer 优于 U-Net 用于长程建模：当视频时长增加时，Transformer 的自注意力机制天然适合建模全局依赖
  • 原生多样化训练：不要强行裁剪视频到统一尺寸——让模型从数据的天然多样性中学习
  • 重新描述文本：使用强力的 LLM 将简短 prompt 扩展为详细描述，这显著提升了文本条件的语义质量

11.2 训练策略

  • 优先使用大规模视频数据 + 足够的计算
  • 训练数据的多样性（场景类型、摄像机运动、视频长度）比数据数量更重要
  • 长视频训练数据不需要连续的长片段——训练在间隔不等的视频片段上也可以支撑外推
