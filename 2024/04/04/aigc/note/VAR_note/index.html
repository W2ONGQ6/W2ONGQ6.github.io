Visual Autoregressive Modeling: Scalable Image Generation via Next-Scale Prediction

VAR: 通过下一尺度预测实现可扩展的图像生成

核心信息

  • 标题: Visual Autoregressive Modeling: Scalable Image Generation via Next-Scale Prediction
  • 标题翻译: 视觉自回归建模：通过下一尺度预测实现可扩展的图像生成
  • 作者: Keyu Tian, Yi Jiang, Zehuan Yuan, Bingyue Peng, Liwei Wang
  • 机构: Peking University / ByteDance
  • 发表时间: 2024 年 4 月
  • 发表渠道: NeurIPS 2024 (Best Paper Award)
  • arXiv: 2404.02905
  • 论文链接: https://arxiv.org/abs/2404.02905
  • 代码 / 项目: https://github.com/FoundationVision/VAR
  • 论文类型: 图像生成模型（自回归 + 多尺度）

原文摘要翻译

传统的自回归模型将图像标记化为 2D 网格，并采用光栅扫描顺序的”下一标记预测”范式进行生成。我们发现这种光栅扫描预测范式在视觉生成中存在根本性缺陷。本文提出了视觉自回归建模（VAR），将图像的自回归学习重新定义为”下一尺度预测”：编码器将图像量化为多尺度标记图，自回归过程从 1x1 标记图开始，逐尺度扩展分辨率。在 ImageNet 256x256 基准上，VAR 显著改进了自回归基线，FID 从 18.65 降至 1.73，Inception Score 达 350.2，推理速度提升约 20 倍。VAR 展现出清晰的幂律缩放规律——测试损失与模型规模线性相关（相关系数 -0.998）。VAR 进一步展示了图像修补、外推和编辑等零样本任务泛化能力。这些结果表明 VAR 初步统一了自回归模型与扩散模型各自的优势。

创新点

1. “下一尺度预测”替代”下一 token 预测”

核心思想: 颠覆传统自回归模型的”逐像素/逐 token 光栅扫描”生成范式。取而代之，VAR 按”从粗到细”的多尺度顺序生成——先预测 1x1 的全局结构 token 图，然后 2x2，4x4，8x8……逐级上采样。每个尺度上的所有 token 并行生成，不同尺度之间自回归。

为什么重要: 这是自回归模型在图像生成领域自 DALL-E 以来最重要的概念突破。光栅扫描顺序（从左到右、从上到下）是人造的计算便利而非自然的视觉组织方式。VAR 的下一尺度预测符合人类视觉感知的自然逻辑——先看到大局，再看细节。更重要的是，它从根本上解决了光栅扫描自回归的三个本质缺陷：(1) 计算效率低（逐 token 串行）；(2) 数学结构不符合图像的空间特性；(3) 无法形成清晰的 scaling law。

2. 自回归模型首次超越扩散模型 (DiT)

核心思想: 在 ImageNet 256x256 基准上，VAR 以 FID 1.73 全面超越当时最先进的扩散 Transformer（DiT）。这是自 DALL-E 转向扩散模型以来，自回归方法首次在主流图像生成基准上击败扩散模型。

为什么重要: 自 2022 年以来，扩散模型在图像生成领域几乎建立了绝对统治。VAR 证明了：自回归模型在图像生成上的劣势并非范式固有——而是此前”逐 token 顺序生成”这一错误的任务定义的副产品。这为视觉生成研究重新开启了”自回归 vs 扩散”的竞争路线，意义深远。

3. 清晰的幂律 Scaling Law

核心思想: VAR 呈现出类似 LLM 的幂律缩放规律——测试损失与模型规模之间呈高度线性相关（皮尔逊相关系数接近 -0.998）。这意味着更大模型能带来可预测的性能提升。

为什么重要: 这是自回归范式在图像生成中至今最强有力的论证。scaling law 不仅是”更好”的保证，更是”可预测地更好”的承诺——在模型设计和资源分配中具有实际的指导价值。对比之下，扩散模型虽然也有 scaling law 但不如 VAR 清晰和稳定。

4. 多尺度 VQ-VAE 标记化

核心思想: 将图像编码为金字塔形的多分辨率离散 token 图——从 1x1（一个 token 表示全局信息）到 KxK（大量 token 表示最高频细节）。每个尺度上的 token 来自一个共享的码本。

为什么重要: 多尺度编码自动实现了信息的层级分化——粗尺度 token 编码全局结构（整体布局、大致颜色），细尺度 token 编码局部细节（纹理、边缘）。这为”下一尺度预测”提供了自然的训练信号和生成目标。

5. 20 倍推理加速

核心思想: 相比传统的逐 token 自回归（需要生成 N 个 token 的 N 步），VAR 只需生成 K 个尺度（K << N），且每个尺度内所有 token 并行生成。在 ImageNet 256x256 上实现了约 20 倍的推理加速。

为什么重要: 自回归模型最大的实践缺陷（慢）被大幅缓解。VAR 在保持自回归建模灵活性的同时，将推理速度提升到了与扩散模型可比的水平。

一句话总结

VAR 通过将图像自回归从”下一 token 预测”重新定义为”下一尺度预测”，首次证明纯自回归模型在图像生成质量（FID 1.73）、推理速度（20x 加速）和可扩展性（scaling law）上全面超越扩散 Transformer，为视觉生成开辟了自回归文艺复兴的新路线。

研究问题

核心挑战

传统自回归模型在图像生成中面临三个根本性缺陷：

  1. 数学结构不当: 图像是 2D 结构，光栅扫描把 2D 信息折叠成 1D 序列——破坏了空间邻接关系和拓扑结构
  2. 计算效率低下: N 个 token 需要 N 步串行生成（N=256 对于 16x16 token 网格），而扩散模型只需固定数量的去噪步
  3. Scaling Law 缺失: 光栅扫描自回归在图像上没有展现出类似 LLM 的稳定 scaling law——增加参数量后性能提升不可预测

关键洞察

图像的结构是层次的而非序列的。从全局结构到局部细节的从粗到细的生成顺序，比从左到右的光栅扫描顺序，更符合视觉信息的自然组织规律。

整体架构

VAR 的核心循环：

  1. 多尺度 VQ-VAE 将图像编码为 K 个尺度的 token 图
  2. GPT 风格的 Transformer 以自回归方式预测下一尺度的所有 token
  3. 从 1x1 开始，生成 2x2、4x4…直到最终分辨率

机制流程


Figure 2: 来源—原论文。

步骤 1: 多尺度 VQ-VAE 编码

步骤输入: RGB 图像 X（H x W x 3）
步骤操作:

  • 编码器生成多尺度特征：f_1 (低分辨率), f_2, …, f_K（原始分辨率）
  • 在每个尺度上，通过码本查询将连续特征量化为离散 token
  • Token 图 r_k 的分辨率为 h_k x w_k，尺度 k 从 1 到 K 递增
  • 例：K=5 时，r_1=1x1, r_2=2x2, r_3=4x4, r_4=8x8, r_5=16x16
  • 共享码本 V=[v_1,…,v_4096]，所有尺度使用同一码本
    步骤输出: K 个尺度的离散 token 图，共 N=sum(h_k * w_k) 个 token

步骤 2: 自回归 Transformer 训练（下一尺度预测）

步骤输入: 前 k-1 个尺度的 token 序列 [r_1, r_2, …, r_{k-1}] + 条件信号
步骤操作:

  • 将前 k-1 个尺度的所有 token 展开为序列
  • 添加尺度嵌入和位置嵌入
  • Transformer 处理序列，输出每个位置的预测分布
  • 训练目标：预测尺度 k 的所有 token——p(r_k | r_1, r_2, …, r_{k-1})
  • 损失函数：交叉熵（所有尺度 k token 的负对数似然之和）
    步骤输出: 训练好的自回归 Transformer
    步骤训练目标: L = -E[sum_k sum_i log p(r_{k,i} | r_{<k})]

步骤 3: 推理生成

步骤输入: 条件信号（类别标签或文本）+ 起始 token
步骤操作:

  • k = 1：从起始 token 开始，生成 1x1 的全局 token 图（1 个 token）
  • k = 2：基于 1x1 token 图，生成 2x2 token 图（4 个 token，并行预测）
  • k = 3：基于 1x1+2x2，生成 4x4 token 图（16 个 token，并行预测）
  • …继续直到最终尺度
  • 每个尺度内的所有 token 通过一次前向传播并行生成
    步骤输出: K 个尺度的 token 图，VQ-VAE 解码器重建图像

与光栅扫描自回归的本质区别

维度 光栅扫描自回归 VAR（下一尺度预测）
生成顺序 1D 线性（左->右，上->下） 2D 层级（粗->细）
每步步长 1 个 token 整个尺度的所有 token
总步数 N（如 256 步） K（如 5-10 步）
全局一致性 弱（逐 token 没有全局视野） 强（每个尺度看到所有粗尺度信息）
局部一致性 强（相邻 token 在生成顺序上也相邻） 中（尺度边界可能不连续）
并行度 0（纯串行） 高（尺度内全并行）

多尺度 VQ-VAE 的层级信息分化

VAR 的多尺度编码自然地迫使信息按粒度分化：

  • 1x1 尺度: 全局布局——Sky+Ground 的大致比例、主色调
  • 2x2 尺度: 基本分区——天空/地面/物体的粗略边界
  • 4x4 尺度: 物体形状——猫的轮廓、桌子的位置
  • 8x8 尺度: 语义细节——猫的耳朵、眼睛位置
  • 16x16 尺度: 纹理细节——毛发的纹理、光影变化

这种自然分化使得”下一尺度预测”的任务清晰且梯度信号良好。

深度分析


Figure 5: 来源—原论文。

为什么”下一尺度预测”比”光栅扫描”更合理

光栅扫描自回归的根本问题不是”自回归范式不好”，而是”1D 顺序不适合 2D 数据”：

  1. 因果关系的错误假设: 光栅扫描假设 token_{i, j} 天然依赖于 token_{<i, <j}（所有上方和左边的 token）。但实际上，token 的视觉依赖是 2D 对称的——一个像素对上下左右邻居的依赖是平等的。

  2. 信息缺口问题: 光栅扫描下，生成 token_{i, j} 时，右侧和下方的 token 不存在——但对左侧上方 token 的上下文理解严重不完整。

  3. 全局一致性的丧失: 逐 token 生成没有全局规划——第一个 token 不可能知道整张图会变成什么样子。而 VAR 的 1x1 尺度直接决定了全局结构。

Scaling Law 为什么能在 VAR 上出现而在光栅扫描上不出现

这是一个重要的理论问题。可能的解释：

  1. 任务粒度的均匀性: 下一尺度预测的每个预测任务难度相对均匀——都是从低分辨率到高分辨率的”上采样”。而光栅扫描下，生成第 1 个 token 和生成第 256 个 token 的难度和信息量差异巨大。

  2. 梯度的可预测性: VAR 的损失曲线在每个尺度上都是平滑的，因为每个尺度的预测误差与模型容量之间存在稳定的单调关系。

  3. 信息结构的层级性: 视觉世界天然是层级的，而 VAR 完美匹配了这一特性。

VAR 的”伪自回归”争议

一种批评是 VAR 不是”真正的自回归模型”——因为它在每个尺度内使用并行的双向注意力，只有跨尺度才是自回归的。但这恰恰是 VAR 的智慧：

  • 尺度内并行 = 承认图像 tokens 在同等尺度上没有天然的因果顺序
  • 尺度间自回归 = 承认从粗到细存在天然的因果依赖

VAR 可以被视为”块级自回归”（block-wise autoregression）——每个尺度是一个块。

VAR 的独特优势

VAR 相比扩散模型有几个自回归范式的天然优势：

  1. 似然可计算: 可以准确计算每张图像的似然值（NLL），这对 OOD 检测、异常检测等任务很重要
  2. 灵活的任务适配: 自回归模型天然适合补全、编辑等条件生成任务——只需修改 prefix
  3. 与 LLM 的统一: VAR 可以与 LLM 共享基础架构和基础设施，为多模态统一模型提供道路

局限

1. 高分辨率下的尺度增长

问题: 当目标分辨率很高时（如 1024x1024），需要的尺度数量为 K=log2(1024) ≈ 10，但最高尺度（32x32 token 图=1024 token）突然变得非常大。最后一个尺度的并行生成可能成为瓶颈。

影响: 在极高分辨率下，VAR 的计算效率可能下降。

2. 多尺度 VQ-VAE 的质量瓶颈

问题: 最终生成质量受限于 VQ-VAE 的解码质量。如果 VQ-VAE 有 artifacts（模糊、颜色偏移），VAR 无法修复。

影响: 在面部、文字等精密细节任务上可能不如像素空间的扩散模型。

3. 类别条件到文本条件的迁移

问题: 论文主要验证了类别条件生成（ImageNet）。从 1000 个类到自然语言 prompt 是一个巨大的跳跃——文本的语义空间远大于类别标签。

影响: 文生图场景下的性能尚未在大规模上进行充分验证。

4. 与扩散模型生态的兼容性

问题: ControlNet、IP-Adapter、DreamBooth 等数以千计的社区工具都是为扩散模型设计的。VAR 需要从头建立控制基础设施。

影响: 短期内，VAR 无法享受到扩散模型积累的社区生态红利。

5. 采样多样性的上限

问题: 自回归生成天然倾向于”确定”的生成（高概率路径），多样性不如扩散模型在噪声空间中自由探索。

影响: 在需要高度多样化输出的创意场景中可能不够好。

可复用洞见

1. 任务定义的改变可以颠覆范式优劣

洞见: 自回归 vs 扩散的比较不是范式本身的优劣——而是任务定义（逐 token 预测 vs 去噪）的优劣。通过重新定义”自回归预测什么”（下一尺度而非下一 token），VAR 让自回归范式在图像生成上重新赢得了竞争力。

后续应用: 任何任务都可以通过重新定义”基本预测单元”来改变范式优劣。

2. 视觉信息的多尺度层级结构

洞见: 图像的信息天然是按尺度组织——全局结构 -> 物体形状 -> 细节纹理。与这一自然结构对齐的生成范式，会自然获得更好的效率和缩放特性。

后续应用: 视频生成中，Temporal Hierarchy（帧级 -> 片段级 -> 场景级）可能是类似的多尺度结构。

3. Scaling Law 验证 = 范式合法性的最强论证

洞见: 一个生成范式的优劣，最终判定标准不是某个基准上的数字，而是是否有清晰的 scaling law——因为 scaling law 意味着可预测的进步，从而意味着可投资。

后续应用: 任何新生成范式都应尽早验证 scaling law。

我的笔记

VAR 的 NeurIPS 2024 Best Paper 的意义

VAR 获得 NeurIPS 2024 最佳论文奖，与 SD3 获得 ICML 2024 最佳论文奖形成了有趣的对称——SD3 证明扩散模型可以有 Transformer + Scaling Law，VAR 证明自回归模型也可以（而且更清晰）。这标志着视觉生成领域进入了”两条腿走路”的新阶段。

自回归的”正确做法”

VAR 最深刻的地方不是它击败了 DiT，而是它揭示了一个基本事实：自回归在图像生成上一直”走错了路”。光栅扫描顺序是人类为了方便而人为定义的，没有任何视觉科学依据。VAR 的下一尺度预测则与人类的视觉感知系统（从全局到细节）天然对齐。

多模态统一的未来

VAR 的范式（自回归尺度预测）为”视觉+语言”的统一模型提供了一个新的可能——在同一个 Transformer 中，文本按 token 自回归，图像按尺度自回归。两者的接口（自回归预测下一个单元）是一致的，只是单元的定义不同。

后续问题

1. 与 LLM 的多模态融合

问题: VAR 的尺度自回归能否与 LLM 的 token 自回归在同一个 Transformer 中无缝运行？如果是，这对多模态大模型意味着什么？

2. 视频生成中的下一尺度预测

问题: 视频的三维结构（空间+时间）是否也适合”下一尺度预测”？如果可以，VAR for Video 会是什么样子？

3. 自回归与扩散的融合

问题: 是否存在一种统一的生成框架——结合自回归的结构化优势与扩散的多样性优势？
