Quiet-STaR: Language Models Can Teach Themselves to Think Before Speaking

核心信息

  • 标题: Quiet-STaR: Language Models Can Teach Themselves to Think Before Speaking
  • 标题翻译: 静默STaR：语言模型可以自学在说话前思考
  • 作者: Eric Zelikman, Georges Harik, Yijia Shao, Varuna Jayasiri, Nick Haber, Noah D. Goodman
  • 机构: Stanford University, NotBadAI
  • 发表时间: 2024年3月
  • arXiv: 2403.09629
  • 论文链接: https://arxiv.org/abs/2403.09629
  • 论文类型: 方法论论文

原文摘要翻译

在撰写和交谈时，人们有时会在说话前停下来思考。虽然以推理为重点的工作在推理时引入了内化推理机制，但这些方法通常是在一组狭隘且特定的任务上进行训练的，未能推广到一般推理。我们提出了 Quiet-STaR，它是 Self-Taught Reasoner (STaR) 的推广版本。Quiet-STaR 让语言模型学会在每个 token 处生成内部”思考”（rationale）来解释未来的文本，从而提高其预测能力。这解决了 STaR 的三个关键挑战：计算成本（通过并行生成）、LM 最初不知道如何”思考”（通过基于 REINFORCE 的优化）、以及 LM 需要预测超出单个 token 的文本（通过多 token 预测目标）。在直接应用于预训练 Mistral 7B 后，Quiet-STaR 在 GSM8K 上提升了 4.9% 到 10.9%，在 CommonsenseQA 上提升了 5.3% 到 6.8%，且无需在特定任务上微调。

创新点

1. 通用的隐式推理学习

STaR 只能在特定任务（如数学）上通过微调学习推理，而 Quiet-STaR 使 LM 能从任意文本语料中自主学习推理能力——在每个 token 处生成隐式思考（rationale）帮助预测后续文本。这使得推理学习与预训练分布一致，推动了通用推理能力的涌现。

2. 并行 rationales 生成

为降低计算开销，Quiet-STaR 并行生成所有 token 位置的 rationales，用特殊 token 标记思考的开始和结束，使 LM 在思考时”看到”自己生成的思考内容。

3. REINFORCE 优化非可微目标

使用 REINFORCE 算法优化 rationales 对后续 token 预测的改进，解决”如何让 LM 学会有用思考”的信用分配问题。设计了混合奖励头（mixing head）来动态权衡有思考和没思考时的预测。

一句话总结

Quiet-STaR 是首个让 LLM 从任意文本中自主学习通用隐式推理的方法，通过在每个 token 处并行生成内化思考并用 REINFORCE 优化，使 Mistral 7B 在数学和常识推理上零样本提升 5-11%。

方法主线

机制流程

  1. 并行思考生成: 对输入序列的每个位置，并行生成内部 rationales（用 <|startthought|> 和 <|endthought|> 包裹）
  2. 混合预测: 对每个位置的下一 token 预测，混合两种情况：看了 rationales 的预测和没看 rationales 的预测
  3. REINFORCE 优化: 基于 rationales 对后文预测的改善程度给予奖励，用策略梯度优化 rationales 的生成
  4. 教师强制: 生成 rationales 时，除当前位置外其余使用真实文本，确保思考”有帮助”

关键技术

  • 并行 token 生成: 使用特殊注意力掩码使所有位置的 rationales 并行生成，大幅降低训练时间
  • 混合头（mixing head）: 学习权重 $w$ 动态平衡有/无思考预测，在不需要推理时自动降低思考影响
  • 非短视损失: 优化 rationales 对未来多个 token 的预测帮助，而不仅是下一个 token

核心实验

  • Mistral 7B 零样本 GSM8K: 从 13.8% 提升到 24.7% (+10.9%)
  • Mistral 7B 零样本 CommonsenseQA: 提升 5.3-6.8%
  • 训练使用 OpenWebMath + C4 的混合数据
  • 消融实验证明并行生成和 REINFORCE 优化都是关键组件

局限性与批判

  • 训练仍然需要大量计算（多 GPU 多日）
  • 提升幅度相对有限（5-11%），尚未达到专门推理训练（如 DeepSeek-R1）的水平
  • 内化推理的可解释性有限——模型思考了什么不容易理解
  • 仅在 7B 规模验证，更大模型的 scaling behavior 未知

关键要点

  • 通用隐式推理：LM 可在任意文本上学习”先思考再说”，无需特定任务数据
  • 并行化是关键：使内部推理的训练在实际计算预算下可行
  • 为 o1/R1 类的”推理时思考”提供了预训练阶段的训练方法
