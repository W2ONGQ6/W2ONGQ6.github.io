Transformers are SSMs (Mamba-2): Structured State Space Duality

date: 2024-05-15

Mamba-2: Transformers are SSMs

核心信息

  • 标题: Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality
  • 作者: Tri Dao (Together AI / Princeton), Albert Gu (CMU)
  • 发表: ICML 2024
  • 核心贡献: 通过 Structured State Space Duality (SSD) 证明了 SSM 与线性 Attention 在数学上等价——两者是同一结构化半可分矩阵的两种计算视角
  • 计算创新: Mamba-2 利用矩阵形式（标准 GEMM）进行训练，递归形式（O(1) 内存）进行推理——比 Mamba-1 快 2-8 倍
  • 架构建议: 混合架构（10-20% attention + 80-90% Mamba-2）超越纯 Transformer 和纯 Mamba，是新一代模型的最优设计
  • 统一范围: 将 Mamba(S6)、GLA、RetNet、RWKV、线性 Attention、S4/H3 统一到 SSD 框架

原文摘要翻译

我们证明了 Transformer 的 attention 机制与 state space models (SSMs) 之间存在深刻的数学对偶性。通过 Structured State Space Duality (SSD)，我们将 SSM 表述为结构化半可分矩阵上的变换——递归形式和相关因果注意力是同一底层计算的两个视角。基于此框架设计的 Mamba-2 比 Mamba-1 快 2-8 倍，同时保持了与 Transformer 竞争的性能。状态维度从 Mamba-1 的 16 扩展到 256，在不牺牲训练速度的情况下显著提升了”记忆”容量。混合架构（部分 attention 层 + 部分 Mamba-2 SSM 层）超越了纯 Transformer 或纯 Mamba 架构，为下一代序列模型提供了清晰的设计方向。

创新点

  1. SSD 统一框架 — “统一场论”级别贡献。 证明 SSM 的递归形式（h_t = A_t h_{t-1} + B_t x_t; y_t = C_t h_t）和线性 Attention 的矩阵形式（y = mask(M) X, 其中 M 是结构化半可分矩阵）在数学上等价。这一等价性建立了 Transformer 和 SSM 两个独立发展的研究社区的桥梁——不是取代彼此，而是同一底层结构的双重视角。

  2. 状态维度从 16 到 256 的解放。 Mamba-1 受限于并行扫描算法的效率，d_state 仅能设为 16。Mamba-2 通过矩阵形式训练（不受状态维度大小限制）将 d_state 扩展到 256——16 倍的记忆容量提升，在长程依赖和精确 token 回忆上产生质的改善。

  3. 训练/推理双路径计算策略。 训练时使用矩阵 GEMM 形式（享受 cuBLAS TensorCores 的极致效率），推理时回归递归形式（享受 O(1) 内存和线性时间）。解决了 Mamba-1 需要自定义并行扫描 kernel 的痛点——现在可直接利用 FlashAttention-2 的成熟基础设施。

  4. 混合架构的实证发现。 10-20% attention 层 + 80-90% Mamba-2 SSM 层的混合架构，在 PPL 上超越纯 Transformer 和纯 Mamba，在推理速度上接近纯 Mamba。说明 attention 和 SSM 是互补的工具——attention 擅长精确 token 匹配，SSM 擅长长程压缩。

  5. 理论统一的工程赋能。 SSD 不仅是理论优雅——它直接使 Mamba-2 的工程实现比 Mamba-1 快 2-8 倍。这是”好的理论产生好的工程”的典范——统一的理解使得可以选择最优的计算策略（而不是受限于单一的计算路径）。

一句话总结

SSD 证明了 SSM 和线性 Attention 在数学上是等价的——终结了”Transformer vs SSM”的范式之争，开启了”attention + SSM 互补混合”的架构黄金时代，Mamba-2 比 Mamba-1 快 2-8 倍的工程突破正是这种数学统一的直接产物。

研究问题

核心挑战与子问题

子问题1：SSM 和 Attention 本质联系的严格数学证明。

两个领域发展了不同的数学语言：SSM 使用连续时间微分方程（dx/dt = Ax + Bu; y = Cx + Du → 离散化 → h_t = A h_{t-1} + B x_t; y_t = C h_t）。Attention 使用矩阵乘法和 softmax（O = softmax(QK^T/√d)V）。两者看似没有任何联系。

SSD 的桥梁：SSM 递归展开后可以表示为 y = M x，其中 M 是一个下三角矩阵，每个元素 M_{t,j} = C_t (A_t … A_{j+1}) B_j。这个 M 矩阵具有特殊的数学属性——它是”结构化半可分矩阵” (structured semiseparable matrix)。

半可分矩阵的定义：非对角元素 M_{t,j}（t > j）可以分解为秩 1 矩阵的乘积。A 矩阵的连乘结构（A_t … A_{j+1}）确保了每对（t,j）的非对角元素恰是秩 1 的——满足半可分性的定义。”结构化”指的是秩 1 分解遵循特定的参数化模式（如对角线 A 或三角 A）。

Attention 的角度：线性 Attention（无 softmax）的计算 y = (QK^T ⊙ mask) V 也可以写成 y = M V，其中 M = QK^T ⊙ causal_mask 也是一个下三角矩阵——它的非对角元素 M_{t,j} = q_t^T k_j 同样是秩 1 的（因为两个向量的点积是秩 1 因子分解）。

因此：任何 SSM 可以表达为结构化的（因果 + 半可分）线性 Attention，反之任何满足因果半可分的线性 Attention 也可以解释为 SSM。这是严格的数学等价，而非近似。

子问题2：d_state 从 16 到 256 的意义是什么？

Mamba-1 的状态维度 d_state = 16。在注意力术语中，这意味着模型用 16 维的向量来”压缩总结”所有历史信息——每个 token 只能用 16 个数字来编码整个过去的上下文。对于隐藏维度 2048 的模型：压缩比 = 2048/16 = 128:1——这是极端的压缩。

Mamba-2 将 d_state 扩展到 256。压缩比变为 2048/256 = 8:1——从”极度压缩”变为”合理压缩”。这对需要精确回忆远距离 token 的任务（代码补全中精确复制变量名、长文档中引用前面段落的特定表述）至关重要——256 维的记忆足够区分和保留许多不同的过去 token。

为什么 Mamba-1 被限制在 16？并行扫描算法的计算复杂度与 d_state 不是完全独立的——更大的 d_state 在扫描 kernel 中导致更大的内存移动和 tensor core 利用率下降。Mamba-2 的矩阵形式完全绕过了这个限制——在 GEMM 中，更大的 d_state 仅意味着更宽的矩阵乘法（在 K^T V 的累积中），这在 TensorCores 上仍然高效。

子问题3：矩阵训练 vs 递归推理——能否兼得两者的优势？

Mamba-1 使用并行扫描进行训练——这种算法在概念上高效（O(N log N)），但在 GPU 上的实际实现（自定义 CUDA kernel）无法达到 TensorCore GEMM 的极致效率（因为扫描需要串行传递 scan results，限制了并行度和 tensor core 利用）。

Mamba-2 使用矩阵乘法的训练：将 A、B、C 展开为结构化掩码矩阵 M，然后 y = M × X（标准的 masked GEMM）。这可以直接利用 FlashAttention-2 的成熟 I/O-aware 实现（block tiling、shared memory 优化、TensorCore GEMM），而不需要维护独立的扫描 kernel。

推理时，Mamba-2 仍然使用递归形式：h_t = A_t h_{t-1} + B_t x_t, y_t = C_t h_t——每 token O(1) 时间、O(1) 内存（无 KV cache）。这是一种完美的计算路径切换——训练追求并行效率（选矩阵），推理追求内存效率（选递归）。

子问题4：混合架构为什么优于纯架构？

SSD 的直接推论：attention 和 SSM 不是竞争关系，而是同一底层计算的不同实例。不同的实例适用于不同的子任务：

  • Attention (softmax)：精确 token 匹配、局部窗口内的细粒度注意力——类似于”精准打击”
  • SSM (Mamba-2)：长程上下文压缩、连续序列建模、全局依赖——类似于”大面积覆盖”

在一个 Transformer 层中，”与之前出现的类似 token 建立精确关联”是 attention 的强项（通过 softmax 的 sharp weighting）。”将过去 4000 tokens 的整体语境浓缩到当前 token 的可用表示中”是 SSM 的强项（通过递归状态 S_t 的连续更新）。

实验发现的最优比例：10-20% attention 层 + 80-90% Mamba-2 层。太多 attention 层浪费了长程压缩的效率，太少 attention 层丢失了对关键 token 的精确关注能力。

子问题5：SSD 统一框架的副产品——用 Attention 社区的知识丰富 SSM 研究，反之亦然。

SSD 证明了两个独立发展的研究社区实际上在研究同一个底层对象的不同方面。这意味着：

  • Attention 社区开发的许多”高效 attention”变体（Performer, Reformer, Linear Transformer 等）在 SSD 框架下可被解释为不同的结构化半可分矩阵的参数化。
  • SSM 社区开发的许多”长程依赖”初始化策略（HiPPO, S4 的对角化等）可以作为”更好的注意力机制”的启发——如用 HiPPO 初始化 attention 的 QK 矩阵以使模型自然偏好长程依赖。
  • 混合架构（attention + SSM）是这种统一的自然结果——不是 patchwork，而是同一底层计算的不同配置的”最优组合”。

数据与任务定义

  • 语言建模: The Pile (825GB, 22 数据源), C4 (Colossal Clean Crawled Corpus), FineWeb (高质量 Common Crawl 子集)
  • 下游评估: 标准零样本评估集 — LAMBADA, HellaSwag, PIQA, ARC-Easy, ARC-Challenge, WinoGrande
  • 长序列基准: 2K/4K/8K/16K/32K 序列的训练吞吐和推理延迟
  • 硬件: NVIDIA H100 80GB (主实验), A100 80GB (确认可迁移性)
  • 对比: Mamba-1, FlashAttention-2, S4/H3, GLA, RetNet, 标准 Transformer (LLaMA arch)

Mamba-2 架构详情（以 370M 参数模型为例）

  • 层数: 48 层
  • 隐藏维度: 1024
  • SSM 状态维度 d_state: 256 (关键创新，Mamba-1 为 16)
  • 多头 SSM: 8 个独立 SSM 头，每个头有独立的状态 S 和 A 矩阵
  • Grouped-Value Attention (GVA): 类似 GQA，8 个 Q 头、8 个 K 头共享 4 个 V 头（减少 KV cache）
  • 混合架构配置: 4-6 层 attention (约 10-13%)，42-44 层 Mamba-2 SSM
  • A 矩阵参数化: 对角线矩阵 A_t = exp(-Δ_t ⊙ exp(A_log))（对每个头不同的 A_log 初始化）

方法主线

完整的机制流程

步骤1: 建立 SSD 的数学基础 — 证明递归 SSM 和矩阵 Attention 的等价性

输入: SSM 递归定义 (h_t = A_t h_{t-1} + B_t x_t; y_t = C_t h_t)

操作:

  • 展开递归：将 h_t 表示为所有过去输入的加权和
    • h_t = Σ_{j=1}^{t} (A_t…A_{j+1}) B_j x_j (状态是历史输入的累积)
    • y_t = C_t h_t = Σ_{j=1}^{t} C_t (A_t…A_{j+1}) B_j x_j
  • 将此写为矩阵形式: y = M x，其中 M_{t,j} = C_t (A_t…A_{j+1}) B_j
  • 证明 M 是结构化半可分矩阵（非对角元素为秩 1）
  • 建立对应关系: Q ↔ C (读)、K ↔ B (写)、因果 mask ↔ A 连乘的位置分解
  • 任何满足因果半可分的线性 attention 可解释为 SSM；任何 SSM 可表达为结构化掩码 attention

输出: SSM = Structured Masked Linear Attention 的严格等价性

步骤2: Mamba-2 的架构改进 — 利用训练/推理双路径

输入: SSD 的理论框架

操作:

  • 状态维度扩展 (16 → 256): 矩阵形式不受状态大小限制 — d_state 的增大仅影响 K^T V 累积的矩阵宽度（在 GEMM 中仍然高效）
  • Grouped-Value Attention (GVA): 8 Q/K heads → 4 V heads，与 GQA 类似但应用于 SSM 层 — 减少 V 投影的计算量和内存
  • 多头 A 矩阵: 每个 SSM 头有独立的 A 矩阵初始化（不同衰减率）→ 不同的头学会在不同的时间尺度上操作
    • A_log 初始化: 某些头初始化为大衰减（专注短程），某些为小衰减（专注长程）
    • 这相当于在 SSM 中建立”多时间尺度”的感知能力

输出: Mamba-2 层 — 兼具大记忆容量、多时间尺度建模、高效训练推理的 SSM 层

步骤3: 训练 — 使用矩阵 GEMM 形式（高速训练）

输入: 输入序列 X ∈ R^{N×D}

操作:

  • 将 A, B, C 展开为结构化掩码矩阵 M（下三角, 结构化半可分）
  • y = M × X — 标准 masked GEMM 操作
  • 利用 FlashAttention-2 的 I/O-aware 实现: block tiling → shared memory 缓存 → TensorCore GEMM
  • 因果 mask 直接编码在 M 的结构中（不需要单独的 mask 张量）

输出: 比 Mamba-1 快 2-8 倍的训练 throughput

步骤4: 推理 — 使用递归形式（O(1) 内存推理）

输入: 单个新 token x_t

操作:

  • 维护固定大小的状态 h_t ∈ R^{d_state × D_head}
  • h_t = A_t ⊙ h_{t-1} + B_t × x_t^T (状态更新, ⊙ 是逐元素乘法)
  • y_t = C_t × h_t (输出计算)
  • O(1) 时间、O(1) 内存 — 无需 KV cache

输出: 线性复杂度的高效推理

步骤5: 混合架构设计 — attention + SSM 互补

输入: Mamba-2 SSM 层 + 标准 attention 层

操作:

  • 在 48 层中插入 4-6 个 attention 层（通常在早期和中期层）
  • Attention 层负责”精确检索”（软匹配当前 token 与过去 token 的精细关联）
  • SSM 层负责”全局压缩”（将长程上下文不断更新到状态中）
  • 残差连接和 FFN 层在所有层中保持一致（与标准 Transformer 相同）

输出: 混合架构模型 — PPL 优于纯 Transformer 和纯 Mamba，推理速度接近纯 Mamba

SSD 统一框架的适用范围

SSD 框架证明了以下模型本质上是同一结构化半可分矩阵的不同参数化实例：

深度分析

1. SSD: 终结 “Transformer vs SSM” 的范式战争

SSD 在序列建模领域的影响类似于物理学中”电-磁统一”的范式转换——两个看似完全不同的现象（SSM 的连续时间递归 vs Attention 的离散矩阵乘法）被证明是同一底层数学结构的两种等价表示。

这一统一使两个独立发展的研究社区的成果可以互相借鉴。Attention 社区开发的”高效 attention”算法（Performer, Reformer, Linear Transformer 等）在 SSD 框架下可以被重新理解为对结构化半可分矩阵的不同近似方案。SSM 社区开发的”长程依赖初始化”策略（HiPPO, S4 对角化等）可以为 attention 机制的初始化提供新的启发。

“从选择赢家到选择组合”——SSD 的最重要实践启示。纯 SSM 和纯 Transformer 都不如”attention + SSM 的合理混合”。这是一个深远的启示：未来的架构设计不应问”我们该用什么代替 attention”，而应问”我们如何最优地组合不同的线性时间操作”。

2. 状态维度从 16 到 256 —— 被低估的设计维度

d_state 的扩展揭示了一个被忽视的设计原则：状态维度（记忆容量）是 SSM 性能的核心杠杆之一。Mamba-1 停留在 d_state=16 主要是工程原因（并行扫描在 GPU 上对大状态维度不友好），而非数学或经验原因。Mamba-2 通过替换训练路径（矩阵 GEMM）解除了这个工程限制。

256 维多头的总记忆容量（8 heads × 256 = 2048 维状态/config）在某种程度上接近甚至超过了 Transformer 在合理序列长度上的 KV cache 有效信息量——但与 KV cache 不同的是，SSM 的压缩是”有损的”（固定维度压缩所有历史），而 KV cache 是”无损的”（每个过去 token 保存完整信息）。

这个发现暗示了一个一般性的设计原则：SM 和 RNN 类模型的”状态维度”应该被提升到与”隐藏维度”和”头数”同等重要的超参数地位。欠设计的状态维度（如 16）会严重限制模型的记忆和长程依赖能力。

3. “递归 vs 矩阵”的计算路径按需切换

Mamba-2 引入了”训练和推理使用不同计算路径”的范式——这在 ML 中相当于拥有两个等价但效率特性不同的实现，根据场景（训练需要并行 vs 推理需要内存效率）动态切换。训练用矩阵 GEMM（极致并行 + 利用 TensorCores），推理用递归（O(1) 内存流式处理）。

这个范式可推广到任何具有”递归-矩阵双重形式”的模型——包括许多 RNN 和 attention 的线性化变体。只要模型的计算能被等价地表示为递归和矩阵两种形式，就可以在训练时用矩阵形式享受并行效率，在推理时用递归形式享受 O(1) 内存。这是一个强大的”免费的午餐” (free lunch)。

4. 混合架构的必然性与最优比例的开放性

SSD 的理论结论直接预言了混合架构的优越性。既然 attention 和 SSM 是同一底层操作的两种视角，它们适用于不同的子任务：

  • Attention 擅长: 精确 token 匹配、局部窗口内的细粒度关注、软选择特定过去 token
  • SSM 擅长: 长程上下文的持续压缩、全局依赖的积累、效率优先的大面积覆盖

目前的最优比例（10-20% attention）是基于 370M-1.3B 参数模型的实验。在更大的模型上（7B+），这个比例是否需要调整？Attention 层的”精确关注”能力在更大模型中是否变得更重要（因为模型有更多能力来有效利用精确匹配）？还是变得更不重要（因为大模型的 SSM 头可以弥补信息损失）？这些问题对于指导未来的混合架构设计至关重要。

5. Engineering Impact: 2-8x 加速的三个工程杠杆

Mamba-2 比 Mamba-1 快 2-8 倍不仅仅是”因为我们用了 GEMM”。加速来自三个叠加的工程优化:

(a) 替换自定义 kernel 为标准 GEMM: Mamba-1 的并行扫描 kernel 在 GPU 上的实现效率受限于扫描的串行依赖和减少的 TensorCore 利用率（部分操作是 memory-bound 的 reduction）。标准 cuBLAS GEMM 在 H100 上的 MatMul 效率可达 80-90% 的 hardware peak（约 60+ TFLOPS in BF16），而自定义扫描 kernel 通常仅 40-60%。替换本身贡献了约 2-3x 加速。

(b) 重用 FlashAttention-2 的 I/O 优化: Mamba-2 的矩阵训练形式可以直接利用 FlashAttention 的 block tiling（将大矩阵乘法分解为适配 SRAM 的 tile）、共享内存优化、warp-level 同步等——这些是 FlashAttention 经过大量攻关优化的成果，Mamba-2 免费继承。贡献约 1.5-2x 加速（取决于序列长度）。

(c) 长序列上的 O(N) vs O(N^2): 对于 N>4096 的序列，Mamba-2 的线性复杂度在理论上就超越了 Transformer——但实践中，只有当 N 足够大（>8K）时，这个优势才超过 ATtention 高度优化的实现带来的常数因子。贡献约在长序列上 2-4x 加速（随 N 增大而放大）。

局限和实践挑战

  1. 混合架构中 attention 层比例缺乏自动优化方案。 当前的最优比例（10-20% attention）来自手动搜索实验。对于每个新模型规模、任务分布、甚至硬件平台，最优比例可能不同。没有自动化的架构搜索算法（如 NAS 风格的 attention/SSM 层位置和数量优化）。

  2. 矩阵形式在超长序列上的数值稳定性。 在 SSD 的矩阵形式中，A 矩阵的连乘（A_t…A_{j+1}）在 t-j 很大时，乘积可能变得极小（多个 (0,1) 值连乘导致数值下溢）。Mamba-2 使用了指数化处理来缓解（exp(log A_t + … + log A_{j+1}) 将乘法转为加法），但在 32K+ 序列上仍有微小的累积误差。是否需要在 100K+ 序列上使用类似 GLA 的 log-空间累积策略？

  3. 混合架构的推理部署复杂性。 混合架构同时需要 attention kernel（处理 10-20% 层）和 SSM kernel（处理 80-90% 层），增加了推理引擎的维护负担。对于每个想部署 Mamba-2 混合模型的框架（vLLM, TGI, llama.cpp 等），需要同时集成和优化两种不同类型的算子。这在一定程度上抵消了 Mamba-2 本身的长序列推理优势——因为框架集成比纯 Transformer 更复杂。

  4. d_state=256 在 100K+ 序列上的适用性未验证。 Mamba-2 的主要实验在 2K-32K 序列上。对于 100K+ token 的上下文（当前的 LLM 前沿正在探索这个范围），256 维的压缩是否仍然足够？可能需要更大 d_state（512? 1024?），但又要避免引入训练效率的过度牺牲。存在一个”长度依赖的 d_state scaling law”需要被发现。

  5. attention 层的最优位置策略。 当前 Mamba-2 的混合架构在层间均匀分布 attention 层（如每 6 层穿插 1 个 attention 层）。但直觉上，模型的不同深度可能需要不同密度的 attention：早期层（学习低级特征）可能更少需要精确 attention，中期和后期层（语义推理）可能更需要。这种”非均匀 attention 密度”值得更系统的研究。

  6. 理论统一虽然深刻，但大规模（>7B）实践验证不足。 SSD 框架的优雅理论主要在小规模（370M-1.3B）上验证。Mamba-2 的 2-8x 加速和 PPL 优势是否会直接扩展到 7B-70B 的规模？大模型的 training dynamics 可能导致 SSM 和 attention 的相对优势发生改变。缺乏 7B+ 规模的开源 Mamba-2 模型是采纳这一架构的主要障碍。

  7. 与下一代 attention 方法的关系。 在 Mamba-2 发表后不久，FlashAttention-3、Ring Attention、Tree Attention 等新 attention 方法进一步发展了 attention 的效率。这些方法能在多大程度上缩小 attention 与 SSM 的长序列效率差距？如果 attention 的效率大幅提升（如在 16K+ 序列上也达到接近 O(N) 的实际表现），混合架构的 SSM 层的边际价值就会降低。

可复用洞见

  1. 数学统一常常带来突破性的工程改进。 SSD 不仅是一个理论优雅的结果——它直接使 Mamba-2 比 Mamba-1 快 2-8 倍（通过揭示矩阵计算路径）。这是科学史上一再验证的模式：好的理论理解能够”解锁”新的工程策略。在架构研究中，投入理论理解的 ROI 可能超过投入纯工程调优。

  2. 训练和推理可以使用不同的计算路径，这是”免费的午餐”。 任何具有递归-矩阵双重形式的模型都可以在训练时选矩阵路径（享受并行效率），在推理时选递归路径（享受 O(1) 内存）。这个范式可推广到许多线性化 attention 变体和其他 SSM 模型。

  3. 状态维度（记忆容量）是被严重低估的设计维度。 d_state=256 vs 16 的对比展示了内存容量对模型的显著影响（-0.10 PPL）。在设计 SSM/RNN 类模型时，应将状态维度作为与隐藏维度同等重要的关键超参数——不应该接受”因为是 SSM 所以状态不必大”的假设。

  4. “混合优于单一”是架构设计的元原则。 纯 SSM 和纯 Attention 都不如混合——这个发现超越了具体的模型。它暗示了”architecture specialization” 的理念自然地引出”架构混合”的优越性：不同的计算原语适用于不同的子问题，组合它们可以获得累积的收益。

  5. 重用已有优化 > 从零构建自定义实现。 Mamba-2 的最大工程突破之一是它不需要维护独立的训练 kernel——而是借力 FlashAttention-2 的成熟和持续优化的基础设施。这种”站在巨人的肩膀上”的策略在快速发展的 ML 生态中尤其有效——选择依赖已被广泛采用和优化的组件，避免维护自己的定制库。

  6. “从竞争到合作”是成熟研究社区的标志。 Tri Dao (FlashAttention 作者, 让 attention 极致高效) 和 Albert Gu (Mamba 作者, 提出 attention 替代品) 联手合作，得出”混合使用两者”的结论。这种”不是二选一，而是组合”的学术成熟度是值得学习的——真正的进步常在”对立面”的融合中涌现。

我的笔记

Mamba-2 是我认为 2024 年最优雅的 ML 论文之一。它的核心贡献不是某一个具体算法（这来自 Mamba-1 和 FlashAttention-2 的先驱工作），而是一个统一的理论视角——SSD 框架证明了 SSM 和 Attention 在数学上是严格等价的。这种”统一场论”级别的论文在 ML 中非常罕见——大多数论文要么”提出一个新方法”，要么”改进一个现有方法”，很少能提供一个连接多个独立发展领域的桥梁。

在阅读 SSD 之前，我看 Mamba、GLA、RetNet、RWKV、Linear Attention 是一堆不同的”对抗 Transformer 的竞争者”——每个都有自己的一套术语、理论、和基准。SSD 之后的视角完全不同：它们都是同一结构化半可分矩阵的不同参数化实例，它们的优劣取决于参数化在特定任务和规模下的表现。这个视角转变不仅是理论兴趣——它直接指导了实践：”既然它们是同一个东西的不同形式，那我们就可以组合它们”——直接导致了混合架构（attention + Mamba-2）这一关键洞见。

Tri Dao 和 Albert Gu 的合作叙事也反映了罕见的学术成熟度。Tri Dao 是 FlashAttention 的作者（他的主要贡献是让 attention 更高效），Albert Gu 是 Mamba 的作者（他的主要贡献是提出 attention 的替代品）。理论上，两人的工作方向是”对立的”——Tri Dao 让你更好地用 attention，Albert Gu 让你用别的东西取代 attention。但两人选择了合作，然后一起得出”attention 不应被取代——它应该与 SSM 组合使用”。这种”超越学派对立、追求真理”的精神，是 SSD 背后的人文故事。

混合架构的建议——“10-20% attention + 80-90% Mamba-2”——是这篇论文最重要的实践洞见。它回答了一个困扰架构研究的问题：”我们真的需要完全抛弃 attention 吗，还是 attention 仍有其独特价值？” 答案很清晰：attention 在”精确 token 匹配”方面有着不可替代的效率，而 SSM 在”全局上下文长程压缩”上更优。两者互补——不是”二选一”，而是”1+1 > 2”。

状态维度从 16 扩展到 256 也让我反思了”被架构实现在限制所忽视的设计空间”。SSM 的 d_state=16 似乎是一个合理的默认（”这是一个压缩状态，不需要太大”），直到 Mamba-2 证明 256 能带来显著的 PPL 改善（-0.10）。这个教训提醒我：永远质疑默认超参数的来源——它是来自实证最优，还是来自工程便利？前者应该被信任，后者应该被重新验证。

最后，SSD 对”好的理论产生好的工程”提供了一个优美的案例。A不只是一个”nice to have”的优雅证明——它直接导致了 Mamba-2 的 2-8x 加速（因为知道了 SSM 可以用矩阵乘法实现）。这是爱因斯坦级别的统一——“质能等价”不只是哲学，它直接产生了原子能。SSD 不只是理论优雅，它直接解锁了新的工程可能性。

后续问题

  1. SSD 的统一理论能否扩展到交叉 attention 和多模态场景（text-image cross-attention, encoder-decoder attention）？cross-attention 的半可分矩阵有什么特征？

  2. 能否用 SSD 框架来自动搜索和设计新的”结构化半可分矩阵”参数化——即新的线性时间架构？SSD 能否成为架构搜索的搜索空间定义？

  3. d_state 的 scaling law 是什么？d_state=256 在 32K 序列下最优，在 128K 序列下是否需要 512 或 1024？是否存在 d_state ∝ log(N) 的 scaling relation？

  4. SSD 的数值稳定性在 100K+ 序列上如何？是否需要引入 log-空间累积（类似 GLA）或其他稳定性机制？

  5. 混合架构中 attention 层的最优位置是否可以形式化为一个优化问题（如 layer-wise importance analysis 来决定哪些层受益最多于 attention）？

  6. 随着 FlashAttention-3 和 Ring Attention 的发展，attention 在长序列上的效率可能在多大程度上缩小与 SSM 的差距？是否会改变混合架构的最优比例？
