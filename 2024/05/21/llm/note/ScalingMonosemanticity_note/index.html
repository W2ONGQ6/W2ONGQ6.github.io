Scaling Monosemanticity: Extracting Interpretable Features from Claude 3 Sonnet

Scaling Monosemanticity: 从Claude 3 Sonnet中提取可解释特征

核心信息

  • 标题: Scaling Monosemanticity: Extracting Interpretable Features from Claude 3 Sonnet
  • 标题翻译: 缩放单义性：从Claude 3 Sonnet中提取可解释特征
  • 作者: Adly Templeton, Tom Conerly, Jonathan Marcus 等（28位作者）
  • 机构: Anthropic
  • 发表时间: 2024年5月21日
  • 发表渠道: Anthropic Transformer Circuits网站（交互式论文）
  • 论文链接: https://transformer-circuits.pub/2024/scaling-monosemanticity
  • 论文类型: 可解释性研究 / 实证验证

原文摘要翻译

我们首次在商业级大语言模型（Claude 3 Sonnet）上成功训练了稀疏自编码器（Sparse Autoencoder），在模型中间层的残差流上提取了数千万个可解释的内部特征。我们训练了三个规模的SAE——约100万、400万和3400万特征——证明了该方法能够跨数量级扩展，且SAE训练本身遵循可预测的缩放定律。我们发现的这些特征令人惊讶地具体：它们对应特定的城市、人物、科学概念、编程语法，以及更抽象的概念如安全漏洞、欺骗、偏见和谄媚。值得注意的是，尽管Claude 3 Sonnet是纯文本训练的，这些特征却是跨语言和跨模态的——例如，”金门大桥”特征在英文、中文、日文的文本描述中和在图像展示中都会激活。我们进一步证明，通过人为地操纵这些特征（如clamp到高值或低值），可以因果性地改变模型的行为输出，这为AI安全研究提供了新的实验范式。

创新点

1. 稀疏自编码器从玩具模型到生产级模型的跨越

核心思想: 此前Anthropic的”Towards Monosemanticity”（2023年10月）仅在单层小Transformer上验证了SAE的可行性。本工作在Claude 3 Sonnet（商业级生产模型，数十亿参数，多层结构）上大规模部署SAE。

规模跨越:

  • 之前的验证: 1层小Transformer
  • 本工作: Claude 3 Sonnet（数十层，数十亿参数）
  • SAE特征数: 从几千扩展到3400万（扩展约10^4倍）

为什么重要: 这是”机械化可解释性”（Mechanistic Interpretability）领域的里程碑。在此之前，社区普遍怀疑这些方法能否从玩具模型扩展到实用模型——毕竟两者之间的鸿沟是巨大的。这篇论文用实证回答了”能”。

2. 跨语言和跨模态的特征统一性

核心思想: 尽管模型是纯文本训练的，提取出的SAE特征却表现出跨语言（英语、法语、中文、日语等）和跨模态（对纯文本训练的特征却对图像中的对应概念产生响应）的激活模式。

具体案例:

  • “金门大桥”特征: 在英文”Golden Gate Bridge”、中文”金门大桥”、日文”ゴールデンゲートブリッジ”以及金门大桥图片中都激活
  • “数学”特征: 在英文数学讨论、中文数学题、数学公式图片中都激活

为什么重要: 这表明模型内部形成了概念级别的（而非语言级别的）内部表征——即存在某种抽象的”概念空间”，不依赖于特定的语言或模态。这对于理解LLM如何在跨语言场景中工作具有根本性启示。

3. 安全相关特征与特征级操控

核心思想: 论文识别出了与AI安全高度相关的特征，并证明通过操控这些特征可以因果性地改变模型行为。

识别的安全特征类别:

  • 欺骗（Deception）
  • 谄媚（Sycophancy）
  • 权力追求（Power-seeking）
  • 偏见（Bias）
  • 安全漏洞（Security vulnerabilities）
  • 危险内容生成（Dangerous content）

特征操控实验: 通过将某个特征的值”clamp”（锁定）到极高或极低，观察模型行为变化。例如，将”金门大桥”特征强行激活后，模型会在完全不相关的上下文中反复提到金门大桥。

为什么重要: 这开启了”特征级安全调控”的新范式——相较于RLHF只能调控模型的整体输出行为，特征级操控可以精确地定位和修正特定的不安全倾向。

4. SAE训练的缩放定律

核心思想: SAE自身的训练也遵循可预测的缩放定律——随着特征数量的增加（100万→400万→3400万），SAE的解释覆盖率和重构质量按可预测的方式提升。

为什么重要: 这意味着SAE方法不仅”在玩具模型上管用”，而且可以”通过增加投入来系统地提升效果”——这是从”有趣但无用的研究方向”转变为”有实际投资价值的研究方向”的关键。

一句话总结

Anthropic首次在商业级模型Claude 3 Sonnet上成功部署了稀疏自编码器（SAE），提取了3400万个可解释的内部特征——这些特征表现出跨语言/跨模态的概念统一性，包括可操控的安全相关特征，证明了可解释性技术可以从玩具模型扩展到生产级模型，为AI安全的”特征级”调控提供了全新范式。

研究问题

核心挑战

LLM的内部运作是一个”黑箱”——我们知道输入和输出，但不知道中间发生了什么。机械化可解释性（Mechanistic Interpretability）试图打开这个黑箱，理解模型内部的”思想”。

关键问题：

  1. 能否在商业级模型（而非仅玩具模型）中提取有意义的内部特征？
  2. SAE方法能否跨数量级扩展？
  3. 提取的特征是否具有跨语言和跨模态的统一性？
  4. 能否通过操控特征来改变模型行为？

前人研究的局限

  1. 规模鸿沟: 先前的可解释性研究主要在1-2层的小Transformer上进行，与生产级模型之间存在巨大的规模差距
  2. 特征可解释性有限: 即使在小模型上找到的”特征”，其可解释性也参差不齐
  3. 缺乏因果验证: 大多数研究只能观察到相关性（”这个神经元在X输入时激活”），无法证明因果性（”激活这个神经元会导致X行为”）

关键洞察

稀疏自编码器可以作为”显微镜”——将一个密集激活的模型层分解为大量可解释的、独立控制的特征，而且这个”显微镜”的放大倍数可以通过增加SAE特征数来持续提升。

步骤1: 稀疏自编码器（SAE）训练

步骤位置选择: 在Claude 3 Sonnet的中间层残差流上（选择中间层是因为它编码了比底层更抽象、比顶层更”未压缩”的中间表示）
步骤SAE架构:

  • 编码器: 残差流激活 → 特征激活（线性+ReLU + TopK稀疏化）
  • 解码器: 特征激活 → 重建的残差流激活（线性）
    步骤训练目标: L = L_reconstruct + lambda * L_sparsity
  • L_reconstruct: MSE（重建误差）
  • L_sparsity: 鼓励仅有少量特征激活的稀疏惩罚
    步骤输出: 训练好的SAE（编码器+解码器权重）

步骤2: 特征可解释性分析

步骤输入: SAE提取的特征激活模式
步骤操作:

  • 对每个特征，找到”最强激活”的输入文本（top-activating examples）
  • 人工审查这些文本是否围绕同一概念
  • 对特征进行主题标注（金门大桥、安全漏洞、Python代码等）
    步骤输出: 可解释特征的标注集合

步骤3: 跨语言/跨模态验证

步骤输入: 同一概念的不同语言描述（如中英日法）/不同模态（文本+图像）
步骤操作:

  • 将多语言/多模态输入通过模型生成残差流激活
  • 通过SAE查看”概念X”特征的激活强度
  • 验证该特征是否在所有语言/模态表达中都激活
    步骤输出: 特征跨语言/跨模态一致性的量化证据

步骤4: 特征因果操控实验

步骤输入: Claude 3 Sonnet模型 + 训练好的SAE
步骤操作:

  • 在模型运行时，人为地将某个特征的值”clamp”到极高值
  • 观察模型输出是否被此特征”劫持”（如频繁提到金门大桥）
  • 对安全特征做类似操控，观察不安全行为增减
    步骤输出: 特征与行为之间因果关系的实证证据

理论分析

SAE的数学框架

稀疏自编码器将一个激活向量x（残差流）分解为:

其中:

  • f_i(x)是第i个特征在输入x上的激活值
  • d_i是第i个特征对应的解码向量（”特征方向”）
  • b是偏置项

关键约束: f_i(x)在绝大多数输入上应为零（稀疏性），只在特定概念出现时才激活。

SAE训练的缩放定律

实验发现以下缩放关系:

  • 随着特征数N_f增加，L0（平均活跃特征数）保持大致恒定
  • 重构损失MSE随N_f的增加而递减
  • 递减模式呈现幂律: MSE ∝ N_f^(-alpha)

这意味着”增加更多特征”是提升可解释性覆盖率的可靠方法——并且回报是可预测的。

概念级表征的理论意义

跨语言/跨模态的特征统一性表明了LLM内部的一种重要结构：概念空间。

模型不是分别存储”Golden Gate Bridge”、”金门大桥”、”ゴールデンゲートブリッジ”和一张桥的图片——而是存储了一个统一的”金门大桥概念”，三种语言和一种视觉表达都是该概念的”触发器”。

这对语言模型的理解模式有深远启示：

  • 翻译不是”源语言→目标语言”的映射，而是”源语言→概念→目标语言”
  • 跨语言zero-shot能力自然产生于这种统一的概念表征
  • 视觉理解能力可能可以”诞生”于纯文本训练的概念空间中

特征级操控 vs 行为级操控

RLHF是”行为级操纵”——它改变模型的最终输出行为，但不知道内部的哪个”齿轮”被调整了。SAE提供了”特征级操控”——精确地找到与特定行为相关的内部特征并调整它。

两者互补：

  • RLHF擅长整体行为调整（”变得更有帮助”）
  • SAE擅长精确的局部调整（”减少在X话题上的谄媚倾向”）
  • 组合使用可能是未来的最优方案

方法论局限的现实评估

论文作者坦诚了当前方法的重要局限：

  1. 特征不完整: 3400万特征仍然只覆盖了模型内部分表示的一小部分——大量的”暗物质”未被发现
  2. 因果性验证不足: 虽然特征clamp能改变行为，但不等于完全理解了该特征在模型计算中的完整因果角色
  3. 跨层机制的缺失: SAE只能分析单层，但模型的计算是跨层流动的——当前方法无法追踪一个”思想”如何在层间演化

局限

1. 特征覆盖率不完整

问题: SAE提取的特征只覆盖了模型内部表征的一小部分。大量未被SAE捕获的计算”暗物质”仍然是黑箱。

影响: 不能声称已经”理解”了模型的运作——只能说在可理解的部分继续深入。

2. 单一层级分析

问题: SAE仅在中间层分析，无法追踪概念如何在多层之间演化、组合和变换。

影响: 缺少对模型”计算流程”的端到端理解——仅知道”某一时刻”激活了哪些概念。

3. 自动化可解释性评估的不成熟

问题: 特征的”可解释性”目前主要依赖人工审查（看激活最强的文本是否有关联），缺乏自动化的、可扩展的评估方法。

影响: 无法对每个SAE训练版本做全面评估，只能抽样检查。

4. 无法保证”完备性”

问题: 即使找到的所有特征都是可解释的，也无法保证”没有遗漏关键特征”——模型的某些危险计算可能隐藏在当前SAE无法捕获的维度中。

可复用洞见

1. SAE作为通用可解释性工具

洞见: 稀疏自编码器可以作为任何Transformer模型的”解剖工具”——不限于Claude，适用于任何架构和领域。

如何应用:

  • 在自己训练的模型上部署SAE，分析模型内部表征
  • 检查模型是否形成了不当的偏见特征
  • 验证微调是否按预期方向改变了模型的内部表征

2. 跨模态概念空间的验证方法

洞见: 纯文本训练的模型形成的概念表征是跨模态的，可以通过图像输入验证（即使模型本身不支持图像输入，也可以通过CLIP等外部编码器）。

如何应用:

  • 使用多模态探针测试纯文本模型的概念表征
  • 设计跨模态一致性实验来验证”概念压缩”的质量

3. 特征级安全审计

洞见: 可以审计模型内部是否存在危险的特征——如欺骗、偏见、越狱倾向等——即使这些特征没有被触发。

如何应用:

  • 在模型部署前，用SAE扫描是否存在与不安全行为相关的特征
  • 监控已部署模型的特征激活模式，检测异常行为
  • 设计特征级的”安全开关”来精确禁用特定不安全倾向

我的笔记

对后续研究的启发

  1. 可解释性从”学术好奇”到”工程可操作”的转变: 这篇论文最重要的遗产是将机械化可解释性从纯学术研究推向了”对商业部署AI有实际价值”的领域——安全审计、行为调控、偏见检测。

  2. “显微镜”隐喻的威力: SAE提供了不同”放大倍数”的模型内部视角。但正如显微镜发明后花了几个世纪才真正理解细胞生物学，SAE也需要长时间的研究积累才能达到对模型行为的完整理解。

  3. 可解释性研究的”ChatGPT时刻”: 类似于ChatGPT让AI出圈，这篇论文让可解释性研究出圈——在安全政策和AI治理讨论中被广泛引用。

实际应用场景

  1. 模型安全审计: 在发布前用SAE检查是否存在危险特征
  2. 偏见消除: 识别并抑制与种族、性别等敏感维度相关的不当特征
  3. 行为调试: 当模型出现异常行为时，用SAE定位是哪些内部特征在作怪

后续问题

1. 能否实现跨层特征追踪？

问题: 如何将SAE分析扩展到多层，追踪一个概念在不同层之间的演化——从”识别”到”理解”到”使用”？

2. “暗物质”是什么？

问题: SAE无法捕获的计算维度代表了什么？是噪声、冗余还是我们尚未理解的更复杂的计算模式？

3. 特征的因果完备性

问题: 操控SAE特征是否能完全解释模型的行为变化？还是说存在SAE无法捕获但对行为至关重要的”隐藏变量”？

4. 回路分析

问题: 不同特征之间如何交互？能否构建特征级别的”计算回路”图，完整描述一个输入如何通过特征激活网络产生输出？

5. 跨模型的特征对应

问题: Claude的”金门大桥”特征在GPT-4中是否有对应特征？不同模型的概念空间是否同构？
