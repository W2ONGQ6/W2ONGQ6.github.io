LLM专题-06：多模态大模型 —— 如何让 LLM 看懂图、听懂声音？

多模态大模型 (Multimodal LLMs)

Learning Transferable Visual Models From Natural Language Supervision (CLIP)

  • arXiv: 2103.00020
  • 发表: ICML 2021
  • 作者: Alec Radford, Jong Wook Kim, Chris Hallacy, Aditya Ramesh, Gabriel Goh, Sandhini Agarwal, Girish Sastry, Amanda Askell, Pamela Mishkin, Jack Clark, Gretchen Krueger, Ilya Sutskever, OpenAI
  • 简介: 通过在大规模（4 亿对）图文数据上进行对比学习训练，CLIP 学习到了将视觉概念与自然语言对齐的统一表示，使得模型可以在任意下游图像分类任务上进行零样本分类——只需用文本描述类别即可。
  • 核心创新:
    • 对比语言-图像预训练范式：放弃传统的”预测图像标签”的监督学习路线，转而采用对比学习——拉近匹配的图文对（正样本）的表征、推开不匹配的图文对（负样本）的表征。在一个大 batch 内，所有非匹配对都构成负样本，训练效率极高。这一设计使模型学到了视觉与语言的联合嵌入空间。
    • 大规模弱监督数据：使用从互联网收集的 4 亿对（图像，文本描述）数据进行训练，文本描述即当年流行的 alt-text。这种数据的质量远低于传统策划数据集（如 ImageNet），但规模和多样性远超后者，使得学到的表征具有惊人的泛化能力。
    • 零样本迁移的突破：在不使用任何下游训练数据的情况下，CLIP 在 30 个不同的视觉分类基准上的表现与全监督的 ResNet-50 相当，包括 ImageNet（76.2% top-1）、细粒度分类、物体识别、动作识别、OCR 场景文本识别等多种任务。这证明了”用语言描述视觉概念”是一种通用的视觉学习范式。
  • 代表意义: CLIP 是多模态学习的转折点。它证明了视觉和语言可以在一个统一的对比学习框架下自然对齐，且这种对齐带来的视觉表征具有远超传统监督学习的泛化能力。CLIP 的视觉编码器成为几乎所有后续视觉-语言模型的标准组件——从 BLIP-2 到 LLaVA、从 Stable Diffusion 到 DALL-E，没有 CLIP 预训练的视觉编码器，今天绝大多数多模态系统都将无从构建。

Flamingo: a Visual Language Model for Few-Shot Learning

  • arXiv: 2204.14198
  • 发表: NeurIPS 2022
  • 作者: Jean-Baptiste Alayrac, Jeff Donahue, Pauline Luc, Antoine Miech, Iain Barr, Yana Hasson, Karel Lenc, Arthur Mensch, Katie Millican, Malcolm Reynolds, Roman Ring, Eliza Rutherford, Serkan Cabi, Tengda Han, Zhitao Gong, Sina Samangooei, Marianne Monteiro, Jacob Menick, Sebastian Borgeaud, Andrew Brock, Aida Nematzadeh, Sahand Sharifzadeh, Mikolaj Binkowski, Ricardo Barreira, Oriol Vinyals, Andrew Zisserman, Karen Simonyan, DeepMind
  • 简介: 首个在大规模上构建的视觉语言模型（VLM），通过 Perceiver Resampler 架构和交织图文训练，在少量示例甚至零样本的情况下展现出强大的多模态理解能力，奠定了现代 VLM 的架构范式。
  • 核心创新:
    • Perceiver Resampler 架构：面对”如何将可变数量的视觉特征高效地喂给固定大小的语言模型”这一核心挑战，Flamingo 提出了优雅的解决方案——Perceiver Resampler 通过交叉注意力机制，将来自视觉编码器的任意数量的视觉 token 压缩为固定数量（如 64 个）的”视觉摘要”token，然后插入语言模型的各层。这种设计实现了视觉信息的高效注入，同时保持了计算效率。
    • 交织图文预训练：Flamingo 在包含图文交织的网页数据（从互联网收集的约 400 亿图文交错文档）上进行训练，使模型自然地学会在文本和图像之间切换——理解文本→看图像→继续文本→再看另一张图像。这比”单张图像+描述”的流水线式训练更能模拟真实世界中的多模态理解和对话场景。
    • gated cross-attention 机制：在每个 transformer 层中，通过可学习的门控参数控制视觉信息与语言表示的融合程度，初始化为零以保护预训练语言模型的知识不被视觉信息破坏。这使得模型可以在视觉和语言之间进行细粒度的、逐层可控的信息融合。
    • 强大的少样本多模态能力：仅需在 prompt 中提供少量图文交替的示例，Flamingo 就能适配大量开放集视觉任务（视觉问答、图像描述、视频理解等），在 16 个多模态基准上取得当时最佳结果，其中多个任务以少样本方式超越了全微调的专用模型。
  • 代表意义: Flamingo 是多模态大语言模型（MLLM）领域的先驱之作。它确立了”冻结视觉编码器 + 轻量连接模块 + 冻结语言模型”的三段式架构范式，这一思路直接影响了后续的 BLIP-2、LLaVA 等几乎所有开源 VLM。Flamingo 也是第一个证明多模态少样本学习可以大规模可行的系统，其架构思想至今仍深刻影响着 GPT-4V、Gemini 等最先进多模态系统的设计。

BLIP-2: Bootstrapping Language-Image Pre-training with Frozen Image Encoders and Large Language Models

  • arXiv: 2301.12597
  • 发表: ICML 2023
  • 作者: Junnan Li, Dongxu Li, Silvio Savarese, Steven Hoi, Salesforce Research
  • 简介: 提出 Q-Former（Querying Transformer）作为轻量级桥梁模块，连接冻结的视觉编码器和冻结的大语言模型，仅需训练约 1.2% 的参数量即可让 LLM 学会”看懂”图像，是多模态 LLM 领域最优雅高效的架构设计之一。
  • 核心创新:
    • Q-Former 架构设计：Q-Former 的核心是一组可学习的查询向量（query tokens），通过交叉注意力从视觉编码器的输出中提取与文本最相关的视觉信息。它同时接受图像特征和文本输入，通过三个预训练目标（图文对比学习、图文匹配、图像条件语言建模）学习如何”提问”视觉编码器、如何将重要视觉信息压缩进查询向量，以供下游 LLM 使用。
    • 两阶段高效训练：第一阶段，仅 Q-Former 与视觉编码器交互进行视觉-语言对齐预训练；第二阶段，Q-Former 的输出通过一个轻量线性投影连接到冻结的 LLM。整个过程中，视觉编码器和 LLM 的权重完全不更新，仅 Q-Former 参数（约 188M）可训练，相比全量微调节省了超 98% 的训练开销。
    • 启发了整个开源 MLLM 生态：BLIP-2 证明了”冻结 + 桥梁”范式是可行的，且其性能远超端到端微调的效率预期。Q-Former 的查询压缩思想在后续工作（如 Video-LLaMA 的 Video Q-Former、InstructBLIP 等）中被广泛采纳和扩展，形成了 Q-Former 系列架构家族。
  • 代表意义: BLIP-2 是 MLLM 方向被引用最多的论文之一。它用极简的设计回答了多模态模型的核心工程问题——“如何让已经很强的大语言模型学会看图像，同时又不破坏它已有的语言能力？”其”冻结 + 轻量桥梁”的范式成为开源多模态 LLM 的标准做法，Q-Former 的查询机制也在无数后续工作中被证明是灵活而高效的。BLIP-2 是多模态 LLM 工程设计的里程碑。

Visual Instruction Tuning (LLaVA)

  • arXiv: 2304.08485
  • 发表: NeurIPS 2023
  • 作者: Haotian Liu, Chunyuan Li, Qingyang Wu, Yong Jae Lee, University of Wisconsin-Madison / Microsoft Research
  • 简介: 利用 GPT-4 生成多模态指令数据集，通过极简的线性投影将视觉特征接入 LLaMA，使模型获得多模态对话能力。LLaVA 以其简单性和高效性成为最广泛使用的开源多模态 LLM 之一。
  • 核心创新:
    • 利用语言模型生成多模态训练数据：使用 GPT-4/ChatGPT 对 COCO 图像的文字描述进行扩展，自动生成三种类型的高质量指令数据——详细图像描述、图像对话和多步推理问答。这种”用 LLM 生成多模态指令数据”的思路极大降低了多模态数据的人工标注成本，成为后续 MLLM 的标配做法。
    • 极简架构——线性投影层：不同于 BLIP-2 的 Q-Former 等复杂连接模块，LLaVA 仅用一个简单的线性投影层将 CLIP 视觉编码器的输出映射到 LLM 的文本嵌入空间。尽管架构极简，但这在有高质量指令数据支撑的微调下效果出色，证明了”数据质量 > 架构复杂度”在多模态 LLM 中的重要性。
    • 开源生态和持续迭代：LLaVA 不仅论文本身影响力巨大，其开源代码和模型权重催生了庞大的衍生生太——LLaVA-1.5、LLaVA-NeXT、LLaVA-Med、LLaVA-Plus 等多个后续版本持续改进，覆盖更细粒度的视觉理解、医学影像、多图像推理等场景，使其成为开源 MLLM 的旗舰项目。
  • 代表意义: LLaVA 是开源多模态 LLM 的标杆。它的核心贡献不仅是技术上的——极简架构也能做出顶级效果——更是生态上的：它让多模态 LLM 研究的门槛大幅降低。任何有基本计算资源的研究者都可以基于 LLaVA 的架构和数据配方构建自己的多模态模型。同时，LLaVA 通过视觉指令微调实现的多模态对话能力，逼近了当时闭源 GPT-4V 的效果，大幅缩小了开源与闭源在多模态领域的差距。

GPT-4V(ision) System Card

  • arXiv: 2309.17421
  • 发表: 2023 年 9 月
  • 作者: OpenAI
  • 简介: 系统性地报告了 GPT-4V 的多模态能力——视觉推理、OCR、UI 理解、图表解读、医学影像分析、手写识别等——全面展示了当时最先进多模态 LLM 的能力边界，设定了业界对 MLLM 的期望标准。
  • 核心创新:
    • 全面的多模态能力展示：GPT-4V 不仅能描述图像，还能进行精细的视觉推理（如数出图片中的特定物体数量、解释视觉幽默、识别并解读图表数据）、多模态知识问答（结合图像内容和世界知识回答问题）、以及复杂文档理解（表格提取、流程图解析、数学公式识别）。
    • 系统化的安全评估和分析：System Card 首次详细披露了一个多模态大模型在安全、偏见、幻觉等方面的评估结果。包括对”不允许识别公众人物”的限制政策、医疗建议安全性的测试、视觉越狱攻击的防御等，为多模态模型的安全对齐设立了标杆。
    • 界面和 UI 理解能力：GPT-4V 展示了令人惊讶的 UI 理解能力——能够理解屏幕截图、识别 UI 元素、推断用户意图。这直接启发了”视觉 Agent”方向：让模型通过”看屏幕”来操作电脑和手机，成为 GUI Agent（如 Claude Computer Use）的核心视觉基础。
  • 代表意义: GPT-4V System Card 是”多模态 LLM 的能力宣言”。它向全世界展示了顶尖多模态模型的真实水平——远超大多数人此前的想象。虽然 System Card 没有公开架构细节，但它定义的”能力清单”（视觉推理、OCR、UI 理解、医学影像）成为了整个行业评估和对比多模态模型的默认维度。它也标志着多模态 LLM 从”科研探索”走向”产品化”的转折点——在此之后，多模态能力被视为先进 LLM 的必备功能，而非锦上添花。

Video-ChatGPT: Towards Detailed Video Understanding via Large Vision and Language Models

  • arXiv: 2306.05424
  • 发表: ACL 2024
  • 作者: Muhammad Maaz, Hanoona Rasheed, Salman Khan, Fahad Shahbaz Khan, Mohamed bin Zayed University of Artificial Intelligence (MBZUAI)
  • 简介: 将多模态 LLM 的能力从静态图像扩展到视频理解，构建了 10 万条视频指令数据集和首个系统化的视频对话评估框架，在多类视频问答基准上超越同期模型。
  • 核心创新:
    • 构建 100K 规模的视频指令数据集：通过半自动化的标注流程，结合人工标注和自动生成，构建了约 10 万条高质量的视频-指令-回答三元组。数据涵盖详细视频描述、时序推理、因果分析和开放式视频问答等多种对话类型，为视频 MLLM 的指令微调提供了关键数据基础。
    • 首个视频对话量化评估框架：提出从五个维度评估视频对话质量——信息正确性（Correctness of Information）、细节导向（Detail Orientation）、上下文理解（Contextual Understanding）、时序理解（Temporal Understanding）和一致性（Consistency）。这一框架至今仍是评估视频对话模型的标准参考。
    • 视频编码的时间适配：基于 CLIP 视觉编码器，加入时间池化策略来捕获跨帧时序信息，在保持计算效率的同时让模型能够理解视频中的动态事件。输出通过线性投影层接入 Vicuna/LLaMA LLM 进行指令微调，架构设计的简洁性继承了 LLaVA 的理念。
  • 代表意义: Video-ChatGPT 是视频多模态 LLM 方向的标杆论文。它系统性解决了”如何让 LLM 理解视频”这个比图像理解更具挑战性的问题——视频不仅有视觉内容，还有时序动态和跨帧因果关系。其视频指令数据集和评估框架至今被几乎所有后续视频 LLM 工作引用和采用，在视频理解从”静态帧集合”进化到”时序故事理解”的过程中，Video-ChatGPT 扮演了关键的奠基角色。

Gemini: A Family of Highly Capable Multimodal Models

  • arXiv: 2312.11805
  • 发表: 2023 年 12 月
  • 作者: Gemini Team, Google DeepMind
  • 简介: 构建了原生多模态大模型家族（Ultra/Pro/Nano），从设计之初即支持文本、图像、音频、视频和代码的交织理解与生成，在 MMLU 和多模态基准上达到当时领先水平，代表主流大厂的首个全栈原生多模态 LLM。
  • 核心创新:
    • 原生多模态设计（非”外挂”）：不同于大多数 MLLM 的”先训练视觉编码器，再挂到 LLM 上”的流水线方案，Gemini 从预训练开始就在图文、音视频、代码的交织数据上进行联合训练。这种”原生”设计使模型在各模态之间的理解和交互更加自然深入，而非仅在 LLM 的文本空间中”翻译”视觉信息。
    • 三档规模家族设计：Ultra（最强，面向复杂推理）、Pro（均衡，面向多种任务）、Nano（端侧部署），覆盖从云端到移动端全场景。Nano 版本的端侧部署能力使得多模态 LLM 首次可以在 Android 设备上本地运行，开启了设备端 AI 的新范式。
    • 极长上下文与多模态理解结合：Gemini 1.5 Pro 支持高达 100 万 token 的上下文窗口，且支持多模态长上下文（如长达 1 小时的视频、数百页 PDF），使得”对整个视频进行问答”和”对整本书的图文内容进行检索”成为现实。
    • MMLU 基准突破：Gemini Ultra 是首个在 MMLU（大规模多任务语言理解）上超过人类专家的模型（90.04%），同时也是在多模态推理（MMMU）、数学推理、代码生成等多项基准上达到 SOTA。它证明了原生多模态训练不会损害单一模态（文本）的能力，反而能相互增强。
  • 代表意义: Gemini 代表了多模态 LLM 从”拼接型”到”原生型”的范式转变。它打破了一个隐含假设——“训练多模态模型需要在文本能力上做出妥协”。Gemini 跑通了整条”原生多模态 + 全模态 SOTA”的路线，为整个行业指明了方向。其多尺寸家族策略（云端 Ultra 到端侧 Nano）也成为后续 Google 和整个行业产品化的标准模式。从技术意义上看，Gemini 是多模态 LLM 走向成熟和实用化的标志性事件。

Qwen2-VL: Enhanced Vision-Language Model with Dynamic Resolution and Multimodal Rotary Position Embedding

  • arXiv: 2409.12191
  • 发表: 2024 年 9 月，Alibaba Qwen Team
  • 作者: Peng Wang, Shuai Bai, Sinan Tan 等，Alibaba Cloud
  • 简介: Qwen2-VL 是 Qwen 团队的多模态旗舰模型，引入动态分辨率输入和 M-RoPE（多模态旋转位置编码），使模型能够自然地处理任意分辨率的图像和视频，在主流多模态基准上与 GPT-4o 和 Claude 3.5 达到同等水平，并完全开源。
  • 核心创新:
    • 动态分辨率（Dynamic Resolution）：传统 VLM 将所有输入图像缩放到固定尺寸（如 336x336），损失了大量细粒度信息。Qwen2-VL 引入动态分辨率机制——模型根据图像的原始宽高比和大小，动态地决定需要多少视觉 token 来表示该图像。大图、高分辨率图自动分配更多 token，小图、简单图分配更少 token。这种自适应分配让模型既能在细粒度 OCR 和文档理解上受益于高分辨率，又不会在简单图像上浪费计算资源。
    • M-RoPE（多模态旋转位置编码）：Qwen2-VL 的核心架构创新是将位置编码扩展到三维——二维空间位置（图像的宽高坐标）+ 一维时间位置（视频帧的位置）。M-RoPE 在三个维度上分别应用旋转位置编码，并将分离的维度拼接为统一的查询-键空间。这使得模型能够同时理解”这个 token 在图像的哪个位置”和”这个 token 是视频的第几帧”，实现了真正的时空统一感知。
    • 全模态覆盖：Qwen2-VL 支持图像、视频、多图像交错的文本理解，以及复杂文档（PDF、表格、截图、手写体）的结构化解析。在 MathVista（数学视觉推理）、MMMU（多学科多模态理解）、DocVQA（文档问答）等基准上均达到或超越同期 GPT-4o 水平。特别是视频理解——能够回答长达 20 分钟视频的因果和时序问题，准确率超越当时的所有开源模型。
  • 代表意义: Qwen2-VL 是 2024 年下半年最强大的开源多模态模型之一。它在技术上证明了三件事——（a）动态分辨率而非固定缩放在多模态理解中至关重要；（b）视频理解可以自然地统一到图像理解框架中（通过 M-RoPE 的时空位置编码）；（c）开源多模态模型完全有能力与最强的闭源多模态模型竞争。其 2B/7B/72B 三档规模的完整开源，覆盖了从移动端到云端服务器的全场景多模态部署需求。

InternVL 2.5: Expanding the Performance Boundaries of Open-Source Multimodal Models

  • arXiv: 2412.05218
  • 发表: 2024 年 12 月，Shanghai AI Laboratory / SenseTime / CUHK 等
  • 作者: Zhe Chen, Weiyun Wang, Yue Cao 等，Shanghai AI Laboratory
  • 简介: InternVL 2.5 系列将大规模视觉编码器（InternViT-6B）与多种语言模型（从 1B 到 78B）组合，通过渐进式对齐训练策略，在几乎所有主流多模态基准上刷新了开源 SOTA，并在 MMMU 上首次达到 70%+ 的开源记录。
  • 核心创新:
    • 大规模视觉编码器（InternViT-6B）：不同于大多数 VLM 使用相对小的视觉编码器（如 CLIP ViT-L/14 的 300M 参数），InternVL 系列坚持使用 6B 参数的大规模 ViT 作为视觉前端。理论动机是——视觉编码器的规模和能力决定了模型”看到”的精细程度，而 LLM 的文本理解能力再强也无法弥补”看不清楚”的损失。InternViT 在 120 亿图文对上进行预训练，能够在像素级别理解复杂图表和文档的细微结构。
    • 渐进式三阶段对齐训练：InternVL 2.5 使用精细的训练课程——阶段 1：仅训练连接器（视觉编码器和 LLM 冻结），在噪声较大的图文描述数据上建立基本的视觉-语言映射；阶段 2：解冻 LLM 参数进行多模态预训练，引入更高质量的多模态数据（文档、图表、UI 截图）；阶段 3：全模型（包括视觉编码器部分层）进行指令微调，使用多样化的高质量多模态指令数据。这种三阶段策略大幅提升了训练效率和质量。
    • 跨 LLM 的通用适配：InternVL 2.5 的一个独特设计是——同一个 InternViT 视觉编码器可以被”插入”到不同规模和系列的 LLM 中（InternLM、Qwen、LLaMA），且在不同组合上都保持了领先性能。这说明大规模视觉编码器提供的视觉表示具有高度的”可迁移性”和”模型无关性”。
  • 代表意义: InternVL 2.5 证明了”更好的视觉前端 = 更好的多模态理解”这一核心假设。它挑战了当时业界流行的”视觉编码器不需要太大，LLM 才是关键”的观点。在 MMMU（多学科多模态大学水平测试）、MathVista（数学视觉推理）、DocVQA（文档问答）等多个基准上，InternVL 2.5 刷新了开源记录，并在 MMMU 上首次突破 70%，大幅缩小了与 GPT-4o 等闭源模型的差距。

Molmo and PixMo: Open Weights and Open Data for State-of-the-Art Multimodal Models

  • arXiv: 2409.17146
  • 发表: 2024 年 9 月，Allen Institute for AI (AI2)
  • 作者: Matt Deitke, Christopher Clark, Tom Duerig 等，AI2
  • 简介: Molmo 不仅在性能上挑战了 GPT-4o 级别的多模态模型，更重要的是其独特的”数据开放”哲学——不仅开源模型权重，还开源了构建视觉理解能力所需的高质量标注数据集 PixMo，允许完全复现整个训练管线。
  • 核心创新:
    • PixMo 数据集——高质量多模态数据的新标杆：PixMo（Pixels for Molmo）是 Molmo 的”秘密武器”——一组由人类标注者在图像上逐像素标注的数据集，包含三种关键数据类型：（a）Dense Captioning（密集图像描述），每个图像标注 3-5 句涵盖不同区域和对象的描述；（b）2D Pointing（二维指向），用坐标标注图像中的具体物品位置和关系；（c）Visual Counting（视觉计数），标注图中特定对象的数量及其位置。这些”像素级”的标注质量远超传统图文对的 alt-text 噪声标注。
    • 小规模高质量数据 vs 大规模噪声数据：Molmo 的 pixmo 数据总量不足 100 万条，远小于大多数 MLLM 使用的数亿乃至数十亿条图文对。但凭借数据的高质量（全部由训练有素的标注者逐一标注），Molmo 在多项视觉基准上匹敌甚至超越使用数亿条数据训练的更大模型。Molmo 7B 在多项任务上接近 GPT-4o 水平，Molmo 72B 达到了 GPT-4o 约 90% 的性能——但使用的数据量不到后者的 1%。
    • 从数据到模型的全链路开放：AI2 不仅开源了 Molmo 系列的所有模型权重，还开源了所有训练数据（PixMo）、标注规范、训练代码和评估工具。这意味着任何研究者都可以完全复现 Molmo 的全流程，并在此基础上进行改进。这种”从数据到模型”的全链路开放是开源 MLLM 中前所未有的透明度。
  • 代表意义: Molmo 的核心信息与 Phi-1 在 LLM 领域的发现高度一致——“数据质量 > 数据量”，这一规律在多模态领域同样成立。AI2 通过 Molmo 证明了，访问高质量标注数据的价值可能大于访问更大规模的预训练数据。对于资源受限的学术实验室，这个发现极为重要——它意味着通过精心构建一个小型但高质量的数据集，也能训练出有竞争力的多模态模型。Molmo 也是开源 AI 透明度方面的典范，为整个 MLLM 社区树立了数据开放的新标准。

NVLM: Open Frontier-Class Multimodal LLMs

  • arXiv: 2409.11402
  • 发表: 2024 年 9 月，NVIDIA
  • 作者: Wenliang Dai, Nayeon Lee, Boxin Wang 等，NVIDIA
  • 简介: NVIDIA 发布 NVLM-72B，一个在纯文本和多模态任务上均达到 GPT-4o 级别性能的开源多模态模型，提供了 Decoder-only 和 Cross-Attention 两种架构变体，证明动态高分辨率输入和高质量训练数据是多模态 SOTA 的关键。
  • 核心创新:
    • 纯文本能力不降反升的多模态模型：NVLM 的一个令人惊讶的发现是——经过精心多模态训练后，模型不仅在多模态任务上表现优异，其在纯文本任务上的表现甚至相比纯文本基线有所提升。具体来说，NVLM-D 72B（基于 Qwen2-72B）在 MMLU 上的成绩从 82% 提升到 84%，在数学推理和代码任务上也均有提升。这表明多模态训练可以提供”正迁移”效应——通过视觉信息增强了语言理解。
    • 动态高分辨率分块（Dynamic High-Resolution Tiling）：NVLM 采用了一种创新的高分辨率处理策略——将高分辨率图像切分为多个动态大小的 tiles（每块 448x448），每个 tile 通过共享的视觉编码器生成嵌入，然后所有 tile 的嵌入与全局缩略图嵌入融合后送入 LLM。tile 的数量和排列根据图像的原始宽高比自适应确定，最大支持 6x6 即 36 个 tiles（约 1.8K 像素分辨率），实现了文档、图表、UI 截图等的精细理解。
    • 双架构并行研究：论文同时提供 Decoder-only 架构（NVLM-D）和 Cross-Attention 架构（NVLM-X）的分析——Decoder-only 将视觉 token 直接拼接在文本 token 之前送入自回归 LLM，实现简单但计算效率随视觉 token 线性增长；Cross-Attention 通过交叉注意力将视觉特征注入 LLM 各层，视觉 token 不参与自回归，长视觉上下文更高效。两者的对比分析为后续架构选择提供了宝贵的实证依据。
  • 代表意义: NVLM 是 NVIDIA 首次以”前端模型开发者”而非”硬件提供者”身份进入 LLM 领域，标志着算力厂商对大模型本身的深度参与。NVLM-72B 在发布时的多项多模态和纯文本基准上与 GPT-4o 持平，证明了开源模型的追赶速度。该工作对”多模态训练有利于纯文本能力”的发现，也为多模态和纯文本”各自为政”的训练模式提供了”为什么不一起训练”的实证佐证。

Cambrian-1: A Fully Open, Vision-Centric Exploration of Multimodal LLMs

  • arXiv: 2406.16860
  • 发表: 2024 年 6 月（NeurIPS 2024 接收），NYU / UC Berkeley / Weizmann Institute 等
  • 作者: Shengbang Tong, Ellis Brown, Penghao Wu 等
  • 简介: Cambrian-1 对多模态 LLM 中的视觉组件进行了系统性的全面探索——包括 18 种视觉编码器、5 种多模态连接器、以及 5 种指令微调数据策略——产出了迄今为止最详细的开源多模态系统设计”配方”，并形成了一个全方位的数据、代码和模型评估生态。
  • 核心创新:
    • 视觉编码器的系统化基准测试：Cambrian-1 评测了 18 种视觉编码器（从 CLIP 到 DINOv2 到 ConvNeXt），得出几个关键结论——（a）不同视觉编码器的优势高度互补（CLIP 擅长语义识别、DINOv2 擅长细粒度空间关系、ConvNeXt 擅长纹理分析），组合多个编码器的视觉特征显著优于单一编码器；（b）视觉编码器的”语言对齐”质量（是否经过图文对比预训练）比其原始视觉能力更关键；（c）视觉编码器的模型大小存在阈值效应——低于 300M 参数时增加规模收益大，超过后收益递减。
    • 视觉连接器的”麻雀虽小五脏俱全”：论文比较了 5 种连接器设计（线性投影、Q-Former、MLP、卷积重采样器、可学习的下采样）的性能，发现最简单的线性投影在绝大多数任务上竟然与最复杂的 Q-Former 相当。但 Q-Former 在需要空间理解的细粒度任务上略有优势。最终推荐的”最优性价比”方案是——使用 2 层 MLP 连接器，在简洁性和效果之间取得最佳平衡。
    • CV-Bench——视觉中心的多维度评估基准：传统 VLM 评估基准倾向于”先看文本问题再找图像证据”，使得纯语言能力较弱的模型在视觉任务上吃亏。Cambrian-1 构建了 CV-Bench，专门评估模型的视觉感知能力（物体计数、空间关系、颜色识别、OCR），将”纯语言能力”这个混淆变量降到最低，提供更公正的视觉能力评测。
  • 代表意义: Cambrian-1 是多模态 LLM 工程领域的”消融实验百科全书”。它没有提出一个全新的架构，而是为多模态模型设计的每个组件提供了系统性的实验证据——为后续研究者和工程师提供了”选什么视觉编码器、用什么连接器、用什么训练数据”的决策依据。它也是”视觉中心主义”多模态研究的代表作——强调”把 Vision 做好”比”把 LLM 做大”更能提升多模态理解能力。

MM1: Methods, Analysis & Insights from Multimodal LLM Pre-training

  • arXiv: 2403.09611
  • 发表: 2024 年 3 月，Apple
  • 作者: Brandon McKinzie, Vadim Sheinin, Vaishaal Shankar 等，Apple
  • 简介: 来自 Apple 团队的多模态 LLM 系统工程论文——通过大规模的消融实验系统分析了多模态预训练的每一个关键决策，最终得出的 MM1 模型达到当时的多模态第一梯队水平，为 Apple Intelligence 的多模态能力提供了技术基础。
  • 核心创新:
    • 多模态设计空间的系统工程化分析：与 Cambrian-1 类似，MM1 对多模态预训练的设计空间进行了大规模消融——包括图像编码器选择、分辨率缩放策略、预训练数据配比（图文对 vs 图文交错文档）、以及连接器设计。关键发现包括——（a）图文交错数据（interleaved）对模型的多图像推理能力至关重要，纯图文对训练无法获得多图像推理能力；（b）分辨率采用”多尺度编码器”（同时输入缩略图和多个高分辨率裁剪块）是最优策略；（c）数据配比的最优点在不同训练阶段不同——预训练需要更多图文对，微调阶段需要更多图文交错数据。
    • SFT 后连续预训练的策略揭示：MM1 的一个重要实验洞察是——在 SFT（监督微调）之后再进行少量的”多模态继续预训练”（multimodal continual pre-training），可以显著修复 SFT 过程中可能丢失的通用视觉理解能力。这说明 SFT 可能导致所谓的”能力坍缩”（模型缩窄到只会在特定格式下回答问题），而后期少量预训练可以将这些泛化能力”找回来”。
    • 合成数据在大规模 VLM 中的有效验证：MM1 的实验证实了合成图像描述数据（由更强大的模型生成的 caption）在预训练中可以有效地替代一部分人类标注的图文对数据。75% 合成数据 + 25% 人类注解数据的混合配比，在绝大多数基准上达到与 100% 人类数据可比的效果，大幅降低了数据成本。
  • 代表意义: MM1 是 Apple 在多模态 LLM 领域的首次系统性技术亮相，为后来的 Apple Intelligence Vision 功能奠定了技术基础。它的技术报告以详实的消融实验著称，为多模态 LLM 的工程决策提供了宝贵的参考。尽管 Apple 没有开源 MM1 的权重，但其技术报告的细节程度（包括数据配比、训练策略、失败案例分析）为开源社区提供了可复现的路线图。

Chameleon: Mixed-Modal Early-Fusion Foundation Models

  • arXiv: 2405.09818
  • 发表: 2024 年 5 月，Meta AI
  • 作者: Chameleon Team, Meta AI
  • 简介: Chameleon 从根本上重新思考了多模态模型的设计——不是在文本 LLM 上”外挂”视觉编码器（late fusion），而是将图像 token 化和文本 token 化进行统一处理，从预训练的第一天起就在图文混合序列上进行 next-token prediction，实现了真正的”原生多模态融合”。
  • 核心创新:
    • 早期融合（Early Fusion）——全 token 统一架构：Chameleon 的核心哲学是”图像和文本在模型眼中应该是同一种东西”。为此，图像被 VQ-VAE 离散化为一系列视觉 token（类似文本 token），然后在 Transformer 中与文本 token 完全平等地混合在一起进行序列建模。模型在任意图文混合序列上使用标准的 next-token prediction 损失进行训练。这种设计不需要专门的视觉编码器、视觉-语言连接器、或特殊的多模态注意力机制——所有模态均在统一的 Transformer 骨干中处理。
    • 图文混合生成能力：因为 Chameleon 统一了 token 空间，它天然拥有”图文混合生成”的能力——模型可以从文本 prompt 生成图像（通过自回归生成视觉 token 然后解码为像素），也可以从图像 prompt 生成文本，甚至可以在一条回复中交替生成文本和图像。这种”任意模态进，任意模态出”的灵活性是 late fusion 架构无法天然实现的。
    • 规模化挑战与价值：Chameleon 的训练极具挑战——图像离散化为 token 后序列长度剧增（一张 512x512 图像约 1024 个视觉 token），对 Transformer 的上下文窗口和计算量带来巨大压力。但论文也展示了早期融合的规模化优势——随着模型和训练数据扩大，Chameleon 在多模态理解任务上的性能持续提升，且对视觉细节的感知能力（如颜色、纹理、空间关系）显著优于 late fusion 模型。MoE 变体（Chameleon-MoE）缓解了部分计算压力。
  • 代表意义: Chameleon 代表了多模态 LLM 的”激进派”——放弃已经验证的 late fusion 路线，回到第一原则重新设计全模态统一的架构。虽然 Chameleon 在 2024 年的性能尚未全面超越最强的 late fusion 模型（如 GPT-4o），但它的技术路线代表了一个更长远的方向——真正通用、模态无关的 AI 序列建模器。Meta 也是唯一在 Chameleon 上投入大量资源的公司，其在这种”原生融合”路线上积累的经验对未来多模态基础模型的发展具有重要参考价值。
