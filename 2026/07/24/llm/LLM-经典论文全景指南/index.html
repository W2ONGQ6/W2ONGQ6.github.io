2017–2026 LLM 演进趋势

2017–2019: Transformer 革命

  • Attention Is All You Need (2017) 提出 Transformer 架构，彻底取代 RNN/LSTM
  • BERT (2018) 用双向编码统治了 NLU 任务
  • GPT-2 (2019) 首次展示了语言模型的多任务零样本能力

2020–2021: 规模时代开启

  • GPT-3 (2020) 175B 参数，证明了 Few-Shot Learning 的巨大潜力
  • Scaling Laws (Kaplan, 2020) 系统性地量化了模型大小、数据、算力的关系
  • LoRA / QLoRA (2021/2023) 让高效微调成为可能

2022: 对齐与能力涌现

  • InstructGPT / RLHF 开创了人类偏好对齐范式
  • Chinchilla 重新定义了最优训练数据量
  • Chain-of-Thought 让 LLM 学会了推理
  • Emergent Abilities 系统描述了规模带来的能力质变

2023: 开源爆发与多模态

  • LLaMA 开放权重，撬动了整个开源生态
  • GPT-4 将多模态和推理能力推上新高度
  • Mistral 7B 展示了小模型的惊人潜力
  • LLaVA / BLIP-2 打开了视觉-语言的大门
  • DPO 提供了比 RLHF 更简单的对齐方案

2024: 推理进化与智能体

  • LLaMA 3/3.1 成为最强的开放模型
  • Mamba / RWKV 等替代架构受到关注
  • 智能体 从概念走向应用（SWE-agent、Devin）
  • o1-preview 展示了全新的推理时计算范式
  • DeepSeek-V3 用极低成本训练出顶级模型

2025–2026: 推理规模化与效率

  • DeepSeek-R1 开源了类 o1 的推理模型，展示了 RL 驱动的推理涌现
  • Qwen3 统一了思考模式与非思考模式
  • 更多基础模型 从训练效率到推理效率全面优化
