推理加速-09：长上下文外推

精选最具代表性的论文，涵盖将 LLM 上下文窗口扩展到预训练长度之外的方法，涉及位置编码创新、高效微调技术以及免训练的推理技巧。

奠基性前身工作

Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation (ALiBi)

  • arXiv: 2108.12409
  • 发表: ICLR 2022
  • 作者: Ofir Press (University of Washington), Noah A. Smith, Mike Lewis (Facebook AI Research / Allen Institute for AI)
  • 简介: 用一种静态的、无须学习的线性偏置替代位置嵌入，将其加到 attention 分数上，使得在短序列上训练的模型无需任何额外训练即可外推到更长的序列。
  • 核心创新:
    • 在 softmax 之前的 attention 分数上添加一个简单的线性偏置 m * distance，按照距离成比例地惩罚远距离 token 之间的 attention。
    • 每个 attention head 获得一个固定的、等比间隔的斜率；完全不使用与位置相关的可学习参数。
    • 在 512 个 token 上训练的模型可有效外推到 3000+ 个 token，在长度泛化方面优于正弦位置编码和旋转位置编码方法。
  • 代表意义: ALiBi 是第一个证明长度外推可以在开箱即用、无需重新训练的情况下工作的方法。它证明了位置信息不需要通过学习或嵌入向量的方式获得——一个简单的加法偏置就足够了。尽管 RoPE 后来成为了主导标准，ALiBi 被 BLOOM 和 MPT 等模型采用，并开创了免训练上下文扩展这一研究领域。

Extending Context Window of Large Language Models via Positional Interpolation (PI)

  • arXiv: 2306.15595
  • 发表: arXiv, June 2023
  • 作者: Shouyuan Chen, Sherman Wong, Liangjian Chen, Yuandong Tian (Meta AI)
  • 简介: 将 RoPE 的位置索引线性地缩小，使其落在原始预训练范围内，然后进行短暂的微调，以极小的计算代价将上下文窗口扩展到 32K token。
  • 核心创新:
    • Position Interpolation：将所有位置索引按因子 L'/L（L 为原始上下文长度，L’ 为目标长度）进行缩放，使得模型永远不会遇到未经训练的位置。
    • 作者提供了理论证明，表明插值误差比外推误差至少小约 600 倍。
    • 仅需在少量长上下文数据上进行约 1,000 步微调。
  • 代表意义: PI 是第一个实用的、被广泛采用的基于 RoPE 的上下文扩展方法。它确立了”插值优于外推”的范式，此后所有 RoPE 扩展方法（NTK、YaRN、LongRoPE）都建立在此基础之上。在 PI 出现之前，从业者仅能在模型的预训练上下文长度内使用模型；在 PI 之后，扩展上下文成为了一个标准的微调步骤。

核心论文

RoFormer: Enhanced Transformer with Rotary Position Embedding (RoPE)

  • arXiv: 2104.09864
  • 发表: Neurocomputing (Elsevier), Volume 568, February 2024 (arXiv 预印本自 2021 年 4 月起)
  • 作者: Jianlin Su, Murtadha Ahmed, Yu Lu, Shengfeng Pan, Wen Bo, Yunfeng Liu (追一科技)
  • 简介: 通过在复平面中旋转 query 和 key 向量来编码位置信息，通过点积自然地编码相对位置差异，从而能够通过频率缩放实现长度外推。
  • 核心创新:
    • Rotary Position Embedding：对 query 和 key 向量施加旋转矩阵，旋转角度与 token 的绝对位置成正比。点积 q_i^T k_j 于是仅依赖于相对位置 i - j。
    • 不同的频率分量（RoPE 的不同维度）以不同的速度旋转，创造出一种随距离衰减的多尺度位置表示。
    • 通过调整旋转频率（base 参数），无需改变架构即可天然支持序列长度外推。
  • 代表意义: RoPE 是几乎所有现代开源 LLM 的事实标准位置编码——LLaMA（全部版本）、Mistral、Qwen、DeepSeek、Gemma、Phi、Falcon 等等。从 PI 开始的每一篇上下文扩展论文都以 RoPE 模型为基础。其优雅的数学形式以及相较于可学习/正弦嵌入的经验优势，使其成为整个长上下文外推领域的基础。

YaRN: Efficient Context Window Extension of Large Language Models

  • arXiv: 2309.00071
  • 发表: ICLR 2024
  • 作者: Bowen Peng, Jeffrey Quesnelle, Honglu Fan, Enrico Shippole
  • 简介: 通过应用非均匀频率插值（NTK-aware + NTK-by-parts）和动态 attention 温度缩放，仅需 400 步训练即可将基于 RoPE 的 LLM 扩展到 64K-128K 的上下文窗口。
  • 核心创新:
    • NTK-aware 插值: 与对所有 RoPE 频率进行相同线性缩放（这会破坏高频局部信息）不同，YaRN 以非均匀方式分布插值——高频维度（短波长）获得较少缩放，从而保持局部位置敏感度。
    • NTK-by-parts: 波长小于原始上下文长度的维度完全不进行插值（局部距离被精确保留）。波长远大于原始上下文长度的维度接受完整插值。一个 ramp 函数处理中间情况。
    • Attention 温度缩放: 在更长的上下文下动态增加 softmax 温度，以抵消由于远距离 token 位置之间的余弦相似度降低而导致的熵坍塌。
  • 代表意义: YaRN 成为最广泛采用的 RoPE 扩展方法。它仅需 0.1% 的原始预训练数据（400 步）即可达到 128K 上下文，保持短上下文性能，支持 Flash Attention 2，并被 NousResearch 用于在 Hugging Face 上发布广泛使用的扩展版 LLaMA 2 和 Mistral 模型。其 NTK-aware 方法影响了几乎所有后续的 RoPE 扩展工作。

LongLoRA: Efficient Fine-tuning of Long-Context Large Language Models

  • arXiv: 2309.12307
  • 发表: ICLR 2024
  • 作者: Yukang Chen, Shengju Qian, Haotian Tang, Xin Lai, Zhijian Liu, Song Han, Jiaya Jia (CUHK / MIT / UMass)
  • 简介: 使用 Shifted Short Attention (S2-Attn) 进行训练，并将 LoRA 最小限度地扩展到包含 embedding 和 normalization 层，从而实现在单台 8xA100 机器上将 LLaMA 模型微调至 100K 上下文长度。
  • 核心创新:
    • Shifted Short Attention (S2-Attn): 将 attention head 分成两组；一组在连续分块上执行常规的分组 attention，另一组在应用分组 attention 之前将 token 平移半个 group size。这在训练时近似于完整的全局 attention，同时每个 group 保持 O(n) 复杂度。
    • LoRA+: 将标准 LoRA（仅训练 attention 投影权重）扩展为同时训练 embedding 和 normalization 层。Normalization 层仅占 Llama2-7B 参数的 0.004%，但训练它们能显著缩小与全量微调的差距。
    • 稀疏 attention 仅在训练时使用；在 inference 时，模型使用标准的密集 attention——无架构变更，完全兼容 Flash Attention 2。
  • 代表意义: LongLoRA 通过使长上下文微调在单台 8-GPU 机器上变得可行，实现了长上下文微调的民主化。其 S2-Attn 方法简洁优雅（仅两行代码）却十分有效，并确立了一个原则：训练时的 attention 和推理时的 attention 可以不同——这一关键洞见被后续工作反复使用。它还发布了被广泛使用的 LongAlpaca 数据集，用于长上下文指令微调。

PoSE: Efficient Context Window Extension with Positional Skip-wise Training

  • arXiv: 2309.10400
  • 发表: ICLR 2024
  • 作者: Dawei Zhu, Nan Yang, Liang Wang, Yifan Song, Wenhao Wu, Furu Wei, Sujian Li (北京大学 / Microsoft Research)
  • 简介: 在固定长度的短序列上训练，通过操控跳跃式位置索引来模拟任意远距离依赖关系，将训练长度与目标上下文长度完全解耦。
  • 核心创新:
    • Positional Skip-wisE 训练: 将训练上下文窗口划分为若干分块，然后为每个分块的位置索引添加不同的跳跃偏置项。通过在每个训练样本上变化跳跃偏置和分块长度，模型能够看到目标上下文范围内的所有可能的相对位置对。
    • 实现了仅用 2K 训练长度达到 128K 上下文扩展——与全长度微调相比，训练内存减少了 64 倍。
    • 兼容所有基于 RoPE 的模型（LLaMA、LLaMA2、Baichuan2）和所有插值策略（Linear、NTK、YaRN）。理论上支持无限上下文长度。
  • 代表意义: PoSE 证明了长上下文数据对于上下文扩展并非必要——只有接触到长距离位置索引才是关键。这一洞见是根本性的：它将”数据问题”与”位置编码问题”分离开来。跳步训练范式影响了后续工作，并证明了仅用短序列训练数据就能实现高效的上下文扩展。

LLM Maybe LongLM: Self-Extend LLM Context Window Without Tuning (SelfExtend)

  • arXiv: 2401.01325
  • 发表: ICML 2024 (Spotlight)
  • 作者: Hongye Jin, Xiaotian Han, Jingfeng Yang, Zhimeng Jiang, Zirui Liu, Chia-Yuan Chang, Huiyuan Chen, Xia Hu (Texas A&M University)
  • 简介: 仅在推理过程中扩展 LLM 的上下文窗口，无需任何微调，通过构建一种双层 attention 机制，使用 floor division 将远距离位置映射到模型的训练范围内。
  • 核心创新:
    • Floor Division attention: 对于分组 attention head，将位置 i 映射到 floor(i / group_size)，将远距离位置折叠到模型的训练范围内。这使模型能够仅使用其已经掌握的 attention 模式来关注超出原始上下文限制的 token。
    • 双层 attention: 将分组 attention（用于长距离依赖）与标准邻居 attention（用于窗口内的局部上下文）相结合，两者均使用原始模型权重计算，不做任何修改。
    • 免训练: 开箱即用，适用于 Llama、Mistral、Phi-2、Qwen、Gemma 及其他基于 RoPE 的模型。推理时仅需约 4 行代码修改。
  • 代表意义: SelfExtend 证明了 LLM 固有地具备长上下文能力，这些能力可以在不进行训练的情况下被”解锁”。这是一个深刻的发现——它表明在标准预训练过程中，模型已经学会处理超出其名义上下文窗口的位置，但标准的 attention 机制无法访问这种能力。该方法在 Google I/O 2024 上被用于展示 Gemma 的长上下文能力。

LongRoPE: Extending LLM Context Window Beyond 2 Million Tokens

  • arXiv: 2402.13753
  • 发表: ICML 2024
  • 作者: Yiran Ding, Li Lyna Zhang, Chengruidong Zhang, Yuanyuan Xu, Ning Shang, Jiahang Xu, Fan Yang, Mao Yang (Microsoft Research)
  • 简介: 通过对不同维度和层的最优非均匀 RoPE 频率重缩放因子进行进化搜索，将基于 RoPE 的 LLM 推至创纪录的 2,048K（200 万）token 上下文窗口。
  • 核心创新:
    • 进化搜索 RoPE 重缩放因子: 发现不同的 RoPE 维度和不同的层受益于不同程度的插值量。低维度和早期层比高维度和后期层需要更少的插值。
    • 渐进式扩展策略: 首先在 256K 上下文长度上微调，然后应用第二次位置插值步骤以达到 2048K——避免了直接在 2M 长度序列上训练的需要。
    • 短上下文恢复: 在推理时重新调整 8K 长度的 RoPE 因子，以防止通常伴随极端上下文扩展而出现的短序列性能退化，实现超过 90% 的 passkey 检索准确率。
  • 代表意义: LongRoPE 创下了基于 RoPE 的模型可实现的最长上下文窗口纪录（2M token），并被集成到微软的 Phi-3 模型家族中（Phi-3-mini/small/medium/vision 128K-instruct 变体）。其发现——不同层需要不同的 RoPE 频率——是一个根本性的架构洞察：它表明即使在单个模型内部，位置编码也不是一个一刀切的问题。

CLEX: Continuous Length Extrapolation for LLMs

  • arXiv: 2310.16450
  • 发表: ACL 2024 (Main Conference)
  • 作者: Guanzheng Chen, Xin Li, Zixuan Meng, Shiqian Liang, Lidong Bing (Sea AI Lab / NUS)
  • 简介: 将位置编码建模为连续函数（通过神经 ODE 学习），而非离散插值——使模型可以在训练时使用短序列学习位置编码的连续动态，在推理时外推到任意长度。
  • 核心创新:
    • 神经 ODE 位置编码: 将 RoPE 的旋转角度演进建模为一个由小型神经网络参数化的连续动态系统——d(rotation_angle)/d(position) = NN(position, rotation_angle)。神经 ODE 求解器可以输出任意位置的位置编码，不受离散点限制
    • 训练与外推的统一: RoPE 参数化后，模型的训练过程自动包含了对连续位置外推的学习——因为神经 ODE 学会了”位置编码如何随位置变化”，而非仅记忆特定位置的位置编码
    • 极小参数开销: 神经 ODE 网络仅增加约 0.01% 的额外参数，对训练速度和内存的影响可忽略
    • 与插值方法的协同: CLEX 可以与 PI、NTK、YaRN 等插值方法联合使用——先用插值方法扩展到目标长度，再用 CLEX 学习泛化到更长长度
    • 在 LLaMA-2 上从 4K 训练长度直接外推到 32K 推理长度，困惑度保持稳定
  • 代表意义: CLEX 将位置编码从离散的”点对点映射”升级为连续的”动态系统学习”。其神经 ODE 框架赋予位置编码两个关键能力——（1）支持任意长度的外推（不再受预定义的 RoPE base 或插值范围的限制）和（2）学习特定任务/数据的最优位置编码动态。这一理论与 DeepSeek-V2 的 MLA（也使用连续压缩表示）有概念上的共鸣。

LM-Infinite: Simple On-the-Fly Length Generalization for LLMs

  • arXiv: 2308.16137
  • 发表: NAACL 2024
  • 作者: Chi Han, Qifan Wang, Wenhan Xiong, Yu Chen, Heng Ji, Sinong Wang (UIUC / Meta AI)
  • 简介: 提出极简的推理时长上下文外推方法——仅需在注意力计算中添加一个 Lambda 形衰减掩码和限制距离的 softmax——无需插值、无需微调、无需修改模型，即可实现从 2K 到 32K 的外推。
  • 核心创新:
    • Lambda 形注意力掩码: 在注意力分数上叠加一个随距离增加的惩罚项——近距离的 token 保持完整注意力，随着距离超过某个阈值，注意力呈 lambda 形衰减。衰减形状由两个超参数控制：衰减开始的距离和衰减强度
    • 距离限制 softmax: 在 softmax 分母中引入一个距离相关的修正项——距离越远，分母中的贡献越小，等效于降低远距离 token 的有效注意力权重
    • 完全不需要训练: 两个超参数可以通过在少数长上下文样本上进行网格搜索来确定，无需任何模型参数修改
    • 即插即用: 适用于所有基于 RoPE 的预训练模型（LLaMA、Mistral、Qwen 等），仅需在推理代码中添加约 5 行代码
    • 在 LLaMA-2-7B 上从 2K 外推到 32K，在 passkey retrieval 和长文档 QA 上实现了可用的准确率
  • 代表意义: LM-Infinite 代表了”极简主义”的极致——它证明了仅需在推理时修改注意力分数，就能实现有意义的长上下文外推。虽然其质量不如 YaRN 或 SelfExtend 等更复杂的方法，但其零训练、零微调、零模型的特性使其成为最易部署的长上下文方案。该方法特别适合对延迟敏感的应用（因为不增加任何计算开销）。

ChunkLlama: Efficient Long-Context Processing with Dynamic Chunk Attention

  • arXiv: 2402.09741
  • 发表: arXiv，2024 年 2 月
  • 作者: Yukang Chen, Shengju Qian, Haotian Tang, Xin Lai, Zhijian Liu, Song Han, Jiaya Jia (CUHK / MIT / UMass)
  • 简介: 在 LLM 中引入”分块检索-详细关注”两阶段注意力——第一阶段使用粗粒度的分块级注意力快速定位相关信息，第二阶段仅在相关块内进行精细的 token 级注意力——在长上下文下实现 6-10 倍注意力加速。
  • 核心创新:
    • 双粒度注意力: 第一阶段使用分块级 key（每个分块的代表性 key）进行粗糙但快速的注意力计算，选择 top-k 个最相关的分块；第二阶段仅在被选中的分块内进行标准的 token 级注意力
    • 动态分块大小: 分块大小根据序列长度和上下文类型动态调整——信息密集的上下文（如代码）使用较小的分块（更精细的检索），信息稀疏的上下文（如重复文本）使用较大的分块
    • 分块摘要向量: 为每个分块计算一个摘要 key 向量（如分块内所有 key 的平均值或 L2 pooling），用于第一阶段的快速相关性评估
    • 与 RoPE 兼容的分块策略: 分块时保留 RoPE 的相对位置信息，确保位置编码在分块级别仍然有效
    • 在 LLaMA-2-7B 上以 128K 上下文实现 6-10 倍注意力加速，在 LongBench 和 Needle-in-Haystack 上性能无损
  • 代表意义: ChunkLlama 将信息检索中的”粗筛-精排”范式引入了 LLM 注意力计算——先用廉价的分块级注意力快速过滤，再用昂贵的 token 级注意力精细处理。它代表了”分层注意力”方向的最优工程实现。其动态分块策略是一个实用的贡献——不同上下文类型确实需要不同的检索粒度。

Resonance RoPE: Improving Context Length Generalization of LLMs

  • arXiv: 2403.00071
  • 发表: ACL 2024 (Findings)
  • 作者: Suyuchen Wang, Ivan Kobyzev, Peng Lu, Mehdi Rezagholizadeh, Bang Liu (Mila / Université de Montréal / Huawei Noah’s Ark Lab)
  • 简介: 解决 RoPE 外推中的”共振”问题——某些频率分量在训练窗口内形成驻波模式，在外推时这些模式被破坏——通过频谱平滑和频率重分布来消除共振，实现更平滑的长度外推。
  • 核心创新:
    • RoPE 共振问题识别: 发现 RoPE 的某些频率分量（尤其是基频的整数倍）在预训练上下文长度内形成完整的周期振荡（”共振”），在外推时，这些模式因为缺少对称边界而被破坏，导致困惑度突然上升
    • 频谱平滑策略: 对 RoPE 的频率分布进行平滑处理——使用高斯平滑核或多项式拟合并，消除那些与上下文长度形成整数倍关系的”危险频率”
    • 最低频率扩展: 将 RoPE 的 base theta 参数调整，使最低频率的周期远大于目标上下文长度（而非预训练上下文长度），避免低频分量在目标长度内完成不完整的周期
    • 频率自适应重缩放: 不是对所有频率进行均匀缩放（如 PI），而是仅对”共振风险”的频率进行缩放，保持非共振频率不变
    • 在 LLaMA-2 和 Mistral 上从 4K 外推到 32K，困惑度比标准 PI 低约 0.5-1.0
  • 代表意义: Resonance RoPE 提供了一个”频域”视角来分析位置编码的外推行为——不是从 token 距离的角度，而是从频率分量的角度。其共振理论解释了许多 RoPE 外推失败案例的根本原因（如某些模型在特定长度下突然崩溃），为更稳定的外推方法设计提供了理论指导。

Infini-Attention: Unbounded Context with Compressive Memory

  • arXiv: 2404.07143
  • 发表: ICML 2024
  • 作者: Tsendsuren Munkhdalai, Manaal Faruqui, Siddharth Gopal (Google Research)
  • 简介: 在标准 Transformer 中引入一个压缩记忆模块——将 KV cache 中被驱逐的旧 token 在线压缩到一个固定大小的记忆矩阵中——使标准 Transformer 在不增加计算量的前提下获得无限上下文能力。
  • 核心创新:
    • 压缩记忆（Compressive Memory）: 在标准注意力之外，维持一个固定大小的记忆矩阵 M（shape: d_model x d_mem）。当 KV cache 中的旧 token 被滑动窗口驱逐时，它们通过 delta-like 的在线更新被压缩到 M 中——类似于 DeltaNet 的记忆更新规则
    • 双重注意力: 每个 token 同时关注（1）滑动窗口内的近期 token（标准局部注意力）和（2）压缩记忆 M 中的全局信息（记忆注意力），两者输出通过可学习的门控融合
    • 线性时间和 O(d^2) 记忆: 压缩记忆的大小 O(d_model x d_mem) 与序列长度无关，其中 d_mem 通常设为 d_model 或更小，因此计算复杂度随序列长度线性增长
    • 持续预训练策略: Infini-Transformer 首先作为标准 Transformer 预训练，然后通过持续预训练添加压缩记忆模块
    • 在 1B 模型上用 5K 上下文预训练，在 1M token 的 passkey retrieval 任务上实现 100% 准确率（标准 Transformer 在 5K 以上完全失败）
  • 代表意义: Infini-Attention 是一个优雅的解决方案——不修改 Transformer 的核心架构，而是在其基础上添加一个”上下文垃圾回收器”（压缩记忆）。它将长上下文处理从”保留所有 KV cache”转变为”压缩旧 token、保留新 token”，类似人类”遗忘细节但保留要点”的记忆机制。Google 已在 Gemini 1.5 Pro 的架构中采用了类似的思想。

LongAlign: A Recipe for Long Context Alignment of LLMs

  • arXiv: 2401.18058
  • 发表: EMNLP 2024
  • 作者: Yushi Bai, Xin Lv, Jiajie Zhang, Yu He, Ji Qi, Lei Hou, Jie Tang, Yuxiao Dong, Juanzi Li (清华大学 / Zhipu AI)
  • 简介: 提供了首个系统性的长上下文对齐方案——包括长上下文指令数据构建、打包与排序策略、以及 SFT 和 RLHF 的训练配方——证明了”上下文扩展”和”上下文对齐”是两个独立但互补的过程。
  • 核心创新:
    • LongAlign 数据集: 从 9 个长文档来源（书籍、论文、代码库、对话记录等）构建了约 10K 个长上下文指令-响应对，覆盖 8 种任务类型（摘要、QA、信息检索、生成等），序列长度 8K 到 64K
    • 长度平衡的打包策略: 在训练批次中按序列长度打包样本，确保每个 GPU 处理相似的总 token 数，避免因序列长度不均导致的负载不均衡
    • 整理排序策略: 训练数据按难度和长度进行排序和课程式排列——从短上下文到长上下文逐步过渡，使模型逐步适应长上下文
    • SFT + DPO 两阶段对齐: 第一阶段使用 LongAlign SFT 数据让模型学会在长上下文中遵循指令，第二阶段使用 DPO 偏好数据优化模型在长上下文任务中的输出质量
    • 将 ChatGLM3-6B（上下文 8K）扩展到 64K，在 LongBench-Chat 上提升约 30% 的性能
  • 代表意义: LongAlign 填补了长上下文研究的一个重要空白——大多数工作关注”如何扩展上下文窗口”（YaRN、PI、LongRoPE），但很少关注”扩展后如何对齐”。LongAlign 证明了上下文扩展只是第一步，让模型在长上下文中表现良好还需要专门的对齐训练。其方法和数据集已被 Zhipu AI 的 GLM-4 系列模型采用。
