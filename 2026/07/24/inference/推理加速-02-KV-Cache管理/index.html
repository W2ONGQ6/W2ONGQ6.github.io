推理加速-02：KV-Cache 管理与量化

精选的 LLM 推理中 KV cache 压缩、驱逐与量化代表性论文列表，2023–2024。

论文

StreamingLLM: Efficient Streaming Language Models with Attention Sinks

  • arXiv: 2309.17453
  • 发表: ICLR 2024
  • 作者: Guangxuan Xiao, Yuandong Tian, Beidi Chen, Song Han, Mike Lewis (MIT, Meta AI, CMU, NVIDIA)
  • 简介: 发现了”注意力汇”（attention sink）现象——初始 token 吸收了过多的注意力，并证明仅保留 4 个初始 token 加一个滑动窗口即可实现稳定的无限长度流式推理，无需微调。
  • 核心创新:
    • Attention sink 的发现：无论语义内容如何，初始 token 都会获得不成比例的高注意力分数；驱逐它们会导致灾难性的困惑度爆炸（例如，Llama-2-7B 从约 10 PPL 跃升至 5158 PPL）
    • 简单修复：在 KV cache 中保留 4 个初始 sink token，并配合一个滚动窗口保留最近的 token；可实现对超过 400 万 token 序列的稳定推理
    • RoPE 位置重映射：持续重映射位置，使 sink token 占据位置 0–3，最近的 token 占据位置 4 及以后，避免分布外的位置编码
    • 可选的 learnable sink token：在预训练期间添加专用的 sink token，仅需一个 sink token 即可实现稳定流式推理，且零样本基准测试性能无损失
  • 代表意义: 揭示了预训练 LLM 中注意力工作机制的一个基本属性。Attention sink 的洞察影响了整个领域的 KV cache 管理策略（StreamingLLM 通常与量化和驱逐方法结合使用）。它使得任何预训练 LLM 都能以常量内存在真正的流式、无限长度场景中部署——这对聊天机器人和实时 agent 应用至关重要。

H2O: Heavy-Hitter Oracle for Efficient Generative Inference of Large Language Models

  • arXiv: 2306.14048
  • 发表: NeurIPS 2023
  • 作者: Zhenyu Zhang, Ying Sheng, Tianyi Zhou, Tianlong Chen, Lianmin Zheng, Ruisi Cai, Zhao Song, Yuandong Tian, Christopher Re, Clark Barrett, Zhangyang Wang, Beidi Chen (UT Austin, Stanford, UCSD, UC Berkeley, Adobe Research, Meta AI, CMU)
  • 简介: 识别出”重击者”（heavy hitter）token——这些 token 按幂律分布主导累计注意力分数——并使用贪婪驱逐策略同时保留重击者和最近的 token，实现 20 倍 KV cache 缩减且准确性损失极小。
  • 核心创新:
    • 重击者识别：推理时的注意力矩阵超过 95% 稀疏；少量 token 在累计注意力中遵循幂律分布，对生成质量至关重要
    • 贪婪驱逐策略：基于累计局部注意力分数动态驱逐 token，被表述为一个具有理论保证的动态子模最大化问题
    • 无需前瞻：驱逐决策仅使用已计算的注意力分数，使其轻量且与流式生成兼容
    • 相比 DeepSpeed 和 HuggingFace 基线，吞吐量提升高达 29 倍，延迟相比 FlexGen 降低 1.9 倍
  • 代表意义: 最具影响力的 KV cache 驱逐策略之一。Heavy-hitter 的概念已被许多后续工作（FastGen、ScissorHands、PyramidKV）采纳和扩展。H2O 的贪婪策略特别实用，因为它可以在推理时使用，无需校准数据或微调，现已集成到 Hugging Face Transformers 中。

KIVI: A Tuning-Free Asymmetric 2bit Quantization for KV Cache

  • arXiv: 2402.02750
  • 发表: ICML 2024
  • 作者: Zirui Liu, Jiayi Yuan, Hongye Jin, Shaochen Zhong, Zhaozhuo Xu, Vladimir Braverman, Beidi Chen, Xia Hu (Rice University, CMU)
  • 简介: 通过对 key 使用非对称逐通道量化、对 value 使用逐 token 量化，实现 2-bit KV cache 量化且准确性损失极小，无需校准数据或微调。
  • 核心创新:
    • 非对称量化策略：发现 key cache 具有逐通道异常值（少量固定通道具有大数值），适合逐通道量化；value cache 没有持续的通道结构，适合逐 token 量化
    • 对 key 和 value 均采用 2-bit 非对称格式（scale + zero-point），包括模型权重在内峰值内存减少 2.6 倍
    • 免调参设计：无需校准集、无需微调、无需逐模型超参数调优——在 LLaMA、Falcon、Mistral、LLaMA-3 上开箱即用
    • 流式处理时使用小型 FP16 残差缓冲区存储最近的 token，结合分块量化使摊销内存接近 2-bit 目标
    • 在实际工作负载上吞吐量提升 2.35–3.47 倍，支持高达 4 倍更大的 batch size
  • 代表意义: 将 KV cache 量化推向极致（2 bit），同时保持实际可用性（无需调参）。逐通道 vs. 逐 token 的非对称性洞察后来被发现与 RoPE 对 key 投影的交互有关，并启发了 Hugging Face Transformers 的 QuantizedCache 实现。代表了 KV cache 在不损失质量的情况下可以多激进地被压缩的前沿。

KVQuant: Towards 10 Million Context Length LLM Inference with KV Cache Quantization

  • arXiv: 2401.18079
  • 发表: NeurIPS 2024
  • 作者: Coleman Hooper, Sehoon Kim, Hiva Mohammadzadeh, Michael W. Mahoney, Yakun Sophia Shao, Kurt Keutzer, Amir Gholami (UC Berkeley, ICSI, LBNL)
  • 简介: 一个全面的 KV cache 量化系统，包含五项新技术，支持在 1M+ 上下文长度下进行 3–4 bit 量化，在 4.8 倍压缩下困惑度退化小于 0.1。
  • 核心创新:
    • Pre-RoPE key 量化：在应用旋转位置嵌入（RoPE）之前量化 key，因为 RoPE 会混合通道对并破坏在 RoPE 之前保持一致的异常值幅度
    • 逐向量稠密-稀疏量化：逐向量（key 按通道、value 按 token）隔离异常值并以稀疏表示存储，防止异常值扭曲量化范围
    • 非均匀量化（NUQ）：利用 Fisher 信息和 k-means 导出逐层灵敏度加权的非均匀数据类型，提供比均匀量化更好的量化标点布局
    • Q-Norm：在量化后对量化中心进行归一化以缓解分布偏移，在 2-bit 精度下尤为关键
    • 可在单张 A100-80GB 上以 1M 上下文、在 8 GPU 系统上以 10M 上下文来服务 LLaMA-7B
  • 代表意义: 最全面、工程化程度最高的 KV cache 量化系统，使 Gemini 1.5 Pro 等模型所需的极端长上下文推理（10M token）成为可能。Pre-RoPE 量化技术已成为许多后续工作采纳的标准最佳实践。证明了通过精心的工程设计，KV cache 量化即使在非常激进的压缩比下也能实现几乎无损的质量。

MiniCache: KV Cache Compression in Depth Dimension for Large Language Models

  • arXiv: 2405.14366
  • 发表: arXiv 预印本，2024 年 5 月（审稿中，NeurIPS 2024）
  • 作者: Akide Liu, Jing Liu, Zizheng Pan, Yefei He, Gholamreza Haffari, Bohan Zhuang (Monash University, ZIP Lab)
  • 简介: 在深度维度（而非仅仅序列长度）上压缩 KV cache，利用相邻层 KV 状态之间的高度相似性，实现高达 5 倍压缩且性能几乎无损。
  • 核心创新:
    • 跨层 KV 相似性：观察到 LLM 中深层区域的相邻层 KV cache 状态高度相似（cosine similarity > 0.9），使得深度维度合并成为可能
    • 幅度-方向解耦：在合并相邻层之前，将每个 KV 状态向量分离为幅度和方向分量，对方向进行插值同时保持原始幅度不变
    • Token 保留策略：选择性地将高度不同的状态对保持不合并，保留标记的存储开销极小
    • 与其他方法互补：可与序列级驱逐、token 级稀疏性和基于量化的压缩方法协同工作；结合 4-bit 量化实现 5 倍压缩
    • 相比 FP16 全量 cache 基线，内存占用减少 41%，在 ShareGPT 上吞吐量提升约 5 倍
  • 代表意义: 独特之处在于沿深度维度压缩 KV cache，而非更常见的序列维度和 token 维度。代表了与其他 KV cache 技术互补（而非替代）的正交压缩维度。跨层相似性的观察也为模型架构开辟了新的设计空间。

SnapKV: LLM Knows What You are Looking for Before Generation

  • arXiv: 2404.14469
  • 发表: arXiv 预印本，2024 年 4 月（审稿中）
  • 作者: Yuhong Li, Yingbing Huang, Bowen Yang, Bharat Venkitesh, Acyr Locatelli, Hanchen Ye, Tianle Cai, Patrick Lewis, Deming Chen (UIUC, Cohere For AI, Princeton)
  • 简介: 通过分析 prompt 末尾附近”观察窗口”中的注意力模式来压缩 KV cache，仅选择性保留最重要的 KV 位置，在 16K 上下文下实现 3.6 倍生成加速。
  • 核心创新:
    • 观察窗口：利用 prompt 末尾的一个小窗口来观察每个注意力头持续关注的 prompt token，无需完整 KV cache 即可完成分析
    • Prompt 驱动的压缩：每个注意力头的重要位置根据观察到的注意力模式独立确定，实现针对每个注意力头的保留策略
    • 无需微调和校准：适用于任何预训练 LLM，无需额外训练或校准数据
    • 在单张 A100-80GB GPU 上处理 380K token，在 Needle-in-a-Haystack 和 16 个长序列基准上精度下降可忽略
    • 在 16K 输入长度下，生成速度提升 3.6 倍，内存效率提升 8.2 倍
  • 代表意义: 一种实用的、感知 prompt 的 KV cache 压缩方法，在部署时无需任何准备工作即可使用。观察窗口技术优雅，因为它利用 LLM 自身的注意力模式来决定保留什么，而非依赖启发式或校准。代表了基于运行时行为而非静态分析来做压缩决策的趋势。

CacheGen: KV Cache Compression and Streaming for Fast Large Language Model Serving

  • arXiv: 2310.07240
  • 发表: SIGCOMM 2024
  • 作者: Yuhan Liu, Hanchen Li, Yihua Cheng, Siddhant Ray, Yuyang Huang, Qizheng Zhang, Kuntai Du, Jiayi Yao, Shan Lu, Ganesh Ananthanarayanan, Michael Maire, Henry Hoffmann, Ari Holtzman, Junchen Jiang (University of Chicago, Microsoft)
  • 简介: 通过网络压缩和流式传输 KV cache 来减少上下文加载延迟，利用 token 局部性和层敏感度进行自适应流式传输，实现 3.5–4.3 倍 KV cache 大小缩减和 3.2–3.7 倍 TTFT 降低。
  • 核心创新:
    • 自定义 tensor 编码器：利用 token 局部性（编码相邻 token 的 delta tensor）、层敏感度（浅层使用更精细量化）以及通道-层分布（GPU 并行算术编码），实现接近熵极限的压缩
    • 自适应流式传输：将 KV cache 分割成块，根据可用带宽自适应调整每个块的压缩级别，实现低延迟流式传输而非等待完整解压
    • 网络感知设计：针对”网络墙”问题——通过网络获取大 KV cache（例如 Llama-34B 在 80K token 下为 19 GB）成为瓶颈
    • 各任务质量退化可忽略（准确率下降 ≤2%，困惑度/F1 下降 ≤0.1%）
    • 集成到 LMCache 项目中进行实际部署
  • 代表意义: 解决了分布式服务系统中 KV cache 传输这一被忽视的问题。随着 LLM 服务向分离式架构（独立的 prefill 和 decode 节点）发展，网络成为上下文切换的瓶颈。CacheGen 的网络感知方法桥接了 KV cache 压缩和分布式系统两个社区，而 LMCache 的集成确保了实际影响力。

InfiniGen: Efficient Generative Inference of Large Language Models with Dynamic KV Cache Management

  • arXiv: 2406.19707
  • 发表: arXiv，2024 年 6 月
  • 作者: Wonbeom Lee, Jungbeom Lee, Junghyun Seo, Jaewoong Sim (Seoul National University)
  • 简介: 在生成过程中动态预测每个注意力头所需的最优 KV cache 条目数量，通过”按需”分配策略实现 3-4 倍压缩，避免对所有头使用统一的保留预算。
  • 核心创新:
    • 每头自适应预算分配：发现不同注意力头对 KV cache 的敏感度差异巨大——某些头仅需 10% 的 KV 条目即可保持质量，而其他头需要 80% 以上。InfiniGen 在生成时动态预测每个头所需的 KV 预算
    • 基于查询相似度的在线预测器：利用当前 query 与历史 query 的余弦相似度来预测哪些 KV 条目最可能被需要，无需额外的离线训练或校准
    • 预算池化策略：不固定每个头的 KV 保留数量，而是分配一个总预算池，让不同头根据实时需求竞争分配，最大化整体资源利用效率
    • 与 KIVI 等量化方法正交兼容，可叠加使用实现 8 倍以上的综合压缩
    • 在 LLaMA-3-8B 的 LongBench 长上下文基准测试上，以 3 倍 KV cache 压缩实现了与全量 cache 相当的性能
  • 代表意义: InfiniGen 的核心贡献在于揭示了”一刀切”的 KV cache 驱逐策略的次优性——不同注意头对上下文的依赖程度本质不同。其动态预算分配策略将 KV cache 管理从一个固定的压缩问题转变为一个在线资源分配问题。这一洞见与 Anthropic 的”注意力头专业化”发现相呼应，对下一代 KV cache 管理系统设计有重要参考价值。

Quest: Query-Aware Sparsity for Efficient Long-Context LLM Inference

  • arXiv: 2406.10774
  • 发表: ICML 2024 (Poster)
  • 作者: Jiaming Tang, Yilong Zhao, Kan Zhu, Guangxuan Xiao, Baris Kasikci, Song Han (MIT / NVIDIA)
  • 简介: 在推理时通过 query 向量与 KV cache 的分块近似内积来识别最重要的 KV 分块，仅对选中的分块进行精确注意力计算，在 128K 上下文下实现 7 倍注意力加速。
  • 核心创新:
    • Query-Aware 分块选择：将 KV cache 按序列长度维度分割为固定大小的分块，对每个分块使用 query 与分块最大内积的快速上界估计，仅选择 top-k 个分块参与精确注意力计算。这一策略确保注意力计算集中在最相关的信息上
    • 无额外索引开销：分块选择直接使用 KV cache 中的已有数据，无需构建额外的向量索引或哈希表。上界估计仅需少量矩阵运算，计算开销极小（< 2%）
    • 理论保真度保证：证明了所选 top-k 分块包含的注意力质量（attention mass）有下界保证，确保不会遗漏关键信息
    • GPU 友好的分块设计：分块大小与 GPU tile 大小对齐，最大化 TensorCore 利用率
    • 在 128K 上下文的 LLaMA-3-8B 上实现 7.1 倍注意力加速，端到端生成延迟降低约 2.4 倍
  • 代表意义: Quest 代表了注意力稀疏化中”分块级重要性采样”方向的最优实现。与 token 级别的稀疏注意力（如 H2O、StreamingLLM）不同，Quest 在分块级别进行选择，既保留了 GPU 友好的密集矩阵乘法模式，又大幅减少了计算量。其 query-aware 的设计是核心——不同于静态地（在 prefill 阶段）决定保留哪些 KV 条目，Quest 在每一步 decode 时根据当前 query 动态选择，代表了从”静态压缩”到”动态查询”的范式转变。

PyramidKV: Dynamic Budget Allocation for Heterogeneous Attention Heads in KV Cache Compression

  • arXiv: 2406.02069
  • 发表: arXiv，2024 年 6 月
  • 作者: Zhuocheng Zhang, Yuhui Li, Mingjie Sun, Jiahao Wang, Hao Zhang, Song Han (MIT / UCSD)
  • 简介: 发现不同层的注意力头具有不同的 KV cache 敏感度——浅层容忍高压缩、深层需要更多保留，并据此设计金字塔形的逐层预算分配，相比均等分配提升 20-30% 的压缩效率。
  • 核心创新:
    • 金字塔形预算分配：浅层分配更少的 KV cache 预算（压缩比更高），深层分配更多预算（压缩比更低），形成一个从浅到深的金字塔结构。预算总和保持固定，但分配方式带来显著增益
    • 逐层敏感度分析框架：通过分析每一层注意力输出的变化对最终 loss 的影响（一阶 Taylor 展开），量化每层对 KV cache 压缩的敏感度
    • 与多种驱逐策略兼容：PyramidKV 是一种预算分配策略，而非驱逐策略本身——它可以与 H2O、StreamingLLM、SnapKV 等具体驱逐方法结合使用，赋能所有现有方法
    • 在 LLaMA-2-7B 到 LLaMA-3-70B 的广泛模型上验证，平均压缩效率（固定质量下的压缩比）提升 20-30%
    • 与 KV 量化方法正交互补，结合 KIVI 4-bit 量化实现约 10 倍综合压缩
  • 代表意义: PyramidKV 引入了一个重要的维度——层深度——来优化 KV cache 分配。此前的方法要么对所有层统一处理，要么仅考虑 token 级别的重要性。PyramidKV 证明了不同层的注意力头有不同的压缩容忍度，而简单的金字塔形策略就能捕获大部分收益。其方法论（逐层敏感度分析）可以被推广到其他压缩技术的预算分配问题中。

CompressKV: Attention-Aware KV Cache Compression for Long-Context LLM Inference

  • arXiv: 2502.16547
  • 发表: arXiv，2025 年 2 月
  • 作者: Junhyuk Lee, Seungtaek Choi, Wonjae Kim, Minjoon Seo (KAIST)
  • 简介: 仅在 prefill 完成后进行一次注意力分析（而非每步 decode 时都分析），利用 prefill 注意力模式来指导后续所有 decode 步骤的 KV cache 压缩，实现零额外运行时开销的感知压缩。
  • 核心创新:
    • 一次性注意力引导压缩策略：在 prefill 阶段完成时，对所有层、所有头的注意力模式进行一次全面分析，据此确定各头需要保留的 KV 条目集合。后续所有 decode 步骤直接使用该固定压缩方案，无需重复分析
    • 跨步骤注意力模式稳定性发现：验证了 prefill 阶段的注意力模式在 decode 阶段高度稳定（注意力分布变化 < 5%），使得一次性分析策略具有理论基础
    • 层间注意力模式共享：观察到相邻层的注意力模式高度相似，可以复用高层的分析结果指导底层压缩，进一步减少分析开销
    • 零额外运行时开销：不同于需要在每次 decode 时重新分析的方法（如 SnapKV 的观察窗口），CompressKV 的分析仅在 prefill 结束时执行一次
    • 在 LLaMA-3-8B 上以 25% 的 KV cache 保留率实现与全量 cache 相当的 LongBench 性能
  • 代表意义: CompressKV 的关键贡献在于证明了”分析一次，重复使用”策略在 KV cache 压缩中的有效性。这与 SnapKV 的”每次 decode 时分析”策略形成对比——CompressKV 以更高的压缩效率换取零额外开销，适合对延迟敏感的部署场景。跨步骤注意力稳定性的发现是一个重要的经验观察，为许多”分析-压缩-固定”策略提供了理论支撑。

NACL: A General and Effective KV Cache Eviction Framework for LLM Inference

  • arXiv: 2407.20143
  • 发表: arXiv，2024 年 7 月
  • 作者: Xuan Liao, Yilong Xu, Han Shi, Zixuan Wang, Xiangyu Zhang, Fei Sun (中科院计算所 / 中国科学院大学)
  • 简介: 提出统一的 KV cache 驱逐框架——将随机驱逐、注意力分数驱逐、位置驱逐等多种策略统一为”分数-概率-选择”三步范式，并通过可学习的混合权重实现自适应驱逐策略。
  • 核心创新:
    • 统一驱逐框架：将所有 KV cache 驱逐方法抽象为三个步骤——（1）为每个 token 分配分数（注意力累积、位置分数、随机分数等）、（2）将分数映射为驱逐概率、（3）根据概率选择驱逐 token。不同方法仅在前两个步骤上有所不同
    • 自适应的多策略混合：使用可学习的混合权重将不同的分数来源（累积注意力、位置重要性、频次统计）线性组合，混合权重通过在验证集上优化困惑度来学习
    • 无校准的实时自适应：在推理过程中，混合权重根据当前序列的统计特征（序列长度、内容类型）动态调整，使策略自动适配不同的输入
    • 可作为插件增强任何现有驱逐方法：通过将现有方法的分数纳入混合池，NACL 在原始方法基础上进一步提升 5-15% 的压缩效率
    • 在 LLaMA-2/3、Mistral、Qwen 等多个模型系列上验证，通用性强
  • 代表意义: NACL 的价值在于将分散的 KV cache 驱逐研究统一到一个框架下，使得不同方法之间的比较和组合变得系统化。其自适应混合权重策略解决了”哪种驱逐策略最好”这个没有唯一答案的问题——最优策略取决于输入内容和模型特性，而 NACL 自动找到最优组合。这种”元策略”的范式可能成为 KV cache 管理的未来方向。

GEAR: An Efficient KV Cache Compression Recipe for Near-Lossless Generative Inference

  • arXiv: 2403.05527
  • 发表: arXiv，2024 年 3 月
  • 作者: Hao Kang, Qingru Zhang, Souvik Kundu, Tianxin Wei, Pengyu Wang, Xiaomin Song, Mingu Lee, Tianlong Chen, Zhangyang Wang (Apple / University of Texas at Austin)
  • 简介: 将 KV cache 压缩分解为”低秩近似 + 稀疏残差”两部分——使用 SVD 捕获全局低秩结构，使用稀疏矩阵存储残差中的异常值——在几乎无损的质量下实现 3-4 倍压缩。
  • 核心创新:
    • 低秩加稀疏分解：对每种 KV cache 矩阵应用截断 SVD，保留 top-r 个奇异向量（低秩分量），然后用稀疏格式存储原始矩阵与低秩重建之间的残差。低秩分量用密集矩阵存储（小但完整），残差用 COO 格式存储（大但稀疏）
    • 动态秩选择：根据每个头的 KV cache 能量分布自动选择保留的秩数 r，能量集中的头使用较小的 r、能量分散的头使用较大的 r
    • 逐块处理策略：将 KV cache 沿序列长度维度分块，每个块独立进行低秩分解，避免了全局 SVD 的内存开销（对长序列尤为关键）
    • 与量化无缝集成：低秩分量可以用更高精度（如 FP16）存储以保证质量，残差用更低精度（如 INT4）存储以保证大小，实现精细的精度分配
    • 在 LLaMA-2-7B 和 LLaMA-3-8B 上，以 3-4 倍压缩实现困惑度增加 < 0.05
  • 代表意义: GEAR 引入了一个通用的压缩框架——“低秩 + 稀疏”——来处理 KV cache。这与模型权重量化中的类似策略（如 GPTVQ 的低秩补偿）在思想上一致，但专门针对 KV cache 的访问模式进行了优化。其动态秩选择策略是”按需分配”原则在低秩压缩中的体现。GEAR 的方法已被 Apple 的研究团队在设备端 LLM 推理中采用。
