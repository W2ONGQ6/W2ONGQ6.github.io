2023–2026 LLM 推理加速趋势总览

2023: 基础突破年

  • FlashAttention-2 将注意力计算推向接近硬件极限
  • vLLM/PagedAttention 开创了 KV Cache 虚拟内存管理范式
  • GPTQ / AWQ / SmoothQuant 奠定了 W4A16 / W8A8 量化路线
  • Speculative Decoding 论文开启了投机解码研究方向
  • SparseGPT / Wanda 实现了 GPT 规模模型的一键剪枝

2024: 系统优化年

  • FlashAttention-3 针对 H100 深度优化，引入异步与 FP8
  • KV Cache 压缩 成为独立研究方向：KIVI、KVQuant、SnapKV、MiniCache
  • 投机解码 繁荣发展：Medusa、Eagle-2、Sequoia 各显神通
  • SGLang 将结构化生成与 RadixAttention 结合
  • DeepSeek-V2 的 MLA + MoE 架构展示了极致效率
  • Mamba-2 统一了 SSM 与 Attention 的理论框架

2025–2026: 规模化落地年

  • DeepSeek-V3/R1 展示了 MoE + FP8 + 大规模 RL 的工业化路线
  • KV Cache 分离（Mooncake、DistServe）成为大规模部署标配
  • 投机解码 从论文走向生产（多家推理框架内置支持）
  • BitNet/1-bit LLM 开始展示端侧部署可行性
  • GPU-CPU 混合推理（Splitwise、FlexGen 思路延续）趋于成熟
