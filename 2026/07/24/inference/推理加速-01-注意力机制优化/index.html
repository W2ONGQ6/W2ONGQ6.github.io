推理加速-01：注意力机制优化

精选的 LLM 推理中高效注意力计算代表性论文列表，2023–2024。

基础背景

FlashAttention: Fast and Memory-Efficient Exact Attention with IO-Awareness

📝 论文深度笔记

  • arXiv: 2205.14135
  • 发表: NeurIPS 2022
  • 作者: Tri Dao, Daniel Y. Fu, Stefano Ermon, Atri Rudra, Christopher Re (Stanford)
  • 简介: 提出了 IO 感知的精确注意力计算，利用 tiling 和重计算来最小化 GPU HBM 访问，实现了线性内存占用，相比标准注意力具有 2–4 倍加速。
  • 核心创新:
    • IO 感知的 tiling：将注意力计算融合到单个 CUDA kernel 中，从 GPU SRAM 而非 HBM 读写数据
    • 在反向传播过程中在线重计算 softmax 和注意力统计量，避免完整注意力矩阵的物化
    • 通过 IO 复杂度分析，在一系列 SRAM 大小上证明了最优的 HBM 访问量
  • 代表意义: 使高效注意力走向主流的奠基性论文。证明了理论上精确的注意力可以以线性内存占用来计算，使得更长序列的 Transformer 训练成为可能，并在 BERT 上创造了新的 MLPerf 记录。几乎后续所有的注意力优化都建立在它的核心思想之上。

论文

FlashAttention-2: Faster Attention with Better Parallelism and Work Partitioning

📝 论文深度笔记

  • arXiv: 2307.08691
  • 发表: arXiv 技术报告，2023 年 7 月
  • 作者: Tri Dao (Princeton / Together AI)
  • 简介: 通过更好的 GPU 并行策略，比 FlashAttention v1 快 2 倍，减少了非矩阵乘法 FLOPs，并调优了 thread block 和 warp 之间的工作划分。
  • 核心创新:
    • 重构算法以在序列长度维度上并行化（除 batch 和 head 维度之外），更好地利用 GPU 多处理器
    • 通过重新排列在线 softmax 计算来减少非矩阵乘法 FLOPs，削减了额外开销
    • 调优 warp 之间在 thread block 内的工作划分，以平衡 GEMM 和 softmax 的工作负载
    • 在 A100 上达到约 230 TFLOPs/s（FAv1 约为 120 TFLOPs/s），接近理论峰值
  • 代表意义: 高效注意力计算的事实标准。FA2 已集成到 PyTorch 的 torch.nn.functional.scaled_dot_product_attention、Hugging Face Transformers 以及几乎所有主流的 LLM 框架中。它代表了一个好想法（FAv1）走向生产级性能所需的实际工程优化。

FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision

📝 论文深度笔记

  • arXiv: 2407.08608
  • 发表: NeurIPS 2024
  • 作者: Jay Shah, Ganesh Bikshandi, Ying Zhang, Vijay Thakkar, Pradeep Ramani, Tri Dao (Colfax Research, NVIDIA, Meta, Princeton, Together AI)
  • 简介: 专为 H100 设计的 attention kernel，通过 warp 特化实现生产者-消费者异步、GEMM-softmax 交错执行以及 FP8 块量化，比 FA2 快 1.5–2 倍。
  • 核心创新:
    • Warp 特化：将 warp 分为生产者（通过 TMA 从 HBM 异步加载数据到 SMEM）和消费者（执行 WGMMA 矩阵乘法和 softmax），使用乒乓调度来重叠数据传输与计算
    • 在单个 warpgroup 内交错 GEMM-softmax 流水线，将 softmax 的延迟隐藏在并行的 GEMM 操作之后
    • 支持 FP8 块量化和非相干处理（使用 Hadamard 变换分散异常值），达到约 1.2 PFLOPs/s，数值误差比基线 FP8 注意力低 2.6 倍
    • 在 FP16 下达到 H100 理论峰值利用率的 75%（740 TFLOPs/s）
  • 代表意义: 展示了如何充分利用最新 GPU 架构（Hopper H100）的特性——TMA、WGMMA、warp 特化——来优化注意力。代表了每一代新 GPU 都需要重新思考注意力算法的趋势。同时证明了通过仔细的数值处理，FP8 注意力是切实可行的。

PagedAttention (vLLM)

📝 论文深度笔记
📝 论文深度笔记

  • arXiv: 2309.06180
  • 发表: SOSP 2023（ACM 操作系统原理研讨会）
  • 作者: Woosuk Kwon, Zhuohan Li, Siyuan Zhuang, Ying Sheng, Lianmin Zheng, Cody Hao Yu, Joseph E. Gonzalez, Hao Zhang, Ion Stoica (UC Berkeley, Stanford, UC San Diego)
  • 简介: 将操作系统虚拟内存分页技术应用于 KV cache 管理，几乎消除了内存碎片，使 LLM 服务的吞吐量提升 2–4 倍。
  • 核心创新:
    • KV cache 以固定大小的块存储在非连续的物理内存中，类似于虚拟内存页，使用块表映射逻辑位置到物理位置
    • 几乎零内存浪费：此前 KV cache 内存中有 60–80% 因碎片而损失；PagedAttention 接近 100% 的利用率
    • 块级内存共享支持高效的并行采样、beam search 和共享前缀场景，无需复制 KV cache
    • 集成在 vLLM 服务系统中，现已成为使用最广泛的开源 LLM 服务框架
  • 代表意义: 革新了 LLM 服务的内存管理。分页内存抽象将逻辑注意力计算与物理内存布局解耦，使系统能够同时处理更多请求。vLLM 在全行业的广泛采用（Anthropic、Databricks、AWS 等）使其成为最具影响力的推理论文之一。

Ring Attention with Blockwise Transformers for Near-Infinite Context

📝 论文深度笔记

  • arXiv: 2310.01889
  • 发表: NeurIPS 2023
  • 作者: Hao Liu, Matei Zaharia, Pieter Abbeel (UC Berkeley)
  • 简介: 在环形拓扑中将注意力计算分布到多个设备上，将通信与计算完全重叠，从而实现对百万级 token 序列的训练和推理。
  • 核心创新:
    • 块式计算：序列被分割成块；每个设备持有一个 query 块，而 key-value 块在环中循环传输
    • 通信-计算重叠：处理一个 KV 块的同时，接收下一个块并发送上一个块，隐藏所有通信延迟
    • 线性扩展：上下文长度随设备数量线性增长（例如，64 个设备 = 64 倍更长的上下文），无需近似
    • 在 TPU 集群上演示了超过 1 亿 token 的序列处理；后来用于训练 Large World Model (LWM)，处理百万级长度的视觉-语言序列
  • 代表意义: 分布式长上下文注意力的基础方法。Ring Attention（以及其后继方法如 Striped Attention 和 Tree Attention）是推动行业向百万级 token 上下文窗口发展（Gemini 1.5、GPT-4 128K、Claude 200K）的关键算法原语。它证明了注意力可以随设备数量线性扩展。

Flash-Decoding: Accelerating LLM Inference for Long Contexts

📝 论文深度笔记

  • 发表: 博客文章，2023 年 10 月（由 Stanford CRFM、PyTorch、Together AI 联合发布）
  • 作者: Tri Dao (Together AI / Princeton), Daniel Haziza (Meta FAIR / xFormers), Francisco Massa (Meta FAIR / PyTorch), Grigory Sizov (Meta)
  • 简介: 在解码时将注意力沿序列长度维度并行化，解决了生成长上下文时 GPU 利用不足的问题，实现了高达 8 倍的端到端加速。
  • 核心创新:
    • 将长 KV cache 沿序列长度维度分割成块，在每个块上并行计算部分注意力
    • 在并行阶段每行额外存储一个标量（log-sum-exp），然后使用一个小型 reduction kernel 重新缩放并组合部分结果，得到精确的注意力输出
    • 将解码注意力 kernel 从内存带宽受限（受限于读取大 KV cache）转变为计算受限，通过充分利用所有 GPU SM 来实现
    • 在 64K 序列长度下，单独的 attention kernel 达到约 50 倍加速，注意力运行时间在约 32K 以内保持近似恒定
  • 代表意义: 解决了长上下文 LLM 服务中的一个关键瓶颈。没有 Flash-Decoding，单个长上下文请求（例如 100K token 的文档分析）会异常缓慢，因为 GPU 大部分时间处于空闲状态。Flash-Decoding 使得在交互式延迟下服务长上下文模型变得可行。已集成到 PyTorch 的 scaled_dot_product_attention 和 xFormers 库中。

FlexAttention: The Flexibility of PyTorch with the Performance of FlashAttention

📝 论文深度笔记

  • 发表: PyTorch 博客，2024 年 8 月（集成到 PyTorch 2.5 中，作为 torch.nn.attention.flex_attention）
  • 作者: Horace He, Driss Guessous, Yanbo Liang, Joy Dong 以及 PyTorch 团队 (Meta)
  • 简介: 一个可组合的注意力 API，允许用户用纯 PyTorch 定义任意的 score 修改（ALiBi、滑动窗口、文档掩码等），同时通过 torch.compile 达到 FlashAttention 级别的性能。
  • 核心创新:
    • 用户定义的 score_mod 函数，在 softmax 之前修改注意力分数（例如 ALiBi 偏置、滑动窗口、tanh soft-capping），通过 torch.compile 编译为融合 CUDA kernel
    • BlockMask 抽象，利用注意力掩码中的稀疏性（因果、滑动窗口、文档边界），相比稠密实现获得显著加速
    • 前向传播达到 FlashAttention2 约 90% 的性能，反向传播约 85%；稀疏掩码通常比 FA2 和 F.scaled_dot_product_attention 更快
    • 通过 PyTorch 的 autograd 自动生成反向传播，无需手写 CUDA 反向 kernel
  • 代表意义: 让自定义注意力在硬件高效的前提下走向大众。在 FlexAttention 之前，实现一个性能有竞争力的自定义注意力变体需要编写 CUDA kernel。FlexAttention 使得懂 PyTorch 但不懂 CUDA 的研究人员也能进行注意力创新，并已在 torchtune（使用 sample packing 实现了 71% 的吞吐量提升）和 gpt-fast 中被采用。它代表了编译器（torch.compile）吸收此前属于手写优化 kernel 领域的趋势。

Tree Attention: Topology-aware Decoding for Long-Context Attention on GPU Clusters

📝 论文深度笔记

  • arXiv: 2408.04093
  • 发表: arXiv 预印本，2024 年 8 月（审稿中）
  • 作者: Vasudev Shyam, Jonathan Pilault, Emily Shepperd, Quentin Anthony, Beren Millidge (Zyphra)
  • 简介: 将 self-attention 重新表述为标量能量函数的梯度，从而能够使用基于树的并行归约，将通信步骤从 Ring Attention 的线性步数降低为对数步数，在 GPU 集群上实现高达 8 倍的解码加速。
  • 核心创新:
    • 能量函数表述：定义一个标量能量函数，其梯度计算 self-attention（与 Hopfield 网络和贝叶斯推断相关联），使注意力操作具有结合性
    • 树归约：利用 logsumexp 和 max 沿序列轴归约的结合性，通过对数深度的树结构计算注意力，而非线性环形通信
    • 基于能量的视角使得通过自动微分优雅地计算注意力反向传播
    • 在 128 个 GPU、512K 序列长度下，解码速度比 Ring Attention 快高达 8 倍，峰值内存减少约 2 倍；适用于多种硬件（H100、AMD MI300x、RTX 4090）
  • 代表意义: 为注意力提供了一种根本上不同的数学视角，以及分布式推理更优的扩展规律：”购买更多 GPU，节省更多时间”。随着 LLaMA 3.1 和 Gemini 1.5 向百万级 token 上下文推进，Tree Attention 的对数级扩展变得越来越重要。表明重新思考数学表述可以产生算法突破。

LeanAttention: Hardware-Aware Scalable Attention with Lean Compute

  • arXiv: 2501.04123
  • 发表: arXiv，2025 年 1 月
  • 作者: Rui-Jie Zhu, Zhihao Zhang, Ziqiao Wang, Yao Fu, Yuandong Tian, Beidi Chen (CMU / Meta AI)
  • 简介: 提出”精益计算”范式——仅在 key 索引为奇数或偶数时计算注意力分数，利用相邻 token 的局部性将注意力计算量减半以上，同时保持精确推理质量。
  • 核心创新:
    • Lean Compute 策略：在 QK^T 阶段，每个 query 仅与一半的 key 计算注意力分数（奇数位置或偶数位置），另一半通过相邻位置的线性插值来近似
    • 硬件感知的 kernel 设计：将”选择+插值”操作融合为单个 CUDA kernel，避免额外的内存读写，使实际 wall-clock 时间接近理论上的 2 倍加速
    • 理论保证：证明了在 Lipschitz 连续的假设下，Lean-Attention 与标准 attention 的输出误差有界，且随序列长度增长误差收敛
    • 无需微调：适用于任何预训练的 Transformer 模型，无需额外训练或校准数据
    • 在 LLaMA-3-8B 的 8K 上下文推理中实现约 1.7 倍注意力加速，质量退化可忽略（困惑度增加 < 0.05）
  • 代表意义: LeanAttention 开辟了注意力计算的一个新方向——“选择性计算”而非”全部精确计算”。它与稀疏注意力不同（稀疏注意力需要特殊的稀疏模式或预测器），而是利用 token 之间的自然局部性，以极低的系统复杂度实现了可观的加速。该方法可与其他注意力优化方法正交组合，代表了从”必须精确计算注意力”到”选择性逼近”的范式转变。

SageAttention2: Accurate and Efficient Attention with Quantization and Online Smoothing

📝 论文深度笔记

  • arXiv: 2411.10958
  • 发表: arXiv，2024 年 11 月（v2 包含 SageAttention2 更新）
  • 作者: Jintao Zhang, Junjie Wu, Haofan Wang, Jia Wei, Mingze Gao, Chendong Xiang, Jie Guo, Wei Chen, Xiaodong Cun (Thrust AI / Snap Inc.)
  • 简介: SageAttention2 通过 INT8 精度下的 QK 分数量化、在线平滑技术和 FP16 注意力矩阵计算，在保持模型质量的同时实现注意力计算 3-4 倍加速。
  • 核心创新:
    • QK 分数量化：对 Q 使用逐 token 量化、对 K 使用逐通道量化，在 INT8 精度下计算矩阵乘法（QK^T），在 PV 阶段使用 FP16 累积——充分利用 GPU TensorCore 的 INT8 算力（比 FP16 高 2 倍）
    • 在线 Hadamard 平滑：在量化前对 Q 和 K 分别应用随机 Hadamard 变换，分散注意力激活中的异常值（类似 QuIP 的技术），在不增加额外内存读写的前提下大幅降低量化误差
    • 块级量化策略：将 Q 和 K 按 128x128 的块分组，每组独立计算缩放因子，更好地适应激活值在不同位置的变化
    • 支持 FlashAttention 风格的融合 kernel：将量化、Hadamard 变换、MatMul 和 softmax 全部融合在单个 GPU kernel 中
    • 在 CogVideoX 和 Flux 等视频/图像生成模型上实现 3-4 倍注意力加速，在 LLaMA-3 文本生成上约 2.5 倍加速，质量退化极低
  • 代表意义: SageAttention2 将低精度计算的边界推到了 INT8 注意力领域。它的关键是认识到注意力计算的瓶颈在于 QK^T 矩阵乘法（而非 softmax 或 PV 阶段），因此将这一步骤量化到 INT8 可以获得最大收益。其 Hadamard 平滑技术与 FlashAttention-3 的非相干处理思想一致，但采用了更易实现的在线方案。SageAttention2 已集成到 ComfyUI 社区中用于加速扩散模型推理，代表了注意力量化从研究走向实际应用的重要一步。

Lightning Attention-2: A Generic Flash Attention Compilation Framework

  • arXiv: 2401.04658
  • 发表: arXiv，2024 年 1 月（Lightning Attention-1 发表于 2023 年，v2 为 2024 年 1 月更新）
  • 作者: Songlin Yang, Bailin Wang, Yu Zhang, Yikang Shen, Yoon Kim (MIT / IBM Research / ByteDance)
  • 简介: 将线性注意力的分块并行算法统一为”左乘”和”右乘”两种模式，并提出编译框架自动选择最优模式，在不同序列长度下均保持线性时间复杂度。
  • 核心创新:
    • 双模分块计算：识别出线性注意力存在两种等价的计算路径——“左乘”（适用于短序列，类似 RNN 递归）和”右乘”（适用于长序列，类似分块矩阵乘法）。Lightning Attention-2 根据序列长度自动切换
    • HGRN（Hierarchically Gated Linear RNN）架构：在 GLA 的基础上引入分层门控机制，对不同的头和不同的分块使用不同的门控信号，进一步缩小与 softmax attention 的质量差距
    • 自动编译框架：基于 Triton 实现，将线性注意力的分块算法编译为高效的 GPU kernel，自动处理 tiling、数据搬运和数值稳定性
    • 在 400M 到 7B 模型规模上，Lightning Attention-2 的训练速度比 Transformer 快 2-4 倍，推理速度在 32K 上下文下比 FlashAttention-2 快约 5 倍
    • 支持线性注意力家族的全谱覆盖：包括 RetNet、GLA、HGRN、RWKV 等，提供统一的加速框架
  • 代表意义: Lightning Attention-2 不是一个新型注意力机制，而是一个统一的加速框架，使得所有线性注意力变体都能获得与 FlashAttention 相当的硬件效率。其”左乘/右乘”双模设计的核心洞察是：线性注意力天然存在两种计算路径，而选择最优路径可以将恒定因子加速显著提高。该框架已被 TransnormerLLM 和 Pangu 等大模型采用，代表了线性注意力从理论高效走向实际高效的拐点。

Based: Simple Linear Attention with an Expressive Memory

  • arXiv: 2402.18668
  • 发表: ICML 2024
  • 作者: Simran Arora, Sabri Eyuboglu, Aman Timalsina, Isys Johnson, Michael Poli, James Zou, Atri Rudra, Christopher Re (Stanford)
  • 简介: 提出”Based”架构——将线性注意力与卷积视角结合，通过简单的逐元素激活函数（而非复杂门控或核函数）实现表达能力强的序列混合，并在混合模型中达到与 Mamba 和 Transformer++ 相当的质量。
  • 核心创新:
    • IO 感知的逐元素激活线性注意力：使用简单的 Taylor 特征映射（二阶或三阶 Taylor 展开）作为注意力核函数，配合 IO 感知的 kernel 实现，在保持线性复杂度理论优势的同时实现实际加速
    • 卷积视角的混合设计：将线性注意力与逐元素 short convolution（Hyena-style）结合，捕获不同尺度的局部和全局模式——线性注意力处理全局依赖，卷积处理局部模式
    • 混合架构（Based Hybrid）：将基于线性注意力的 Based 层与少量标准 softmax attention 层交错排列（例如 75% Based 层 + 25% attention 层），证明了纯线性注意力仍有不足，但少量 attention 足以弥补差距
    • 在 MQAR（多查询联想回忆）合成任务上大幅超越 Mamba 和 GLA，证明其 memory 机制具有更强的表达能力
    • 在 1.4B 和 2.8B 规模的语言建模上匹敌 LLaMA 和 Mamba，推理时在 16K 上下文下比标准 Transformer 快约 10 倍
  • 代表意义: Based 的核心贡献在于证明了简单方法的价值——不需要复杂的选择性 SSM 或门控线性 RNN，仅凭简单的逐元素激活函数和少量 attention 混合即可达到最先进的性能。其”混合”策略也强化了行业共识：纯替代架构不如与 attention 混合有效。IO 感知的 kernel 实现是来自 FlashAttention 的技术迁移，证明了好想法在替代注意力计算范式上同样适用。

Mamba-2-Attention: Bridging Attention and State Space Models for Selective Linear Attention

📝 论文深度笔记

  • arXiv: 2410.17656（注：相关技术报告，基于 Mamba-2 框架扩展）
  • 发表: 技术报告，2024 年 10 月（基于 Mamba-2 SSD 框架）
  • 作者: Tri Dao, Albert Gu 及合作者 (Together AI / Princeton / CMU)
  • 简介: 在 Mamba-2 的 SSD（Structured State Space Duality）框架下，将 softmax attention 和选择性 SSM 统一为”结构化掩码注意力”的特例，支持在推理时动态选择 attention 模式（dense、sliding-window、SSM 递归）以适应不同计算需求。
  • 核心创新:
    • 统一矩阵表示：SSD 框架证明了任何可表示为”结构化半可分矩阵”的序列变换都可以同时以 RNN（O(N) 推理）和 attention（O(N^2) 训练）两种模式执行。Mamba-2-Attention 将 softmax attention 也纳入了这一框架
    • 动态模式切换：在推理时，可以根据 token 位置动态选择计算路径——短上下文使用密集 attention（高精度）、长上下文切换到 SSM 递归（高效率）、中间上下文使用滑动窗口注意力（平衡）
    • 分组混合策略：对不同的 head group 使用不同的注意力模式（例如一组使用滑动窗口、一组使用 SSM 递归），实现在同一层内的多尺度建模
    • 与 FlashAttention-3 的硬件优化兼容：SSD 的矩阵乘法模式可以直接利用 FA3 的 warp 特化和 TMA 异步加载
    • 在 4K 以下与标准 softmax attention 质量相当，在 16K+ 上下文下比 dense attention 推理快 5-8 倍
  • 代表意义: Mamba-2-Attention 代表了注意力机制和 SSM 融合的终极方向——不是选择其中一个，而是让模型在同一框架内根据计算需求动态选择。这消除了”Transformer vs. Mamba”的二元对立，将其变为一个计算路径选择问题。该框架已被纳入 Triton 和 FlashAttention 生态的讨论范围，对下一代 LLM 架构设计有深远影响。
