推理加速-08：替代架构（SSM/Mamba/RWKV）

虽然 Transformer 架构一直主导着 LLM 发展，但其二次 attention 复杂度为长上下文处理和高效推理带来了根本性的瓶颈。从 2023 年至 2026 年，替代架构——State Space Models (SSM)、线性 RNN 和混合设计——出现了爆发式增长，证明了次二次复杂度的模型可以在推理时大幅提升效率的同时，达到甚至超过 Transformer 的质量。本章节涵盖最具影响力的替代架构论文。

论文

Mamba: Linear-Time Sequence Modeling with Selective State Spaces

📝 论文深度笔记

  • arXiv: 2312.00752
  • 发表: arXiv，2023 年 12 月（未在传统会议上经过同行评审；后续工作 Mamba-2 发表于 ICML 2024）
  • 作者: Albert Gu（CMU），Tri Dao（Together AI / Princeton）
  • 简介: 引入选择性（输入依赖）state space model，结合硬件感知的并行扫描算法，以线性时间推理和 5 倍吞吐量实现 Transformer 级别的建模质量。
  • 核心创新:
    • Selective State Space Model (S6): 与使用固定线性时不变参数的早期 SSM（S4、H3）不同，Mamba 将 SSM 参数（Delta、B、C）设计为输入依赖的函数，实现内容感知推理——模型学会对每个 token 选择性地传播或遗忘信息
    • 硬件感知并行扫描算法: 由于选择性使高效卷积模式不可用，针对 GPU SRAM/HBM 内存层级设计了自定义并行扫描算法，灵感来源于 FlashAttention 的 I/O 感知设计
    • 移除 attention 甚至 MLP 块，采用精简的端到端 SSM 设计来简化架构
    • Mamba-2.8B 在语言建模上超过同等规模的 Transformer，并匹敌两倍规模的 Transformer，同时生成吞吐量提升 5 倍
  • 代表意义: Mamba 无疑是自 “Attention Is All You Need” 以来最具影响力的替代架构论文。它证明了非 Transformer 架构可以在质量上真正具有竞争力，同时提供线性时间推理——催生了整个研究生态（Mamba-2、Jamba、Griffin、Caduceus 等）。其硬件感知设计理念（将算法与硬件视为一个协同设计问题）已成为标准实践。

Transformers are SSMs: Generalized Models and Efficient Algorithms Through Structured State Space Duality (Mamba-2)

📝 论文深度笔记

  • arXiv: 2405.21060
  • 发表: ICML 2024
  • 作者: Tri Dao（Together AI / Princeton），Albert Gu（CMU）
  • 简介: 通过”Structured State Space Duality”（SSD）证明了 SSM 与线性 attention 在数学上是等价的，统一了两个此前独立的研究社区，并产出了比 Mamba-1 快 2-8 倍的 Mamba-2。
  • 核心创新:
    • Structured State Space Duality (SSD): 证明了 state space model 对应于结构化半可分矩阵（structured semiseparable matrices），SSM 的递归形式和 masked attention 是同一计算的两种视角——一种线性时间，一种可并行训练
    • 线性 Attention 与 SSM 的统一框架: 形式化了 SSM 与 “Structured Masked Attention” (SMA) 之间的联系，证明了任何快速递归的 kernel attention 方法本质上都是一个 SSM
    • Mamba-2 架构: 将 state 维度从 16 增加到 256（约 16 倍），速度损失极小，引入 Grouped-Value Attention (GVA) 和多头 SSM 设计
    • 比 Mamba-1 快 2-8 倍，在 2K 上下文长度下与 FlashAttention-2 相当，在 16K 时快 6 倍
    • 混合模型（4-6 attention 层 + Mamba-2 层）超越纯 Transformer++ 和纯 Mamba-2，证实 attention 与 SSM 是互补的
  • 代表意义: 这篇论文提供了连接 SSM 和 attention 社区的理论桥梁。通过证明它们的数学等价性，它终结了”Transformer vs. SSM”的争论，将其重新定义为何时使用哪种计算形式（递归 vs. 并行）的问题。SSD 框架使基于原理的混合设计成为可能，充分结合两者之长。

RWKV: Reinventing RNNs for the Transformer Era

📝 论文深度笔记

  • arXiv: 2305.13048
  • 发表: Findings of EMNLP 2023
  • 作者: Bo Peng, Eric Alcaide, Quentin Anthony 等，EleutherAI 和 Generative AI Commons
  • 简介: 一种新颖的线性 attention 架构，训练时像 Transformer 一样可并行化，推理时以 RNN 方式运行、O(1) 内存占用——无需 KV cache。
  • 核心创新:
    • WKV（Receptance Weighted Key Value）机制: 用通道导向的线性 attention 机制取代标准 QKV attention，使用 receptance (R)、key (K) 和 value (V) 向量，每个通道配有可学习的时间衰减向量
    • 双重形式: 既可以以 Transformer 方式计算（并行训练，O(T^2)），也可以以 RNN 方式计算（高效推理，O(T) 时间，O(1) 内存），兼具两种范式的优势
    • 逐通道时间衰减: 每个通道学习自己的指数衰减率，使模型能够在不同维度上跨不同时间尺度保留信息
    • 扩展到 14B 参数——当时有史以来训练过的最大 RNN 语言模型——在标准基准测试上匹敌同等规模的 Transformer
  • 代表意义: RWKV 是基于 RNN 的 Transformer 主要替代方案，拥有强大的开源社区和 Apache 2.0 协议。它证明了类 RNN 架构不仅能匹敌 Transformer 的质量，还能完全消除 KV cache——这对长上下文和内存受限的部署场景是至关重要的优势。RWKV 社区已持续迭代至 RWKV-7。

Gated Linear Attention (GLA) Transformers with Hardware-Efficient Training

  • arXiv: 2312.06635
  • 发表: ICML 2024
  • 作者: Songlin Yang, Bailin Wang, Yikang Shen, Rameswar Panda, Yoon Kim，MIT / IBM Research / ByteDance
  • 简介: 为 linear attention 引入数据依赖的门控机制，配合硬件高效的分块并行训练算法，显著缩小了 linear attention 与 softmax attention 之间的质量差距。
  • 核心创新:
    • 线性 Attention 的数据依赖门控: 为线性 attention 递归添加一个可学习的遗忘门（`alpha_t`），由低秩 sigmoid 参数化推导而来，大幅提升表达能力并增强训练稳定性，远超普通 linear attention
    • FlashLinearAttention 算法: 一种 I/O 感知的实现，利用 GPU TensorCores 进行高效矩阵乘法，同时在 log 空间中为门控项保持数值稳定性
    • 两级分块并行: chunk 间计算使用半精度 TensorCore GEMM 以提升速度；chunk 内使用全精度 log 空间操作以保证门控递归的数值稳定性
    • GLA Transformer 在 340M 和 1.3B 规模上匹敌 LLaMA 架构的 Transformer、RetNet 和 Mamba，且具有强大的长度泛化能力（在 2K 上训练，可泛化到 20K+）
  • 代表意义: GLA 解决了 linear attention 的一个根本问题：速度快但质量远低于 softmax attention。通过引入可学习的门控——类似于 LSTM 的遗忘门——GLA 缩小了大部分差距。其硬件感知的分块训练算法建立了现在被 linear attention 文献广泛使用的模式。

Griffin: Mixing Gated Linear Recurrences with Local Attention for Efficient Language Models

📝 论文深度笔记

  • arXiv: 2402.19427
  • 发表: arXiv，2024 年 2 月
  • 作者: Soham De, Samuel L. Smith, Anushan Fernando, Aleksandar Botev 等（包括 Albert Gu），Google DeepMind
  • 简介: Google DeepMind 对 Mamba 的回应，引入了 Hawk（纯递归）和 Griffin（递归 + local attention）架构，在性能上超越 Mamba 的同时训练速度比 Transformer 更快。
  • 核心创新:
    • RG-LRU（Real-Gated Linear Recurrent Unit）: 一种新颖的门控线性递归层，作为构建模块——比 Mamba 的 selective SSM 更简单但同样有效
    • 混合 Griffin 架构: 将 RG-LRU 层与滑动窗口 local attention 交错排列，结合了 RNN 在长程上下文上的效率和 attention 在局部 token 交互上的精确性
    • Hawk 架构: 一个纯递归基线（完全不含 attention），用更少的训练 token 在 downstream 任务上仍然超越 Mamba
    • Griffin 以少 6 倍的训练 token 匹敌 Llama-2 的质量；在长序列上展现出比 multi-query attention Transformer 更高的吞吐量和更低的延迟
    • 有效扩展到 14B 参数，在超出训练长度的上下文上展现出强大的长上下文外推能力
  • 代表意义: Griffin 的重要性部分在于其共同作者包括了 Albert Gu（Mamba 的创造者），代表了 Google 专业知识与 SSM 社区的融合。RG-LRU 是一种极简的门控机制，达到了 Mamba 级别的质量，而 Griffin 混合设计验证了递归 + local attention——而非纯 SSM——才是未来的发展方向。

Jamba: A Hybrid Transformer-Mamba Language Model

📝 论文深度笔记

  • arXiv: 2403.19887
  • 发表: arXiv，2024 年 3 月（2024 年 7 月修订）
  • 作者: Opher Lieber, Barak Lenz, Hofit Bata, Gal Cohen 等，AI21 Labs
  • 简介: 首个生产级的混合 SSM-Transformer 模型，将 Mamba 层与 Transformer 层及 MoE 交错排列，在单张 80GB GPU 上即可支持 256K 上下文。
  • 核心创新:
    • 交错 Transformer-Mamba 架构: 在同一模型内交替排列完整的 Transformer 层（带 attention）和 Mamba（SSM）层，并选择性添加 MoE 层以提升容量
    • 单 GPU 256K 上下文: 可在单张 80GB GPU 上运行，同时支持 256K token 上下文长度——得益于 Mamba 层恒定大小的 state 消除了大部分层的 KV cache 负担
    • 52B 总参数量 / 12B 激活参数，通过 MoE 实现，公开提供 Apache 2.0 权重
    • 系统性地研究了架构设计决策：Mamba 层与 attention 层的比例、专家放置位置以及模态的交错方式
    • 后续工作 Jamba-1.5 引入 ExpertsInt8 量化，在 8x80GB GPU 上实现 256K 上下文且无质量下降
  • 代表意义: Jamba 证明了混合 SSM-Transformer 架构可以在生产规模上运行并进行商业化部署。虽然 Mamba 和 Griffin 奠定了研究基础，但 Jamba 展示了混合方法的实用性：可以在保留 attention 的关键作用的同时获得 SSM 的大部分效率。论文中详尽的架构消融研究为任何构建混合模型的人提供了宝贵的指南。

RWKV-5/6 (Eagle & Finch): Matrix-Valued States and Dynamic Recurrence

📝 论文深度笔记

  • arXiv: 2404.05892
  • 发表: arXiv，2024 年 4 月
  • 作者: Bo Peng, Daniel Goldstein, Quentin Anthony 等，RWKV 开源社区
  • 简介: RWKV 的多代演进，引入了多头矩阵值状态（RWKV-5 Eagle）和数据依赖的动态递归（RWKV-6 Finch），在保持 RNN 效率的同时大幅提升表达能力。
  • 核心创新:
    • RWKV-5 (Eagle) – 多头矩阵状态: 将时间混合拆分为多个头，使用矩阵值状态（而非向量），类似于 Transformer 从单头 attention 到多头 attention 的演进，外加新的门控机制和 GroupNorm
    • RWKV-6 (Finch) – 动态数据依赖递归: 学习到的时间衰减通过基于 LoRA 的 token shifting 变为输入依赖，每个通道的衰减率根据当前和前一个 token 动态变化——一种”二阶”递归机制
    • Finch 的内存使用比 FlashAttention 少 40%，比 Mamba 少 17%，同时保持同等质量
    • Finch 从 4K 训练上下文泛化到 20K+ 推理上下文，无需额外训练，在多查询联想回忆（MQAR）任务上表现出色
  • 代表意义: RWKV 家族是来自开源社区（而非大型实验室）最成功的”替代架构”，拥有草根开发模式和 Apache 2.0 协议。Eagle 和 Finch 展示了持续的架构优化可以在不放弃核心 RNN 范式的情况下缩小与 Transformer 的差距——并为 RWKV-7 “Goose” 奠定了基础，后者声称具备超越 TC0 复杂度类的理论能力。

RWKV-7 “Goose”: Expressive Dynamic State Evolution

📝 论文深度笔记

  • arXiv: 2503.14456
  • 发表: arXiv，2025 年 3 月
  • 作者: RWKV 开源社区
  • 简介: 最新一代 RWKV，将状态更新重新表述为 in-context learning 过程并引入向量值门控，在 3B 规模上以仅 1/3 的训练数据即实现最先进的多语言性能。
  • 核心创新:
    • 广义 Delta 规则（Generalized Delta Rule）: 将状态更新框架化为内部模型上的梯度下降——分离”删除”和”替换”keys 以实现灵活的信息管理
    • 向量值学习率: 每个状态通道拥有自己上下文依赖的学习率，实现对信息保留的细粒度控制
    • 可证明超越 TC0 复杂度类：2 层 RWKV-7 可以解决群组状态追踪（group state-tracking）任务，4 层可以模拟任何 DFA——这些任务在理论上对固定深度的 Transformer 是不可能的
  • 代表意义: RWKV-7 代表了一个理论突破：它不仅是一个更快的 Transformer 替代品，而是在表达能力上有可证明优势的架构。对于超过 4K token 的序列，其推理速度比 FlashAttention-3 更快，使其成为长上下文部署场景中最具吸引力的选择之一。

Hymba: A Hybrid-head Architecture for Small Language Models

  • arXiv: 2411.13676
  • 发表: arXiv，2024 年 11 月（NVIDIA & Mila）
  • 作者: Xin Dong, Yonggan Fu, Shizhe Diao, Wonmin Byeon, Zijia Chen, Ameya Sunil Mahabaleshwarkar, Shih-Yang Liu, Matthijs Van Keirsbilck, Min-Hung Chen, Yoshi Suhara, Yingyan Lin, Jan Kautz, Pavlo Molchanov (NVIDIA / Mila / Georgia Tech)
  • 简介: 提出”混合头”架构——在每一层同时使用注意力头和 SSM 头，通过可学习的门控融合两者的输出——在 125M 到 1.3B 的小模型规模上超越所有纯 Transformer 和纯 SSM 基线。
  • 核心创新:
    • 混合头并行架构：每一层包含并行的注意力子层和 SSM 子层，各自独立处理隐藏状态，输出通过可学习的门控（sigmoid gating）融合。这与 Jamba 的”交错层”（交替放置 Transformer 层和 Mamba 层）有根本区别——混合头在同一层内混合，而非跨层交错
    • 注意力头和 SSM 头的互补分工：分析表明，注意力头擅长捕获精确的 token 级依赖（如复制、计数），SSM 头擅长处理长程上下文和压缩历史信息，两者在同一层内互补
    • 参数效率优化：在小模型规模下（125M-1.3B），混合头设计比纯 Transformer 或纯 Mamba 的参数效率更高——因为两种头的参数共享底层 MLP 和归一化层
    • 训练效率的元学习分析：使用”data distribution次元”指标量化模型在不同数据分布上的适应能力，证明混合头架构具有更平坦的损失景观
    • 在相同参数预算下，Hymba-1.3B 在 HellaSwag、ARC、PIQA 等基准上大幅超越 Mamba-1.4B 和 Transformer-1.3B
  • 代表意义: Hymba 代表了混合架构设计的精致化——不是简单地在模型内同时使用 attention 和 SSM，而是在同一层内将它们并行融合。其分析揭示了 attention 和 SSM 在建模能力上的互补性，为”最优混合比”的设计提供了理论基础。该架构已被 NVIDIA 在其小型语言模型研究管线中采用。

TTT: Test-Time Training Layers for Sequence Modeling

  • arXiv: 2407.04620
  • 发表: ICML 2024 (Spotlight)
  • 作者: Yu Sun, Xinhao Li, Koustubh Dalal, Jiantao Jiao, Hongyi Wang, Aaron Gokaslan, Taco Cohen, Karen Simonyan, Laurent Sifre (GenSim AI / Stanford / UC Berkeley / Google DeepMind)
  • 简介: 提出 TTT（Test-Time Training）层——在推理过程中，模型使用自监督损失更新其隐藏状态中压缩的”模型”，而非固定的递归规则——将 RNN/SSM 层重新定义为在线学习过程，实现线性复杂度下表达能力的跃升。
  • 核心创新:
    • 推理时在线学习：传统 RNN 和 SSM 使用固定规则更新隐藏状态（如 Mamba 的 selective scan）。TTT 层将隐藏状态视为一个小型 MLP 的权重，在每个 token 上进行一步梯度下降来更新这个 MLP——本质上是在推理时”学习”如何压缩上下文
    • 自监督重建目标：TTT 层的学习目标是重建当前窗口内的 token 或预测下一个 token，使用与语言建模一致的损失函数
    • 小模型在隐藏状态内：每个 TTT 层维护一个微小的神经网络（通常为 2 层 MLP，约 1000 个参数），其权重是隐藏状态的一部分，并通过梯度下降在每个 token 上更新
    • 与标准 SSM 的双重实现：TTT 既可以像 SSM 一样递归计算（推理时 O(1) 内存），也可以像 attention 一样并行计算（训练时），通过巧妙的对偶公式实现
    • 在 MQAR 和语言建模任务上超越 Mamba-2 和 GLA，尤其在需要精确记忆和检索的长上下文场景中表现突出
  • 代表意义: TTT 层的核心思想——“隐藏状态不是固定的向量，而是一个不断学习的小模型”——是对序列建模架构设计的根本性重新思考。它将”状态更新”从启发式规则升级为”在线学习”，使模型能够根据其接收到的信息自适应地调整其记忆压缩策略。这一范式使 RNN/SSM 的隐藏状态表达能力达到与 Transformer 全注意力可比拟的水平。

xLSTM: Extended Long Short-Term Memory

  • arXiv: 2405.04517
  • 发表: NeurIPS 2024
  • 作者: Maximilian Beck, Korbinian Poeppel, Markus Spanring, Andreas Auer, Oleksandra Prudnikova, Michael Kopp, Günter Klambauer, Johannes Brandstetter, Sepp Hochreiter (NxAI / JKU Linz)
  • 简介: 重新发明 LSTM——引入指数门控（替代 sigmoid 门控）、矩阵记忆单元和可并行训练模式——使经典 LSTM 在语言建模上达到 Transformer 和 Mamba 水平，同时保持 RNN 的 O(1) 推理。
  • 核心创新:
    • 指数门控（Exponential Gating）: 将 LSTM 的 sigmoid 遗忘门替换为指数函数 exp(Wx+b)，使门控值可以大于 1，支持信息的乘法而非仅衰减——大幅提升了序列中长期依赖的建模能力
    • 矩阵记忆单元（sLSTM 和 mLSTM）: 标量 LSTM（sLSTM）保留经典 LSTM 的逐元素门控，用于细粒度控制；矩阵 LSTM（mLSTM）使用全矩阵记忆单元，支持并行训练（通过类似于 Linear Attention 的 chunkwise 并行算法）
    • mLSTM 的可并行训练: 通过将 mLSTM 的递归公式重写为类似于 GLA 的并行形式，mLSTM 在训练时可像 Transformer 一样并行（使用 CUDA 优化的 kernel），推理时保持 RNN 的高效递归
    • 残差块设计（xLSTM Block）: 将 sLSTM 和 mLSTM 组合到类似于 Transformer 的残差块中，包含 Pre-LayerNorm、残差连接和多头设计
    • 在 1.3B 规模上匹敌 LLaMA 和 Mamba，在长上下文和状态追踪任务上超越两者
  • 代表意义: xLSTM 是对 LSTM 这一经典架构的现代化改造——证明了 LSTM 的核心设计理念（门控记忆单元）在正确的数学改造下仍然有效。其指数门控是一个最小但高影响力的改变，直接从 LSTM 跃升到与现代 SSM 和 Transformer 竞争的水平。xLSTM 证明了”老架构 + 新数学 = SOTA”的可行性。

DeltaNet: Linear Transformers with the Delta Rule for In-Context Learning

  • arXiv: 2405.07933
  • 发表: NeurIPS 2024
  • 作者: Songlin Yang, Bailin Wang, Yu Zhang, Yikang Shen, Yoon Kim (MIT / IBM Research / ByteDance)
  • 简介: 将 delta 规则（一种经典的在线学习算法）引入线性注意力——在推理时，查询向量与记忆（隐藏状态）通过类似于 Widrow-Hoff delta 规则的更新进行交互——赋予线性注意力 in-context learning 能力。
  • 核心创新:
    • Delta 规则线性注意力：在线性注意力的框架下（Q、K、V 和隐藏状态 H），将记忆更新建模为 H_new = H_old - beta * (H_old @ k_i - v_i) @ k_i^T——即 delta 规则更新。这使得隐藏状态可以根据”当前存储的值”与”目标值”之间的差异进行自适应调整
    • 移除-替换机制：传统线性注意力只能”添加”信息到隐藏状态（通过外积 K^T V），DeltaNet 可以”更正”已有信息——当遇到与历史 token 相似的 key 时，新的 value 可以覆盖旧的 value
    • 与 Mamba 和 GLA 的关联：DeltaNet 的更新规则在特定参数设置下退化为 GLA（单步梯度下降）或 Mamba（选择性状态空间），建立了这些模型之间的理论联系
    • 硬件高效的分块并行：使用与 Lightning Attention-2 类似的分块并行算法，训练时可并行到长序列
    • 在语言建模上匹敌 GLA 和 Mamba，在需要 in-context 学习和状态追踪的合成任务上大幅领先
  • 代表意义: DeltaNet 将线性注意力与经典在线学习理论（delta 规则 / LMS 算法）联系起来。其核心贡献是证明了”记忆更新规则”是线性注意力的关键设计维度——简单地改变记忆更新规则（从累积到 delta 规则）就能赋予模型全新的能力（如 in-context learning）。这一理论框架启发了后续的 RWKV-7 和 Titans 等工作。

Titans: Learning to Memorize at Test Time

  • arXiv: 2501.00663
  • 发表: arXiv，2025 年 1 月
  • 作者: Ali Behrouz, Peilin Zhong, Vahab Mirrokni (Google Research)
  • 简介: 提出三层记忆架构——核心记忆（长期压缩）、上下文记忆（当前序列）和持久记忆（任务元知识）——赋予线性 RNN 在推理时主动决定”记住什么”和”遗忘什么”的能力，实现事实检索和 in-context learning 的统一。
  • 核心创新:
    • 三层神经记忆架构: （1）核心记忆：一个持续更新的长期记忆模块，使用类似于 DeltaNet 的 delta 规则管理——决定何时更新和删除信息；（2）上下文记忆：传统的滑动窗口注意力，处理局部上下文；（3）持久记忆：可学习的、任务无关的参数，编码元知识（类似 prefix tuning）
    • 惊喜度驱动的记忆更新: 使用 token 的”惊喜度”（负对数似然）作为记忆更新的触发信号——高惊喜度（出乎意料）的 token 触发深度记忆编码，低惊喜度（可预测）的 token 仅进行浅层更新
    • 记忆衰减与遗忘：核心记忆中的信息随时间衰减，衰减率由 token 的重要性和内容类型自适应调整——类似于人脑的记忆巩固过程
    • 线性复杂度推理：整体架构以线性 RNN 方式运行，O(1) 推理内存（除滑动窗口部分的 O(W) 外），训练时通过并行扫描算法实现 O(N log N)
    • 在长上下文基准（BABILong、RULER、Needle-in-Haystack）上大幅超越 Transformer、Mamba-2 和 DeltaNet，尤其在需要从上下文中检索精确事实的任务上
  • 代表意义: Titans 代表了”神经记忆”研究方向的集大成者——将 DeltaNet 的 delta 规则、Titans 自己的惊喜度驱动机制、持久记忆的任务先验和人类的记忆心理学概念融合为一个统一的记忆架构。其”推理时主动记忆管理”的范式超越了简单的 KV cache 压缩，而是赋予模型真正的”记忆系统”。如果成功扩展到更大规模，Titans 可能成为 Transformer 的有力替代者。

Samba: Simple Hybrid State Space Models for Efficient Unlimited Context Language Modeling

  • arXiv: 2406.07522
  • 发表: arXiv，2024 年 6 月（Microsoft Research）
  • 作者: Liliang Ren, Yang Liu, Yadong Lu, Yelong Shen, Chen Liang, Weizhu Chen (Microsoft Research)
  • 简介: 提出 Samba 架构——在 Mamba 层之间插入滑动窗口注意力层，用最少的 attention 层（每 4 层 1 个 attention 层）弥补 SSM 在精确信息检索上的不足，在 3.8B 规模上匹敌强 Transformer 基线。
  • 核心创新:
    • 稀疏交错混合设计：每 4 层包含 3 个 Mamba 层和 1 个滑动窗口注意力层（窗口大小 2048），形成”Samba block”。这一比例（3:1）比 Griffin 和 Jamba 更偏向 Mamba——仅使用最小量的注意力来修复 SSM 的关键缺陷
    • 精确记忆瓶颈识别：通过消融实验系统地确定了 SSM 失败的确切位置——在精确的”复制”和”检索”任务上，滑动窗口注意力可以在不牺牲线性复杂度优势的情况下提供所需的精确性
    • 递归内存叠加：滑动窗口 attention 层的输出被添加到递归状态中，使模型能够将局部精确的 attention 结果持久化到长程 SSM 记忆流中
    • 无限上下文外推：Samba 可在 4K 上下文长度上训练，直接外推到 1M token 且困惑度稳定——优于纯 Mamba（Mamba 在外推上也有退化）和纯 Transformer（外推完全失败）
    • 在 Phi-3 配方下训练的 Samba-3.8B 在 MMLU、HumanEval 和 GSM8K 等基准上匹敌 Phi-3-mini（3.8B）
  • 代表意义: Samba 提供了一种”极简混合”方案——不是激进地混合 attention 和 SSM（如 Jamba 的 1:1 比例），而是只在绝对必要的地方插入最小量的 attention。其 3:1 的比例和滑动窗口策略是高效的工程折中。最令人印象深刻的是其无限上下文外推能力——在 4K 上训练即可外推到 1M+，这对实际部署有巨大价值。
