推理加速-03：投机解码

精选的 LLM 推理加速中投机解码与并行 token 生成代表性论文列表，2023–2024。

论文

Fast Inference from Transformers via Speculative Decoding

  • arXiv: 2211.17192
  • 发表: ICML 2023 (Oral)
  • 作者: Yaniv Leviathan, Matan Kalman, Yossi Matias (Google Research)
  • 简介: 提出投机解码的奠基性论文：使用小型草稿模型生成候选 token，然后通过大型目标模型的一次并行前向传播来验证所有候选 token，且输出分布可证明与原始模型一致。
  • 核心创新:
    • Draft-then-verify 范式：一个小型高效近似模型自回归地生成若干候选 token，然后大型目标模型通过一次并行前向传播处理所有候选 token
    • 用于精确恢复的拒绝采样：一种新颖的投机采样方案，确保输出分布在数学上与目标模型的标准自回归解码完全相同，使该方法成为无损方案
    • 无需重新训练或修改架构：只需将目标模型与任意较小的草稿模型配对，即可使用现成模型
    • 在 T5-XXL (11B) 的翻译和摘要任务上实现 2–3 倍实际加速，在 LaMDA (137B) 对话上也得到验证
  • 代表意义: 开启了整个投机解码领域的论文。其核心洞察——困难的语言建模任务包含小型模型可以预测的简单子任务，并且候选验证可以批量进行——是该类别所有后续工作的基础。可证明的输出分布保证（无损性）对实际采用至关重要。被广泛实现为 Hugging Face 的”辅助生成”（assisted generation），并部署在生产服务系统中。

Medusa: Simple LLM Inference Acceleration Framework with Multiple Decoding Heads

  • arXiv: 2401.10774
  • 发表: ICML 2024
  • 作者: Tianle Cai, Yuhong Li, Zhengyang Geng, Hongwu Peng, Jason D. Lee, Deming Chen, Tri Dao (Princeton, Together AI, UIUC, CMU, University of Connecticut)
  • 简介: 通过在主模型上添加多个额外的解码头来消除对单独草稿模型的需求，并行预测多个后续 token 并通过树状验证实现 2.2–3.6 倍加速。
  • 核心创新:
    • 无需草稿模型的投机解码：在冻结的 backbone 的最后一个隐藏层之上添加轻量级解码头（单层前馈网络），每个头预测一个不同的未来 token 位置
    • 用于验证的树注意力：从多个头的预测构建一棵候选树，使用特殊构造的注意力掩码同时验证所有路径
    • Medusa-1（无损）：仅微调新增头部，backbone 保持冻结，维持精确的输出分布（约 2.2 倍加速）
    • Medusa-2：backbone 和头部使用特殊配方联合微调，实现 2.3–3.6 倍加速且质量影响极小
    • 自我蒸馏和典型接受：在无训练数据时通过自我蒸馏处理，使用温度阈值接受来进一步提高速度
  • 代表意义: 开创了无需草稿模型的投机解码方法，证明少量廉价头部可以达到甚至超过单独草稿模型的性能。这消除了寻找、加载和维护单独草稿模型的实际负担。Medusa 的树注意力验证已成为许多后续工作（包括 Eagle）采纳的标准技术。

EAGLE: Speculative Sampling Requires Rethinking Feature Uncertainty

  • arXiv: 2401.15077
  • 发表: ICML 2024 (Poster)
  • 作者: Yuhui Li, Fangyun Wei, Chao Zhang, Hongyang Zhang (University of Waterloo, Microsoft Research)
  • 简介: 在特征层面（倒数第二层特征）而非 token 层面进行草稿预测，通过自回归地预测特征再解码为 token，实现比普通解码快 3 倍的加速，且接受率高于 token 级别方法。
  • 核心创新:
    • 特征级草稿预测：不预测 token，而是预测倒数第二层的下一个特征向量，再将其解码为 token——特征预测是一个更直接、不确定性更低的任务
    • Token-advanced 特征预测：通过将当前 token 序列向前推进一个时间步，解决特征级自回归中的固有不确定性，给草稿模型更多上下文
    • 无损：无需对目标 LLM 进行微调；生成的文本保持与原模型相同的分布
    • 在 MT-bench 上比普通解码快 3 倍，比 Lookahead 快 2 倍，比 Medusa 快 1.6 倍；在单张 RTX 3090 GPU 上，LLaMA2-Chat 13B 达到约 160 tokens/s
    • LLaMA2-Chat 70B 实现 2.7–3.5 倍延迟加速
  • 代表意义: 证明了特征级草稿预测从根本上优于 token 级草稿预测。其关键洞察——预测连续特征比预测离散 token 更容易且能获得更高接受率——改变了投机解码的研究方向。EAGLE 在消费级 GPU（RTX 3090）上的性能表明，投机解码不仅适用于数据中心。

EAGLE-2: Faster Inference of Language Models with Dynamic Draft Trees

  • arXiv: 2406.16858
  • 发表: EMNLP 2024
  • 作者: Yuhui Li, Fangyun Wei, Chao Zhang, Hongyang Zhang (University of Waterloo, Microsoft Research)
  • 简介: 在 EAGLE 的基础上引入上下文感知的动态草稿树，根据置信度分数调整树结构，实现 3.05–4.26 倍加速（比 EAGLE v1 提升 20–40%）。
  • 核心创新:
    • 动态草稿树：认识到接受率不仅依赖位置（如静态草稿树所假设），也依赖上下文；每一步根据草稿模型自身的置信度分数调整树结构
    • 基于置信度的节点选择：EAGLE 草稿模型具有良好的校准性（置信度分数与真实接受率高度近似）；EAGLE-2 利用这一点在每一步将最高置信度的 token 选为树节点
    • 在三个 LLM 系列（Vicuna、LLaMA2-Chat、LLaMA3-Instruct）的六种任务类型上实现 3.05–4.26 倍加速
    • 每个草稿-验证周期的平均接受长度为 4–5.5 个 token
    • 声称在某些场景下使 RTX 3060 的生成速度可与 A100 媲美
  • 代表意义: 代表了截至 2024 年中投机解码的最先进水平。动态草稿树在不增加复杂机制的前提下解决了早期方法的一个关键限制（刚性树结构）。表明校准良好的草稿模型可以自我引导构建草稿树，推动投机解码在开源模型上实现实际 4–5 倍加速。

Break the Sequential Dependency of LLM Inference Using Lookahead Decoding

  • arXiv: 2402.02057
  • 发表: ICML 2024
  • 作者: Yichao Fu, Peter Bailis, Ion Stoica, Hao Zhang (UC Berkeley, UC San Diego)
  • 简介: 使用 Jacobi 迭代在没有任何草稿模型或额外头的情况下并行生成多个 token，然后从 Jacobi 轨迹中缓存并验证 n-gram，实现 1.5–2.3 倍加速并精确保持输出。
  • 核心创新:
    • Jacobi 解码重新表述：将自回归解码视为使用不动点 Jacobi 迭代法求解非线性系统，同时解码所有未来 token
    • 双分支架构：lookahead 分支使用固定的 2D 窗口从 Jacobi 迭代轨迹生成投机 n-gram，验证分支通过一次前向传播验证候选 token
    • 无需草稿模型：与投机解码不同，仅使用目标模型本身——无需训练、加载或维护辅助模型
    • 单一注意力掩码：两个分支使用同一注意力掩码以利用 GPU 并行性，兼容 FlashAttention
    • 步骤数量随 log（每步 FLOPs）线性减少，允许在步骤数和每步计算量之间进行权衡
    • 单 GPU 上 1.5–2.3 倍加速，多 GPU 强扩展下代码补全最高 4 倍加速
  • 代表意义: 独特之处在于不借助任何辅助模型就实现了投机解码般的加速。Jacobi 迭代的视角将 LLM 解码与经典数值方法联系起来，提供了一种根本上不同的方法。”无需草稿模型”的特性使其在加载第二个模型不切实际的部署场景中特别有吸引力。扩展规律分析（步骤数 vs. FLOPs）为加速上限提供了理论洞察。

SpecInfer: Accelerating Large Language Model Serving with Tree-based Speculative Inference and Verification

  • arXiv: 2305.09781
  • 发表: ASPLOS 2024（杰出论文奖）
  • 作者: Xupeng Miao, Gabriele Oliaro, Zhihao Zhang, Xinhao Cheng, Zeyu Wang, Zhengxin Zhang, Rae Ying Yee Wong, Alan Zhu, Lijie Yang, Xiaoxiang Shi, Chunan Shi, Zhuoming Chen, Daiyaan Arfeen, Reyna Abhyankar, Zhihao Jia (CMU 及合作者)
  • 简介: 集体使用多个小型草稿模型（collective boost-trees）生成 token 树，配合基于树的并行解码器在 LLM 一次前向传播中验证所有候选 token，相比现有服务系统实现 1.5–3.5 倍加速。
  • 核心创新:
    • Collective boost-trees：利用多个小型投机模型（SSMs）集体生成预测，而非单一草稿模型，将其预测组织成一棵 token 树，每个节点代表一个候选 token
    • 树状并行解码：特殊构造的因果注意力掩码使目标 LLM 能够在一次前向传播中同时验证 token 树中的所有候选序列
    • GPU 优化的树验证：树注意力计算针对 GPU 执行进行了优化，在验证期间最大化 batch 利用率
    • 可证明保持模型质量：LLM 作为 token 树验证器而非增量解码器，确保输出质量与标准自回归解码一致
    • 分布式推理 1.5–2.8 倍加速，offloading 推理 2.6–3.5 倍加速；基于树的解码相比单序列投机解码额外提供约 1.2–1.5 倍加速
    • 因代码质量和可复现性获得 ASPLOS 2024 杰出论文奖
  • 代表意义: 最全面的工业规模投机推理系统。SpecInfer 展示了如何将多个草稿模型、基于树的验证和 GPU 优化整合为一个生产就绪的服务系统。Collective boost-trees 方法和基于树的并行解码影响了后续的服务框架（vLLM 的投机解码、TensorRT-LLM）。已集成到 FlexFlow 服务系统中。

Sequoia: Scalable, Robust, and Hardware-Aware Speculative Decoding

  • arXiv: 2402.12374
  • 发表: arXiv，2024 年 2 月（NeurIPS 2024 审稿中）
  • 作者: Zhuoming Chen, Avner May, Ruslan Svirschevski, Yuhsun Huang, Max Ryabinin, Zhihao Jia, Beidi Chen (CMU / Meta AI / Stanford / Together AI)
  • 简介: 通过动态推测树构建和硬件感知的推测长度优化，解决了大规模投机解码中的异构硬件适应性问题，在消费级到数据中心级 GPU 上均实现了接近最优的加速比。
  • 核心创新:
    • 硬件感知的推测长度优化器：建立了一个分析模型来预测不同硬件平台上推测验证的延迟（考虑内存带宽、计算吞吐量、KV cache 大小），自动选择最优的推测 token 数量。消费级 GPU（高带宽-计算比）适合更多推测 token，数据中心 GPU 适合更少的推测 token
    • 鲁棒的推测树构建：不是简单地从高概率到低概率排序，而是使用”期望接受长度”作为优化目标来构建推测树，同时考虑 token 概率和计算开销
    • 自适应草稿模型切换：维护多个草稿模型（小模型、n-gram 模型、Medusa 头），根据当前生成内容的难度动态选择最合适的草稿源
    • 在消费级 RTX 3090 上实现 4.2 倍加速，在 A100 上实现 2.6 倍加速——证明了推测解码在不同硬件上的最优策略有本质差异
  • 代表意义: Sequoia 填补了投机解码研究中的一个关键空白——硬件感知优化。此前的方法通常假设”更多推测 token = 更好”，但 Sequoia 证明了最优推测长度是硬件依赖的。其自适应草稿模型切换策略也是多草稿源协同的首次系统探索，为生产环境中的投机解码部署提供了实用的调优框架。

DistillSpec: Knowledge Distillation for Speculative Decoding

  • arXiv: 2310.08461
  • 发表: ICML 2024
  • 作者: Sen Yang, Shujian Zhang, Congying Xia, Yihui Feng, Caiming Xiong, Mingyuan Zhou (Salesforce AI Research / UT Austin)
  • 简介: 使用知识蒸馏从目标模型中训练专用的草稿模型——而非使用独立的小模型——使草稿模型的输出分布与目标模型高度对齐，将推测接受率从大约 60% 提升到 80-90%。
  • 核心创新:
    • 面向推测的知识蒸馏目标：设计了专门的蒸馏损失函数，在最小化 token 分布 KL 散度的同时，额外惩罚”草稿模型预测正确但目标模型拒绝”的情况——即优化”可接受性”而非仅优化”准确性”
    • 多教师蒸馏：使用目标模型的多个中间层输出作为额外的训练信号，使草稿模型不仅模仿输出分布，还模仿内部表征
    • 在线蒸馏：在服务过程中持续收集目标模型的输出，微调草稿模型以适应实际部署中的分布偏移
    • 草稿模型可以是架构完全不同的模型（如使用 T5-small 作为 LLaMA-7B 的草稿模型），只要输出空间相同
    • 在 LLaMA-7B 和 LLaMA-13B 上将推测接受长度从平均 2.1 提升到 3.5-4.0，端到端加速比提升约 50%
  • 代表意义: DistillSpec 解决了投机解码的一个核心矛盾——草稿模型和目标模型出自不同训练流程时，输出分布往往不对齐，导致大量的 draft token 被拒绝。通过蒸馏训练专门对准目标模型的草稿模型，显著提高了接受率。该方法在 Salesforce 的生产服务中部署，证明了”定制化草稿模型”优于”通用草稿模型”。

Glide: Globally-Guided Speculative Decoding with Lightweight Drafters

  • arXiv: 2502.10668
  • 发表: arXiv，2025 年 2 月
  • 作者: Ziqian Zeng, Jiahong Yu, Shuai Xu, Qingshan Jiang, Liang Chen, Haiyun Jiang, Qianyi Cai, Jiaqing Liang, Yanghua Xiao (复旦大学 / 达观数据)
  • 简介: 在目标模型的最后隐藏层上添加一个全局引导模块，在不增加序列深度的情况下提前注入全局意图信息，使轻量草稿模型能够以更高的准确率预测后续 token 序列。
  • 核心创新:
    • 全局引导模块（Global Guidance Module）：一个轻量级的注意力层，在目标模型输出 logits 之前，将全局上下文向量（通过 attention pooling 从历史 token 中提取）注入到隐藏层中，帮助草稿模型”看到更大的图景”
    • 零额外推理 FLOPs：引导模块仅在验证阶段被目标模型执行，草稿阶段不承担额外开销。验证时的开销可忽略（< 1% 的额外计算）
    • 与前向-后向一致性约束：引导模块的输出被训练用于预测未来 token——迫使隐藏层学习到前瞻性的表征，这对下游的草稿预测极为有利
    • 与 EAGLE-2 和 Medusa 兼容：可作为插件增强现有的自投机解码方法，在 EAGLE-2 的基础上进一步将接受长度提升约 15%
    • 在 LLaMA-3-8B 和 Qwen-2.5-7B 上实现 1.5-2.0 倍于 EAGLE-2 的加速比
  • 代表意义: Glide 的核心创新是”在目标模型中引入前瞻性信号”——它不改变草稿模型，而是改变目标模型本身的表征，使其更有利于草稿预测。这是一个之前被忽视的方向。其全局引导模块的轻量级设计使其成为最具成本效益的投机解码增强方案之一。

Ouroboros: Speculative Decoding with Large Draft Models

  • arXiv: 2402.13720
  • 发表: arXiv，2024 年 2 月（EMNLP 2024）
  • 作者: Weilin Zhao, Tengyu Pan, Xu Han, Yudi Zhang, Ao Sun, Yuxiang Huang, Kaihuo Zhang, Zhiyuan Liu, Maosong Sun (清华大学)
  • 简介: 翻转投机解码的常规范式——使用与目标模型大小相当的草稿模型（而非更小的模型），通过一种高效的短语验证策略实现了超大推测窗口（10-20 token），将吞吐量提升 1.5-2 倍。
  • 核心创新:
    • 大草稿模型策略：将标准投机解码的”小模型推测、大模型验证”翻转为”大模型推测、超大模型验证”或”相同规模模型推测和验证”。理由是：大草稿模型的推测质量远高于小模型，接受长度足以弥补单 token 推测成本
    • 短语验证（Phrase Verification）：不使用传统的逐个 token 验证，而是将推测 token 组成短语（以低概率 token 为边界分割），对每个短语进行批量验证。如果短语的首 token 被接受，整个短语都大概率被接受
    • 推测长度预测器：基于草稿模型的熵来动态预测最优推测长度——高熵（不确定性高）时推测更少 token，低熵时推测更多 token
    • 当草稿模型与目标模型大小相当时，自投机解码（草稿=目标）可带来 1.5-2 倍加速——这一发现挑战了”草稿模型必须远小于目标模型”的常规认知
  • 代表意义: Ouroboros 打破了一个根本性假设——投机解码要求草稿模型显著小于目标模型。通过短语验证和动态长度策略，它证明了即使是相同规模的模型也可以从投机解码中受益。这对 MoE 模型（DeepSeek-V3 等）尤其重要，因为找到比 MoE 更小但足够准确的草稿模型很难。Ouroboros 的思想已被 DeepSeek-V3 的 MTP 策略所采纳。

SPEED: Speculative Pipelined Execution for Efficient Decoding

  • arXiv: 2310.18872
  • 发表: NeurIPS 2024
  • 作者: Coleman Hooper, Sehoon Kim, Hiva Mohammadzadeh, Hasan Genc, Kurt Keutzer, Amir Gholami (UC Berkeley)
  • 简介: 将投机解码的草稿生成和验证阶段流水线化——草稿模型生成下一个 batch 的猜测 token 时，目标模型同时验证上一个 batch——实现推测与验证的完全重叠，将生成延迟降低高达 3 倍。
  • 核心创新:
    • 投机流水线：将草稿生成和验证分配到不同的 GPU 流（CUDA streams），通过双缓冲机制实现完全并行。目标模型验证 batch N 的同时，草稿模型已在生成 batch N+1 的候选 token
    • 异步 KV cache 管理：草稿模型和目标模型各自维护独立的 KV cache，验证阶段的 KV cache 更新对草稿模型异步可见，避免流水线中的同步等待
    • 推测-验证重叠因子分析：提供了理论分析，量化了在不同草稿模型速度比和接受率下的最优推测长度
    • 零质量损失：与所有投机解码方法一样，通过拒绝采样确保输出分布与标准自回归解码完全一致
    • 在 LLaMA-2-7B（目标）和 LLaMA-68M（草稿）的组合上，相比标准投机解码实现 1.4-1.8 倍额外加速
  • 代表意义: SPEED 的核心贡献是将系统级优化（流水线并行）引入投机解码领域。之前的投机解码工作主要关注算法层面（如何提高接受率），SPEED 则关注如何消除草稿生成和验证之间的空闲等待。其流水线架构可以叠加在任何投机解码算法之上，代表了从”算法优化”到”系统优化”的自然演进。

Multi-Candidate Speculative Decoding

  • arXiv: 2401.06706
  • 发表: arXiv，2024 年 1 月
  • 作者: Sen Yang, Yujia Qin, Yankai Lin, Zhiyuan Liu, Maosong Sun (清华大学)
  • 简介: 在每一步同时验证多个草稿模型生成的候选序列（而非单个序列），通过并行验证多条推测路径来最大化每个验证步骤的接受 token 数量，实现高达 5.5 倍的生成加速。
  • 核心创新:
    • 多候选人并行验证：使用多个草稿模型（或同一个草稿模型的不同采样）生成多条推测路径，在目标模型的一次前向传播中同时验证所有路径——每条路径独立接受或拒绝
    • 最优候选人选择：从所有被部分接受的路径中，选择”接受长度 x 最终 token 概率”乘积最大的路径作为输出，最大化每步验证的实际收益
    • 草稿模型多样性：使用不同架构（n-gram、小型 Transformer、Medusa 头）或不同采样温度的多个草稿源，确保推测路径具有互补性而非冗余
    • 可证明的分布保持：证明了多候选人验证仍然通过拒绝采样保持目标模型的精确输出分布
    • 在 LLaMA-7B 上使用 3 个草稿模型实现平均 4.2 倍加速（在推理密集型任务上高达 5.5 倍）
  • 代表意义: Multi-Candidate Speculative Decoding 将投机解码从一个”串行猜测”问题转变为”并行搜索”问题——通过同时探索多条路径，显著降低了”所有猜测都被拒绝”的概率。其”草稿模型多样性”的洞察尤为重要：不同性质的草稿源提供互补的推测，集体性能远超最佳单草稿源。
