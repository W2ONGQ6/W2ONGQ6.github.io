Learning Transferable Visual Models From Natural Language Supervision (CLIP)

CLIP: Learning Transferable Visual Models From Natural Language Supervision

1. TL;DR / 一句话总结

CLIP（Contrastive Language-Image Pre-training）通过对比学习在 4 亿（图像，文本）对上进行训练，学习将图像和文本映射到共享的嵌入空间，实现了前所未有的零样本迁移能力：无需任何微调即可在 30 个计算机视觉数据集上达到与监督 ResNet-50 相当或更优的性能。CLIP 开创了 “视觉基础模型” 的概念，深刻影响了 Stable Diffusion、DALL-E 2 等后续工作。

2. 研究背景与动机 (Background & Motivation)

2.1 ImageNet 监督学习的局限

截至 2020 年，计算机视觉的主流范式是：

这种范式的根本问题：

问题 表现 后果
封闭词汇 只能识别预定义的类别（如 ImageNet 的 1000 类） 无法泛化到新概念
标注成本高 ImageNet 需要上百万人工标注 限制了可扩展性
域迁移困难 从 ImageNet 到医学图像的迁移效果差 每个新领域需要新数据
脆弱性 对自然分布偏移高度敏感 真实世界部署不可靠

2.2 自然语言监督的机遇

互联网上存在海量的 （图像，文本）配对数据：

  • 社交媒体帖子（Instagram, Twitter）
  • 电商产品描述
  • 新闻配图
  • 维基百科插图

这些数据的独特性：

  • 规模巨大：4 亿对 v.s. ImageNet 的 140 万张
  • 开放词汇：文本描述覆盖了极其丰富的概念
  • 自然分布：反映了真实世界的视觉概念分布
  • 低成本：近乎无限供应，无需人工标注

2.3 核心假设

通过对大规模 （图像，文本） 对进行简单的对比学习，模型可以：

  1. 学习到丰富的视觉概念表示
  2. 将视觉概念与自然语言描述对齐
  3. 实现零样本迁移到任意视觉分类任务
  4. 学习到比固定类别标签更鲁棒的表示

3.1.2 训练机制（逐步骤详述）

Step 1: 数据预处理

  • 图像：随机裁剪到 224×224 (ViT) 或 288×288 (ResNet)，归一化
  • 文本：BPE tokenize，最大序列长度 76 tokens

Step 2: 编码器前向传播

  • 图像编码：I_i = W_i * ImageEncoder(image_i)（投影到共享嵌入空间 + L2 归一化）
  • 文本编码：T_i = W_t * TextEncoder(text_i)（投影到共享嵌入空间 + L2 归一化）

Step 3: 构建 N×N 相似度矩阵

  • 计算批次内所有 N 个图像嵌入和 N 个文本嵌入之间的余弦相似度
  • 对角线上的 N 个元素是真正的 (图像, 文本) 配对——正样本
  • 非对角线的 N*(N-1) 个元素是错误配对——负样本

Step 4: 双向对比损失

  • Image→Text: 对每行 i 计算 CrossEntropy(相似度向量 / tau, 标签=i)
  • Text→Image: 对每列 j 计算 CrossEntropy(相似度向量 / tau, 标签=j)
  • 总损失 = (Image→Text + Text→Image) / 2

Step 5: 梯度更新

  • 使用 AdamW 优化器，cosine 学习率调度
  • 所有参数（两个编码器 + 投影矩阵 + 温度 tau）联合更新

5. 关键技术洞察 (Key Insights)

Insight 1: 自然语言比固定标签更好的监督信号

CLIP 最根本的洞察是：自然语言作为监督信号的表达能力远超固定类别标签。ImageNet 的 1000 个类别强迫模型学习一个 “1000 选 1” 的狭隘世界观。而自然语言（”一只在草地上玩耍的金毛犬”）不仅包含了类别信息，还包含了属性、关系、场景等丰富语义。这使得 CLIP 学到的表示更接近人类对视觉世界的理解方式。

Insight 2: 对比学习比生成式预训练更高效

与 GPT 系列的自回归生成式预训练不同，CLIP 证明了对比目标（判别哪些图文匹配）在学习高质量表示方面更高效。一个简单的解释是：生成式建模需要重建每个像素/单词，浪费了大量容量在低层次的细节上；而对比学习直接优化 “语义匹配” 这一高层目标。

Insight 3: 批量大小是关键的超参数

CLIP 的训练极度依赖大批量：使用 32,768 的 batch size（在 592 块 V100 GPU 上训练 18 天）。这是因为对比学习依赖批次内的负样本——batch size 越大，负样本越多，对比信号越强。这一发现被后续的 SimCLR、MoCo 等工作进一步验证。

Insight 4: Prompt 是 CLIP 的 “使用说明书”

CLIP 对 prompt 模板的敏感度揭示了一个深层事实：模型的零样本能力需要通过正确的 “语言界面” 来激活。这不仅仅是一个工程细节，而是指出了视觉语言模型的核心交互方式 —— 自然语言就是 API。

8. 优势与局限 (Strengths & Limitations)

8.1 优势

  1. 零样本泛化：无需任何微调即可在 30 个数据集上表现优异。
  2. 分布鲁棒性：在自然分布偏移上远超监督模型（如 ImageNet-Sketch 上 60.4% vs 24.1%）。
  3. 开放词汇：不受固定类别限制，理论上可以识别任意概念。
  4. 多模态表示：统一的图像-文本嵌入空间，支持跨模态检索和生成。
  5. 表示质量：学到的特征对多种下游任务具有极强的迁移能力。

8.2 局限

  1. 计算昂贵：需要 256,000 GPU-hours (V100) 和 4 亿对数据。
  2. 细粒度任务差：在纹理分类、卫星图、OCR 等精细任务上不及监督模型。
  3. 抽象概念弱：对计数、空间关系等抽象概念的理解有限。
  4. 数据偏见：训练数据来自互联网，继承了性别、种族等社会偏见。
  5. 语言依赖：主要面向英语，跨语言泛化能力有限。
  6. 因果推理弱：缺乏对因果关系的理解，仅依赖表面相关性。
