核心问题：少算参数与少存历史是两件事

大模型的推理成本至少有两条来源：前馈网络的参数计算，以及注意力对历史序列的访问。MoE 主要处理前者，GQA 和混合注意力则影响后者。把它们分开理解，才能读懂从 Qwen1.5-MoE 到 Qwen3-Next 的路线。

本篇的关键结论：激活参数反映单个 token 的部分计算规模，总参数决定权重存储的基础负担；长上下文成本还取决于注意力与缓存结构。 A3B 不等于只需容纳 3B 权重。

一、先用一个模型理解 MoE

稠密 Transformer 通常让每个 token 经过同一套前馈网络。MoE 则准备多个专家，由路由器为当前 token 选择少量专家，再合并输出。带共享专家时，可以用下面的示意式理解：

专家通常是学习得到的参数子网络，并没有预先贴好“数学”“代码”标签。同一个请求的不同 token 可以选择不同专家，因此不能把 MoE 当成多个独立聊天模型轮流回答。

二、Qwen1.5-MoE：复用已有知识，探索细粒度专家

  • 官方发布：Qwen1.5-MoE: Matching 7B Model Performance with 1/3 Activated Parameters，2024-03-28。
  • 作者 / 机构：Qwen Team，阿里巴巴。
  • 配置：约 14.3B 总参数、2.7B 激活参数；公告以 60 个路由专家加 4 个共享专家描述其细粒度划分，每 token 选择 4 个路由专家。

简介

Qwen1.5-MoE-A2.7B 探索如何利用已有稠密模型的训练成果，构建每 token 计算更少的 MoE。官方将这种初始化称为 upcycling，起点是已有的 Qwen-1.8B。

核心创新

细粒度专家。 把前馈网络的容量组织成更多、更小的专家，路由器可以组合不同子网络，而不是每次选择少数非常大的 FFN。这增加了组合灵活性，也提高了对路由与计算内核的要求。

Upcycling 初始化。 将稠密模型的已有参数用于 MoE 初始化，并引入随机性帮助专家分化。这样可以复用已经学到的知识，减少从零训练的压力。它与“复制同一个模型后永远保持相同权重”不同，后续训练仍会更新专家。

共享与路由分工。 共享部分总是参与计算，路由部分提供条件容量。共享专家可以承载常见变换，但其作用仍由训练决定，不应把“通用知识”理解成严格隔离的数据库。

代表意义与性能边界

公告展示了较低激活参数下具有竞争力的任务表现，并报告特定 A100、vLLM、输入输出长度设置下的吞吐收益。它验证了工程可行性，但该收益不能直接外推到 CPU、低并发或其他专家并行配置。

三、Qwen3-MoE：无共享专家与全局批次均衡

  • 论文：Qwen3 Technical Report，2025 年 5 月，An Yang 等。
  • 首发型号：Qwen3-30B-A3B、Qwen3-235B-A22B。
  • 结构核对：235B-A22B 配置文件。

简介

Qwen3-MoE 使用 128 个专家，每 token 激活 8 个，不设置共享专家。其注意力沿用 GQA 路线，而不是 DeepSeek 的 MLA。Qwen3 还引入 QK-Norm 并去除 QKV bias，以改善训练稳定性。

核心创新一：允许专家在更大统计范围内分工

如果要求每个很小的批次都平均使用所有专家，那么来自同一领域的一组 token 也会被强行分散，可能限制专家专门化。Qwen3 采用全局批次负载均衡，让模型在更大的统计范围内保持负载合理，同时允许局部数据偏向相关专家。

这里的逻辑是“局部可以有偏，全局仍需可控”。不能反过来解释成“小批次均衡必然造成全局不均衡”。辅助目标仍可能与语言建模目标存在权衡，具体训练同步与累积实现需读对应实现，不能仅凭名称推导开销百分比。

核心创新二：稀疏 FFN 与稳定注意力共同工作

QK-Norm 控制 Query 和 Key 的尺度，帮助注意力打分在大规模训练中保持稳定；MoE 改变前馈网络计算分配。二者作用在不同子层，分别处理训练稳定性与条件计算容量。

代表意义

Qwen3 说明共享专家不是 MoE 的必要条件。专家数、专家宽度、Top-K 和均衡策略共同决定能力与成本，不能用一个专家数量排行榜判断结构优劣。

四、Qwen3-Next：用混合注意力处理长序列

  • 官方发布：2025-09-11，见官方发布记录。
  • 模型卡：Qwen3-Next-80B-A3B-Instruct。
  • 作者 / 机构：Qwen Team，阿里巴巴。

简介与公开结构

Next 的 80B-A3B 型号拥有 48 层，以 12 个重复组组织：每组 3 层 Gated DeltaNet 后接 1 层 Gated Attention，各层配合 MoE。模型卡列出 512 个路由专家、每 token 选择 10 个，并有 1 个共享专家。

核心创新一：状态更新与显式历史访问混合

标准注意力通常保存不断增长的 Key / Value，并在生成时查询历史。Gated DeltaNet 通过带门控的状态更新表达历史信息，在递推推理中不需要为该层保存全部历史 KV。它有利于控制长序列的缓存与计算开销，但压缩状态与逐位置访问的表达方式不同。

Next 保留周期性的门控注意力层，使模型仍能在这些层显式访问历史 token。因此它既不是纯线性注意力模型，也不是完全没有 KV Cache。上下文变长时，完整注意力层的缓存仍会增长。

核心创新二：超稀疏专家与稳定性设计

80B 总参数中约 3B 参与每 token 激活，说明参数容量和单 token 计算可以进一步分离。模型卡还列出 zero-centered、带权重衰减的归一化设计，用于稳定训练。架构越稀疏，越需要关注专家数据量、路由负载和内核利用率。

核心创新三：Multi-Token Prediction

MTP 在训练时引入未来多个 token 的预测信号，也可用于推理加速。推理时是否真的提速，取决于引擎是否支持相应路径、预测接受率和验证成本；有 MTP 权重不意味着任意 generate() 调用都会自动更快。

代表意义

Next 把稀疏参数与混合序列建模组合起来，特别面向长上下文工作负载。其原生上下文为 262,144 token，可按模型卡进一步外推；原生长度、外推上限与实际服务设置是三个不同概念。

五、从 Next 到 Qwen3.5 / 3.8：延续与边界

Qwen3.5-397B-A17B沿用每组 3 层 Gated DeltaNet 加 1 层 Gated Attention 的组织方式，并加入视觉语言训练。其语言模型部分为 60 层，专家配置为 512 个路由专家、激活 10 个路由专家加 1 个共享专家。

Qwen3.8-2.4T-A95B模型卡则给出 92 层、2.4T 总参数与 95B 激活参数。这里只比较已公开的结构，不据此推断未公开的数据配方或训练成本。开放权重卡列出的模态与托管 Max 服务的功能也应分别读取。

具体模型 总参数 / 激活参数 路由专家数 / 每 token 选择数 共享专家 序列建模
Qwen1.5-MoE-A2.7B 14.3B / 2.7B 60 / 4 公告按 4 个细粒度共享专家描述 注意力 + MoE
Qwen3-235B-A22B 235B / 22B 128 / 8 无 GQA + MoE
Qwen3-Next-80B-A3B 80B / 3B 512 / 10 1 Gated DeltaNet + 门控注意力

共享专家的宽度和实现会变，表中的“1”与早期“4”不能直接当作同等容量单位。
