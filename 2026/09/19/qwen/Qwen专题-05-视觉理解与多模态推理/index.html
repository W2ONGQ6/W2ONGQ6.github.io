Qwen专题-05：视觉理解与多模态推理 —— 从 Qwen-VL 到原生视觉语言基座

核心问题：图像不是一段没有分词的文本

一张文档图片同时包含字符、版式和空间关系；一个视频还包含帧间变化与真实时间。视觉语言模型需要把这些信息转成语言模型可以利用的表示，并尽量避免在缩放或压缩时丢掉决定答案的细节。

Qwen-VL 系列的演进可以沿三条线阅读：视觉分辨率如何处理、位置与时间如何表达、视觉信息如何进入语言推理。

一、先区分四类视觉任务

任务 一个例子 答案依赖什么
图像描述 描述街景 物体、场景与关系
文档解析 提取发票金额与税号 小字、结构、字段对应关系
视觉定位 给出按钮或物体坐标 精确空间位置、坐标约定
视频推理 判断先取杯子还是先开水龙头 帧顺序、时间戳、跨帧关联

一个模型在图像描述上表现好，不意味着它一定适合发票抽取。评估应覆盖目标任务实际依赖的信息尺度。

二、Qwen-VL：从视觉问答扩展到文字与定位

  • 论文：Qwen-VL: A Versatile Vision-Language Model for Understanding, Localization, Text Reading, and Beyond，2023-08-24 首发。
  • 作者 / 机构：Jinze Bai 等，Qwen 团队、阿里巴巴。
  • 实现：Qwen-VL 官方仓库。

简介

Qwen-VL 在 Qwen 语言模型基础上，通过视觉编码、输入输出接口与分阶段训练引入图像能力。除了描述和问答，报告还强调定位与图像文字读取。

核心创新

视觉与语言对齐。 视觉编码器从像素中提取特征，再将其接入语言模型。对齐训练使模型能够把特征与“哪个物体”“哪个位置”“哪些文字”等语言问题关联起来。

图像、文本与框的联合数据。 报告使用 image-caption-box 等信息建立语义和位置联系，让模型不仅说出“有一只猫”，还能够回答它在哪里。

分阶段训练。 对齐阶段与指令阶段承担不同职责：先让模态表示可以共同工作，再学习多轮问答和任务交互。不是只给纯语言模型加一个图像占位符就能获得视觉能力。

代表意义

初代为后续文档理解和视觉智能体打下基础。不过，固定或受限分辨率下的视觉压缩可能使小字与细节丢失，推动后续动态分辨率设计。

三、Qwen2-VL：动态分辨率与 M-RoPE

  • 论文：Qwen2-VL: Enhancing Vision-Language Model’s Perception of the World at Any Resolution，2024-09-18 首发。
  • 作者 / 机构：Peng Wang 等，Qwen 团队、阿里巴巴。
  • 发布记录：2024 年 8 月起，见视觉系列官方仓库。

简介

Qwen2-VL 的关键变化是让图像分辨率与视觉 token 数动态对应，并用多模态旋转位置表示处理文本、图像和视频。

核心创新一：Naive Dynamic Resolution

把长文档图片强行缩成小正方形会损失小字和布局。动态分辨率允许不同尺寸图像产生不同数量的视觉 token，从而保留更多原始信息。

它没有消除资源约束。视觉 token 越多，语言模型需要处理的上下文越长，预填充与缓存成本也越高。实践中需要通过像素预算、裁剪或分块控制成本，不能把“任意分辨率”理解成无限制输入。

核心创新二：Multimodal RoPE

文本主要依赖一维顺序，图像有高度和宽度，视频还包含时间。M-RoPE 在位置表示中分别处理这些轴，让视觉结构不只依赖被展平后的 token 顺序。

例如，两段文字在图像中上下对齐，可能属于同一列；若只看展平顺序，就容易把它们与旁边列中的值误配。空间位置提供了恢复关系的额外信号。

代表意义

Qwen2-VL 将“更清楚地看”和“更合理地编码位置”连接起来，为文档和视频任务提供共同表示基础。但位置编码本身不会完成 OCR 或事件理解，仍依赖训练数据与模型容量。

四、Qwen2.5-VL：高效视觉编码与真实时间

  • 论文：Qwen2.5-VL Technical Report，2025-02-19 首发。
  • 作者 / 机构：Shuai Bai 等，Qwen 团队、阿里巴巴。
  • 模型发布：2025-01-28 首批发布，后续增加 32B 等型号。

简介

Qwen2.5-VL 继续强化文档解析、精确定位和长视频理解，并通过原生动态分辨率 ViT、窗口注意力与时间表示降低部分开销、改善时空理解。

核心创新一：视觉编码器中的窗口注意力

高分辨率图像包含大量 patch，如果全部视觉 token 都做全局两两交互，成本会快速增加。窗口注意力将部分计算限制在局部区域，配合必要的全局信息交互，让细节保留更可承受。

这里优化的是视觉编码阶段，不能据此推断后续语言模型完全不再承担长视觉序列的开销。

核心创新二：动态帧率与绝对时间编码

相同数量的帧可能对应几秒，也可能对应几分钟。只有帧索引时，模型难以判断真实持续时间。Qwen2.5-VL 的时间设计让视频内容与真实时间联系更紧密，有利于事件定位与时序判断。

动态采样可以平衡时长和成本，但采样遗漏的瞬间无法凭空恢复。例如快速闪烁的指示灯，可能需要更高帧率或局部重新采样才能确认。

核心创新三：结构化输出与视觉操作

文档抽取要求把字段和值准确对应；定位输出要求遵守坐标约定。Qwen2.5-VL 将这些能力扩展到计算机与移动设备操作，但“模型预测了按钮位置”距离“完成操作”仍差实际点击、观察反馈和检查状态的循环。

代表意义

这一代使视觉模型更加接近工具：既可抽取可解析数据，也可提供可执行定位。应用需要明确图像缩放后的坐标系、输出 schema 和异常情况，避免把预测坐标直接用于不同尺寸画面。

五、Qwen3-VL：细粒度信息进入更深的推理过程

  • 论文：Qwen3-VL Technical Report，2025-11-26 首发。
  • 作者 / 机构：Qwen 团队、阿里巴巴。
  • 首批模型发布：2025-09-23，后续补齐稠密和 MoE 尺寸及 Instruct / Thinking 版本。
  • 实现与示例：Qwen3-VL 官方仓库。

简介

Qwen3-VL 支持原生 256K 的文本与多模态交错上下文。报告着重介绍 interleaved-MRoPE、DeepStack 和文本时间戳对齐三项结构变化。

核心创新一：Interleaved-MRoPE

改进时间、高度、宽度位置成分在频率维度上的安排，增强空间与长时间范围的表示。它延续 M-RoPE 的多轴思路，但具体布局不同，不能仅用“还是 RoPE”忽略实现变化。

核心创新二：DeepStack

利用 ViT 的多层特征加强视觉与语言对齐，而不仅依赖最终一层的视觉表示。不同层可能保留不同尺度的信息，融合这些特征有助于语言推理接触更细的视觉线索。

例如，一张图表的整体趋势和角落里的单位标注属于不同尺度的信息，正确回答可能同时依赖两者。多层融合提供了更丰富的输入路径，但并不保证所有细节都被识别。

核心创新三：文本形式的时间戳对齐

报告采用显式文本时间戳帮助模型定位视频事件。时间因此不仅进入位置编码，也以语言模型可直接关联的形式参与上下文，有助于回答“在第几秒发生什么”。

代表意义

Qwen3-VL 强化了多图、视频和文档的跨片段推理，并提供不同尺寸满足延迟与质量需求。Thinking 与 Instruct 的比较要匹配预算，不能把更长输出获得的收益都归因于视觉编码器。

六、Qwen3.5：视觉语言进入共同基座

Qwen3.5-397B-A17B 模型卡明确列出视觉编码器和语言模型，并强调早期融合的多模态训练。它使“通用基座”与“视觉语言分支”的界线发生变化。

但这是具体系列的架构描述，不代表所有后续开放型号都支持相同模态。尤其是开放的 Qwen3.8-2.4T-A95B 与托管 Max 服务，在模型卡中有功能区别。选择时要检查具体 checkpoint 的 processor、模型类和输入 schema。

七、从论文走向文档解析产品

一个稳健的发票解析流程通常包括：保留原始图像 → 按预算缩放或切块 → 输出字段与证据位置 → 校验金额、税号等格式 → 对不确定字段补充局部识别。

评测时应同时观察：

  • 字符是否识别正确，字段和值是否匹配。
  • 表格的合并单元格、页间续表是否保留关系。
  • 缩放后的小字是否丢失，局部裁剪能否改善结果。
  • 模型是否把看不清的内容猜成合理但错误的值。

处理视频时，再增加真实时间戳误差和跨帧事件排序指标。下一篇继续讨论加入声音之后，系统怎样保持时间对齐并输出自然语音。
