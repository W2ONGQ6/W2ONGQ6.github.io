地平线：从芯片到全栈的智驾基座

一、企业定位：车载智能的 Wintel 野心

地平线（Horizon Robotics）成立于 2015 年，由前百度深度学习研究院负责人余凯创立。与其他四家企业不同，地平线是唯一一家以芯片为核心、向上构建全栈智驾方案的 Tier 1 供应商。其战略定位可概括为：“芯片 + 算法软件”双轮驱动，目标成为智能汽车时代的 Wintel（Windows + Intel）组合。

截至 2026 年，地平线已实现：

  • 1000 万片车规级 AI 芯片出货，中国市场第一
  • 覆盖 10+ 主流 OEM（包括理想、长城、上汽、比亚迪、大众等）
  • 2026 年 7 月香港上市，成为”中国自动驾驶芯片第一股”
  • 城市 NOA 芯片市占率 22.8%（2026H1），国内排名第二

核心壁垒：软硬件协同设计能力 —— Journey 芯片针对 BEV、Transformer、世界模型等算法深度优化，HSD 软件栈反向定义芯片架构需求，形成正向飞轮。

二、技术架构全景

2.1 Journey 芯片家族演进

芯片型号 算力 功耗 工艺 核心特性 量产时间
Journey 2 4 TOPS 2W 16nm 首款车规芯片，ADAS 入门 2020
Journey 3 5 TOPS <5W 16nm ASIL-B 认证，低成本方案 2021
Journey 5 128 TOPS 30W 16nm NOH 高速领航，支持 Transformer 2022
Journey 6P 560 TOPS <80W 7nm 城市 NOA，端到端架构，BEV 原生支持 2024
Journey 7（规划中） >1000 TOPS TBD 5nm L3/L4 级，世界模型加速 2027E

Journey 6P 架构创新：

  1. BEV 原生加速器：硬件加速 LSS（Lift-Splat-Shoot）、BEVFormer 等视图转换算子
  2. 稀疏注意力引擎：针对 Transformer 大模型的稀疏计算优化
  3. 座舱 + 驾驶融合：单芯片同时处理智能座舱和 ADAS，降低 BOM 成本
  4. 低功耗设计：560 TOPS 算力下功耗 <80W，对标英伟达 Orin-X（254 TOPS/60W）性能密度更优

2.2 HSD (Horizon SuperDrive) 全栈方案

HSD 是地平线基于 Journey 6P 打造的一站式端到端城市辅助驾驶系统，其架构特点：

感知层：纯视觉 BEV 为主

  • 多相机 BEV 融合：支持 6-12 路相机输入，统一鸟瞰图表示
  • 时序融合：利用历史帧信息增强遮挡场景理解
  • 可选激光雷达：支持视觉 + 激光雷达融合，但软件栈优先保证纯视觉可用

预测层：Transformer 时空预测

  • Agent 轨迹预测：基于注意力机制的多模态轨迹生成
  • 占据网络：输出未来时刻的 3D 占据概率，支持不规则障碍物

规划层：端到端单阶段架构

  • 直接轨迹输出：从 BEV 特征一步到位生成轨迹，无中间模块
  • 可解释性增强：虽是端到端，但保留关键中间表示供调试

控制层：模型预测控制（MPC）

  • 横纵向解耦：分别处理转向和加减速
  • 舒适性优化：针对中国路况的加速度曲线调优

与竞品对比：

  • vs. 小鹏 XNGP：HSD 更保守（单阶段端到端，但保留模块化接口），小鹏更激进（X-World 视频生成世界模型）
  • vs. Momenta Mpilot：HSD 依赖芯片硬件优势，Momenta 强调数据飞轮
  • vs. 华为 ADS：HSD 纯软件授权灵活性更高，华为全栈绑定 MDC 平台

三、学术成果与论文

地平线作为芯片公司，论文产出相对较少，但在硬件效率优化方向有显著贡献：

3.1 核心论文

WidthFormer: Toward Efficient Transformer-based BEV View Transformation

  • 核心思想：提出”宽度优先”的 Transformer 架构，用单层 Decoder 替代多层堆叠，降低推理延迟
  • 技术亮点：新颖的 3D 位置编码机制，使 BEV 特征提取效率提升 40%
  • 工程价值：专为 Journey 芯片的稀疏注意力引擎设计，可实时运行（30fps）
  • 论文链接：arXiv:2401.03836

3.2 专利布局

截至 2026 年，地平线累计申请 1200+ 专利，核心领域包括：

  • 芯片架构：BEV 加速器、稀疏 Transformer 引擎
  • 感知算法：多相机时序融合、占据网络量化
  • 数据闭环：自动标注、场景筛选、长尾挖掘

四、产品落地与合作生态

4.1 量产车型覆盖

OEM 搭载车型 芯片方案 软件方案 功能级别
理想 L 系列全系 Journey 5 理想自研 AD Max 高速 NOA
长城 魏牌、坦克系列 Journey 5/6P HSD 城市 NOA
上汽 飞凡、智己 Journey 3/5 上汽自研 + HSD L2+ / NOH
大众中国 ID 系列（2026+） Journey 6P HSD SuperDrive 城市 NOA
比亚迪（传闻） 高端车型 Journey 6P 联合开发 TBD

关键里程碑：

  • 2025 年 4 月：大众与地平线宣布深化合作，HSD 将成为 VW 中国主力 ADAS 方案
  • 2026 年：iCAR V23 SUV 首发搭载 HSD，对标特斯拉 FSD 的端到端体验
  • 2026H1：HSD 在城市 NOA 芯片市场份额 22.8%，仅次于英伟达

4.2 商业模式创新

  1. 芯片 + 软件分层授权：

    • 芯片 Only：OEM 采购 Journey 芯片，自研算法（如理想）
    • 芯片 + HSD：打包方案，OEM 专注整车集成（如长城、大众）
    • IP 授权：授权 Journey 架构 IP 给其他芯片厂商（探索中）

  2. 数据闭环服务：

    • 提供影子模式、自动标注工具，帮助 OEM 构建数据飞轮
    • 收费模式：按车辆数 + 按里程数混合计费

  3. 座舱 + 驾驶融合芯片：

    • 2026 年发布统一 SoC，单芯片覆盖座舱和 ADAS
    • 降低 OEM 硬件成本，提升地平线单车价值量

五、优势分析

5.1 核心竞争力

  1. 软硬件协同壁垒

    • Journey 芯片为 BEV、Transformer 深度优化，算法运行效率是通用 GPU 的 2-3 倍
    • HSD 软件栈反向定义芯片需求，形成正向飞轮

  2. 性价比优势

    • Journey 6P：560 TOPS / <80W，性能功耗比优于 Orin-X
    • 单芯片成本约英伟达方案的 60-70%，对主流市场吸引力强

  3. 开放生态策略

    • 不绑定整车厂，软硬件分层授权灵活
    • 大众、长城等合作证明其 Tier 1 地位

  4. 量产经验积累

    • 1000 万片出货带来的长尾场景数据
    • 车规级可靠性验证（ASIL-B 认证）

5.2 技术亮点

  • BEV 原生硬件加速：行业首个专为 BEV 算法设计的加速器
  • 端到端单阶段架构：HSD 避免模块级联误差累积
  • 低功耗高算力：适配主流车型热管理需求

六、劣势与挑战

6.1 核心短板

  1. 算法创新不及造车新势力

    • 地平线作为 Tier 1，需兼容多家 OEM 需求，算法激进度不如小鹏、理想
    • X-World、Max-V1 等前沿研究由 OEM 主导，地平线更偏工程优化

  2. 数据飞轮受限

    • 虽有 1200 亿公里数据，但数据所有权归 OEM，地平线无法直接用于模型训练
    • 对比 Momenta 的飞轮模式，地平线缺少 L4 级数据闭环

  3. 高端市场竞争力不足

    • Journey 6P 性能虽强，但对标英伟达 Thor（2000 TOPS）、华为 MDC 810 仍有差距
    • 高端车型（50 万+）倾向选择英伟达或华为全栈方案

  4. 依赖外部 foundry

    • 7nm 芯片依赖台积电代工，地缘政治风险
    • 5nm 先进工艺获取难度增加

6.2 商业风险

  • 客户集中度：理想是最大客户，其自研芯片计划可能影响未来订单
  • 价格战压力：黑芝麻、芯驰等国产芯片厂商竞争加剧
  • 软件授权接受度：传统 OEM 对”买软件”接受度低于”买硬件”

七、未来发展方向

7.1 技术路线图（2026–2028）

短期（2026–2027）

  1. Journey 6P 规模化量产

    • 目标：覆盖 20+ OEM，年出货 500 万片
    • HSD 城市 NOA 覆盖全国主要城市（无高精地图）

  2. 统一座舱 + 驾驶 SoC 上车

    • 推动中央计算架构普及
    • 单车价值量从 500+

  3. HSD 2.0 升级

    • 端到端世界模型集成
    • 支持车路协同 V2X

中期（2027–2028）

  1. Journey 7 发布

    • 算力突破 1000 TOPS，功耗 <100W
    • 原生支持视频生成世界模型（对标 X-World）
    • 瞄准 L3 级高速/城市自动驾驶

  2. IP 授权业务拓展

    • 向全球芯片厂商授权 BEV 加速器 IP
    • 成为车载 AI 芯片的”ARM”

  3. 数据闭环服务商业化

    • 推出 SaaS 平台，帮助 OEM 构建自有数据飞轮
    • 收入模式：订阅制 + 按里程计费

7.2 战略转型：从芯片公司到平台公司

目标定位：成为智能汽车的 Wintel

  • 芯片层（Intel）：Journey 系列覆盖 L2–L4 全场景
  • 软件层（Windows）：HSD 成为行业标准 ADAS 软件栈
  • 生态层：开发者社区、工具链、认证体系

关键举措：

  1. 开放 HSD SDK，吸引第三方开发者
  2. 建立 Journey 芯片生态联盟（类比 Arm Flexible Access）
  3. 推动车载 AI 计算标准制定（参与 ISO/SAE 标准）

7.3 跨域扩展

  • 机器人：Journey 芯片适配人形机器人（低功耗 + 实时性）
  • 智能座舱：从 ADAS 延伸至舱内感知（DMS/OMS）
  • 边缘计算：工业、安防等场景复用 Journey 架构

八、与竞争对手的战略对比

维度 地平线 英伟达 华为 Mobileye
核心优势 性价比 + 本土化 算力天花板 全栈生态 视觉算法积累
客户类型 开放合作 高端车型 战略绑定 传统 OEM
软件策略 可选授权 DRIVE OS 必选 鸿蒙绑定 EyeQ 封闭
弱点 高端算力不足 成本高 + 供货周期长 地缘政治敏感 激光雷达支持弱

地平线的生存空间：

  • 主流市场（15–35 万车型）：性价比 + 灵活性碾压英伟达/华为
  • Tier 1 生态位：不与 OEM 竞争整车，信任度高于华为
  • 本土供应链：规避中美科技脱钩风险

九、总结：通往 Wintel 的三道关

地平线的战略清晰：用芯片建护城河，用软件占生态位，最终成为智能汽车的基础设施。但要实现 Wintel 梦想，需跨越三道关卡：

第一关：算力天花板（技术关）

  • Journey 7 必须在性能上追平英伟达 Thor（2000 TOPS），否则高端市场永远失守
  • 5nm/3nm 先进工艺获取难度上升，需提前锁定产能或探索 Chiplet 架构

第二关：软件生态（商业关）

  • HSD 需要从”一个方案”变成”一套标准”，形成开发者社区和工具链生态
  • 说服更多 OEM 接受”软件付费”模式，打破”硬件一次性买断”的惯性

第三关：数据飞轮（长期关）

  • 当前数据归 OEM 所有，地平线无法构建类似 Momenta 的闭环
  • 需探索联邦学习、数据交易等机制，在不触碰隐私前提下提取共性知识

如果三关全破，地平线将成为中国版 Mobileye + Arm 的组合体；若任一环节受阻，则可能沦为”性价比芯片供应商”而非平台级玩家。
