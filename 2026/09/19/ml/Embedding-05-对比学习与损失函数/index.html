一、对比学习核心思想

1.1 什么是对比学习？

对比学习（Contrastive Learning）：通过比较样本间的相似性和差异性来学习表示。

核心原则：

  • 拉近正样本：语义相似的样本在向量空间中靠近
  • 推远负样本：语义不同的样本在向量空间中远离

数学表达：

1.2 为什么有效？

理论基础：

  • 对比学习等价于在相似图上做谱聚类（Spectral Clustering）
  • InfoNCE 损失是互信息的下界（Lower Bound of Mutual Information）
  • 通过对比学习学到的表示具有不变性和区分性

实践优势：

  • 无需标注：自监督学习，正负样本自动构造
  • 泛化能力强：学到的表示可迁移到下游任务
  • 简单高效：易于实现和扩展

真实检索数据很少满足“每个 query 只有一个正确文档”。例如“如何退款”可以同时命中退款入口、时效说明和特殊订单规则。若把除一个正例外的全部候选都视为负例，训练会主动破坏这些可接受结果之间的关系。

五、难负样本挖掘

5.1 为什么需要？

问题：随机负样本太简单，模型容易区分
解决：挖掘”看起来像但实际不是”的难负样本

策略分类：

  1. Semi-hard negatives：距离在 和 之间
  2. Hard negatives：距离 < （最难）

5.2 在线挖掘 vs 离线挖掘

在线挖掘（Online Mining）：

  • 训练时从当前 batch 中选择难负样本
  • 计算高效，但负样本池有限

离线挖掘（Offline Mining）：

  • 预先用检索模型（如 BM25）找到难负样本
  • 构造 五元组
  • 负样本质量高，但需要额外计算

5.3 ANCE（Approximate Nearest Neighbor Negative Contrastive Estimation）

定期更新难负样本：

优势：动态更新，避免过拟合到固定负样本

5.4 先排除假负例，再追求“更难”

难负例越接近 query，越可能其实是漏标正例。例如 query 为“怎么修改收货地址”，检索到“下单后地址变更说明”很可能相关；若将其强行推远，模型会学到与业务相反的边界。

推荐的挖掘流程：

  1. 用 BM25 或当前模型召回每个 query 的 Top-50 / Top-200；
  2. 排除已知正例、同一文档的近重复 chunk 与同一业务实体；
  3. 对得分最高的候选做人工抽检，记录漏标率；
  4. 优先使用 semi-hard 样本；对存在歧义的样本降权或跳过；
  5. 每轮挖掘都固定模型、索引和数据版本，保证实验可回溯。

六、对比学习的理论分析

6.1 与互信息的关系

InfoNCE 损失可以写成：

定理：最小化 InfoNCE 等价于最大化 （互信息）的下界。

6.2 与谱聚类的联系

重要结论（2023 年论文）：

对比学习 = 在样本相似图上做谱聚类

具体来说，InfoNCE 的优化等价于：

  1. 构造相似图：节点是样本，边权重是相似度
  2. 求解图拉普拉斯矩阵的特征向量
  3. 特征向量即为学到的 Embedding

这解释了为什么对比学习能学到聚类结构。

6.3 负样本数量的影响

更多负例通常能提高任务难度，但收益不保证随 线性增长：batch 越大，假负例、数据重复和优化不稳定的概率也会升高。负例的质量与多样性往往比单纯堆大 batch 更重要。

实践建议：

  • 先用当前显存能承受的 batch 建立基线；
  • 记录有效负例数、假负例抽检率与不同来源负例的占比；
  • 显存不足时可用跨设备 negatives、梯度缓存或队列，但要注意队列向量与当前编码器存在陈旧性；
  • 最终用独立检索集验证，而不是只观察训练 loss。

八、总结

8.1 损失函数对比

损失函数 正样本数 负样本数 适用场景
InfoNCE 1 K (批量-1) 通用，最流行
Triplet Loss 1 1 需要精细三元组采样
MNR Loss 1 批量-1 SBERT 等文本 Embedding
Cosine Loss 1 0 有标注相似度分数

8.2 最佳实践

  1. 先对齐任务：检索、STS、分类和多模态匹配的正负例定义不同。
  2. 从 InfoNCE / MNRL 开始：简单、可扩展，且适合双编码器检索。
  3. 温度系数要与 batch、维度一起调：从 0.05–0.1 起步，观察验证集而非训练 loss。
  4. 大 batch 不等于好数据：优先处理多正例、去重和假负例。
  5. 难负样本需要审核：先使用 semi-hard，再逐步加入高分 hard negatives。
  6. 双向任务用双向指标：对称损失、图→文与文→图都要单独评测。
