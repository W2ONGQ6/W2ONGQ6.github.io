2026 年主流 Embedding 模型对比

一、MTEB 基准测试

1.1 什么是 MTEB？

MTEB (Massive Text Embedding Benchmark) 是评估 Embedding 模型的综合基准，包含：

  • 56+ 任务
  • 8 大类别：检索、重排序、分类、聚类、配对分类、STS、摘要、BitextMining
  • 112 数据集
  • 多语言支持

1.2 评估指标

  • 检索（Retrieval）：NDCG@10, MAP, Recall@100
  • 重排序（Reranking）：MAP, MRR
  • 分类（Classification）：Accuracy, F1
  • 聚类（Clustering）：V-measure, 调整兰德指数
  • 语义相似度（STS）：Spearman/Pearson 相关系数

注意：MTEB 平均分可能误导——检索任务通常比分类更重要（RAG 场景）。

2.2 BGE-M3：多语言多功能多粒度

BGE (BAAI General Embedding) - M3 特点：

  • Multi-Lingual：100+ 语言支持
  • Multi-Functionality：密集检索、稀疏检索、多向量检索
  • Multi-Granularity：句子、段落、文档级别

技术创新：

  • 自知识蒸馏：教师模型自己训练学生
  • Retromae 预训练：遮盖编码器 + 解码器重建
  • 混合检索：dense + sparse + multi-vector 三种模式

训练数据：

  • 500M+ 弱监督文本对
  • 跨语言平行语料（Wikipedia）
  • 合成困难负样本

2.3 E5-Mistral-7B：指令感知大模型

E5 (Text Embeddings by Weakly-Supervised Contrastive Pre-training) 演进：

  • E5-base/large (2022)
  • E5-v2 (2023)
  • E5-Mistral-7B-instruct (2024)：基于 Mistral-7B，支持指令

技术特点：

  • 指令感知：理解任务意图（”Represent this sentence for searching relevant passages”）
  • 弱监督训练：无需人工标注，自动挖掘正负样本
  • LoRA 微调：冻结 Mistral 主体，只训练适配层

训练步骤：

  1. CCPairs 数据（Common Crawl 正负样本对）
  2. 对比学习 + InfoNCE 损失
  3. 多任务微调（检索、分类、STS）

2.4 GTE：阿里达摩院出品

GTE (General Text Embeddings) 系列：

  • GTE-base/large/large-zh (2023)
  • GTE-large-v1.5 (2024)：改进训练流程

训练数据：

  • 海量中英文数据（搜索引擎、电商、社交媒体）
  • 领域多样性：新闻、科技、金融、医疗

优势：

  • 中文表现优异（中文语料占比高）
  • 电商/搜索场景效果好
  • Apache 2.0 开源，可商用

3.2 Gemini Embedding 2：多模态统一

发布时间：2026 年 3 月 10 日

核心特性：

  • 五模态支持：文本、图像、视频、音频、PDF
  • Matryoshka Representation：一个模型输出多种维度（256/512/768/1024）
  • 100+ 语言：零样本跨语言检索
  • 长上下文：支持 8K tokens

使用场景：

  • 跨模态检索：文本搜视频、图像搜文档
  • 多语言知识库：统一索引中英日韩
  • 灵活维度：低延迟用 256 维，高精度用 1024 维

Voyage 3 特点：

四、模型选型指南

4.1 场景匹配矩阵

场景 推荐模型 理由
中文 RAG BGE-M3, GTE-large 中文语料充足
英文 RAG E5-Mistral-7B, Voyage 3 MTEB 检索性能优
多语言知识库 BGE-M3, Gemini Embed 2 100+ 语言支持
多模态检索 Gemini Embed 2 唯一五模态统一
低延迟需求 all-MiniLM-L6-v2 22M 参数，384 维
高精度需求 NV-Embed-v2, Voyage 3 MTEB 榜首
离线部署 BGE-base, GTE-base 开源可商用
成本敏感 all-MiniLM-L6-v2 免费自托管

4.2 权衡三要素

1. 精度（Accuracy）

  • MTEB 分数：NV-Embed-v2 (70.2) > Gemini (71.3，但检索略低)
  • 检索任务单独看：Voyage 3 (63.2) > OpenAI v3 (60.4)

2. 速度（Latency）

  • 模型大小：22M (MiniLM) < 278M (Qwen) < 568M (BGE-M3) < 7B (E5-Mistral)
  • 维度：384 < 768 < 1024 < 3072 < 4096
  • QPS：MiniLM (1000+) > BGE-base (200) > E5-Mistral (20)

3. 成本（Cost）

  • 自托管：GPU 租金（$0.5-2/小时） + 维护成本
  • API 调用：Gemini ( 0.12) < OpenAI ($0.13)
  • 长期：100M tokens → Gemini 3.6k/月

六、总结与建议

6.1 开源首选

  • 综合性能：BGE-M3（多语言）、E5-Mistral-7B（英文）
  • 速度优先：all-MiniLM-L6-v2
  • 中文场景：BGE-M3、GTE-large

6.2 商业首选

  • 多模态：Gemini Embedding 2（唯一选择）
  • 高精度：Voyage 3、NV-Embed-v2
  • 成本敏感：Gemini Embedding 2（$0.025/M tokens）

6.3 混合策略

两阶段检索：

  1. 第一阶段：小模型（MiniLM）召回 top-100
  2. 第二阶段：大模型（E5-Mistral）重排序 top-10

平衡速度与精度，成本仅增加 10%，精度提升 20%。
