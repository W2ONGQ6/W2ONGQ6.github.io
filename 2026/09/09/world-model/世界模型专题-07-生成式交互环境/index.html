引言：从“看一段视频”到“走进视频里”

视频生成模型回答“接下来可能出现什么画面”，交互式世界模型还必须回答“按下左键、转动视角或执行抓取后会怎样”。两者只差一个动作条件，工程难度却相差很大：输出必须低延迟地逐帧生成，长时间保持状态，还不能忽略用户输入。

这条路线经历了三次转折：VideoGPT 把视频变成离散 token 序列；IRIS 证明 Transformer 世界模型可以直接训练 RL agent；Genie 用 latent action model 从没有动作标签的互联网视频中发现控制。DIAMOND 与 GameNGen 随后又把 diffusion 推到可玩的神经环境。

这种分解有三个优势：

  • token 序列能直接使用 Transformer；
  • 量化降低预测空间复杂度；
  • 生成分布可表达多种未来，而不是回归平均帧。

代价是 tokenizer 的 information bottleneck。码本没有保留的细节，后面的 dynamics 再强也恢复不了；码本若过大，序列建模又变得昂贵。

与普通视频预测相比，它必须通过反事实测试：固定相同历史，分别输入“左”和“右”，生成未来应在几何与运动上稳定分叉。

一个模型可能在训练数据里发现动作与画面的相关性，却没学到真正干预关系。例如数据中“向左”总出现在某类地图，模型可能换背景而不是转向。因而动作遵循不能只看自然视频质量，需要 controlled intervention 和闭环任务测试。

三、IRIS：Transformer 世界模型成为 RL 训练场

IRIS 由三部分组成：

  1. discrete autoencoder 将 Atari 帧编码为 tokens；
  2. autoregressive Transformer 根据历史 token 与动作预测下一 tokens、奖励和终止；
  3. actor-critic 在生成的 imagined trajectories 中训练。

在 Atari 100k 协议下，智能体只有相当于约两小时游戏的真实交互。IRIS 在 26 个游戏上取得 1.046 的 mean human-normalized score，并在其中 10 个超过人类基线。这个结果的重要性是：sequence model 可以从有限数据构建足够支持策略训练的离散视觉世界。

同时，Atari 的动作空间小、规则固定、视觉范围有限，不能直接外推到开放 3D 世界。IRIS 是生成式世界模型作为训练环境的强证据，不是通用物理模拟器的证明。

四、Genie：没有动作标签，怎样学会控制

整个系统由时空 tokenizer、latent action model 和自回归 dynamics model 组成。用户不需要知道 latent action 的语义，只需尝试不同离散控制，观察角色向左、向右、跳跃或产生其他变化。

4.1 Latent action 为什么重要

它把海量被动视频转化为近似交互数据，使 world model 不再受限于昂贵动作标注。更深一层，它把“动作是什么”从人工定义改为从可观察状态变化中发现。

4.2 Latent action 的局限

  • 相机运动与对象动作可能纠缠；
  • 视频中未出现的干预无法凭空识别；
  • latent action 不一定能对齐真实执行器；
  • 时间上相邻不等于因果，LAM 可能编码不可控事件。

Genie 的 11B 参数模型展示了由文本、草图、照片或生成图像初始化可控制 2D 环境。它更接近“可探索内容生成器”，距稳定训练通用 agent 所需的长期、可校准环境仍有距离。

五、DIAMOND：视觉细节可能直接影响策略

离散 token 世界模型效率高，但 tokenizer 可能丢掉细小却关键的信息，例如游戏中的子弹、计分状态或小物体。DIAMOND（DIffusion As a Model Of eNvironment Dreams）用 diffusion model 直接生成下一观测，论证视觉细节对 RL 并非总是无关。

六、GameNGen：扩散模型实时模拟 Doom

GameNGen 分两阶段训练：

  1. 先让 RL agent 玩 Doom，记录画面与动作；
  2. 训练 diffusion model，根据历史帧和动作生成下一帧。

部署时，模型自回归地把自己生成的帧作为下一步上下文。论文报告在单个 TPU 上约 20 FPS，可进行分钟级交互；短片段的人类评审接近随机区分真实游戏与模型生成。

长程稳定依赖 conditioning augmentation：训练时故意破坏历史输入，让模型学会从自己产生的小错误中恢复，而不只适应干净的真实历史。这直接针对 teacher forcing 与自由滚动之间的分布差异。

不过“视觉上像 Doom”与“规则上等价于 Doom”仍不同。模型可能在少见地图、极端动作序列、隐藏状态和精确碰撞规则上失真。神经游戏引擎的评测必须从画质扩展到状态覆盖和游戏机制一致性。

七、Genie 2：从 2D 平台视频走向生成式 3D 世界

Genie 2 接受单张 prompt image，生成可由键盘和鼠标控制的 3D 环境。Google DeepMind 官方材料展示了角色动画、对象交互、光照、水体、烟雾和视角变化，并报告可维持最长约一分钟、常见展示为 10–20 秒。

它的重要变化有两个：

  • 初始世界不再局限于训练视频里的固定关卡，可从图像按需生成；
  • 环境可供人或 agent 实时采取动作，成为训练和评估 embodied agent 的候选基础设施。

但 Genie 2 没有同步公开完整论文与训练细节。对其能力的陈述应标记为官方技术展示，不能与公开 benchmark、可复现实验等量齐观。

架构只是表面，最关键的变量是数据中有没有干预覆盖。一个生成器若只看过“正常玩法”，很难可靠模拟玩家故意撞墙、长时间原地旋转或反复执行无意义动作；而这些恰恰是 agent 探索时会出现的行为。

九、交互世界的六项硬指标

9.1 Latency

交互要求每一步在固定时限内产生结果。离线生成一分钟视频和以 20–30 FPS 响应动作是不同系统问题。

9.2 Action controllability

动作改变必须及时、方向正确，并持续影响后续状态，而不是只改变下一帧局部纹理。

9.3 State persistence

拿走的物品不能转身后复原，离开视野的对象不能被忘记，地图拓扑不能随生成漂移。

9.4 Stochastic calibration

模型不仅要生成可能未来，还要给不同未来合理概率。总生成最常见结果会漏掉稀有危险事件。

9.5 Mechanic consistency

碰撞、生命值、库存、任务进度等隐藏规则应跨长程保持，而不只是画面连贯。

9.6 Agent utility

最终要测在模型中训练或评估的 agent，转到真实环境后是否仍有效。视觉人评不能替代 policy transfer。

十、代表工作

VideoGPT: Video Generation using VQ-VAE and Transformers

  • 论文：Yan et al., 2021
  • 核心创新：用 VQ-VAE 离散化视频，再以 Transformer 自回归建模时空 token。

Transformers are Sample-Efficient World Models

  • 论文：Micheli, Alonso & Fleuret, ICLR 2023
  • 核心创新：IRIS 在 discrete Transformer world model 中训练 agent，在 Atari 100k 展示样本效率。

Genie: Generative Interactive Environments

  • 论文：Bruce et al., 2024
  • 核心创新：从无动作标签互联网视频学习 latent actions，并生成逐帧可控环境。

Diffusion for World Modeling: Visual Details Matter in Atari

  • 论文：Alonso et al., NeurIPS 2024 Spotlight
  • 核心创新：DIAMOND 以 diffusion world model 保留视觉细节并训练 RL agent。

Diffusion Models Are Real-Time Game Engines

  • 论文：Valevski et al., ICLR 2025
  • 核心创新：GameNGen 在动作条件 diffusion 中以约 20 FPS 自回归模拟 Doom。

Genie 2: A Large-Scale Foundation World Model

  • 材料：Google DeepMind, 2024
  • 核心展示：由单图生成可键鼠控制的 3D 环境，最长约一分钟。
  • 证据等级：官方研究展示，缺少完整公开论文和独立复现。

小结：可交互不是视频生成上的一个按钮

从 VideoGPT 到 IRIS，视频 token 成为可供策略学习的环境状态；Genie 用 latent action 打开无标签视频，DIAMOND 与 GameNGen 则证明 diffusion 也能以动作条件实时滚动。交互式世界模型由此从“小型游戏中的想象训练”走向“按需生成可玩的环境”。

下一篇讨论规模化后的变化：Sora 把视频生成描述为世界模拟，GAIA-1 把真实驾驶动作接进生成，Cosmos 建立 Physical AI 平台，Genie 3 与 GWM-1 则把实时、长上下文和产品化推到前台。核心问题仍是：生成得像世界，是否等于理解世界？
