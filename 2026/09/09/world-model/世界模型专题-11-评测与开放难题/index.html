引言：最危险的模型不是不会生成，而是自信地生成错误后果

世界模型横跨 latent dynamics、树搜索、视频生成、机器人和驾驶，很难用单一排行榜比较。像素 FVD、latent loss、环境回报分别只观察能力的一层。尤其在规划中，模型不需要对所有未来都平均准确，却必须在候选动作之间做对排序。

本篇给出一套从内部表征到真实闭环的五层评测框架，并集中讨论对象持久性、因果干预、概率校准、模型利用和评测污染等开放问题。

一、五层评测阶梯

Level 1：表示充分性

检查 latent state 是否包含位置、速度、对象身份、接触、任务进度等变量。常用 linear probe、few-shot probe 或 retrieval。

局限：信息能被 probe 读出，不代表 transition 会正确维护，也不代表 planner 会使用。

Level 2：条件预测

检查单步/多步观测、状态、奖励、终止预测：

应按 horizon 绘制误差曲线，而不是只报告一个平均数。

Level 3：反事实动作一致性

固定相同历史，改变动作 ，测预测差异是否符合真实干预：

还要与真实 simulator 或可控实验的 比较。仅仅“不同动作生成不同画面”不够，方向和量级都应正确。

Level 4：规划保真度

给定候选动作集合，世界模型对回报或风险的排序应接近真实环境：

这通常比像素误差更贴近用途。可以进一步测 top-1 regret：

Level 5：闭环效用与安全

最终测用模型规划或训练的 agent 在真实/高可信环境中的成功率、回报、数据效率、约束违反和尾部风险。只有这一层能证明世界模型对行动真正有用。

二、为什么 FID、FVD 和人眼都不够

FID/FVD 比较生成样本与真实数据的 feature distribution，适合整体视觉质量，却有三类错位：

  • 对动作是否执行不敏感；
  • 对小但关键的几何错误不敏感；
  • 分布相似不保证单条轨迹状态一致。

人眼也容易被纹理和光影吸引，忽略库存、碰撞盒、对象身份和时序因果。一个驾驶模型可以生成电影般画面，却让远处行人凭空消失；一个机器人模型可把抓取画得流畅，却让手指穿过杯壁。

因此视觉指标应与 action adherence、geometry、state persistence 和 downstream policy 指标并列，而非作为总代分数。

三、对象持久性与未观测状态

世界不是当前画面的集合。对象离开视野后，其身份、位置和状态仍应存在。可设计三类测试：

3.1 Occlusion recovery

对象被遮挡后再次出现，检查身份、属性和运动轨迹是否连续。

3.2 Revisit consistency

agent 离开房间、执行一段动作后返回，检查先前移动或拿走的对象是否保持改变。

3.3 Hidden variable intervention

改变画面不可见但会影响未来的变量，例如质量、摩擦或库存，观察模型能否从历史推断并持续维护。

纯 sliding-window video generator 容易在信息退出窗口后遗忘。扩大 context 能延迟遗忘，却不能保证形成可写、可读、不可随意重绘的 persistent state。

四、几何与物理：合理样片不等于校准模拟

物理评测至少分三层。

4.1 Kinematics

位置、速度、关节限制、相机轨迹是否连续，物体是否穿透。很多模型首先学会这一层。

4.2 Dynamics

质量、力、摩擦、碰撞、形变是否满足量级与因果关系。视觉上自然的运动可能仍违反动力学。

4.3 Stochastic physics

同一初始条件下，真实系统有一组结果分布。应比较均值、方差、分位数和 rare event frequency，而不是从模型中挑一条最好看的样本。

例如抛球落点可用 calibration curve 检查：模型声称 80% 覆盖区间时，真实落点应约 80% 落入。如果只有 45%，模型就是过度自信。

五、行动因果性：从相关视频到干预模型

离线视频通常来自行为策略 ：

数据只覆盖 常做的动作。世界模型要评估新策略 ，却会遇到 选择而 很少选择的反事实动作。

可靠评测需要：

  • 从相同状态执行多个动作的 paired intervention；
  • 对动作大小、方向和时序做系统 sweep；
  • 将相机控制与对象控制分离；
  • 检查 action permutation 后模型是否仍靠场景先验猜未来；
  • 对数据支持外动作测 uncertainty 或拒绝，而非强行输出。

没有干预覆盖时，生成结果最多是 observational prediction，不能无条件解释为 causal simulation。

六、模型利用：规划器是最严格的红队

planner 会搜索让模型回报最大的动作：

即使平均误差很小，只要存在窄小的高估区域，优化器就会集中到那里。可用三个实验诊断：

6.1 Search-budget curve

逐渐增加 CEM samples、MCTS simulations 或 diffusion candidates。若模型内回报持续升高、真实回报反而下降，说明更多搜索在加剧 model exploitation。

6.2 Adversarial action search

直接寻找使模型与真实 simulator 分歧最大的动作序列，构造模型的反例集。

6.3 Holdout policy evaluation

训练模型时保留行为风格明显不同的一组 policy，用这些 policy 产生的轨迹测试分布外 dynamics，而不是随机切分相邻帧。

随机 train/test split 往往泄漏几乎相同的场景与策略分布，严重高估泛化。

七、不确定性应怎样评估

一个模型说“不知道”必须满足两点：错误时 uncertainty 较高，给出的概率数值也大致校准。

常用指标包括：

  • negative log-likelihood 与 proper scoring rules；
  • expected calibration error；
  • prediction interval coverage；
  • ensemble disagreement 与真实误差的相关性；
  • OOD detection AUROC；
  • risk-coverage curve：拒绝最不确定样本后，剩余错误怎样下降。

对控制更关键的是 selective planning：只在模型置信范围内规划，超出范围切换到保守 controller 或请求新观测。一个会拒绝 5% 危险状态的模型，可能比所有状态都自信回答的模型更有用。

八、跨层基准怎样设计

一个完整 benchmark 不应只有公开视频集，还需可执行环境或受控实验。

维度 测试设计 指标
视觉 held-out 自然轨迹 FVD、感知距离、人评
状态 对象/几何 probe position、identity、IoU、depth
动作 同状态多干预 action adherence、effect error
记忆 遮挡与回访 state persistence、map consistency
概率 重复随机实验 NLL、coverage、calibration
规划 候选动作真实复验 rank correlation、regret
闭环 agent 连续交互 success、return、violations、tail risk

还应同时报告训练数据、动作覆盖、推理计算、context length 和是否使用未来信息。否则同名“世界模型”可能比较的是完全不同问题。

九、2025–2026 评测转向

随着交互式视频世界模型增多，评测正在从单段视频质量转向组合能力：

  • **EWMBench（2025）**拆分 embodied world model 的场景、运动与语义质量；
  • **What-If World（2026）**聚焦具身场景中的反事实因果；
  • **MiraBench（2026）**评估机器人模型的 action-conditioned reliability；
  • **WorldRoamBench（2026）**关注长时探索中的稳定性；
  • **PlayWorld（2026）**让 agent player 用长期目标检验世界，而非只让视觉模型打分；
  • **CaliBench（2026）**开始追问视频世界模型的随机动力学是否校准。

这些工作多数仍是新预印本，具体指标尚未形成稳定标准，但方向一致：从“生成像不像”转向“状态是否真、动作是否管用、概率是否可信、agent 能否完成长期目标”。

十、开放难题

10.1 长程抽象与局部精度如何兼得

长任务需要低频语义状态，接触控制需要高频几何与力。单一 token 时间尺度很难同时处理，分层 world model 是自然方向。

10.2 记忆应是上下文还是外部状态

长 context 易于训练，却难保证状态可定位和不可篡改；结构化地图、对象 memory 或外部 simulator state 更稳定，却限制开放生成。

10.3 如何学习真正的反事实

互联网视频提供广度，机器人和驾驶日志提供动作，但都缺少同状态多干预。主动实验、因果数据采集和 simulator grounding 仍不可替代。

10.4 世界模型怎样安全更新

在线数据可修正模型，也可能造成遗忘或被异常轨迹污染。需要版本化、回归场景集、uncertainty gating 和可回滚更新。

10.5 “世界”应统一还是模块化

一个巨大生成模型便于共享知识，几何、物理、语言和控制的专门模块更易验证。未来很可能不是纯单体或纯模块，而是共享 backbone 加可校验状态与工具。

十一、给论文阅读者的核查清单

看到“通用世界模型”“物理理解”“可用于规划”等表述时，逐项追问：

  1. 训练数据里有真实动作，还是事后推断 latent action？
  2. 测试是否固定初始状态并改变动作？
  3. 多步结果来自 teacher forcing 还是自由自回归？
  4. 是否报告长 horizon、回访和隐藏状态？
  5. 概率模型是否做 calibration，而非只挑样片？
  6. planner 增加搜索预算后，真实表现是否同步提高？
  7. agent 是否在模型之外的环境复验？
  8. 结果是公开论文/代码，还是仅官方 demo？
  9. “zero-shot”相对于哪些数据和任务？
  10. 失败案例是否覆盖安全关键长尾？

这份清单比记住某个总榜分数更耐用。

小结：世界模型最终要接受行动的检验

评测应从表示、预测、反事实、规划一路走到闭环。视觉质量仍有价值，但它只能证明模型生成了像数据的样本；世界模型真正的承诺是，对未执行的动作给出足以支持决策的后果预测。
