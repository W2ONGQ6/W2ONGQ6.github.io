世界模型专题-03：PlaNet 与 Dreamer —— 在潜空间中学习和想象

引言：把分开的 V、M、C 重新接起来

World Models 证明了“在梦境中训练策略”可行，但它的 VAE、MDN-RNN 和 controller 分阶段训练：视觉编码器关心单帧重建，不知道控制需要什么；控制器也不能用价值函数把短期想象接到长期回报。

PlaNet 与 Dreamer 的推进可以概括为两步：

  1. 用 **Recurrent State-Space Model（RSSM）**联合学习表示、记忆和随机动力学；
  2. 先用 PlaNet 在 latent rollout 中在线搜索动作，再由 Dreamer 学出 actor-critic，把反复搜索摊销进策略网络。

它们奠定了今天 latent world model 的标准骨架。

一、RSSM：确定性记忆与随机状态各司其职

现实环境同时包含两种信息：历史中已知但当前看不见的信息，以及未来本身的随机性。只用 RNN hidden state 容易把所有东西压进一个确定向量；只用逐时刻随机变量，又难以稳定保存长历史。

RSSM 将状态拆成：

  • 确定性 recurrent state ：压缩历史；
  • 随机 state ：表达当前状态和多种可能未来。

三、PlaNet：在潜空间用 CEM 在线规划

PlaNet 不直接训练策略网络。每个真实时刻，它在 RSSM 中评估大量候选动作序列：

Cross-Entropy Method（CEM）的过程是：

  1. 从一个动作序列分布采样候选；
  2. 在世界模型中展开并计算回报；
  3. 保留得分最高的一小批 elite；
  4. 用 elite 重新拟合动作分布；
  5. 迭代若干轮，执行最佳序列的第一步。

PlaNet 的突破是不把未来图像解码出来。规划只需 latent transition 和 reward predictor，图像 decoder 只在训练表征时使用。与像素级视频 rollout 相比，这大幅降低计算量。

PlaNet 留下的墙

  • 每个环境步都重新执行 CEM，计算成本高；
  • 规划 horizon 有限，远期回报难以覆盖；
  • 随机采样搜索在高维动作空间效率下降；
  • 模型仍可能把候选动作带到数据分布之外。

Dreamer 的答案是：让 actor 学会直接提出好动作，让 critic 为 imagination horizon 之后的价值收尾。

五、为什么 imagination horizon 不宜无限增长

Dreamer 通常只展开有限步，然后用 critic bootstrap。这里存在一个三方权衡：

horizon 模型误差 对 critic 的依赖 计算成本
很短 小 高 低
中等 可控 中等 中等
很长 累积严重 低 高

长 rollout 看似更“会想”，却可能让 actor 优化虚假的远期状态；短 rollout 更可靠，但 critic 若估计不准，也会把偏差带回策略。Dreamer 的有效性来自模型、actor 和 critic 共同承担预测，而不是世界模型单独准确到可以无限模拟。

六、DreamerV2：离散潜变量与 Atari

DreamerV2 将随机状态从高斯变量改为多个 categorical variables。离散 latent 可以组合出大量状态，同时避免连续高斯后验用均值混合不同模式。

如果有 个 categorical variable、每个有 类，状态容量为 种组合，但实际表示和采样成本只与 相关。训练用 straight-through gradient 在离散采样处近似反向传播。

它还改进 KL balancing 和 actor gradient，使同一 world model 范式能在 Atari 上达到强性能。这里的意义不只是刷新分数，而是说明 latent imagination 并不限于低维连续控制。

七、DreamerV3：把算法稳定性提升为可扩展性

DreamerV3 的目标是用一套超参数跨越不同观测、动作、奖励尺度和任务。几个看似工程化的设计非常重要。

7.1 symlog：压缩跨数量级信号

它在零附近近似线性，对大数值近似对数，能同时处理小奖励和极大回报，且保留正负号。

7.2 two-hot distributional prediction

奖励与价值不直接回归一个标量，而是在离散 bins 上预测分布，目标值线性分配到相邻两个 bin。相比 MSE，这降低不同奖励尺度带来的梯度失衡。

7.3 return normalization 与稳健损失

actor 的 advantage 按回报分位跨度归一化，减少不同任务尺度对学习率的影响；world model、critic 和 actor 的损失也采用统一的稳定化配方。

DreamerV3 用固定配置覆盖 150 多个任务，并在没有人类数据或预训练 curriculum 的情况下于 Minecraft 获取 diamond。应谨慎理解这个结果：它证明的是通用训练配方和长时序探索能力，而不是已经得到一个开放世界通用模型。

八、Dreamer 路线的能力与边界

它解决了什么

  • 从图像联合学习 belief state 与随机动力学；
  • 用 latent rollout 降低视觉解码成本；
  • 用 actor 摊销在线规划，用 critic 连接远期回报；
  • 让真实经验通过大量 imagined transition 被反复利用。

它没有自动解决什么

  • 模型偏差：actor 仍会寻找模型预测过于乐观的区域；
  • 开放世界泛化：单任务 replay buffer 不等于互联网规模世界知识；
  • 物理可解释性：latent state 的变量不一定对应对象、几何或因果机制；
  • 安全保证：平均回报提高不代表尾部风险受控；
  • 长时记忆：有限 recurrent state 仍可能忘记很久以前离开视野的对象。

九、代表工作

Learning Latent Dynamics for Planning from Pixels

  • 论文：Hafner et al., ICML 2019
  • 核心创新：RSSM 联合确定性记忆与随机状态，PlaNet 直接在 latent space 用 CEM 规划。
  • 承上启下：继承深度状态空间模型，直接催生 Dreamer。

Dream to Control: Learning Behaviors by Latent Imagination

  • 论文：Hafner et al., ICLR 2020
  • 核心创新：在世界模型想象的 latent trajectories 上学习 actor 与 critic。
  • 代表意义：将 Dyna 式 planning update 发展为端到端可微的策略学习。

Mastering Atari with Discrete World Models

  • 论文：Hafner et al., ICLR 2021
  • 核心创新：离散 RSSM、KL balancing 与改进 actor learning。

Mastering Diverse Domains through World Models

  • 论文：Hafner et al., 2023
  • 核心创新：symlog、distributional prediction、归一化等稳定配方，使一套参数跨多类任务工作。
  • 代表意义：把世界模型研究从单项性能推进到算法通用性。

小结：想象不是越长越好，而是要与价值学习闭环

PlaNet 用 RSSM 把观测校正后的 posterior 与纯动力学 prior 放进同一潜状态系统，并在其中搜索动作；Dreamer 再用 actor 摊销搜索、用 critic 截断长程模型误差。它们证明，世界模型的强大不依赖生成完整视频，而来自一个对任务充分、可快速滚动的内部状态。

下一篇转向 MuZero。它会把“任务充分”推到更激进的结论：如果搜索只需要奖励、价值和策略，那么模型甚至不必重建观测，也不必让 latent transition 对应真实环境状态。
