引言：规模化视频模型何时变成世界模型

当视频模型学会镜头运动、三维透视、对象交互和较长时间一致性时，把它称作“world simulator”很诱人。但一个基础事实不能跳过：视频预测观察到的相关性，动作条件模型才开始接近干预。

本篇不按宣传片质量排列模型，而按能力阶梯分析：

Sora、GAIA-1、Cosmos、Genie 3 和 GWM-1 分别站在这条阶梯的不同位置。

一、为什么规模化可能学到某些世界规律

视频是物理世界经过相机投影留下的轨迹。为了预测后续帧，模型不得不利用一些潜在结构：

  • 对象在遮挡前后保持身份；
  • 相机移动与视差反映三维布局；
  • 物体运动受惯性、接触和重力约束；
  • 人和交通参与者具有目标与行为模式。

即使网络没有显式对象或 3D 模块，为降低预测损失，也可能在内部形成近似表示。但“可能形成”不等于“稳定、因果、可用于任意规划”。数据偏差允许模型用捷径拟合常见视频，而不是恢复真实物理机制。

二、Sora：把视频统一为时空 patches

OpenAI 的 Sora 技术报告将不同分辨率、宽高比和时长的视频先压缩到 latent space，再切分为 spacetime patches。Transformer 在统一 token 接口上训练，类似语言模型处理不同长度文本。

其中 可以是文本、图像或视频条件。统一 patch 表示使模型能利用原始尺寸数据，并随计算规模改善生成质量。

报告展示了三维一致性、长程连贯、对象持久和简单交互等涌现现象，也明确展示物理失败：玻璃破碎不正确、物体状态突变、左右混淆、复杂因果无法持续。

因此 Sora 提供的是一个重要假设的证据：大规模视频生成器会学到部分隐式世界结构。但它没有通用、低延迟的动作 API，也没有展示用模型 rollout 改善 agent policy，不能仅凭逼真视频认定为完整决策世界模型。

三、GAIA-1：把驾驶动作带入生成模型

相比普通驾驶视频预测，动作条件允许反事实生成：改变 steering、braking 等控制，未来道路视角和车辆运动应相应变化。模型使用离散 video tokens 建模高层时序，再由 diffusion decoder 恢复画面细节。

GAIA-1 的意义在于把大规模真实驾驶数据、语言描述和 action conditioning 放进同一生成模型，为数据生成、场景编辑与规划预演提供接口。

但真实驾驶存在明显的 observational confounding：人类司机只在特定情境采取某动作，数据缺少同一起点下多个动作的真实后果。仅靠日志学习的模型，仍难保证反事实正确。

四、Cosmos：世界模型从单体模型变成平台

NVIDIA Cosmos 在 2025 年将 World Foundation Model（WFM）定义为面向机器人与自动驾驶的可定制生成模型平台，而不只是一个 checkpoint。初始平台包括：

  • 高压缩率、面向图像和视频的 Cosmos Tokenizer；
  • autoregressive 与 diffusion 两类 world foundation models；
  • 视频数据清洗、过滤和标注流水线；
  • 用于 Physical AI 微调、生成和安全控制的训练工具。

技术报告称预训练数据来自约 2000 万小时视频，经过处理形成 9 万亿 token。这里的规模有两层作用：覆盖更多对象与场景，也让同一基础模型可通过条件或后训练适配驾驶、机器人和合成数据。

4.1 Predict 与 Reason 的分工

Cosmos 后续把能力进一步区分：

  • Predict：生成动作或条件驱动的未来视觉，用于数据增强、policy evaluation 和仿真；
  • Reason：视觉语言模型理解物理场景、推断后果并产生决策相关描述。

生成与推理结合很有吸引力，但二者互相输出并不自动保证物理正确。reasoner 可能为错误视频给出合理解释，generator 也可能把语言先验画得自然。最终仍需几何、动作和闭环指标锚定。

五、Genie 3：实时性与分钟级一致性

Google DeepMind 在 2025 年公布 Genie 3：从文本生成多样的动态世界，以 720p、24 FPS 实时交互，并宣称可在几分钟内保持一致，视觉记忆可影响约一分钟前的内容。它还支持 promptable world events，在交互过程中用文本改变天气或加入对象。

与 Genie 2 常见的 10–20 秒、最长约一分钟展示相比，Genie 3 把可用 horizon 和分辨率明显推进。实时自回归生成还意味着每帧必须在严格预算内综合不断增长的历史，而不能离线看完整段视频。

证据边界

Genie 3 发布时是 limited research preview，官方没有公开完整模型、训练数据、系统论文或可复现 benchmark。可确认的是官方展示的接口与性能口径；尚不能确认的是：

  • 对任意动作序列的机制一致性；
  • 隐藏状态与对象持久性的系统测量；
  • 作为 agent 训练环境的 sim-to-real / sim-to-game transfer；
  • 对稀有物理事件的概率校准。

这不是否定系统，而是区分 demo evidence 与 experimental evidence。

六、GWM-1：世界模型产品面的三种接口

Runway 于 2025 年末公布 GWM-1，称其为基于 Gen-4.5 的实时 autoregressive General World Model，并分成三类产品接口：

  • GWM Worlds：由静态场景生成可探索环境；
  • GWM Avatars：生成可实时对话、保持角色的数字人物；
  • GWM Robotics：动作条件多视角视频、合成数据与离线 policy evaluation。

这体现世界模型产品化后的分化：同一个“预测世界”概念，面向创作时追求控制和连续体验，面向机器人时则需要动作语义、跨视角几何和策略评测可信度。

公开页面提供了能力展示和 SDK 方向，但缺少足以独立核查的完整技术报告。尤其“用生成视频离线评估策略”属于高风险用途：若模型对失败动作过于乐观，评测会系统性高估 policy。部署前必须与真实回放、物理 simulator 和小规模硬件测试交叉验证。

七、从 video foundation model 到 world foundation model

可以用四个必要条件判断名称是否名副其实。

7.1 Action interface

模型需要接受离散动作、连续控制、轨迹、相机位姿或语言干预，并显示可重复的后果差异。

7.2 Persistent state

世界不能只存在于最近几帧。对象身份、地图拓扑、库存和任务状态需要跨遮挡与回访保持。

7.3 Calibrated dynamics

对于本来多模态的未来，样本频率应近似真实概率。画出一种“很合理”的未来不够。

7.4 Decision utility

模型应在 agent 训练、规划、风险评估或数据闭环中带来可测收益，并在真实/高可信环境中复验。

若只满足视觉质量和文本控制，它仍是很强的视频基础模型；满足后两层，才更接近可承担环境角色的 world foundation model。

八、规模化带来的新系统问题

8.1 记忆不能只靠扩大 context window

长上下文保存 token，不等于形成稳定地图。模型需要区分当前可见内容、持久世界状态和可丢弃渲染细节，否则回访时仍可能重写历史。

8.2 实时生成要求计算随时间近似稳定

若每帧 attention 都扫描全部历史，交互越久成本越高。KV cache、分层记忆、state compression、流式 diffusion/consistency distillation 因而成为核心。

8.3 数据规模会放大而非消除偏差

互联网视频偏向可观看、成功、常见的行为；机器人真正需要的失败、极端接触和安全临界状态反而稀缺。大数据改善覆盖，但不会自动提供反事实配对。

8.4 世界生成也有安全边界

用于自动驾驶和机器人时，错误是行为风险；用于人物和开放环境时，还涉及身份、版权、内容真实性和可操纵模拟。平台级 WFM 需要数据治理、输出标记和用途限制，而不只是模型护栏。

九、代表工作与证据层级

工作 时间 公开证据 可以支持的结论

Cosmos 2025 技术报告、代码/模型与平台材料 WFM 可作为 Physical AI 预训练和定制平台

表中的“公开证据”刻意单列，因为前沿世界模型越来越多先以 demo、API 或博客发布。能力主张应随论文、代码、权重、benchmark 和独立复现逐步升级，而不是一次性全盘接受。

十、一个更严格的“理解物理”测试

让模型生成球落地的视频只能证明它会复现常见视觉模式。更强测试应逐层加入干预：

  1. 改变球的初始高度，落地时间是否系统变化；
  2. 改变重力方向，轨迹是否随条件改变；
  3. 用训练分布外材质和质量，模型是否表达不确定性；
  4. 球离开视野后再回访，状态是否持续；
  5. planner 能否利用模型选择动作，并在真实环境得到预期结果。

只有最后一层把世界模型从“会画物理”连接到“能靠物理预测行动”。

小结：世界模型的门槛正在从画质移向因果与闭环

Sora 展示大规模视频模型中的隐式时空结构，GAIA-1 加入真实动作，Cosmos 把 tokenizer、生成器和数据管线平台化，Genie 3 与 GWM-1 则推进实时交互和应用接口。它们让“视觉世界基础模型”成为清晰的工程方向。

但规模和画质无法替代动作因果、概率校准与闭环验证。下一篇把这些模型放到最苛刻的用户之一：机器人。接触动力学、控制频率、跨 embodiment 和真实硬件会迫使世界模型从“能生成”走向“能行动”。
