世界模型专题-05：不确定性与 TD-MPC —— 怎样控制模型偏差

引言：模型越会规划，越会找到自己的漏洞

学习世界模型的理由是减少真实交互，但 planner 或 policy 会主动寻找模型中回报最高的区域。只要模型在某个分布外动作上过于乐观，优化器就可能反复选择它。这不是普通测试误差，而是一种对抗关系：决策器会把微小模型偏差放大成行为失败。

2018 年后的模型型强化学习围绕三种对策发展：

  1. PETS 用 ensemble 显式估计“模型不知道什么”；
  2. MBPO 只信任短 rollout，让真实数据承担长期锚点；
  3. TD-MPC 在为控制学习的 latent space 中做短程规划，再由价值函数接管远期。

它们共同说明，可靠世界模型不等于追求无限长、无限逼真的预测。

一、两种不确定性必须分开

给定状态动作 ，预测分布的不确定性来自两类来源。

1.1 Aleatoric uncertainty：世界本来就随机

例如球碰撞后的微小扰动、其他驾驶员的多种合理意图。即使拥有无限数据，也只能预测一个分布：

常见做法是预测均值和方差，或使用 mixture、diffusion 等多模态分布。

1.2 Epistemic uncertainty：模型因为没见过而不知道

例如机器人从未尝试某个极端关节姿态。增加相关数据后，这类不确定性应下降。它对规划尤其重要，因为高 epistemic uncertainty 意味着模型外推不可信。

PETS 的意义

PETS 在真实交互很少的连续控制任务中显示出强样本效率。它把“不确定性应进入规划，而不是只在论文图里报告”变成具体系统。

代价也很明确：ensemble × particles × CEM iterations 带来高计算量；模型分歧只是 epistemic uncertainty 的近似，多个网络也可能共享相同盲区。

三、MBPO：不要问模型能滚多远，要问何时值得信任

MBPO 的核心观察是：学习模型做一步预测通常比做很长 rollout 可靠。与其在模型里生成完整 episode，不如从真实 replay state 出发，只展开 步：

策略通常用 SAC 训练。模型只负责增加当前数据分布附近的局部样本，真实 buffer 持续提供锚点。

3.1 为什么短 rollout 可能优于长 rollout

粗略地说，模型使用带来两项相反效应：

  • rollout 越长，生成数据越多，方差和真实采样需求越低；
  • rollout 越长，模型误差与分布偏移累积越严重，偏差越高。

因此最优 horizon 不一定随模型能力单调增大。MBPO 使用较短并逐渐调整的 horizon，在“多用模型”和“少信模型”之间取平衡。

这也是一个重要认识转变：世界模型不必成为可独立运行的完美 simulator；只要在局部区域提供有用的附加训练信号，就能改善策略。

四、离线 RL：模型偏差遇上不可补数据

在线 MBPO 发现错误后还能回真实环境采样，离线 RL 只有固定数据集。策略一旦选择数据外动作，世界模型和价值函数可能同时过度乐观，而且无法在线纠正。

MOReL 则把高度不确定的状态动作转移到一个低回报 absorbing state，明确告诉策略“越出数据支持范围就按坏结果处理”。

这些方法牺牲潜在高回报换可靠性，但不确定性估计若不准，也可能过度保守。真正难点是 support estimation：数据没覆盖哪里，比单纯预测下一状态更难可靠判断。

前半段由世界模型显式展开，horizon 之后由 learned Q 接管。policy prior 提供高质量候选动作，随机采样则保留探索；规划分布经过 elite 加权反复更新。

这是一种很实用的责任划分：

  • dynamics 擅长相对可信的短期后果；
  • Q function 用数据驱动方式概括长期；
  • policy prior 减少高维随机搜索；
  • MPC 每步用真实观测重新锚定。

TD-MPC 由此把 Dreamer 式 latent model、MuZero 式 task-oriented representation、MPC 与 TD learning 汇合到一套紧凑架构里。

七、TD-MPC2：从单任务配方到多任务世界模型

TD-MPC2 改进模型归一化、Q ensemble、动作先验和训练稳定性，并在 104 个连续控制任务上系统评估。它还展示了从多任务数据训练单一 agent/world model，并随参数、数据和任务数量扩展的能力。

这里的“可扩展”要谨慎理解：

  • 它表明同一模型可以共享不同控制任务的动力学结构；
  • 并不等于解决任意真实世界环境；
  • 任务仍有统一接口和相对受控的观测动作空间；
  • 对跨 embodiment、语言条件和开放世界视觉的支持，需要后续 world foundation model 路线。

TD-MPC2 的价值在于证明：面向控制的 latent model 不必永远是单环境小模型，它也能形成规模效应。

八、四种抑制模型偏差的方法

方法 代表工作 核心假设 代价/盲点
模型 ensemble PETS 模型分歧能暴露数据不足 计算昂贵，共享盲区仍存在
短 rollout MBPO 局部动力学比长期预测可靠 长期依赖 value/policy bootstrap
不确定性惩罚 MOPO/MOReL 数据外区域应保守处理 可能错杀有价值的探索
任务导向 latent + MPC TD-MPC 只预测规划需要的结构 表征难审计，换任务可能丢信息

它们并不互斥。一个真实机器人系统可以同时使用 ensemble、短 horizon、terminal value、约束优化和安全 fallback。

九、评测时最容易犯的错

9.1 只报告随机验证集的一步误差

训练分布上的 MSE 不能代表 planner 主动访问的状态。应按 rollout horizon、策略分布与 uncertainty calibration 分层评估。

9.2 用模型内回报证明模型有效

策略和模型可能共同自洽却共同错误。必须回真实环境或高可信 simulator 测闭环 return 与 constraint violation。

9.3 把平均性能当作安全性

平均回报无法反映少见但严重的失败。至少需要报告尾部风险、worst-group、collision/violation 和 OOD 状态下的拒绝机制。

9.4 不控制规划计算预算

更多 particles、ensemble members 和 CEM iterations 本身能提高结果。比较算法时必须同时报告环境样本与决策时计算。

十、代表工作

Deep Reinforcement Learning in a Handful of Trials using Probabilistic Dynamics Models

  • 论文：Chua et al., NeurIPS 2018
  • 核心创新：PETS 以概率 ensemble、trajectory sampling 和 CEM 组合高样本效率控制。

When to Trust Your Model: Model-Based Policy Optimization

  • 论文：Janner et al., NeurIPS 2019
  • 核心创新：从真实 replay state 进行短模型 rollout，用少量模型步数改善 off-policy 学习。
  • 代表意义：把“完美长模拟”改写成“局部模型何时有用”。

MOPO: Model-based Offline Policy Optimization

  • 论文：Yu et al., NeurIPS 2020
  • 核心创新：按模型不确定性惩罚合成转移的奖励，使离线策略远离不可靠区域。

Temporal Difference Learning for Model Predictive Control

  • 论文：Hansen et al., ICML 2022
  • 核心创新：在任务导向 latent space 联合学习 dynamics、reward、Q 与 policy prior，以短程 MPC 加终端价值决策。

TD-MPC2: Scalable, Robust World Models for Continuous Control

  • 论文：Hansen et al., ICLR 2024
  • 核心创新：稳健训练与多任务扩展，在 104 个连续控制任务上统一评估。

小结：可靠的世界模型知道自己只能看多远

PETS 把不确定性送进规划器，MBPO 把模型限制在短 rollout，TD-MPC 用任务导向 latent dynamics 负责眼前、用 Q function 负责远方。三者都反对一个诱人的误解：更长、更清晰的生成一定带来更好决策。
