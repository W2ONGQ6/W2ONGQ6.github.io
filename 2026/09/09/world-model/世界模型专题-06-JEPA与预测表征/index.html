引言：不可预测的细节不应占满模型容量

下一帧像素并不是一个干净目标。树叶怎样抖动、纹理怎样闪烁、被遮挡区域具体出现哪一种合理细节，往往无法从当前观测唯一确定。像素生成模型为了覆盖这些细节，需要复杂概率分布；若使用均方误差，又容易把多种未来平均成模糊画面。

JEPA（Joint-Embedding Predictive Architecture）的主张是：不要预测输入本身，而要预测输入在抽象表示空间中的 embedding。 目标 encoder 可以把不可预测的局部细节消隐，只留下对象、运动和场景语义等更稳定结构。

这条路线把世界模型从“生成未来”推向“理解哪些未来是可预测的”。但只有在加入动作并用于规划后，它才完整回答“行动会造成什么后果”。

一、三种自监督预测目标

1.1 像素重建

1.2 对比预测

Contrastive Predictive Coding（CPC）让上下文表示靠近真实未来、远离负样本：

它避免直接生成像素，但性能依赖负样本构造；把其他样本当作负例，也可能排斥语义相同的内容。

1.3 联合嵌入预测

JEPA 使用 context encoder、target encoder 和 predictor：

它不重建 ，也不要求显式负样本，而是在 embedding space 预测 target block 的表示。

二、不用负样本和 decoder，为什么不会坍塌

如果两个 encoder 都自由更新，把所有输入映射到同一个常数就能让损失为零。JEPA 系列通过非对称结构避免这个平凡解：

  • target branch 使用 stop-gradient，不接受 predictor 的反向梯度；
  • target encoder 通常由 context encoder 的指数滑动平均更新；
  • context 与 target 使用不同可见区域，predictor 必须从上下文推断缺失信息；
  • masking 策略让任务既不太简单，也不因目标完全不可预测而退化。

EMA 更新为：

target encoder 因而像一个缓慢移动的教师。它不是固定标签，而是与学生共同演化但变化更稳。

三、I-JEPA：预测大块语义，而不是补纹理

I-JEPA 从一张图像中取较大的 context block，并预测多个空间分离的 target block 表征。与随机小 patch masking 相比，大块 target 迫使模型利用对象和场景级上下文，而不是依赖相邻纹理插值。

target 的位置编码告诉 predictor 要预测哪里，但 target 像素本身不可见。模型若想预测“桌面右侧被遮挡区域”的表示，需要理解桌面、物体布局和全局语义。

I-JEPA 证明纯 feature prediction 可以学到强视觉表示，并避免生成 decoder 的计算。但它处理静态图像，不含环境动作，因此更准确地说是世界模型的表征学习组件，而非完整 dynamics model。

四、V-JEPA：从空间遮挡走向时空预测

V-JEPA 把 target 扩展到视频中的时空 tube。context encoder 只看未遮挡 token，predictor 估计被遮挡时空区域的 target embeddings。

视频 masking 必须避免信息泄漏：若只随机遮掉单帧小 patch，相邻帧几乎可以复制答案。V-JEPA 使用大范围、跨多帧的遮挡，使模型必须理解对象运动和较长时序结构。

4.1 为什么 feature prediction 适合视频

假设未来人物抬起手臂，但衣服褶皱和背景像素有大量可能。像素模型要为全部细节分配概率，feature predictor 只需预测“同一人物、手臂上抬、位置变化”对应的抽象表示。

从信息角度看，target encoder 学会一种选择性：

这不是理论上自动保证的等式，而是 masking、架构与训练数据共同形成的归纳偏置。

4.2 V-JEPA 的证据边界

V-JEPA 在 frozen backbone 的动作识别与运动理解任务上表现强，说明表示包含时序结构。但“能识别动作”不等于“能预测自身动作的后果”：原始 V-JEPA 没有控制输入，也没有闭环规划实验。

因此应区分：

  • action-free predictive model：学习世界自然演化的表征；
  • action-conditioned world model：学习干预后果；
  • planning-capable world model：模型预测能实际比较候选动作。

五、V-JEPA 2：从互联网视频走向机器人规划

V-JEPA 2 先在超过 100 万小时互联网视频和图像上做 action-free 预训练，学习通用视觉与运动表示。随后得到两种用途。

5.1 理解：把视觉 encoder 接到语言模型

对齐 LLM 后，模型可执行视频问答和时间推理。这验证表示可被语言接口读取，但语言问答仍不是物理控制的直接证据。

5.2 规划：V-JEPA 2-AC

V-JEPA 2-AC 使用少于 62 小时无标签 DROID 机器人视频做动作条件后训练：

给定目标图像编码 ，规划器搜索使预测终态接近目标的动作序列：

论文将其零样本部署到两个实验室的 Franka 机械臂，以 image goal 完成抓取和放置；目标环境没有额外采集数据，也没有任务专用奖励。

这是 JEPA 路线的重要闭环：互联网视频提供广泛视觉运动先验，少量机器人交互把表示接到可执行动作，MPC 再把 latent prediction 变成行为。

六、JEPA 与生成式世界模型不是谁取代谁

维度 JEPA/feature prediction 像素生成世界模型
目标 预测抽象 embedding 建模可见未来分布
无关细节 可由 target encoder 丢弃 通常仍需生成
可视化 难直接检查 直观可看
数据生成 不直接支持 可生成训练/测试视频
规划速度 latent cost 较低 解码成本通常更高
安全审计 隐状态语义不透明 可见但画面逼真可能掩盖因果错误

二者可以组合：用 JEPA latent 做快速规划，同时用生成 decoder 做诊断或合成数据；也可以让生成模型的中间 feature 承担 policy representation。真正的选择取决于用途，而不是某种目标在概念上更“高级”。

七、预测表征仍面对的难题

7.1 表征距离是否等于任务距离

image goal planning 假设 embedding 更接近就代表任务更接近完成。但视觉语义相似不一定等于机械可达，尤其在接触、遮挡和精细姿态上。

7.2 多种未来怎样表示

简单 L2 feature loss 仍可能预测 embedding 均值。JEPA 研究纲领提出能量模型或 latent variable 表达多模态未来，但实际系统如何稳定训练仍在发展。

7.3 动作从哪里来

互联网视频规模巨大，却通常没有机器人动作标签。latent action model、inverse dynamics、文本动作和少量机器人轨迹各有偏差；把“人或相机在视频中发生移动”对齐到具体执行器控制，不是自动完成的。

7.4 隐状态遗漏如何被发现

生成错误还能看到，latent omission 则可能只在机器人失败时暴露。需要 probe、counterfactual test、闭环控制和不确定性评测共同检查。

八、代表工作

Representation Learning with Contrastive Predictive Coding

  • 论文：van den Oord et al., 2018
  • 核心创新：用自回归上下文预测未来表示，并以 InfoNCE 对比目标学习跨模态表征。
  • 历史位置：把“预测未来”确立为通用自监督信号，但仍依赖负样本。

A Path Towards Autonomous Machine Intelligence

  • 论文：LeCun, 2022
  • 核心贡献：提出 JEPA、世界模型、配置器、成本模块和短期记忆组成的自主机器架构研究纲领。
  • 证据等级：观点与架构蓝图，不是单个完整系统的实验论文。

Self-Supervised Learning from Images with a Joint-Embedding Predictive Architecture

  • 论文：Assran et al., ICCV 2023
  • 核心创新：I-JEPA 用大块 context 预测 target embeddings，无需像素 decoder 和显式负样本。

Revisiting Feature Prediction for Learning Visual Representations from Video

  • 论文：Bardes et al., 2024
  • 核心创新：V-JEPA 通过时空遮挡和 feature prediction 学习视频运动表征。

V-JEPA 2: Self-Supervised Video Models Enable Understanding, Prediction and Planning

  • 论文：Assran et al., 2025
  • 核心创新：大规模 action-free 视频预训练，少量机器人视频后训练成动作条件模型，并以 image goal 做零样本规划。
  • 代表意义：首次把 JEPA 表征路线从 benchmark understanding 较完整地接到真实机器人规划。

小结：抽象的价值，在于丢得恰到好处

JEPA 的洞察不是“像素永远不重要”，而是世界中大量细节既不可预测，也与当前决策无关。通过预测 target encoder 的表示，模型可以把容量集中在更稳定的对象、运动和语义结构上。

但丢弃信息本身也是风险。一个完整世界模型仍要用动作条件、目标到达和真实闭环来验证表示是否充分。下一篇转向另一端：VideoGPT、IRIS、Genie、DIAMOND 和 GameNGen 不放弃生成，而是把视频生成器推成可以逐帧交互的神经环境。
