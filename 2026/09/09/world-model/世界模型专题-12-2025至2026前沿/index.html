世界模型专题-12：2025–2026 前沿 —— 从 WFM 到可验证智能体

引言：前沿不再争论“能不能生成”，而在争论“能不能托付行动”

2024 年证明了视频模型可以成为可交互神经环境；2025 年把它规模化为 World Foundation Model（WFM）；到 2026 年，World Action Model（WAM）、长程 memory、实时 diffusion、物理校准和 RL 后训练同时爆发。

新名词很多，但真正的技术变化可以压缩成六个问题：

  1. 世界状态能否在分钟乃至更长交互中保持；
  2. 被动视频怎样转化为可执行动作知识；
  3. 生成器能否达到机器人闭环所需延迟；
  4. 世界模型与策略应联合还是分离；
  5. 物理 simulator 与生成模型怎样互补；
  6. 模型的预测何时足以被 planner 信任。

本篇的文献截点为 2026 年 9 月 8 日。2026 年工作大多尚为预印本，文中只把它们作为前沿证据，不按成熟共识书写。

一、趋势一：从 World Model 到 World Foundation Model

传统世界模型围绕单环境训练，WFM 则希望从跨场景视频中学共享动态，再以条件或后训练适配游戏、驾驶和机器人：

Cosmos 把 tokenizer、autoregressive/diffusion backbone、数据处理和安全组件组成平台；Genie 3 与 GWM-1 强调文本初始化、实时交互和多用途接口；Matrix-Game 等开放工作则推动可训练、可部署的交互模型。

“foundation”应至少体现三种扩展：

  • 跨环境数据预训练，而非只记一个游戏；
  • 可通过少量数据对齐新控制接口；
  • 同一 backbone 支持预测、生成、规划或数据合成中的多个任务。

模型参数大、视频好看，并不足以证明基础性。迁移曲线和新 domain 的数据效率才是关键证据。

二、趋势二：latent action 把无标签视频变成行为数据

世界视频多，动作标签少。Genie 使用离散 latent action，DreamDojo 使用连续 latent action，2026 年更多工作尝试从人类、其他机器人和游戏视频提取统一动作表示。

典型目标包含 inverse 与 forward 两部分：

如果 latent action 真正抓住可控变化，它应满足：同一动作跨不同场景效果结构相似，不同动作在同一状态产生可区分后果，并能以少量 paired data 对齐机器人控制。

主要风险是把不可控事件编码成动作。例如摄像者转头、另一个人移动或剪辑变化，都可能被 inverse model 当成“代理动作”。因而 latent action 需要 controllability、disentanglement 和 embodiment transfer 三重验证。

三、趋势三：WAM 联合“世界怎样变”与“我该怎么做”

2026 年 WAM 的快速扩张，来自一个直觉：VLA 只预测动作，视频模型只预测未来，而机器人需要二者闭环。

联合分布可有两种分解：

或：

前者先行动再预测后果，接近 forward dynamics；后者先形成目标未来再反推动作，接近 video plan + inverse dynamics。实际模型还会 joint denoise 视频与 action chunk。

DreamZero 报告 14B WAM 以 7 Hz 真实闭环运行，并展示跨 embodiment 迁移；Fast-WAM 随后发现去掉测试时未来生成仍保持竞争力，而去掉训练时视频监督损失更大。这使 WAM 研究从架构命名进入可检验问题：收益究竟来自显式规划，还是来自更好的训练表征？

四、趋势四：实时生成从模型问题变成系统问题

交互延迟包括 tokenizer、backbone、多步去噪、action decoder 和控制通信：

只加速 backbone 不一定提升控制频率。2025–2026 的常见路线包括：

  • diffusion/flow distillation，把几十步采样压到少数步；
  • causal autoregressive generation，只生成最新帧并复用 KV cache；
  • latent rollout，不在每个候选上解码 RGB；
  • action chunking，让高层模型低频输出一段动作；
  • fast policy head，在训练时用世界预测、部署时跳过视频生成；
  • 分层控制，让 WAM 提供子目标，传统 controller 处理高频反馈。

实时不是单一 FPS。一个 24 FPS 可探索世界和一个 7 Hz 机器人策略面向不同控制带宽；必须同时报告端到端 latency、hardware、batch size、context 和动作执行周期。

五、趋势五：长记忆从“大窗口”走向显式世界状态

长时间自回归失败通常不是纹理逐渐变差，而是世界历史被重写：门重新关闭、物体复原、路线拓扑改变。仅增加上下文长度有三个问题：成本增长、相关信息被稀释、状态无法保证唯一和一致。

2026 年的长程世界模型开始使用：

  • compressed recurrent state；
  • 可寻址 frame/object memory；
  • 结构化地图或 3D scene representation；
  • 区分 committed state 与渲染结果的混合系统；
  • 回访一致与未观测状态 benchmark。

一个有用的设计原则是把世界分成三层：

持久状态不应因生成器重采样而改变，渲染状态则可保留多样性。这比把一切都压进最近视频 token 更接近传统 simulator 的状态纪律。

六、趋势六：神经生成与物理模拟重新结合

纯 simulator 物理可靠但视觉和开放场景昂贵，纯生成模型视觉灵活但物理漂移。混合路线让二者分工：

simulator 决定几何、碰撞和 committed state，生成模型负责外观、未建模细节和跨域渲染。TourPhysics（2026）等工作明确区分 simulator state、geometry evidence、generator controls 与 appearance memory，反映这种回归。

混合模型牺牲“全由数据端到端学出”的纯粹性，却更适合高风险 Physical AI：关键物理可验证，视觉仍可规模化。真正难点变成接口误差，例如 simulator 几何过粗时，生成器是否会视觉修补并掩盖状态错误。

七、趋势七：用 RL 改善长程生成与行动一致性

最大似然或 diffusion loss 对所有 token/像素局部平均，却不直接优化长程对象持久、动作执行或任务成功。2026 年出现更多 RL/post-training 路线：

WorldReward 等工作以 VLM 和人工审查构造动作一致与视觉质量偏好，WorldCycle、persistent world model 等则针对长 rollout 自验证和训练。

RL 的风险同样熟悉：reward model 可能被生成器利用。一个 VLM reward 喜欢“看起来完成抓取”，不代表接触真实。可靠后训练应使用几何工具、simulator state、action trace 和人工评审的组合奖励，并保留 held-out 闭环测试。

八、趋势八：可验证性成为世界模型的产品边界

当世界模型用于创作，偶发物理错误可以重采样；用于策略训练或安全评估时，错误会系统性迁移给 agent。因而出现“admissibility”问题：对当前初始状态、动作集合和 horizon，这次模型 rollout 是否有资格作为决策证据？

可验证系统需要：

  1. 检查输入是否在训练支持范围；
  2. 估计 rollout uncertainty 随 horizon 的增长；
  3. 验证硬约束，如碰撞、关节与地图拓扑；
  4. 对关键候选使用第二模型或 simulator 交叉检查；
  5. 不满足条件时拒绝给出确定评估，缩短 horizon 或回真实环境。

这把“模型总体好不好”改写为“这一次预测能不能被使用”，更贴近工程部署。

十、接下来最可能发生的架构汇合

未来系统很可能不是单个全能视频模型，而是分层闭环：

共享 backbone 提供规模化知识，显式 state 与物理工具提供可验证性，policy head 提供实时性，闭环观测负责纠偏。这个结构并不如“一个模型模拟一切”简洁，却更符合世界模型六十年来反复证明的原则：预测必须服务行动，行动必须接受反馈。

十一、对未来工作的五个高价值问题

11.1 Scaling law 应该预测什么

参数和视频 token 增加能改善 FVD，但世界模型真正需要 action regret、long-horizon consistency 和 policy transfer 的 scaling law。

11.2 如何获得反事实数据

被动视频无法覆盖同状态多动作。可控 simulator、自主机器人 play、小规模真实干预和因果数据设计需要联合，而非等待互联网数据自然解决。

11.3 世界状态是否需要对象与 3D 结构

端到端 latent 灵活，object-centric/3D state 更可验证。哪些结构应硬编码、哪些可从规模中涌现，是长期核心争论。

11.4 模型与策略怎样共同扩展又不共同作弊

联合训练提高效率，也让错误互相强化。需要独立 holdout environment、cross-model verification 与真实闭环审计。

11.5 世界模型何时应拒绝预测

开放世界永远存在未知。可靠智能的标志不只是覆盖更广，还包括校准地知道 horizon、动作和状态何时超出能力边界。

十二、整套专栏的主线回看

世界模型的发展不是从小视频模型一路放大，而是五条线逐渐汇合：

  1. 控制理论给出状态估计、滚动规划和反馈纠偏；
  2. Dyna 与模型型 RL把 learned model 变成额外经验；
  3. World Models、Dreamer、MuZero、TD-MPC分别探索重建型、想象型、价值等价与任务导向 latent；
  4. JEPA追问应预测像素还是抽象语义；
  5. Genie、Cosmos、WAM把大规模视频、动作和实时交互推向 Physical AI。

贯穿始终的不是某个网络，而是一个闭环：

世界模型的终点不是生成一个永不出错的替代现实，而是让智能体在有限、可校准的内部模型中更好地行动，并在模型无知时及时回到现实。

小结：从会想象，到值得信任

2025–2026 的 WFM 与 WAM 把数据规模、生成质量和控制接口迅速推进；与此同时，Fast-WAM、因果 benchmark、长记忆和混合物理系统把研究拉回更严格的问题。下一阶段的突破未必来自更漂亮的视频，而可能来自更诚实的不确定性、更稳定的状态、更快的闭环，以及更能揭穿模型自洽幻觉的评测。

这也是整套专栏最后的判断：世界模型不是因为会描绘世界而重要，而是因为它可能让行动者在真正改变世界之前，先比较后果；它是否成功，只能由行动后的世界来回答。
