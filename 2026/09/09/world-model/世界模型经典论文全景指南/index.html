世界模型经典论文全景指南（1960–2026）

世界模型不是一种模型，而是一种关于智能的主张

世界模型（World Model）这个词今天同时出现在强化学习、视频生成、机器人、自动驾驶和自监督学习中。它们看起来差异很大：Dreamer 在紧凑潜空间里想象轨迹，MuZero 不重建画面却能规划，V-JEPA 预测抽象表征，Genie 与 Cosmos 则生成可交互的视觉世界。若只按模型名字罗列，很容易把世界模型误解成“会生成视频的大模型”。

贯穿这些路线的主张其实更朴素：智能体需要一个关于环境如何演化、行动会造成什么后果的内部模型，并用它来预测、规划或学习。 最小形式可以写成：

其中 是观测， 是内部状态， 是动作。只有当预测结果会随动作改变，模型才真正回答反事实问题：“如果采取另一个动作，会发生什么？”

本专栏沿技术发展的因果链来写，不把每篇论文当作孤立的知识点。每一代方法都由上一代留下的瓶颈逼出来：已知模型太昂贵，于是从数据学习；像素太高维，于是进入潜空间；长程滚动会漂移，于是引入不确定性与闭环校正；重建细节不等于支持决策，于是出现 value-equivalent model 与 JEPA；单任务模型不够通用，于是世界模型开始规模化为可交互的 world foundation model。

一、先划清边界：什么才算世界模型

一个系统通常至少满足下面三项中的前两项，才适合称为世界模型：

  1. 状态性：从当前观测或历史中构造足以描述环境的内部状态；
  2. 动力学：预测状态随时间如何变化，最好显式接受动作或控制条件；
  3. 用途闭环：预测被用于规划、策略学习、数据生成、表征学习或风险评估。

因此，几个相邻概念不能简单画等号：

概念 学习对象 是否动作条件 典型用途 与世界模型的关系
视频生成模型 视觉序列分布 不一定 内容生成 加入可执行控制和持久状态后可成为视觉世界模型
动力学模型 是 控制、估计 世界模型的核心组件
环境模拟器 人工规则或数值方程 是 仿真、测试 功能相近，但不一定从数据学习
数字孪生 特定实体的同步副本 通常是 运维、预测 强调对象对应和实时同步，而非通用学习
基础模型 大规模预训练表示 不一定 迁移、多任务 学到可预测、可控制的环境动态后才构成世界基础模型

另一个关键区别是观测预测与状态预测。相机画面包含纹理、光照和背景抖动，决策却可能只关心位置、接触、遮挡与可达性。像素预测更容易被人检查，但潜状态预测通常更便于规划。世界模型的发展史，很大程度上就是在回答：应该保留世界的哪些信息，又该丢掉哪些细节？

二、五条相互汇合的技术主线

2.1 控制与模型型强化学习：模型是用来选动作的

从 Kalman filter、状态空间模型、模型预测控制（MPC），到 Dyna、PILCO、PETS、MBPO 与 TD-MPC，这条线始终以决策为验收标准。模型不需要生成漂亮画面，只要能在策略实际访问的区域内正确比较候选动作即可。

2.2 潜变量生成模型：在压缩空间里展开未来

VAE、RNN 与状态空间模型让高维视觉控制变得可学。World Models、PlaNet 和 Dreamer 的共同骨架是：编码观测、学习潜在动力学、再在潜空间中想象。区别在于潜状态怎样表示随机性、训练目标怎样约束长期预测，以及策略怎样利用想象轨迹。

2.3 价值等价模型：不必还原世界，只需保留决策结构

MuZero 把一个尖锐问题推到台前：若目标只是规划，为什么一定要预测真实下一帧？它只学习对搜索有用的表示、动力学、奖励和价值。这里的“世界”不再要求人类可解释，而要求不同动作在模型里保持正确的相对价值。

2.4 预测表征：在抽象空间预测，而不是追逐每个像素

从 predictive state representation、对比预测到 JEPA、I-JEPA、V-JEPA，这条线认为好的表示应捕捉可预测的高层结构，把不可预测且与任务无关的细节留在表征之外。它连接了自监督学习与世界模型，但也留下一个问题：没有动作的预测器，究竟学到的是世界动态，还是强大的时序表征？

2.5 生成式世界与 Physical AI：把模型扩展成可交互环境

视频 Transformer、扩散模型与流匹配提升了视觉保真度和规模上限。GAIA-1、Genie、GameNGen、DIAMOND、Cosmos、V-JEPA 2 与 2026 年涌现的 World Action Model（WAM）把控制、生成、机器人策略逐渐放进同一接口。新的瓶颈不再只是画质，而是实时性、空间持久性、动作遵循、物理校准和闭环可靠性。

三、1960–2026：问题推动的演进时间线

1960–1999：状态估计、规划与“边学边想”

  • **Kalman filter（1960）**建立线性高斯状态估计的递归范式：看不见真实状态时，维护一个关于状态的信念；
  • MPC形成“预测一段、只执行一步、再用新观测重规划”的滚动闭环；
  • **Dyna（1990/1991）**把真实经验同时用于学习策略和学习环境模型，再用模型生成的经验继续更新；
  • POMDP 与 belief state说明，部分可观测环境中的内部状态本质上是对隐藏世界的后验摘要。

这一阶段奠定了世界模型的功能定义：模型的价值来自它怎样改善决策，而不是它看起来多真实。

2000–2017：概率动力学与深度潜状态

  • 高斯过程动力学和 **PILCO（2011）**显式传播模型不确定性，实现极高样本效率；
  • E2C（2015）、Deep Kalman Filters、DVBF 等把深度生成模型与状态空间动力学结合；
  • 深度模型终于能从图像中学习紧凑、可控制的潜状态，但训练稳定性和长程误差仍是障碍。

2018–2020：World Models、PlaNet、Dreamer 与 MuZero

  • **World Models（2018）**用 VAE + MDN-RNN + Controller 展示“在梦境中训练策略”；
  • **PlaNet（2019）**以 RSSM 融合确定性记忆与随机潜变量，并直接在潜空间用 CEM 规划；
  • **Dreamer（2020）**把规划器改为在想象轨迹上训练 actor-critic，随后发展为跨领域的 Dreamer 系列；
  • **MuZero（2020）**证明不学习环境规则或像素重建，也能学习足以支持树搜索的隐式模型。

这是现代世界模型的第一次汇流：表示、动力学和决策被端到端地放进同一个学习系统。

2021–2023：通用控制、预测表征与生成式环境

  • DreamerV2/V3把离散潜变量、归一化和稳健训练配方扩展到 Atari、连续控制与 Minecraft；
  • EfficientZero、TD-MPC/TD-MPC2把隐式模型、价值学习和短程规划压成更高效的控制系统；
  • JEPA/I-JEPA主张在表征空间预测语义，而不是重建全部输入；
  • GAIA-1、UniSim 等开始用大规模真实视频构建动作条件的驾驶环境。

2024–2025：实时交互与世界基础模型

  • Genie、GameNGen、DIAMOND、Oasis把游戏视频变成可执行动作驱动的神经环境；
  • V-JEPA从视频学习抽象动态，V-JEPA 2进一步加入动作条件并用于机器人规划；
  • Genie 2/3把文本生成世界推进到实时交互和分钟级一致性；
  • Cosmos将 tokenizer、自回归/扩散模型、数据处理和安全护栏组成 Physical AI 平台；
  • 自动驾驶世界模型从“预测视频”扩展到多视角、占据、点云和规划闭环。

2026：World Action Model 与可验证闭环

截至 2026 年 9 月，前沿重点已从“能否生成可控未来”转向五个更严格的问题：

  1. 能否在长时间交互中保持对象、地图和未观测状态；
  2. 能否把离散按键、相机轨迹、机器人关节和自然语言统一为动作接口；
  3. 生成分布是否在物理上校准，而不只是单条样本看起来合理；
  4. 世界模型与策略联合后，是否真的提高真实闭环任务成功率；
  5. 如何检测模型失真，并让规划器在不知道时收手。

2026 年大量工作开始使用 World Action Model 一词，尝试联合预测未来视觉与动作，或从想象的未来反推动作。这个方向仍以预印本为主，专栏会把“已验证的范式变化”和“尚待验证的命名热潮”分开讨论。

读每篇时都可以用四个问题检查它是否真的推动了世界模型：

  1. 它的内部状态表示什么？
  2. 它预测什么，预测是否依赖动作？
  3. 它怎样处理多种可能未来和分布外动作？
  4. 预测最终如何改善规划、策略或数据闭环？

七、贯穿专栏的判断标准

世界模型没有一个能包打天下的分数。我们会把评价拆成五层：

  • 表征充分性：状态是否保留任务需要的信息；
  • 预测与校准：模型是否覆盖多种未来，概率是否可信；
  • 长程一致性：对象离开视野后是否仍存在，空间关系是否漂移；
  • 动作因果性：改变动作时，未来是否按正确方向改变；
  • 闭环收益：模型是否让策略更成功、更安全或更省真实数据。

越靠后的指标越接近世界模型的真正用途，也越难测。视频的 FID/FVD 很低，不代表候选动作排序正确；单步误差很小，也不代表连续滚动不会进入模型从未见过的状态。专栏最后两篇会专门讨论这种“看起来会想象”和“真的能靠想象行动”之间的鸿沟。
