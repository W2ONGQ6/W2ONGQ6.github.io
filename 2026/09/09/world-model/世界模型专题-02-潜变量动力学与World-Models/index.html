世界模型专题-02：潜变量动力学 —— 从 E2C 到 World Models

引言：像素不是状态

经典控制假设状态已经给出，但视觉智能体拿到的是数万乃至数百万维像素。直接在像素空间学习动力学有两个问题：计算昂贵，而且模型会把大量容量花在纹理、光影和传感器噪声上。决策真正需要的往往只是少量变量：物体在哪里、怎样运动、是否接触、动作会造成什么后果。

深度潜变量世界模型因此形成两步：

难点不在“把图压小”，而在于压缩后仍保留可预测、可控制的状态。本篇从 VAE、深度状态空间模型讲到 Ha 与 Schmidhuber 的 World Models，解释现代 latent imagination 范式怎样成形。

一、自编码器为什么还不是世界模型

普通自编码器学习：

并最小化重建误差：

它只要求 能恢复当前观测，没有要求相邻时刻在 latent space 中具有简单动力学。编码器可能把视觉上相似但动力学不同的状态放在一起，也可能用大量维度记录对控制无用的纹理。

要成为世界模型，表示至少还要满足：

  • 时序充分：从 能预测任务相关未来；
  • 动作敏感：不同 导致正确的不同后果；
  • 不确定性表达：多种可能未来不能被平均掉；
  • 可滚动性：模型输出能再次作为输入，误差不会立刻失控。

因此潜表示不能先独立学完再盲目接动力学；表示目标与预测目标必须相互约束。

三、深度状态空间模型：让表示服从动力学

3.1 E2C：在潜空间近似局部线性控制

Embed to Control（E2C）假设复杂非线性观测可以映射到一个局部线性的潜空间：

由当前状态附近的网络预测，因此不是全局线性，而是沿轨迹局部线性。这样既能用神经网络处理图像，又能借用经典线性控制与规划工具。

E2C 的关键不是“用了 VAE”，而是把表示学习和可控制性绑定：若 latent code 无法被简单动力学预测，损失会迫使 encoder 重新组织表示。

3.2 Deep Kalman Filters 与 DVBF：把滤波变成可学习推断

再用神经网络参数化 transition、emission 和近似后验。它们把 Kalman filter 从线性高斯模型扩展到非线性、高维观测。

训练目标不只是逐帧重建，还要求推断后验与动力学先验一致：

第一项问“潜状态能否解释当前观测”，第二项问“只靠上一状态和动作，能否预见这个潜状态”。两者拉扯出既能重建又能预测的表示。

四、World Models：把视觉、记忆和控制器拆成三块

Ha 与 Schmidhuber 在 2018 年的 World Models 用一个极清楚的 V-M-C 架构把潜变量控制带入大众视野：

三个模块分工明确：

  • V（Vision）：VAE 把像素压缩成 latent vector ；
  • M（Memory）：MDN-RNN 根据 、动作和隐藏状态预测下一个 latent 的分布；
  • C（Controller）：小型线性网络根据当前 latent 与 RNN memory 选择动作。

4.1 为什么需要 MDN，而不是普通 MSE

若未来有多个可能结果，用均方误差训练确定性网络会预测条件均值。在图像里表现为模糊，在状态里可能是根本不存在的未来。

4.2 在“梦里”训练控制器

World Models 最有传播力的实验是在 CarRacing 与 VizDoom 上先学习环境模型，再让 controller 完全在模型生成的 rollout 中训练。由于 controller 很小，论文使用 CMA-ES 这类黑盒优化，而不是反向传播穿过整个世界模型。

五、温度：随机性既是现实，也是防作弊机制

MDN-RNN 采样时可用温度 调整分布：温度低，模型给出更确定、更容易的未来；温度高，未来更随机、更多样。

若梦境过于确定，controller 可能找到模型中的狭窄漏洞，在模拟中表现极好，回到真实环境却失败。适当提高温度，相当于让策略面对一个更苛刻、更丰富的环境分布，从而降低对单一模型错误的过拟合。

但温度不是严格的不确定性校准：

  • 它混合了环境本身的随机性（aleatoric uncertainty）；
  • 也混合了模型没学会造成的不确定性（epistemic uncertainty）；
  • 全局调温无法指出模型具体在哪些状态动作上无知。

后来的 PETS 用模型 ensemble 估计 epistemic uncertainty，MBPO 用短 rollout 限制误差传播，都比全局温度更有针对性。

六、World Models 做对了什么，又缺了什么

6.1 三个重要贡献

第一，模块边界清楚。 表示、动力学与控制器可以分别训练和检查，让“内部模拟器”从抽象概念变成可复现架构。

第二，显式建模随机未来。 MDN-RNN 不把未来压成单点，为后来的 stochastic state-space model 铺路。

第三，把 imagined rollout 变成主角。 模型不只是辅助特征提取，而是策略主要的训练环境。

6.2 四个结构性局限

  1. VAE 按单帧训练：它优先保留重建信息，未必保留控制相关变量；
  2. 模块分阶段训练：视觉表示不会因策略最终需要什么而调整；
  3. 长 rollout 容易漂移：RNN 不断吃自己的样本，误差累积；
  4. 控制器优化没有价值 bootstrap：在更复杂任务上，纯黑盒搜索和完整模型 rollout 成本迅速上升。

PlaNet 与 Dreamer 的推进，正是把这些模块重新整合：以 recurrent state-space model 联合训练表示与动力学，在有限 imagination horizon 上结合 value function，并让梯度直接穿过想象轨迹。

七、SimPLe：像素世界模型能否提高 Atari 样本效率

SimPLe（2019）走了与潜空间不同的路线：学习视频预测模型，在模型中用 PPO 训练策略，再回真实环境收集新数据，循环进行。

它在有限真实交互预算下展示了 model-based Atari 的样本效率潜力，也暴露像素 rollout 的困难：画面质量、奖励预测和终止条件任何一个出错，都会误导策略。相比之下，latent model 可以丢弃视觉细节、滚动更快，但其错误更难被人直接看见。

这形成一项至今仍在的权衡：

路线 优点 风险
像素/观测预测 可视化、可生成数据、可人工检查 昂贵，容易浪费容量在无关细节
潜状态预测 紧凑、滚动快、可面向决策 表征可能遗漏关键变量，错误难解释
结构化状态预测 几何清楚、利于约束与安全检查 依赖标注或预设表示，开放世界覆盖有限

八、表示学习的真正验收题

假设两个模型的重建误差分别为 和 ，不能据此断定前者更适合控制。更合理的检查包括：

8.1 线性探针是否读得出关键状态

从 是否能预测位置、速度、接触、对象身份和任务进度？这检查信息是否存在，但不保证策略能稳定利用。

8.2 干预动作后，预测是否正确分叉

固定历史，只改变 ，比较未来是否产生符合因果方向的变化。如果所有动作生成几乎相同的未来，模型只是视频外推器。

8.3 多步 rollout 是否保持任务变量

不只看像素相似度，还看对象是否凭空消失、速度是否漂移、奖励与终止是否一致。

8.4 下游控制是否真的改善

最终比较真实环境回报、样本效率和分布外鲁棒性。若重建更好却控制更差，说明表示目标保留了错误的信息。

九、代表工作

Embed to Control: A Locally Linear Latent Dynamics Model for Control from Raw Images

  • 论文：Watter et al., NeurIPS 2015
  • 核心创新：联合学习图像表示和局部线性潜在动力学，使经典控制方法可用于原始图像。
  • 留下的问题：局部线性与短时域假设难以覆盖复杂、接触丰富的环境。

Deep Kalman Filters

  • 论文：Krishnan, Shalit & Sontag, 2015
  • 核心创新：以深度网络参数化非线性状态转移和观测模型，并进行变分序列推断。
  • 代表意义：连接经典概率状态空间模型与深度生成模型。

Deep Variational Bayes Filters

  • 论文：Karl et al., 2016
  • 核心创新：把控制输入、随机潜状态和可微分变分滤波整合进统一生成模型。

World Models

  • 论文：Ha & Schmidhuber, 2018
  • 核心创新：VAE 压缩视觉，MDN-RNN 建模随机时序，小控制器在学习到的梦境中训练。
  • 代表意义：确立现代深度世界模型“表示 + 记忆 + 想象控制”的直观范式。

Model-Based Reinforcement Learning for Atari

  • 论文：Kaiser et al., ICLR 2020
  • 核心创新：SimPLe 交替训练视频模型与策略，在低真实样本预算下挑战 Atari。
  • 代表意义：展示像素生成模型可服务策略训练，也清楚暴露视觉 rollout 的模型偏差。

小结：压缩不是目的，可预测和可控制才是

E2C 和深度状态空间模型让 latent code 服从时间与动作；World Models 则把 VAE、随机动力学和想象训练组合成影响深远的系统。它们共同完成了从“人工给定状态”到“从像素学习内部状态”的转变。

但 VAE、RNN 和 controller 仍相对割裂，长程训练也缺少稳健的价值估计。下一篇的 PlaNet 会用 RSSM 把确定性记忆与随机状态结合，再用在线规划选择动作；Dreamer 随后进一步把 actor-critic 放进想象轨迹，让世界模型从“模拟器”变成策略学习的主训练场。
