引言：模型必须忠实还原环境吗

World Models 与 Dreamer 都要求 latent state 能解释观测，通常还配有图像 decoder。MuZero 提出一个更功利的问题：如果模型只用于规划，为什么要预测棋盘规则、Atari 画面或所有环境细节？

规划真正需要的是三样东西：当前状态有哪些动作值得搜索，执行动作后会得到什么奖励，未来状态大概值多少。MuZero 因而只学习对决策有用的隐状态，不要求它能生成真实观测。

这条路线被称为 value-equivalent model：模型不必在观测意义上等价于环境，只需在策略和价值相关计算上保留正确结构。

一、从 AlphaZero 的已知规则到 MuZero 的学习模型

AlphaZero 使用 Monte Carlo Tree Search（MCTS），但搜索时需要一个精确 simulator：给定棋盘和动作，规则引擎返回下一棋盘与是否合法。

这对围棋成立，对 Atari 或真实机器人却不成立。MuZero 用三个神经函数替换规则引擎：

1.1 representation function

它把历史观测编码成搜索树根部的隐状态。因为 Atari 单帧不能表达速度，输入可以包含多帧历史。

1.2 dynamics function

给定搜索中的隐状态和候选动作，预测即时奖励与下一个隐状态。

1.3 prediction function

它输出动作先验 与状态价值 ，指导树搜索。

这意味着许多对决策无影响的细节可以被丢弃。例如棋子纹理、Atari 背景动画可能影响像素，却不改变奖励和最优动作。

优势

  • 容量集中到奖励与行动差异；
  • 不需要高成本 observation decoder；
  • latent rollout 更快，适合树搜索；
  • 训练目标与最终规划用途直接一致。

风险

  • 隐状态难以解释和人工审计；
  • 当前任务认为无关的信息，换任务后可能变得关键；
  • 只在当前策略覆盖的动作上正确，不保证反事实泛化；
  • reward/value target 自身有偏时，模型会忠实保留错误目标。

“不重建”不是免费午餐，而是把模型的适用边界收紧到当前决策问题。

五、MuZero 与 Dreamer 到底有什么不同

维度 Dreamer MuZero
状态约束 重建观测 + KL + 奖励 奖励 + 价值 + 策略
决策方式 学习 actor，想象中优化 MCTS 在线搜索
动力学 概率 RSSM 通常确定性隐式 dynamics
长期估计 critic + -return 树搜索 + value head
强项 连续控制、快速执行、样本效率 离散动作、强规划、策略改进
主要风险 模型 rollout 被 actor 利用 搜索反复调用偏置 dynamics

二者并非“显式模型 vs 无模型”。MuZero 明确学习并使用 dynamics，只是这个模型不对应可观察的真实状态。更准确的区分是 observation-predictive 与 decision-predictive。

六、为什么 MuZero 仍然会受模型偏差影响

有人会误以为：既然 MuZero 不预测像素，就绕开了模型误差。实际上，误差只是从视觉空间转移到奖励、价值和动作排序上。

6.1 latent state 没有直接一致性约束

从真实观测编码出的状态 ，与从早期状态滚动 次得到的 ，原始 MuZero 没有直接要求二者一致。多步 unroll 只能通过任务损失间接约束 dynamics。

6.2 搜索会放大微小排序错误

MCTS 集中访问看起来最有希望的分支。如果某个动作的模型价值略微虚高，搜索计算越多，可能越确信这个错误分支。

6.3 策略变化造成数据分布移动

训练目标来自过去的 self-play/replay，而新搜索策略会访问不同状态。持续收集数据和重分析可以追赶这种变化，但不能给出开放世界保证。

7.2 value prefix

预测一段累计奖励而非每一步孤立奖励，缓解 reward clipping 或稀疏奖励下的信息不足。

7.3 model-based value target

对较新样本使用搜索得到的价值，对较旧、策略已变化的样本谨慎构造目标，降低 off-policy value target 偏差。

EfficientZero 的重要启示是：decision-equivalent objective 很强，但在数据有限时，表征一致性仍能提供关键的自监督信号。完全放弃 observation-derived structure 未必最优。

九、代表工作

Mastering Atari, Go, Chess and Shogi by Planning with a Learned Model

  • 论文：Schrittwieser et al., Nature 2020
  • 核心创新：学习 representation、dynamics、prediction 三个函数，在隐空间用 MCTS 规划，无需给定环境规则。
  • 代表意义：证明面向价值与策略学习的模型可以替代可解释 simulator。

Mastering Atari Games with Limited Data

  • 论文：Ye et al., NeurIPS 2021
  • 核心创新：表示一致性、value prefix 和更稳健的价值目标，大幅提升 MuZero 在低数据设置下的效率。
  • 代表意义：将 value-equivalent model 与自监督表征约束重新结合。

Value Equivalence Principle for Model-Based Reinforcement Learning

  • 论文：Grimm et al., NeurIPS 2020
  • 核心创新：形式化模型在一组价值函数上等价的条件，解释任务导向模型为何无需复刻全部环境。

小结：模型的真实性必须相对于用途来定义

MuZero 最深的贡献不是“又一个围棋/Atari 系统”，而是改变世界模型的验收标准：一个内部模型可以不生成可见世界，却仍因保留奖励、价值和动作排序而支持强规划。

但越面向任务，模型越可能丢掉迁移需要的信息；越依赖搜索，局部价值误差越可能被反复放大。下一篇讨论另一条控制路线：PETS、MBPO 与 TD-MPC 怎样显式估计不确定性、缩短 rollout，并在潜空间中把局部规划和价值学习统一起来。
