强化学习经典论文全景指南（1989–2026）

强化学习经典、前沿论文整理（1989–2026）

本文档系统整理强化学习（Reinforcement Learning）领域最具代表性的经典与前沿论文，按技术脉络分为 10 大方向。
覆盖从 Q-Learning、策略梯度等理论奠基，到 DQN 引爆的深度强化学习浪潮，再到 AlphaGo 系列的里程碑系统，直至 2025 年以 RLVR/GRPO 驱动大模型推理的最新前沿，勾勒出 RL 三十余年的完整版图。

标注说明：🏆 里程碑 | 📌 推荐优先阅读 | ⭐ 适合入门

1989–2026 RL 演进趋势

1988–2000：理论奠基

  • TD Learning（Sutton, 1988）时序差分学习，RL 的核心思想诞生
  • Q-Learning（Watkins, 1989）无模型、off-policy 控制的基石
  • 策略梯度定理（Sutton et al., 2000）为直接优化策略提供理论保证

2013–2016：深度 RL 引爆

  • DQN（2013/2015）深度网络 + 经验回放 + 目标网络，攻克 Atari，引爆 DRL
  • A3C / TRPO / DDPG（2015–2016）策略梯度进入深度时代
  • AlphaGo（2016）🏆 击败李世石，RL 历史性时刻

2017–2019：算法成熟与系统突破

  • PPO（2017）简单稳健，成为事实标准
  • SAC / TD3（2018）最大熵与双 Q，连续控制新标杆
  • Rainbow（2018）价值型 RL 集大成
  • AlphaZero / AlphaStar / OpenAI Five（2017–2019）里程碑系统连发

2020–2022：模型型复兴与离线 RL

  • MuZero（2020）无需环境规则的规划，学习式模型登顶
  • Dreamer 系列（2020–2023）世界模型中「想象」训练
  • CQL / IQL / Decision Transformer（2020–2021）离线 RL 与序列建模范式

2022–2026：RL 遇见大模型

  • InstructGPT / RLHF（2022）RL 对齐大模型，开启 ChatGPT 时代
  • DPO（2023）免 RL 的偏好优化
  • GRPO / DeepSeek-R1（2024–2025）🏆 可验证奖励 RL 涌现推理能力
  • DAPO / VAPO 等（2025）RLVR 工程化，agentic RL 兴起
