引子：一条与众不同的技术路线

2025 年 1 月，DeepSeek-R1 的发布在全球范围内掀起了一场关于「AI 训练成本」的地震——英伟达单日市值蒸发近 6000 亿美元，硅谷第一次严肃讨论「算力护城河是否被绕过」。但对于长期跟踪 DeepSeek 论文的人来说，R1 不是一次「横空出世」，而是一条清晰技术脉络的必然结果。

从 2024 年 1 月的第一篇 DeepSeek LLM，到 2025 年底的 DeepSeek-V3.2，这家公司在不到两年时间里发表了约 20 篇高质量论文。如果把这些论文串成一条线，会看到一个反复出现的核心命题：在算力受限的条件下，如何通过架构创新和工程优化，把大模型的「性能/成本」比推到极致。

本文不逐篇罗列论文（那是全景指南和各专题分册的任务），而是尝试回答一个更宏观的问题：这些看似分散的工作之间，存在怎样的内在逻辑？DeepSeek 的技术演进，究竟遵循着怎样的一条主线？

一、四条技术主线

回望 DeepSeek 的全部工作，可以提炼出四条相互交织、层层递进的主线。理解了这四条线，就理解了 DeepSeek 的技术基因。

主线一：效率至上的架构创新（MLA + MoE）

这是 DeepSeek 最鲜明的标签。它的逻辑起点非常朴素：如果买不到最多的卡，就必须让每一块卡产出最多的智能。

  • MoE（混合专家）：从 DeepSeekMoE（2024.01）开始，DeepSeek 就选定了稀疏激活的路线。总参数可以很大（保证容量），但每个 token 只激活一小部分参数（保证成本）。DeepSeekMoE 的原创贡献是「细粒度专家切分 + 共享专家隔离」，这套设计一路延续到 V2、V3，直到 671B / 37B 激活的 V3。
  • MLA（多头潜在注意力）：V2（2024.05）的杀手锏。它把 KV Cache 压缩到原来的约 1/14，直接解决了长上下文推理的显存瓶颈。这不是小修小补，而是对注意力机制存储范式的重构。

这条线的终点是 V3：用约 5.6M 美元、2048 块 H800、两个月，训练出对标 GPT-4o 的模型。

主线二：强化学习驱动的能力涌现（GRPO → R1）

如果说主线一解决的是「怎么便宜地把模型做大」，那么主线二解决的是「怎么便宜地把模型做聪明」。

  • GRPO（组相对策略优化）：首次出现在 DeepSeekMath（2024.02）。它去掉了 PPO 中昂贵的 Critic 网络，用「组内相对奖励」估计优势函数，大幅降低了 RL 训练的显存和计算开销。这是一个被严重低估的工程创新。
  • R1（2025.01）：GRPO 的思想被推向极致。R1-Zero 直接在基座模型上做纯 RL，零人工推理示范，仅靠「答案是否正确」的规则奖励，模型竟自发学会了长链推理、自我验证、回溯反思——著名的「Aha Moment」。

这条线的哲学意义深远：推理能力可能不需要被「教」，而可以从基座中被「激励」出来。

主线三：垂直领域的深耕（Code / Math / Prover）

DeepSeek 从不满足于通用能力，而是在最硬核、最可验证的领域反复锤炼：

  • 代码：DeepSeek-Coder（2024.01）→ Coder-V2（2024.06，比肩 GPT-4-Turbo）
  • 数学：DeepSeekMath（2024.02，GRPO 诞生地）
  • 形式化证明：Prover（2024.05）→ Prover-V1.5（2024.08）→ Prover-V2（2025.04）

选择这些领域并非偶然：代码能编译、数学有标准答案、定理证明可被 Lean 验证——它们都提供了「可自动验证的奖励信号」，这正是大规模 RL 的理想燃料。 垂直领域的探索，反过来喂养了通用推理能力。

主线四：软硬件协同的系统工程（Fire-Flyer → Hardware Insights）

这是 DeepSeek 区别于纯算法团队的关键。它不只是「用」GPU，而是深入到集群、通信、精度、kernel 的每一层：

  • Fire-Flyer AI-HPC（2024.08）：公开了万卡集群的软硬件协同设计，PUE、成本、容错的全套工程细节。
  • FP8 训练 + DualPipe（V3）：把低精度训练和流水线并行的通信重叠做到了工业级。
  • Hardware Insights（2505.09343）：反过来，从 V3 的实践出发，向硬件厂商提出下一代 AI 芯片的设计建议。

算法与硬件的双向奔赴，是 DeepSeek 成本优势的真正底座。

二、时间轴：脉络的具体展开

★ 标记的是对行业产生结构性影响的关键节点。

三、脉络背后的三个「一以贯之」

1. 一以贯之的「成本意识」

从 DeepSeek LLM 副标题里的「Longtermism（长期主义）」，到 V3 的 5.6M 美元，再到 V3.2 的稀疏注意力，成本从来不是事后优化项，而是贯穿架构设计的第一性原则。MLA 省显存、MoE 省算力、GRPO 省 Critic、FP8 省带宽、NSA/DSA 省长上下文开销——每一项创新几乎都能翻译成一句「省了多少钱」。

2. 一以贯之的「开源开放」

DeepSeek 几乎所有旗舰模型都开源权重，且技术报告详尽到可复现的程度。R1 甚至公开了完整的 RL 训练配方，直接引爆了全球数十个团队的复现浪潮。这种开放不是慈善，而是一种技术自信与生态策略：用开源撬动全球智力，反哺自身迭代。

3. 一以贯之的「原创架构」

DeepSeek 很少做「跟随式」创新。MLA、GRPO、无辅助损失负载均衡、NSA、DSA——这些都是从问题本质出发的原创设计，而非对已有方案的微调。它证明了：在大模型时代，来自资源受限环境的原创架构创新，完全可以定义前沿。

四、这条脉络给行业的启示

DeepSeek 的技术演进，本质上是对「Scaling is all you need（规模即一切）」这一主流叙事的一次有力回应。它没有否定规模的价值，而是补充了另一半真相：在给定规模下，架构效率和工程深度决定了你能走多远。

  • 对创业公司：资源劣势可以用架构创新弥补，垂直领域的可验证信号是弯道超车的抓手。
  • 对研究者：GRPO、R1 证明了「简单 + 可验证奖励 + 大规模 RL」的范式威力，能力涌现的边界远未探明。
  • 对整个行业：前沿模型的训练成本可以被压缩一到两个数量级，AI 的「民主化」比想象中来得更快。
