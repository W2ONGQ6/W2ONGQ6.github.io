DeepSeek专题-02：MLA 与 MoE 架构旗舰 —— 如何用 1/10 成本训练世界级大模型

MLA 与 MoE 架构旗舰 (Flagship Architecture)

如果说 DeepSeek 有「代表作」，那一定是 V2 和 V3 这两代旗舰。它们把 DeepSeekMoE 的稀疏激活基因，与全新的 MLA（多头潜在注意力） 相结合，再叠加 FP8 训练、DualPipe 流水线、无辅助损失负载均衡等一系列工程创新，最终在 V3 上实现了震惊全球的结果：约 560 万美元、2048 块 H800、两个月，训练出对标 GPT-4o 的 671B 模型。 这一章是理解 DeepSeek「极致效率」路线的核心。

发展时间线

DeepSeek-V2: A Strong, Economical, and Efficient Mixture-of-Experts Language Model

📝 论文深度笔记

  • arXiv: 2405.04434
  • 发表: 2024 年 5 月（DeepSeek-AI）
  • 作者: DeepSeek-AI（150+ 位贡献者）
  • 简介: 236B 总参数 / 21B 激活参数的 MoE 模型，首创 MLA（Multi-head Latent Attention，多头潜在注意力），将 KV Cache 压缩至传统 MHA 的约 1/14，在大幅降低训练成本（较 DeepSeek 67B 省 42.5%）和推理成本（吞吐提升 5.76 倍）的同时，性能反超前代密集模型。
  • 核心创新:
    • MLA（多头潜在注意力）—— 本章的主角：传统多头注意力（MHA）在推理时需要缓存每一层、每个头的 Key 和 Value，KV Cache 随序列长度和头数线性膨胀，是长上下文推理的头号显存杀手。MLA 的核心思想是低秩联合压缩：将 Key 和 Value 联合投影到一个低维的「潜在向量（latent vector）」中缓存，推理时再通过上投影矩阵恢复。这样每个 token 只需缓存一个小小的潜在向量，KV Cache 骤降约 93%。更巧妙的是，MLA 通过「解耦的 RoPE」设计，在压缩的同时保留了旋转位置编码的兼容性，且性能不降反升——这是因为低秩瓶颈起到了某种正则化作用。MLA 是继 MQA/GQA 之后，注意力 KV 压缩方向上最重要的原创突破。
    • DeepSeekMoE 架构的规模化验证：V2 把前作 DeepSeekMoE 的「细粒度专家 + 共享专家」设计扩展到 236B 规模——160 个路由专家 + 2 个共享专家，每 token 激活 6 个路由专家。证明了这套 MoE 设计在大规模下依然有效且稳定。
    • 经济性的全面兑现：得益于 MLA + MoE 的组合，V2 相比同性能的密集模型，训练成本大幅下降、推理吞吐量提升近 6 倍。DeepSeek 借此在国内掀起了「大模型价格战」，API 价格降至行业零头。
  • 代表意义: V2 是 DeepSeek 从「优秀」走向「独特」的转折点。MLA 的提出，让 DeepSeek 在注意力架构上第一次拥有了别人没有的原创武器，也让「长上下文 + 低成本推理」这一看似矛盾的目标成为可能。此后，MLA 成为 V3、R1 的标配，并被学术界和工业界广泛研究与借鉴。可以说，V2 定义了 DeepSeek 后续所有旗舰模型的架构模板：MLA 管注意力效率，DeepSeekMoE 管参数效率。

DeepSeek-V3 Technical Report

📝 论文深度笔记

  • arXiv: 2412.19437
  • 发表: 2024 年 12 月（DeepSeek-AI）
  • 作者: DeepSeek-AI（200+ 位贡献者）
  • 简介: 以仅约 560 万美元的训练成本训练出 671B 总参数 / 37B 激活参数的 MoE 模型，性能达到与 GPT-4o、Claude-3.5-Sonnet 等顶尖闭源模型相当的水平，革命性地降低了前沿模型的训练门槛，成为 2024 年最具震撼力的 AI 发布。
  • 核心创新:
    • $5.6M 训练成本的革命：在其他顶级模型训练成本动辄数千万至数亿美元的背景下，V3 以约 278.8 万 GPU 小时（H800）、折合约 560 万美元的预算实现了对等性能。这不是单点突破，而是 MLA、DeepSeekMoE、FP8、DualPipe 等一系列技术环环相扣的系统性成果。
    • FP8 混合精度训练：V3 是首批在超大规模模型上成功验证 FP8 训练 的工作之一。通过细粒度的量化策略（tile-wise / block-wise 量化）、高精度累加、以及对激活/权重/梯度不同部分的精度分配，V3 在保持训练稳定性的同时，把计算和通信开销大幅压低。这是低精度训练工程化的里程碑。
    • DualPipe 与通信-计算重叠：针对跨节点 MoE 训练中巨大的 All-to-All 通信开销，V3 设计了 DualPipe 双向流水线并行算法，让前向与反向计算和通信几乎完全重叠，配合定制的高效跨节点通信 kernel，把 H800 受限带宽的劣势降到最低。
    • 无辅助损失的负载均衡（Auxiliary-Loss-Free Load Balancing）：传统 MoE 靠辅助损失强制专家负载均衡，但这会干扰主任务、损害模型质量。V3 改用动态偏置调整——为每个专家维护一个可学习的偏置项，仅用于路由决策而不进入梯度，从而在不引入辅助损失的前提下实现负载均衡。这是 MoE 训练的一大工程突破。
    • 多 token 预测（MTP）训练目标：训练时让模型一次预测多个未来 token，增强了训练信号密度，并可用于推理时的投机解码加速。
  • 代表意义: V3 的核心信息简单而有力：训练世界级大模型的成本可以被压缩一到两个数量级。 它不仅是一篇技术报告，更是一次产业格局的重塑——证明了在出口管制、算力受限的条件下，凭借极致的架构与工程优化，依然可以站上全球前沿。V3 同时也是 DeepSeek-R1 的基座模型：正是有了这个强大而廉价的 Base，才有了随后用纯 RL 点燃推理能力的 R1。V3 与 R1 一前一后，构成了 2024 年底到 2025 年初 AI 领域最重要的叙事。

DeepSeek-V4 (Preview): Towards Highly Efficient Million-Token Context Intelligence

  • arXiv: 2606.19348
  • 发表: 2026 年 6 月（DeepSeek-AI）
  • 作者: DeepSeek-AI
  • 简介: DeepSeek 下一代旗舰的预览版，包含两个 MoE 模型——DeepSeek-V4-Pro（1.6T 总参数 / 49B 激活）与 DeepSeek-V4-Flash（284B 总参数），核心目标是「高效的百万级 token 上下文智能」，把长上下文推理的成本与能力同时推向新高度。
  • 核心创新:
    • 面向百万 token 上下文的架构设计：V4 把长上下文作为第一优先级，综合运用前作积累的 MLA（KV 压缩）与稀疏注意力（NSA/DSA 一脉）等技术，在百万级 token 尺度上依然保持可控的推理成本，将「超长上下文」从实验特性变为实用能力。
    • Pro / Flash 双档位的 MoE 家族：1.6T 的 Pro 追求极致能力，284B 的 Flash 追求高吞吐低延迟，延续了 DeepSeek「一个技术栈、多档位覆盖」的家族策略，兼顾云端旗舰与规模化部署。
    • 效率主线的规模化延续：作为 V2（MLA）→ V3（FP8/MoE）→ V3.2（DSA）之后的下一代旗舰，V4 是 DeepSeek「存储压缩 + 计算稀疏化」效率路线在更大规模上的集成兑现。
  • 代表意义: DeepSeek-V4 是这条旗舰主线目前已知的最新坐标。它标志着 DeepSeek 的关注重心，正从「用更低成本训练更强模型」进一步延伸到「用更低成本处理更长上下文」。作为预览版，它也预示着下一轮竞争的焦点——百万级 token 的长上下文智能，以及支撑它的高效架构。

小结

V2 和 V3 是 DeepSeek 技术路线的集大成之作。V2 用 MLA 补齐了注意力效率的最后一块拼图，V3 则把 MLA + MoE + FP8 + DualPipe 的组合拳打到了工业极致。 它们共同证明：成本不是前沿模型的入场券门槛，架构创新和工程深度才是。而这个「又强又便宜」的 V3 基座，正是下一章主角——推理模型 R1——得以诞生的土壤。
