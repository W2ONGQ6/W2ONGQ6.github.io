自动驾驶自动标注全景综述 —— 从离线感知到数据引擎

引言：为什么自动标注是自动驾驶的「隐形引擎」

自动驾驶的能力，归根结底建立在数据之上。一套端到端或感知模型要想在长尾场景中稳健工作，需要海量、高质量、多模态的标注数据——3D 检测框、跟踪轨迹、车道线、占据栅格、可行驶区域……而这些标注若全部依赖人工，成本高到无法承受：一帧 LiDAR 点云的 3D 框人工标注可能耗时数分钟，一辆车一天就能采集数百万帧。

自动标注（Auto-Labeling） 正是为破解这一瓶颈而生。它的核心思想是：用「不计算力、不计延迟、可看未来」的离线大模型，去自动生成接近甚至超越人工质量的标签，再用这些标签训练车端的实时小模型。这构成了现代自动驾驶「数据引擎（Data Engine）」的心脏——Tesla、Waymo、地平线、华为等玩家的核心竞争力，很大程度上就藏在各自的自动标注流水线里。

本文以综述视角，系统梳理自动标注的技术脉络：从离线 3D 检测的奠基，到 4D 时空重建，再到基础模型驱动的开放词表标注、占据与轨迹标注，最后落到数据引擎的闭环与评测基准。

一、自动标注的问题定义与分类体系

1.1 什么是「自动标注」

自动标注区别于车端感知（onboard perception）的关键，在于它放松了三个约束：

维度 车端感知（Onboard） 自动标注（Offboard/Auto-Labeling）
算力 严格受限（车规芯片） 几乎无限（云端集群）
延迟 实时（<100ms） 离线（可跑数小时）
时序 只能看过去+当前 可看完整序列（过去+未来）
目标 驱动实车行驶 生成高质量训练标签

正是「可看未来」这一点，让自动标注能够利用整段轨迹的信息去反推每一帧的精确状态——例如一辆被短暂遮挡的车，其位置可以由遮挡前后的观测插值/优化得到。这是车端实时感知永远做不到的。

1.2 分类体系

按标注对象与技术路线，自动标注可分为以下几个方向：

# 方向 核心问题 代表方法
1 离线 3D 检测 如何用序列点云生成高精度 3D 框？ 3D Auto Labeling、Auto4D、DetZero
2 4D 时空重建 如何联合优化目标的尺寸与运动轨迹？ Auto4D、CTRL、静态/动态解耦重建
3 基础模型标注 如何用 SAM/CLIP 做开放词表、零样本标注？ SAM、Grounding DINO、OpenAnnotate3D
4 占据栅格标注 如何自动生成稠密 3D 占据真值？ Occ3D、SurroundOcc 的标注管线
5 轨迹/运动标注 如何为预测任务生成干净的历史/未来轨迹？ 基于离线检测+跟踪的轨迹重建
6 数据引擎闭环 如何用模型自动挖掘长尾、迭代标注？ Tesla Data Engine、主动学习闭环

下文逐一展开。

二、离线 3D 检测：自动标注的奠基

自动标注最成熟、研究最充分的方向，是离线 3D 目标检测——为 LiDAR 点云中的每个目标生成高精度 3D 边界框。

2.1 3D Auto Labeling（Waymo, 2021）—— 开创性工作

论文：Qi, C. R. et al. “Offboard 3D Object Detection from Point Cloud Sequences.” CVPR 2021.

🏆 奠基之作 | 📌 必读

核心思想：这是第一个系统性提出「离线 3D 自动标注」范式的工作。它的流水线分为三步：

  1. 多帧检测 + 跟踪：先用 3D 检测器逐帧检测，再通过多目标跟踪把同一目标跨帧关联，得到每个目标的完整轨迹。
  2. 目标为中心的点云聚合：把同一目标在所有帧的点云，按其轨迹对齐到目标坐标系，聚合成一个「稠密」的目标点云——单帧可能只有几十个点，聚合后可达上千点。
  3. 两分支精修：用「静态目标分支」和「动态目标分支」分别对聚合点云做框回归，得到远超单帧检测的精度。

意义：在 Waymo Open Dataset 上，其自动生成的标签质量接近人工标注，证明了「用序列点云 + 离线大模型自动标注」这条路线的可行性，奠定了后续所有工作的基本范式。

📄 arXiv:2103.05073

2.2 Auto4D（Uber ATG, 2021）—— 4D 标签的解耦

论文：Yang, B. et al. “Auto4D: Learning to Label 4D Objects from Sequential Point Clouds.” 2021.

核心思想：提出「4D 标注」的概念，并给出一个优雅的分解——把 4D 目标标签拆成两部分：

  • 3D 尺寸（size）：对刚体目标，其尺寸在整个时序中是恒定的，可由所有帧联合估计一个最准的尺寸。
  • 运动路径（motion path）：描述目标 pose 随时间的演化。

先用「目标尺寸分支」聚合全序列点云估计固定尺寸，再用「运动路径分支」在固定尺寸约束下精修每帧位姿。这种「尺寸-运动解耦」的思想极大提升了时序一致性，成为 4D 自动标注的经典设计。

📄 arXiv:2101.06586

2.3 DetZero（2023）—— 长时序 + 属性精修的集大成

论文：Ma, T. et al. “DetZero: Rethinking Offboard 3D Object Detection with Long-term Sequential Point Clouds.” ICCV 2023.

🏆 Waymo 3D 检测榜首

核心思想：DetZero 重新审视了离线检测的模块化流水线，提出三大改进：

  1. 上界跟踪（upper-bound tracking）：尽可能完整地关联目标轨迹，为后续聚合提供最全的时序信息。
  2. 注意力精修模块（attention-based refining）：用 Transformer 分别精修目标的几何（框）、位置、置信度三类属性，而非单一回归。
  3. 长时序点云聚合：充分利用长达数百帧的序列。

在 Waymo Open Dataset 上，DetZero 首次让自动标注的检测精度超过所有车端和离线基线，L2 mAPH 登顶榜首，标志离线自动标注在检测精度上正式超越人工基线水平。

📄 arXiv:2306.06023

2.4 离线检测的通用范式总结

综合上述工作，离线 3D 自动标注已形成一套稳定的四段式范式：

其威力来源于三个「离线特权」：看未来（用后续帧修正当前帧）、无限聚合（把稀疏单帧变稠密）、大模型（不受车规算力约束）。

三、基础模型驱动的开放词表标注

上述离线检测多针对闭集类别（车、人、骑行者）。而真实道路充满长尾物体——施工牌、掉落轮胎、异形车辆。2023 年后，视觉基础模型（Foundation Models）为开放词表、零样本标注打开了新大门。

3.1 关键积木：SAM 与 Grounding DINO

  • SAM（Segment Anything Model）：Meta 的可提示分割大模型，能对任意图像生成高质量实例掩码。在自动标注中，它把「像素级分割」这一最耗人力的环节几乎变成免费——给一个点/框提示即可得到精确掩码。
  • Grounding DINO：开放词表检测器，输入任意文本（如 “traffic cone”）即可框出对应物体。与 SAM 串联（Grounded-SAM）后，可实现「文本 → 检测框 → 分割掩码」的全自动开放词表标注。

这些 2D 基础模型的输出，可通过相机-LiDAR 标定投影到 3D，为点云提供语义先验，实现 2D→3D 的标签迁移。

3.2 OpenAnnotate3D 与零样本离线标注

代表工作：OpenAnnotate3D、Zero-shot Offboard Panoptic Perception（arXiv:2411.05311）等。

核心思想：把「LLM 理解语义 + VLM/SAM 分割 + 点云几何」三者结合，构建开放词表的离线全景标注系统。给定一句自然语言描述，系统能自动在多模态数据中定位、分割、并生成 3D 标签，且无需为新类别重新训练。这直接攻克了长尾类别标注的痛点——传统闭集方法遇到没见过的类别只能重新标、重新训，而基础模型方法可以「即插即用」。

意义：标注范式正从「闭集监督」走向「开放词表 + 零样本」，大模型的世界知识成为标注长尾的关键杠杆。

四、占据栅格与稠密标注

近年 占据网络（Occupancy Network） 成为感知热点（参见本系列 03），而它的真值——稠密的 3D 占据栅格——同样高度依赖自动标注。

4.1 Occ3D / SurroundOcc 的标注管线

单帧 LiDAR 点云是稀疏的，无法直接作为稠密占据真值。主流做法是一套多帧聚合 + 网格化的自动标注管线：

  1. 动静分离：先用 3D 检测/跟踪把动态目标与静态背景分开。
  2. 静态背景稠密化：把多帧（甚至整段序列）的静态点云，按自车位姿对齐叠加，得到稠密的静态场景。
  3. 动态目标重建：把每个动态目标的多帧点云在其自身坐标系聚合后，再放回各帧对应位置。
  4. 体素化 + 网格填充：将稠密点云体素化为占据栅格，并用泊松重建/光线投射等方法补全被遮挡区域，生成语义占据真值。

Occ3D、SurroundOcc、OpenOccupancy 等基准的真值，正是通过这类自动管线生成的——它们本身就是「占据自动标注」的工程结晶。

4.2 NeRF / 3DGS 驱动的重建式标注

更前沿的方向是用 NeRF / 3D Gaussian Splatting 对整段驾驶序列做神经重建，得到高保真的连续场景表示，再从中「渲染」出任意视角的深度、语义、占据标签。这种「重建即标注」的思路，让标签的几何一致性和稠密度进一步提升，是占据/深度自动标注的新范式。

五、轨迹与运动标注

轨迹预测任务（参见本系列 04）需要每个交通参与者干净、平滑、完整的历史与未来轨迹作为真值。而车端跟踪输出的轨迹往往有抖动、断裂、ID 切换。

自动标注方案：以离线 3D 检测（如 DetZero）的高精度框为基础，做离线全局跟踪 + 轨迹平滑优化：

  • 用整段序列做双向关联，消除 ID 切换；
  • 用运动学模型（如恒定转率速度模型）+ 样条平滑，去除抖动；
  • 对遮挡段用轨迹插值补全。

由此得到的轨迹真值，其平滑性和完整性远超车端实时跟踪，是运动预测模型训练的理想监督信号。这也再次体现「看未来」的离线特权——预测任务的「未来真值」本质就是把序列的后半段当作监督。

六、数据引擎：自动标注的闭环化

单点的自动标注算法之上，是数据引擎（Data Engine） 这一系统级闭环——它把自动标注嵌入「采集 → 挖掘 → 标注 → 训练 → 部署 → 再采集」的飞轮。

6.1 Tesla 式数据引擎

Tesla 在多届 AI Day 上披露的数据引擎，是自动标注工业化的标杆：

  1. 影子模式挖掘长尾：量产车队在影子模式下运行模型，当模型预测与实际驾驶行为不一致时，自动上传该场景（如罕见障碍物、模型误判处）。
  2. 离线自动标注：云端用重建 + 大模型对上传的 clip 做 4D 自动标注（多车轨迹联合重建静态世界 + 动态目标）。
  3. 单元测试式回归：把标注好的长尾场景加入「单元测试集」，确保新模型不退化。
  4. 闭环迭代：新标注数据训练新模型，再部署回车队挖掘新长尾。

其精髓在于：用车队规模自动发现「模型不会的场景」，用离线大模型自动标注这些场景，形成自我改进的飞轮。 人工只在极少数疑难样本上介入。

6.2 主动学习与不确定性挖掘

在算法层面，数据引擎依赖主动学习（Active Learning）：用模型的不确定性（熵、集成分歧、置信度）自动筛选「最值得标注」的样本，把有限的标注预算（无论自动还是人工）花在信息量最大的数据上，避免对海量冗余的简单场景重复标注。

七、评测：如何衡量自动标注的质量

自动标注的评测有其特殊性——目标不是「实时精度」，而是「标签质量」及「对下游模型的增益」：

评测维度 说明
与人工标注的一致性 用 3D IoU、mAP 等对比自动标签与人工真值的吻合度
下游模型增益 用自动标签训练车端模型，看其在标准 benchmark 上的提升（最终指标）
标注-人工对比成本 达到同等下游性能，自动标注节省了多少人工工时
时序一致性 轨迹平滑度、ID 一致性、尺寸稳定性

常用数据集：Waymo Open Dataset（离线检测标注的主战场）、nuScenes（多模态、占据标注）、Argoverse 2（长时序、轨迹）。值得注意的是，DetZero 等工作已证明自动标签在检测精度上可超越人工基线——这意味着自动标注不只是「省钱」，在某些维度上还能「更准」。

八、挑战与展望

当前挑战：

  • 长尾与开放世界：闭集方法难覆盖罕见类别；基础模型标注虽有潜力，但 3D 精度仍待提升。
  • 多模态一致性：相机、LiDAR、地图标签间的对齐与融合仍易出错。
  • 质量的自动校验：如何在无人工真值时自动发现并修正标注错误（label noise），是规模化的关键。
  • 动态与形变目标：行人、可形变物体不满足刚体假设，尺寸-运动解耦不再成立。

未来方向：

  1. 基础模型深度融入 3D：把 SAM/VLM 的开放语义与点云几何深度耦合，实现真正的开放词表 4D 标注。
  2. 重建式标注（NeRF/3DGS） 成为主流：以神经重建为中介，统一深度、占据、语义、轨迹的标注。
  3. 世界模型即标注器：用驾驶世界模型（参见本系列 08）同时生成数据与标签，模糊「仿真」与「标注」的边界。
  4. 端到端时代的「轨迹自动标注」：随着端到端方案兴起，如何自动标注「优质人类驾驶轨迹」作为模仿目标，成为新焦点。

总结

自动标注是自动驾驶「数据飞轮」的隐形引擎。它从 3D Auto Labeling 的离线检测范式起步，经 Auto4D 的尺寸-运动解耦、DetZero 的长时序精修达到超越人工的精度，又在 SAM/Grounding DINO 等基础模型的加持下走向开放词表与零样本，并延伸到占据、轨迹等稠密标注，最终在 数据引擎 中闭环化、工业化。

一句话概括其本质：用「可看未来、不计算力」的离线大模型，把稀疏、含噪的原始数据，自动转化为稠密、干净、可训练的标签。 谁的自动标注飞轮转得更快、更省、更准，谁就在自动驾驶的数据竞赛中占得先机。
