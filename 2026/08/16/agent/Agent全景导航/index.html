AI Agent 全景专题 —— 从能力基石到模型、harness 与应用

写在前面：用一条发展逻辑串起整个 Agent 领域

2023 到 2026 这三年，AI 领域最深刻的变化不是”模型更大了”，而是从”会回答”走向”会行动”——大模型从一个被动的问答框，长成了能自己规划、调用工具、执行多步任务、并从结果中纠错的智能体（Agent）。

但 Agent 领域的资料极度碎片化：模型厂商发布会各说各话，harness 项目层出不穷，评测榜单每月翻新。如果只是罗列”有哪些模型、哪些工具”，读者会淹没在版本号里，抓不住主干。

本专题换一个组织方式：用一条”内生发展逻辑”把整个领域串起来。这条逻辑是一个环环相扣的因果链——每一层的能力上限，都成为下一层要突破的瓶颈：

静态 LLM → 加循环与工具（Agent 雏形）→ 雏形不够可靠 → 模型侧为 agentic 专门训练 → 光有好模型仍不可靠 → harness 工程决定生产可靠性 → 能力就绪后应用爆发 → 评测从”开环问答”被逼向”闭环任务”。

读懂这条链，你就能把任何一个新模型、新工具、新榜单，准确地安放到它在整个版图中的位置。

四大板块与内在因果

板块一：能力基石 —— 一个 LLM 如何变成 Agent

Agent 不是新模型，而是给 LLM 套上一个”感知—决策—行动—反馈”的循环。这一层要讲清四个正交能力：推理规划（Planning）、工具使用（Tool Use）、记忆（Memory）、反思（Reflection），以及把它们缝起来的 ReAct 执行循环。这是理解后面一切的地基——你会看到，后面模型和 harness 的所有努力，都是在强化这四个能力中的某一个。

板块二：前沿模型 —— 为 agentic 而生的军备竞赛

ReAct 雏形暴露了一个残酷事实：通用 LLM 并不擅长当 agent——多步任务里会跑偏、工具调用格式易错、长程规划会失忆。于是 2025–2026 出现了一场”agentic 模型军备竞赛“：Anthropic Claude Opus 4.x、OpenAI GPT-5.x/Codex、智谱 GLM、DeepSeek V4、月之暗面 Kimi K2/K3、阿里 Qwen3 系列——这些模型不再只优化”答得对不对”，而是专门为长程自主执行、原生工具调用、超长上下文做训练。这一板块梳理它们各自的创新点，以及为什么”闭源领先、开源紧追”的格局在 2026 形成。

板块三：Harness 工程 —— 让模型成为可靠的 Agent

一个反直觉但已成共识的结论：生产环境里 agent 靠不靠谱，越来越不取决于模型本身，而取决于包裹模型的那层”harness”（工程外壳）。同一个模型，换一个 harness，任务成功率可以差出几十个百分点。Claude Code、Codex 等把一整套工程实践沉淀了下来：上下文工程（context engineering）、跨会话记忆、失败即关闭的权限系统、多智能体协作、子代理隔离。这一板块讲透 harness 到底在解决模型的哪些”先天不足”。

板块四：编排框架 —— 用工程框架把能力”搭”成 Agent

harness（板块三）是产品级的运行时外壳，而更多开发者面对的问题是：手里有模型和 API，如何用代码把”规划—工具—记忆—多智能体”这些能力快速搭成一个可运行的 agent？ 这正是编排框架（orchestration framework）的位置——它把板块一的四大能力封装成可复用的组件与抽象。LangChain 用 Chain/LCEL 把”提示→模型→工具→解析”串成可组合的管道；LangGraph 进一步用状态图（StateGraph）把 agent 建模为带循环、分支、检查点的有向图，解决了链式抽象难以表达”循环与回退”的痛点；AutoGen、CrewAI 则主打多智能体协作（对话式/角色分工）；LlamaIndex 侧重 RAG 数据编排。这一板块讲清：从”链”到”图”的抽象演进，为什么 agent 的控制流最终收敛到图。

板块五：应用与评测 —— 能力落地与”考卷”的进化

当模型、harness 与编排框架都就位，应用随之爆发：编程智能体、深度研究（deep research）、计算机操作（computer use）、企业级 agent。与此同时，评测也被倒逼着进化——从”开环问答”（给个问题看答对没有）走向”闭环任务“（扔进真实代码库/环境，看它能不能自己干完）。SWE-bench、Terminal-Bench、GAIA、GDPval 等基准的演进，本身就是 Agent 能力边界的一面镜子。你怎么考它，就决定了它往哪进化——这与其他技术史反复出现的规律一致。

系列文章导航

按”能力基石 → 前沿模型 → harness 工程 → 编排框架 → 应用评测”这条内生逻辑顺序阅读，能获得最连贯的理解：

  1. Agent-01：能力基石 —— 一个 LLM 如何变成 Agent
    地基：ReAct 循环 + 规划 / 工具 / 记忆 / 反思四大正交能力。后面模型与 harness 的一切努力，都是在强化其中某一项。
  2. Agent-02：前沿模型 —— 为 agentic 而生的军备竞赛
    通用 LLM 不擅长当 agent → Claude Opus 4.x、GPT-5.x/Codex、DeepSeek V4、Kimi K2/K3、Qwen3、GLM 各自为长程自主执行专门训练；闭源领先、开源紧追的格局。
  3. Agent-03：Harness 工程 —— 让模型成为可靠的 Agent
    好模型 ≠ 可靠 agent：上下文工程、跨会话记忆、fail-closed 权限、多智能体与子代理，Claude Code / Codex 把”最后一公里”沉淀成工程学科。
  4. Agent-04：编排框架 —— 从 LangChain 到 LangGraph
    开发者视角：把规划/工具/记忆/多智能体封装成可复用抽象；从 LangChain 的”链”到 LangGraph 的”状态图”，控制流为何收敛到图。
  5. Agent-05：应用与评测 —— 能力落地与”考卷”的进化
    编程 / 深度研究 / computer use / 企业 agent 爆发；评测从开环问答被逼向闭环任务（SWE-bench→DeepSWE→Terminal-Bench→GAIA→GDPval），闭环这条主线由此收束。

说明：本专题聚焦 2023–2026 的 Agent 发展，模型版本、榜单数据均标注来源与时间点，请以各厂商官方发布与论文为准。领域迭代极快，具体数字会过时，但”能力基石 → 模型 → harness → 应用/评测”这条内生逻辑是稳定的分析框架。

阅读建议：初学者按板块顺序读，能建立完整心智模型；从业者可直接跳到板块二（选型）或板块三（工程落地）。
