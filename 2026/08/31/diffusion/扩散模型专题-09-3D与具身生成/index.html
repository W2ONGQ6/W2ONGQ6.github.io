扩散模型专题-09：3D 与具身生成 —— 多视角、资产与策略

引言：从“看起来对”到“从任何角度都对、还能行动”

2D 图像先验知道大量物体外观，却不天然保证多视角一致。3D 生成要处理几何、材质、光照和相机；具身任务还要求生成的动作序列满足接触和动力学约束。扩散在这两类问题中常扮演强先验或多峰策略分布的建模器。

一、DreamFusion 与 Score Distillation Sampling

DreamFusion 不直接训练 3D 数据集，而是优化一个 NeRF。每轮从随机相机渲染图像，送入冻结的文生图扩散模型；模型给出的去噪方向经由渲染器反传到 3D 表示。这个过程称为 SDS（Score Distillation Sampling）。

优势是借用海量 2D 知识；局限是“Janus 问题”——不同视角可能都像正面，且几何会被 2D 先验的投机纹理欺骗。后续多视角扩散、显式 3D 表示与重建约束都在修补这一点。

二、单图到多视角

Zero-1-to-3 用相机相对位姿作为条件，使模型从单张物体图生成新视角；这类数据可进一步用于 NeRF/mesh 重建。它把“生成一个合理图片”转成“为 3D 重建提供相机一致的观察”，是 2D 扩散服务 3D 管线的典型模式。

三、Diffusion Policy：把动作当作待去噪序列

机器人操作常有多种同样正确的轨迹，单峰回归会平均成一条不可执行的动作。Diffusion Policy 在动作块上加噪并去噪，条件为视觉观测和机器人状态；推理时以 receding horizon 执行前几步后重新规划。它尤其适合接触丰富、轨迹多模态的操作任务。

DreamFusion: Text-to-3D using 2D Diffusion 🏆

  • arXiv: 2209.14988，ICLR 2023
  • 核心创新: 用 SDS 将冻结 2D 扩散模型的 score 蒸馏到 NeRF。

Zero-1-to-3: Zero-shot One Image to 3D Object

  • arXiv: 2303.11328，ICCV 2023
  • 核心创新: 以相对相机位姿条件生成新视图。

Diffusion Policy: Visuomotor Policy Learning via Action Diffusion 📌

  • arXiv: 2303.04137，RSS 2023
  • 核心创新: 以条件去噪表示多峰机器人动作分布。

小结

扩散并不自动赋予 3D 或物理常识；它提供的是一个强大的生成先验。要获得可靠资产和行为，还需要相机几何、可微渲染、传感器反馈与闭环执行共同约束。
