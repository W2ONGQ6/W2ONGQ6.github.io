具身智能专题-08：RT-2 —— 从视觉语言模型到视觉语言动作模型

引言：让视觉语言知识真正落到动作

PaLM-E 说明了语言模型可以接收机器人观测，但一个关键问题仍然存在：模型的知识如何真正转化为机器人动作？

RT-2 的核心路线是把机器人动作表示成离散 token，让视觉语言模型直接做“下一个 token 预测”。这样，图像、语言和动作进入了同一个自回归建模框架。

这不是让语言模型凭空学会物理，而是让已有的视觉语言表示成为动作策略的先验。

四、动作 token 的优势与代价

优势

  • 可以直接复用自回归 Transformer；
  • 动作和语言共享序列建模机制；
  • 离散 token 方便使用交叉熵训练；
  • 语义推理和动作生成在同一模型中完成。

代价

  • 连续动作的量化会带来精度损失；
  • 每个控制周期生成多个 token，推理延迟增加；
  • 单次动作预测不一定能表达多峰连续轨迹；
  • 低层控制仍需要反馈和安全约束。

因此动作 token 更适合中低频策略层，而不是直接替代高频控制器。

五、从“看懂”到“会做”的迁移

VLM 的知识迁移到动作，至少需要三个条件：

  1. 视觉 grounding：视觉 token 必须保留与物体和空间关系相关的信息；
  2. 动作 grounding：动作 token 必须和真实执行结果对应；
  3. 闭环反馈：模型需要根据动作后的新观测修正计划。

小结

RT-2 的核心转折，是把动作变成语言模型可以预测的 token。它让 VLM 不只回答“看到了什么”，而开始回答“下一步怎么做”。但真正的通用机器人策略，还需要跨机器人数据、连续动作生成和更强的现实闭环，这正是后续工作的方向。
