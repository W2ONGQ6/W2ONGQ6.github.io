技巧：四两拨千斤

这类题没有通用框架，靠的是一两个关键观察或数学性质：异或的自反性让重复项自我抵消、摩尔投票用”票数对冲”把多数元素浮出水面、Floyd 判环把数组下标关系看成链表结构从而复用快慢指针。理解这些”巧劲”背后的数学，比背模板更有价值。

1. 只出现一次的数字

难度：Easy | 标签：位运算 | 🔗 LeetCode 第 136 题

题目描述：给定一个非空整数数组 nums，其中除某个元素只出现一次外，其余每个元素均出现两次。找出那个只出现一次的元素。要求不使用额外空间，线性时间复杂度。

示例：nums = [4, 1, 2, 1, 2] → 4

思路解析：异或运算有两个关键性质：a ^ a = 0（自反）和 a ^ 0 = a（保留）。将数组所有元素依次异或，出现两次的数字两两抵消为 0，唯一只出现一次的数字最终与 0 异或，结果就是它自身。整个过程无需额外空间，只需一次线性扫描。

复杂度：时间 O(n)，空间 O(1)。

2. 多数元素

难度：Easy | 标签：摩尔投票 | 🔗 LeetCode 第 169 题

题目描述：给定一个大小为 n 的数组 nums，返回其中的多数元素，即出现次数大于 n/2 的元素。可以假设数组非空且多数元素一定存在。

示例：nums = [2, 2, 1, 1, 1, 2, 2] → 2

思路解析：Boyer-Moore 摩尔投票算法的核心是”票数对冲”：维护一个候选值 candidate 和计数 count，遍历数组时若当前元素等于候选值则 count += 1，否则 count -= 1；当 count 归零时更新候选值为当前元素并重置计数为 1。由于多数元素出现次数超过 n/2，无论它被哪些不同元素对冲，最终剩余的候选一定是多数元素——它的票数在任何对冲中都不会被完全抵消。

复杂度：时间 O(n)，空间 O(1)。

3. 颜色分类

难度：Medium | 标签：双指针、荷兰国旗 | 🔗 LeetCode 第 75 题

题目描述：给定一个包含红色（0）、白色（1）和蓝色（2）的数组 nums，要求在不使用库函数的情况下原地排序，使相同颜色相邻，顺序按红、白、蓝排列。

示例：nums = [2, 0, 2, 1, 1, 0] → [0, 0, 1, 1, 2, 2]

思路解析：荷兰国旗问题（Dijkstra 提出）用三个指针将数组划分为三个区域：low 左边全是 0，high 右边全是 2，mid 是当前探索指针。遍历时：若 nums[mid] == 0，与 low 处交换并同时右移 low 和 mid（交换来的元素已处理过，可以直接推进）；若 nums[mid] == 2，与 high 处交换并左移 high（交换来的元素未知，mid 不动等下一轮处理）；若 nums[mid] == 1，直接右移 mid。整个过程仅一次遍历，原地完成三色分类。

复杂度：时间 O(n)，空间 O(1)。

4. 下一个排列

难度：Medium | 标签：双指针、贪心 | 🔗 LeetCode 第 31 题

题目描述：给定一个整数数组 nums，找出其下一个排列，即字典序上比当前排列大的最小排列。若当前排列已是最大，则重排为最小排列（升序）。要求原地修改，只使用常数额外空间。

示例：nums = [1, 2, 3] → [1, 3, 2]

思路解析：下一个排列意味着”在字典序上比当前排列大的最小排列”。找规律分三步：① 从右往左找第一个”下降点” i，即满足 nums[i] < nums[i+1] 的最右位置——这个位置右侧是非递增序列；② 从右往左找第一个比 nums[i] 大的元素 j，交换 nums[i] 和 nums[j]，使得该位置的数字尽量小地变大；③ 将 i+1 到末尾的部分反转（由非递增变为非递减），得到该前缀下的最小后缀。若第一步找不到下降点，说明整个排列是最大排列，直接全部反转回到最小排列。

复杂度：时间 O(n)，空间 O(1)。

5. 寻找重复数

难度：Medium | 标签：快慢指针、Floyd 判环 | 🔗 LeetCode 第 287 题

题目描述：给定一个包含 n+1 个整数的数组 nums，其中每个整数在 [1, n] 范围内，恰好存在一个重复的整数。在不修改数组且只使用常数额外空间的条件下，找出这个重复的数。

示例：nums = [1, 3, 4, 2, 2] → 2

思路解析：题目保证数组包含 n+1 个整数且每个整数在 [1, n] 范围内，因此可以将数组下标关系看成链表：把 i 看作节点，nums[i] 看作下一个节点的编号，从下标 0 出发构成一条”链”。由于存在重复数字，必然有两个不同下标指向同一个位置，形成环——这正是 Floyd 判环（龟兔赛跑）的适用场景。

算法分两阶段：① 找交点：慢指针每次走一步，快指针每次走两步，它们必然在环内某处相遇；② 找入环点（即重复数字）：将慢指针重置到起点 0，快指针留在相遇点，两者都以每次一步前进，再次相遇时所在的节点编号即为重复数字。原理在于，从起点到入环点的距离，与从第一次相遇点到入环点的距离相等（Floyd 定理的标准推论）。

复杂度：时间 O(n)，空间 O(1)。
