写在前面：为什么按”方法”而不是按”题号”整理

LeetCode Hot 100 是官方按”高频、经典、覆盖面广”三个标准筛出的一百道题，几乎是算法面试的最小必刷集。但很多人刷题的方式是”从 1 刷到 100”，刷完却发现遇到新题依然没思路——因为题号顺序打散了方法之间的内在联系。

本专栏换一个组织方式：按解题方法（算法范式）分类。同一类方法的题目放在一起，你会清晰地看到——

  • 一个套路能解决一整类问题：比如”滑动窗口”这一个框架，能同时拿下最长无重复子串、最小覆盖子串、找所有字母异位词；
  • 方法之间如何递进：双指针是滑动窗口的基础，回溯是 DFS 的一种，多维 DP 是一维 DP 的自然扩展；
  • 拿到新题如何归类：识别”这道题属于哪一类方法”，是从”会做这道题”到”会做这类题”的关键一跃。

每道题都包含：题目难度与链接 → 思路解析（为什么用这个方法、关键观察是什么）→ 复杂度分析 → Python 实现（含注释）。代码力求简洁可读、可直接运行。

十五类核心方法总览

# 方法分类 一句话核心思想 代表题目
01 哈希表 用空间换时间，把”查找”从 O(n) 降到 O(1) 两数之和、最长连续序列
02 双指针 两个指针从两端或同向移动，省去嵌套循环 三数之和、接雨水
03 滑动窗口 维护一个动态区间，避免重复扫描 最长无重复子串、最小覆盖子串
04 普通数组技巧 前缀积、差分、原地标记等数组套路 最大子数组和、合并区间
05 矩阵 二维遍历中的方向控制与原地操作 螺旋矩阵、旋转图像
06 链表 指针操作：反转、快慢指针、虚拟头节点 反转链表、环形链表、LRU
07 二叉树 递归的三种遍历序 + 分治思想 中序遍历、最近公共祖先
08 图论 网格 DFS/BFS、拓扑排序 岛屿数量、课程表
09 回溯 决策树上的 DFS + 撤销选择 全排列、子集、N 皇后
10 二分查找 有序空间里每次砍掉一半 搜索旋转数组、寻找中位数
11 栈与堆 单调栈处理”下一个更大”，堆维护 Top-K 每日温度、前 K 高频元素
12 贪心 每步取局部最优，证明能得全局最优 买卖股票、跳跃游戏
13 动态规划 把问题拆成重叠子问题，用表存结果 爬楼梯、零钱兑换、LIS
14 多维动态规划 状态是二维/多维，常见于网格与双字符串 最小路径和、编辑距离
15 技巧 位运算、摩尔投票等”巧劲”题 只出现一次的数字、多数元素

三条刷题路线建议

路线 A：零基础打地基（按本专栏顺序）

哈希 → 双指针 → 滑动窗口 → 数组 → 矩阵 → 链表 → 二叉树

这七类是”数据结构基本功”，几乎不涉及复杂算法思想，重在熟练指针与遍历操作，建立手感。

路线 B：进阶算法范式

回溯 → 二分 → 栈与堆 → 贪心 → 动态规划 → 多维 DP

这六类是”算法思想”的核心，尤其是回溯和动态规划，是面试区分度最高的部分。建议每类题目做完后，合上代码默写一遍框架。

路线 C：面试冲刺（高频必考）

如果时间紧张，优先掌握这些”出镜率最高”的题：两数之和、无重复最长子串、三数之和、合并区间、反转链表、环形链表、LRU 缓存、二叉树中序遍历、最近公共祖先、岛屿数量、全排列、爬楼梯、零钱兑换、最长递增子序列、编辑距离。

说明：本专栏题目分类参考 LeetCode 官方 Hot 100 的方法学分组。每题的思路解析力求讲清”为什么这样想”，而非只给答案。代码为 Python 3，可直接在 LeetCode 提交。

食用建议：先看思路、盖住代码自己写，写不出再看实现——被动看懂和主动写出，是两种完全不同的掌握程度。
