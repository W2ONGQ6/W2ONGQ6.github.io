LeetCode Hot100-13：动态规划

动态规划：拆解重叠子问题

动态规划的核心在于三要素：状态定义（用什么变量表达”当前情况”）、转移方程（当前状态如何由历史状态推导）、边界初始化（最小子问题的直接答案）。识别 DP 问题的信号通常是”最值/计数/是否可行”与”当前决策依赖之前结果”同时出现——如果暴力递归会反复求解同一子问题，就该用 DP 记忆化或自底向上填表。背包问题是 DP 的重要子类，分为 0/1 背包（每件物品只能选一次）和完全背包（每件物品可重复选），状态压缩到一维时遍历顺序（逆序 vs 正序）是区分两者的关键。掌握这 10 题，能覆盖线性 DP、区间 DP、背包 DP 的主要范式。

1. 爬楼梯

难度：Easy | 标签：动态规划 | 🔗 LeetCode 第 70 题

题目描述：共有 n 级台阶，每次可以爬 1 级或 2 级，求爬到顶部共有多少种不同的方法。

示例：n = 4 → 5（1+1+1+1、1+1+2、1+2+1、2+1+1、2+2）

思路解析：设 dp[i] 为爬到第 i 级台阶的方案数。每次可以走 1 步或 2 步，所以第 i 级只能从第 i-1 级走 1 步到达，或从第 i-2 级走 2 步到达，转移方程为 dp[i] = dp[i-1] + dp[i-2]。边界为 dp[1] = 1, dp[2] = 2，本质上就是斐波那契数列从第 2 项开始的变体。由于每步只依赖前两个值，可以用两个变量滚动代替数组，将空间压缩到 O(1)。

复杂度：时间 O(n)，空间 O(1)。

2. 杨辉三角

难度：Easy | 标签：动态规划、数组 | 🔗 LeetCode 第 118 题

题目描述：给定非负整数 numRows，生成杨辉三角的前 numRows 行。每行首尾为 1，中间第 j 个元素等于上一行第 j-1 与第 j 个元素之和。

示例：numRows = 4 → [[1],[1,1],[1,2,1],[1,3,3,1]]

思路解析：杨辉三角每一行的首尾为 1，中间第 j 个元素等于上一行第 j-1 与第 j 个元素之和，即 dp[i][j] = dp[i-1][j-1] + dp[i-1][j]。逐行生成时，先用 1 填充当前行，再从内侧（索引 1 到 i-1）依据上一行更新，无需额外空间技巧，直接累积结果即可。

复杂度：时间 O(n²)，空间 O(n²)（结果本身）。

3. 打家劫舍

难度：Medium | 标签：动态规划 | 🔗 LeetCode 第 198 题

题目描述：给定一排房屋，每间房存有金额 nums[i]，相邻房间有报警器不能同时盗窃，求在不触发报警的前提下能盗取的最高金额。

示例：nums = [2,7,9,3,1] → 12（抢第 0、2、4 间：2+9+1=12）

思路解析：设 dp[i] 为抢劫前 i 间房子能获得的最大金额。对第 i 间房只有两个选择：不抢，收益与前 i-1 间相同；抢，则不能抢第 i-1 间，收益为 dp[i-2] + nums[i]。转移方程为 dp[i] = max(dp[i-1], dp[i-2] + nums[i])。同样只依赖前两个状态，用滚动变量优化空间。这道题展示了 DP 中”选或不选”决策的标准模板。

复杂度：时间 O(n)，空间 O(1)。

4. 完全平方数

难度：Medium | 标签：动态规划、BFS | 🔗 LeetCode 第 279 题

题目描述：给定正整数 n，返回和为 n 的完全平方数（如 1、4、9、16…）的最少数量。

示例：n = 12 → 3（4+4+4）

思路解析：设 dp[i] 为组成整数 i 所需的最少完全平方数个数。对每个 i，枚举所有满足 j*j <= i 的完全平方数 j²，转移方程为 dp[i] = min(dp[i - j*j] + 1)。边界 dp[0] = 0，其余初始化为无穷大。这是完全背包的变体——完全平方数可重复使用，对应完全背包正序遍历的思路。

复杂度：时间 O(n√n)，空间 O(n)。

5. 零钱兑换

难度：Medium | 标签：动态规划、完全背包 | 🔗 LeetCode 第 322 题

题目描述：给定面值数组 coins 和目标金额 amount，每种硬币可无限使用，返回凑成 amount 所需的最少硬币数，若无法凑成则返回 -1。

示例：coins = [1,5,11], amount = 15 → 3（5+5+5）

思路解析：经典完全背包求最少件数。设 dp[i] 为凑出金额 i 的最少硬币数，边界 dp[0] = 0，其余初始化为 amount + 1（表示不可达）。外层遍历金额 i 从 1 到 amount，内层枚举每枚硬币面值 c：若 i >= c，则 dp[i] = min(dp[i], dp[i - c] + 1)。完全背包的关键在于正序遍历金额，这样 dp[i - c] 已经允许多次使用同一枚硬币（对比 0/1 背包需要逆序）。最终若 dp[amount] > amount 则返回 -1。

复杂度：时间 O(amount × n)，空间 O(amount)。

6. 单词拆分

难度：Medium | 标签：动态规划、哈希表 | 🔗 LeetCode 第 139 题

题目描述：给定字符串 s 和单词字典 wordDict，判断 s 是否可以由字典中的单词（可重复使用）拼接而成。

示例：s = "leetcode", wordDict = ["leet","code"] → true

思路解析：设 dp[i] 表示字符串前 i 个字符能否被字典中的单词拼出。转移时枚举所有切割点 j（0 ≤ j < i）：若 dp[j] 为真，且 s[j:i] 在字典中，则 dp[i] = True。边界 dp[0] = True（空字符串视为合法）。将字典转为集合可将查找优化到 O(1)，整体复杂度 O(n²)。这道题展示了 DP 中”枚举分割点”的范式，与矩阵链乘法等区间 DP 思路一脉相承。

复杂度：时间 O(n²)，空间 O(n)。

7. 最长递增子序列

难度：Medium | 标签：动态规划、二分查找 | 🔗 LeetCode 第 300 题

题目描述：给定整数数组 nums，返回其最长严格递增子序列的长度（子序列不要求连续）。

示例：nums = [10,9,2,5,3,7,101,18] → 4（[2,3,7,101]）

思路解析：O(n²) DP：设 dp[i] 为以 nums[i] 结尾的最长递增子序列长度，对每个 i 枚举 j < i，若 nums[j] < nums[i]，则 dp[i] = max(dp[i], dp[j] + 1)，最终答案为 max(dp)。O(n log n) 贪心 + 二分：维护一个 tails 数组，tails[k] 表示长度为 k+1 的递增子序列中末尾元素的最小值。遍历每个数 x：若 x > tails[-1] 则追加；否则用二分找到第一个 >= x 的位置并替换。tails 的长度即为答案。替换操作保持 tails 单调性，不改变已有长度的最优末尾值，从而让后续数字有更大的拼接机会。

复杂度：O(n²) / O(n log n)，空间 O(n)。

8. 乘积最大子数组

难度：Medium | 标签：动态规划、数组 | 🔗 LeetCode 第 152 题

题目描述：给定整数数组 nums，找出乘积最大的非空连续子数组，返回该乘积。

示例：nums = [2,3,-2,4] → 6（子数组 [2,3]）

思路解析：与最大子数组和不同，乘积存在负负得正的情况——两个负数相乘可能产生最大值。因此需要同时维护当前位置结尾的最大乘积 cur_max 和最小乘积 cur_min。对每个新元素 num，三者取最大（最小）：num 本身（重新开始）、cur_max * num、cur_min * num。若 num 为负，最大与最小会互换，利用 min/max 同时更新可自然处理。全局最大值在每步更新。

复杂度：时间 O(n)，空间 O(1)。

9. 分割等和子集

难度：Medium | 标签：动态规划、0/1 背包 | 🔗 LeetCode 第 416 题

题目描述：给定只包含正整数的非空数组 nums，判断能否将其分割成两个元素和相等的子集。

示例：nums = [1,5,11,5] → true（[1,5,5] 和 [11]，和均为 11）

思路解析：问题等价于：能否从数组中选出若干数，使其和恰好为 total // 2（若总和为奇数则直接返回 False）。这是标准 0/1 背包判可行性问题：背包容量 target = total // 2，每个数字是一件物品，只能选一次，问能否恰好装满。设 dp[j] 为布尔值，表示容量 j 是否可达。转移时逆序遍历容量（防止同一件物品被重复选取）：对每个数 num，从 target 到 num 逆序更新 dp[j] = dp[j] or dp[j - num]。边界 dp[0] = True。逆序是 0/1 背包与完全背包的核心区别。

复杂度：时间 O(n × target)，空间 O(target)。

10. 最长有效括号

难度：Hard | 标签：动态规划、栈 | 🔗 LeetCode 第 32 题

题目描述：给定只含 '(' 和 ')' 的字符串 s，找出其中最长有效括号子串的长度。

示例：s = ")()())" → 4（子串 "()()"）

思路解析：设 dp[i] 为以 s[i] 结尾的最长有效括号子串长度（s[i] 为 '(' 时 dp[i] = 0）。当 s[i] == ')' 时分两种情况：

  1. s[i-1] == '('（直接配对）：dp[i] = dp[i-2] + 2，即在 i-2 结尾的有效串后追加一对括号。
  2. s[i-1] == ')'（内层是有效串）：设 prev = i - dp[i-1] - 1，即跳过 i-1 结尾的有效串，看其前一个字符。若 s[prev] == '('，则与它配对：dp[i] = dp[i-1] + 2 + dp[prev-1]（dp[prev-1] 是 prev 左侧紧邻的有效串长度）。

这两种情况覆盖了所有有效括号的拼接方式，最终返回 max(dp)。

复杂度：时间 O(n)，空间 O(n)。
