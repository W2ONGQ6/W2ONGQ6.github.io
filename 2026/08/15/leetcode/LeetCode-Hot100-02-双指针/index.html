LeetCode Hot100-02：双指针

双指针：省去一层嵌套循环

双指针是将 O(n²) 暴力枚举降到 O(n) 的核心手法。主要分两类：对撞指针——左右两端向中间收拢，常用于有序数组的区间搜索；快慢指针——同向移动但速度或步伐不同，常用于原地修改、链表环检测。熟练运用的关键在于找到每一步移动能”安全排除”若干元素的不变量。

1. 移动零

难度：Easy | 标签：双指针 | 🔗 LeetCode 第 283 题

题目描述：给定数组 nums，将所有 0 移动到数组末尾，同时保持非零元素的相对顺序，要求原地操作，不能拷贝数组。

示例：nums = [0, 1, 0, 3, 12] → [1, 3, 12, 0, 0]

思路解析：
用快慢指针原地处理数组：slow 指向下一个非零值应放置的位置，fast 向右扫描整个数组。每当 fast 遇到非零元素，就把它写到 slow 位置并将 slow 右移；fast 遇到零则直接跳过。扫描结束后 slow 之后的所有位置都是”被移走的零”，统一填 0 即可。不变量：[0, slow) 内全部是已经正确排列的非零元素，顺序与原数组保持一致。

复杂度：时间 O(n)，空间 O(1)。

2. 盛最多水的容器

难度：Medium | 标签：双指针 | 🔗 LeetCode 第 11 题

题目描述：给定长度为 n 的整数数组 height，第 i 条垂线高度为 height[i]，从中选两条垂线与 x 轴围成容器，求容器能盛的最大水量。

示例：height = [1, 8, 6, 2, 5, 4, 8, 3, 7] → 49（选下标 1 和 8 的两条线，min(8,7) * (8-1) = 49）

思路解析：
容积由”两板中较短的那块”与”两板间距”共同决定：area = min(h[l], h[r]) * (r - l)。初始令 l=0, r=n-1，每次记录当前容积后，移动较短的那一侧指针向内收缩。原因在于：若移动较高的一侧，两板间距减小，而决定容积上限的短板高度不变甚至更小，容积只会更小；移动较短的一侧则有机会遇到更高的板，容积才可能增大。因此贪心地淘汰较短板是最优策略，指针相遇时已枚举了所有”潜在最优”区间。

复杂度：时间 O(n)，空间 O(1)。

3. 三数之和

难度：Medium | 标签：双指针、排序 | 🔗 LeetCode 第 15 题

题目描述：给定整数数组 nums，找出所有满足 nums[i] + nums[j] + nums[k] == 0 且 i、j、k 互不相同的三元组，结果不能包含重复的三元组。

示例：nums = [-1, 0, 1, 2, -1, -4] → [[-1, -1, 2], [-1, 0, 1]]

思路解析：
暴力三重循环是 O(n³)，加排序后可用双指针降到 O(n²)。先对数组排序，然后枚举第一个数 nums[i]（固定住），在 i+1 到末尾的区间用对撞指针寻找 nums[l] + nums[r] == -nums[i] 的配对。三个移动原则：① 若三数之和大于 0，r 左移（减小总和）；② 若小于 0，l 右移（增大总和）；③ 等于 0 则记录，然后同时跳过重复元素——l 右移跳过与当前 nums[l] 相同的值，r 左移跳过与当前 nums[r] 相同的值，再继续双指针。外层枚举 i 时同样跳过重复：若 nums[i] == nums[i-1] 则直接 continue，避免产生重复三元组。关键不变量：排序保证左小右大，每次移动都能安全排除当前区间内不可能成立的组合。

复杂度：时间 O(n²)，空间 O(1)（不计输出）。

4. 接雨水

难度：Hard | 标签：双指针 | 🔗 LeetCode 第 42 题

题目描述：给定 n 个非负整数组成的数组 height，每个元素代表宽度为 1 的柱子高度，计算按此排列的柱子能接多少雨水。

示例：height = [0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1] → 6

思路解析：
对于位置 i，它能接的雨水量等于 min(左侧最大高度, 右侧最大高度) - height[i]。朴素做法是预处理两个前/后缀最大值数组，但用双指针可以在一次遍历内完成，省去额外数组。维护 l_max（l 左侧已见过的最大高度）和 r_max（r 右侧已见过的最大高度）。移动规则是谁的最大值更小就移动谁：若 l_max <= r_max，说明位置 l 的储水量完全由 l_max 决定（右边一定有比 l_max 更高的墙），因此安全地累加 l_max - height[l] 并将 l 右移；反之处理 r 端。这里的不变量是：被移动的那一侧，其对侧边界高度一定 >= 本侧已见最大值，所以 min(l_max, r_max) 就等于本侧的 l_max（或 r_max），计算结果与前/后缀数组方法完全等价。

复杂度：时间 O(n)，空间 O(1)。
