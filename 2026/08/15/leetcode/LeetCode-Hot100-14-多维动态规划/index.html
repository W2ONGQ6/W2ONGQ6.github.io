LeetCode Hot100-14：多维动态规划

多维动态规划：二维状态的转移

多维动态规划将状态从一维扩展到二维，常见于网格路径和两个字符串的匹配场景。dp[i][j] 的含义定义是解题的核心——它可以代表”到达位置 (i,j) 的路径数”，也可以代表”前 i 个字符与前 j 个字符之间的最优解”。处理网格路径时，转移方向通常来自上方或左方；处理双字符串问题时，转移的关键在于判断”当前两个字符是否匹配”，相等时可以继承对角线状态，不等时则在插入、删除、替换三种操作中取最优。

1. 不同路径

难度：Medium | 标签：动态规划 | 🔗 LeetCode 第 62 题

题目描述：给定一个 m x n 的网格，机器人从左上角出发，每次只能向右或向下移动一步，求到达右下角共有多少条不同路径。

示例：m = 3, n = 7 → 28

思路解析：定义 dp[i][j] 为从左上角 (0,0) 到格子 (i,j) 的不同路径数。由于机器人只能向右或向下移动，(i,j) 只能从上方 (i-1,j) 或左方 (i,j-1) 到达，因此转移方程为 dp[i][j] = dp[i-1][j] + dp[i][j-1]。边界条件为第一行和第一列全部初始化为 1——沿边走只有唯一路径。按行列顺序填表即可得到答案 dp[m-1][n-1]。

复杂度：时间 O(mn)，空间 O(mn)（可压缩到 O(n)）。

2. 最小路径和

难度：Medium | 标签：动态规划 | 🔗 LeetCode 第 64 题

题目描述：给定一个包含非负整数的 m x n 网格 grid，从左上角出发，每次只能向右或向下移动一步，求到达右下角时经过的路径上数字之和最小值。

示例：grid = [[1,3,1],[1,5,1],[4,2,1]] → 7（路径 1→3→1→1→1）

思路解析：定义 dp[i][j] 为从左上角到 (i,j) 的最小路径和。与不同路径同样只能从上或左到达，转移方程为 dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])。边界初始化时，第一行累加 grid[0][j]（只能一路向右），第一列累加 grid[i][0]（只能一路向下），其余位置按转移方程填充。最终答案在 dp[m-1][n-1]。

复杂度：时间 O(mn)，空间 O(mn)（可原地修改 grid 压缩到 O(1)）。

3. 最长回文子串

难度：Medium | 标签：动态规划、区间DP | 🔗 LeetCode 第 5 题

题目描述：给定字符串 s，返回其中最长的回文子串。回文串是正读和反读都相同的字符串。

示例：s = "babad" → "bab"（或 "aba"，两者均为正确答案）

思路解析：区间 DP 的经典范式——用 dp[i][j] 表示子串 s[i..j] 是否为回文串。转移逻辑是：若 s[i] == s[j]，则 s[i..j] 是否为回文取决于内部子串 s[i+1..j-1] 是否为回文，即 dp[i][j] = dp[i+1][j-1]；若 s[i] != s[j]，则 dp[i][j] = False。边界：长度为 1 的子串 dp[i][i] = True，长度为 2 的子串 dp[i][i+1] = (s[i] == s[i+1])。填表时必须按子串长度从小到大枚举，保证计算 dp[i][j] 时 dp[i+1][j-1] 已经确定。遍历过程中记录最长回文的起始位置和长度即可。

复杂度：时间 O(n²)，空间 O(n²)。

4. 最长公共子序列

难度：Medium | 标签：动态规划 | 🔗 LeetCode 第 1143 题

题目描述：给定两个字符串 text1 和 text2，返回这两个字符串的最长公共子序列的长度。子序列是指从原字符串中删去若干字符（不改变相对顺序）后得到的字符串。

示例：text1 = "abcde", text2 = "ace" → 3（最长公共子序列为 "ace"）

思路解析：定义 dp[i][j] 为 text1 的前 i 个字符与 text2 的前 j 个字符的最长公共子序列长度。转移方程分两种情况：若 text1[i-1] == text2[j-1]（两串的当前末尾字符相等），则这个字符一定可以加入 LCS，dp[i][j] = dp[i-1][j-1] + 1；否则当前末尾字符至少有一个不会出现在 LCS 中，从放弃其中一个的结果取较大值，dp[i][j] = max(dp[i-1][j], dp[i][j-1])。dp 数组大小为 (m+1) × (n+1)，第 0 行和第 0 列初始化为 0（空串与任何串的 LCS 为 0），填表顺序为从左到右、从上到下。

复杂度：时间 O(mn)，空间 O(mn)（可压缩到 O(min(m,n))）。

5. 编辑距离

难度：Medium | 标签：动态规划 | 🔗 LeetCode 第 72 题

题目描述：给定两个单词 word1 和 word2，返回将 word1 转换成 word2 所需的最少编辑操作次数，每次可执行插入、删除或替换一个字符中的任意一种操作。

示例：word1 = "horse", word2 = "ros" → 3（horse→rorse→rose→ros）

思路解析：定义 dp[i][j] 为将 word1 的前 i 个字符转换为 word2 的前 j 个字符所需的最少操作数。转移方程是三路选择的精髓：若 word1[i-1] == word2[j-1]，末尾字符已匹配，无需操作，dp[i][j] = dp[i-1][j-1]；否则有三种操作可供选择，取最小值加 1：

  • 替换：把 word1[i-1] 替换为 word2[j-1]，代价来自 dp[i-1][j-1]；
  • 删除：删掉 word1[i-1]，代价来自 dp[i-1][j]；
  • 插入：在 word1[i] 处插入 word2[j-1]，代价来自 dp[i][j-1]。

即 dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])。边界初始化：dp[i][0] = i（将前 i 个字符全部删除），dp[0][j] = j（插入 j 个字符）。

复杂度：时间 O(mn)，空间 O(mn)（可压缩到 O(min(m,n))）。
