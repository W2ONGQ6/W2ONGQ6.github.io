LeetCode Hot100-07：二叉树

二叉树：递归思维的试金石

前序、中序、后序遍历的本质区别，仅在于”处理当前节点”的时机——前序是进入时处理，后序是返回时处理，中序则夹在左右子树之间；层序遍历换用 BFS 队列，按层推进。大量二叉树题目的核心范式是自底向上的分治：先递归拿到左右子树的信息，再在当前节点汇聚、更新全局状态或向上返回，直径、最大路径和都遵循这一模式。掌握”递归函数的返回值是什么、全局状态在哪里更新”这两个问题，绝大多数二叉树题都能迎刃而解。

1. 二叉树的中序遍历

难度：Easy | 标签：二叉树 / DFS | 🔗 LeetCode 第 94 题

题目描述：给定一棵二叉树的根节点 root，返回其节点值的中序遍历结果（左子树 → 根节点 → 右子树）。

示例：输入 root = [1,null,2,3] → 输出 [1,3,2]

思路解析：中序遍历顺序为”左 → 根 → 右”，递归实现直接对应定义：先递归左子树，再收集当前节点值，再递归右子树。迭代实现用显式栈模拟系统调用栈——持续压入左链直到空，然后弹出节点并访问，再转向右子树，两种写法本质相同，只是栈的管理方式不同。

复杂度：时间 O(n)，空间 O(h)（h 为树高，最坏 O(n)）。

2. 二叉树的最大深度

难度：Easy | 标签：二叉树 / DFS / BFS | 🔗 LeetCode 第 104 题

题目描述：给定一棵二叉树的根节点 root，返回其最大深度，即从根节点到最远叶节点的最长路径上的节点数。

示例：输入 root = [3,9,20,null,null,15,7] → 输出 3

思路解析：最大深度等于左右子树最大深度的较大值加 1，这是典型的后序分治：先拿到左右子树的深度，再在当前节点合并。空节点深度为 0，构成递归边界。也可用 BFS 逐层遍历，每遍历完一层深度加 1，BFS 实现直观且避免系统栈溢出。

复杂度：时间 O(n)，空间 O(h)。

3. 翻转二叉树

难度：Easy | 标签：二叉树 / DFS | 🔗 LeetCode 第 226 题

题目描述：给定一棵二叉树的根节点 root，将其翻转（镜像），返回翻转后的根节点。

示例：输入 root = [4,2,7,1,3,6,9] → 输出 [4,7,2,9,6,3,1]

思路解析：翻转整棵树 = 交换当前节点的左右子节点，然后递归翻转左右子树。这是前序或后序分治均可的题目——后序更符合”先翻好子树再交换”的直觉，前序则先交换再递归。两者等价，因为最终每个节点都会被交换一次。

复杂度：时间 O(n)，空间 O(h)。

4. 对称二叉树

难度：Easy | 标签：二叉树 / DFS | 🔗 LeetCode 第 101 题

题目描述：给定一棵二叉树的根节点 root，判断该树是否关于中轴轴对称（镜像对称）。

示例：输入 root = [1,2,2,3,4,4,3] → 输出 true

思路解析：对称不是单棵子树内部的问题，而是”镜像对”之间的关系：左子树的左孩子对应右子树的右孩子，左子树的右孩子对应右子树的左孩子。因此辅助函数接收两个节点同步递归，检查它们的值是否相等，以及各自的外侧孩子和内侧孩子是否分别对称。

复杂度：时间 O(n)，空间 O(h)。

5. 二叉树的直径

难度：Easy | 标签：二叉树 / DFS | 🔗 LeetCode 第 543 题

题目描述：给定一棵二叉树的根节点 root，返回树的直径，即任意两节点间路径长度的最大值（路径长度为经过的边数，不必经过根节点）。

示例：输入 root = [1,2,3,4,5] → 输出 3（路径为 4→2→1→3 或 5→2→1→3）

思路解析：直径 = 某个节点左子树深度 + 右子树深度，但最长路径不一定经过根节点，所以需要在后序遍历的每个节点处更新全局最大值。递归函数的返回值是”以当前节点为端点向下延伸的最长链长度”（用于父节点计算），而副作用是更新全局答案。这是”返回值服务父节点、全局变量记录答案”模式的经典案例。

复杂度：时间 O(n)，空间 O(h)。

6. 二叉树的层序遍历

难度：Medium | 标签：二叉树 / BFS | 🔗 LeetCode 第 102 题

题目描述：给定一棵二叉树的根节点 root，返回其节点值的逐层分组遍历结果，每层的节点值放在一个子列表中。

示例：输入 root = [3,9,20,null,null,15,7] → 输出 [[3],[9,20],[15,7]]

思路解析：层序遍历标准模板：使用 collections.deque 作为队列，每轮循环处理当前层所有节点（用 for _ in range(len(queue)) 固定本层节点数），将每个节点的值收集到当前层列表，并将非空孩子入队进入下一层。这个”固定层大小后批量处理”的技巧是层序遍历变种题的万用模板。

复杂度：时间 O(n)，空间 O(n)（队列最宽一层）。

7. 将有序数组转换为二叉搜索树

难度：Easy | 标签：二叉树 / 分治 / BST | 🔗 LeetCode 第 108 题

题目描述：给定一个升序排列的整数数组 nums，将其转换为一棵高度平衡的二叉搜索树（每个节点的左右子树高度差不超过 1）。

示例：输入 nums = [-10,-3,0,5,9] → 输出 [0,-3,9,-10,null,5]（或等价的平衡 BST）

思路解析：有序数组的中间元素天然是高度平衡 BST 的根节点——左半部分递归构建左子树，右半部分递归构建右子树。每次取 mid = (left + right) // 2 保证节点数量左右均衡，深度差不超过 1。这是典型的分治构建：子问题结构与原问题相同，边界是子数组为空时返回 None。

复杂度：时间 O(n)，空间 O(log n)（递归栈）。

8. 验证二叉搜索树

难度：Medium | 标签：二叉树 / BST / 中序遍历 | 🔗 LeetCode 第 98 题

题目描述：给定一棵二叉树的根节点 root，判断其是否为有效的二叉搜索树（每个节点的左子树所有节点值严格小于该节点，右子树所有节点值严格大于该节点）。

示例：输入 root = [5,1,4,null,null,3,6] → 输出 false（根节点 5 的右子节点 4 不满足大于 5）

思路解析：有两种等价思路，理解透任意一种即可。上下界法：递归时为每个节点维护合法的值范围 (lo, hi)，根节点范围为 (-∞, +∞)；向左递归时上界收紧为当前节点值，向右递归时下界收紧为当前节点值——这正是 BST 性质的精确编码，任何节点的值必须严格在其所有祖先约束的区间内。中序遍历法：BST 的中序遍历序列严格递增，遍历时只需检查当前节点值是否大于上一个访问节点的值即可，用一个变量记录前驱值。两种方法时间复杂度相同，上下界法更易扩展到其他 BST 问题。

复杂度：时间 O(n)，空间 O(h)。

9. 二叉搜索树中第 K 小的元素

难度：Medium | 标签：二叉树 / BST / 中序遍历 | 🔗 LeetCode 第 230 题

题目描述：给定一棵二叉搜索树的根节点 root 和整数 k，返回该 BST 中第 k 小的节点值（k 从 1 开始计数）。

示例：输入 root = [3,1,4,null,2]，k = 1 → 输出 1

思路解析：BST 的中序遍历（左→根→右）产生严格递增序列，因此第 K 小的元素就是中序遍历的第 K 个节点。用计数器在中序遍历过程中倒数，当计数降到 0 时记录答案并提前终止，避免遍历整棵树。提前终止通过返回值或异常实现，这里用实例变量记录结果。

复杂度：时间 O(h + k)（最优情况），空间 O(h)。

10. 二叉树的右视图

难度：Medium | 标签：二叉树 / BFS / DFS | 🔗 LeetCode 第 199 题

题目描述：给定一棵二叉树的根节点 root，想象站在树的右侧向左看，返回从上到下每层最右侧节点的值。

示例：输入 root = [1,2,3,null,5,null,4] → 输出 [1,3,4]

思路解析：右视图即每一层最右侧的节点值。BFS 层序遍历时，每层的最后一个节点就是右视图节点，直接取每层列表末尾元素即可。DFS 也可实现：按”根→右→左”的顺序前序遍历，每层第一次访问到的节点就是最右侧节点——用 depth == len(result) 判断是否为该层首次访问。

复杂度：时间 O(n)，空间 O(n)（BFS）或 O(h)（DFS）。

11. 二叉树展开为链表

难度：Medium | 标签：二叉树 / 前序遍历 | 🔗 LeetCode 第 114 题

题目描述：给定一棵二叉树的根节点 root，将其原地展开为单链表，链表节点顺序与前序遍历顺序相同（所有 left 指针置为 null，right 指针指向后继节点）。

示例：输入 root = [1,2,5,3,4,null,6] → 原地修改为 [1,null,2,null,3,null,4,null,5,null,6]

思路解析：展开后的顺序是前序遍历顺序（根→左→右）。后序分治思路：先递归展开左子树和右子树，再将左子树接到根的右侧，原右子树接到左子树链尾。具体操作：保存原右子树，将左子树移到右侧（左置空），然后沿新右侧链走到末尾，把原右子树接上。注意必须先递归再调整指针，体现”自底向上”原则。

复杂度：时间 O(n)，空间 O(h)。

12. 从前序与中序遍历序列构造二叉树

难度：Medium | 标签：二叉树 / 分治 / 哈希表 | 🔗 LeetCode 第 105 题

题目描述：给定一棵二叉树的前序遍历数组 preorder 和中序遍历数组 inorder（节点值各不相同），重建并返回原始二叉树。

示例：输入 preorder = [3,9,20,15,7]，inorder = [9,3,15,20,7] → 输出 [3,9,20,null,null,15,7]

思路解析：前序遍历的第一个元素一定是当前子树的根节点。在中序遍历中找到该根节点的位置 idx，则中序序列中 idx 左侧是左子树的所有节点（共 left_size = idx - in_left 个），右侧是右子树的所有节点。据此可以精确切分前序序列：左子树前序区间为 [pre_left+1, pre_left+left_size]，右子树前序区间为 [pre_left+left_size+1, pre_right]，递归构建即可。用哈希表预存中序下标，将每次查找从 O(n) 降为 O(1)，整体时间复杂度降至 O(n)。

复杂度：时间 O(n)，空间 O(n)（哈希表 + 递归栈）。

13. 路径总和 III

难度：Medium | 标签：二叉树 / 前缀和 / 哈希表 | 🔗 LeetCode 第 437 题

题目描述：给定一棵二叉树的根节点 root 和整数 targetSum，统计树中节点值之和等于 targetSum 的路径数目，路径须向下延伸但不必从根节点开始也不必在叶节点结束。

示例：输入 root = [10,5,-3,3,2,null,11,3,-2,null,1]，targetSum = 8 → 输出 3

思路解析：路径必须向下（不能拐弯），可以不从根节点开始也不必到叶节点结束。暴力 O(n²) 对每个节点做一次 DFS，更优的方案是前缀和 + 哈希表，时间 O(n)。维护从根到当前节点的路径前缀和 cur_sum，若存在某个祖先节点使得 cur_sum - ancestor_sum == target，则 [ancestor_child, cur_node] 这段路径和为 target。用哈希表记录路径上各前缀和出现次数，在 DFS 进入时查询并更新，回溯时撤销（保证哈希表只包含当前路径上的前缀和）。

复杂度：时间 O(n)，空间 O(n)。

14. 二叉树的最近公共祖先

难度：Medium | 标签：二叉树 / DFS | 🔗 LeetCode 第 236 题

题目描述：给定一棵二叉树的根节点 root 以及树中两个节点 p 和 q，找到它们的最近公共祖先（LCA），即深度最大的同时是 p 和 q 祖先的节点（节点可以是自身的祖先）。

示例：输入 root = [3,5,1,6,2,0,8,null,null,7,4]，p = 5，q = 1 → 输出 3

思路解析：LCA 的经典后序递归。递归函数的语义是”在以 node 为根的子树中查找 p 和 q，返回找到的节点（或 LCA）”。三种情况决定返回值：(1) node 为空或等于 p/q，直接返回 node；(2) 左右子树各找到一个（左返回非空、右返回非空），说明 p 和 q 分属两侧，当前节点就是 LCA，返回 node；(3) 只有一侧找到，返回那侧的结果（另一侧返回 None）。这个设计的妙处在于，情况 (1) 中”找到 p 就返回 p”的语义在情况 (2) 的汇聚处得到了升华——两侧各自找到，意味着 LCA 就在当前节点。

复杂度：时间 O(n)，空间 O(h)。

15. 二叉树中的最大路径和

难度：Hard | 标签：二叉树 / DFS / 后序遍历 | 🔗 LeetCode 第 124 题

题目描述：给定一棵二叉树的根节点 root，返回任意路径中节点值之和的最大值，路径至少包含一个节点，可以不经过根节点（节点值可为负数）。

示例：输入 root = [-10,9,20,null,null,15,7] → 输出 42（路径 15→20→7）

思路解析：这是直径题目的带权版本，核心思路完全相同。定义递归函数 gain(node) 的语义是”以 node 为端点向下延伸的最大路径贡献值”——如果某侧子树贡献为负则不取（取 0，意味着不走那条路）。后序阶段在每个节点计算”经过该节点的最大路径 = 左贡献 + 当前值 + 右贡献”并更新全局最大值；返回给父节点的是”左右贡献取较大值 + 当前值”（因为路径不能分叉，只能选一侧继续向上）。节点值可为负，因此全局答案初始化为负无穷。

复杂度：时间 O(n)，空间 O(h)。
