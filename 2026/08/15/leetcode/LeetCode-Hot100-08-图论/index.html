LeetCode Hot100-08：图论

图论：遍历与拓扑

网格是最常见的隐式图——每个格子是节点，上下左右四个方向是边，DFS/BFS 通过”淹没”已访问格子来统计连通块数量。拓扑排序则把有向图的依赖关系转化为入度队列，逐层剥除零入度节点，若最终处理节点数不足则图中存在环。Trie（前缀树）是字符串专用的多叉树，每条从根到叶的路径对应一个单词，共享公共前缀节省存储并加速前缀匹配。

1. 岛屿数量

难度：Medium | 标签：DFS/BFS | 🔗 LeetCode 第 200 题

题目描述：给定一个由 '1'（陆地）和 '0'（水）组成的二维网格 grid，计算其中岛屿的数量。岛屿由上下左右相邻的陆地连接而成，网格四周均被水包围。

示例：输入 grid = [["1","1","0"],["0","1","0"],["0","0","1"]]，输出 2（左上角连通块为一座岛屿，右下角单格为另一座）。

思路解析：

遍历整个网格，每当遇到字符 '1'（陆地）时，将计数器加一，然后以该格为起点做 DFS，把所有与之四连通的陆地格子全部标记为 '0'（已访问）。DFS 结束后，这整片岛屿就被”淹没”，后续遍历不会重复计数。最终计数器的值即为岛屿数量。核心思想是：一次 DFS 恰好覆盖一个连通分量，岛屿数 = DFS 被触发的次数。

复杂度：时间 O(mn)，空间 O(mn)（递归栈最坏情况下整个网格都是陆地）。

2. 腐烂的橘子

难度：Medium | 标签：多源BFS | 🔗 LeetCode 第 994 题

题目描述：给定一个 m×n 网格 grid，每个格子值为 0（空）、1（新鲜橘子）或 2（腐烂橘子）。每分钟腐烂橘子会将四连通的新鲜橘子感染，返回直到没有新鲜橘子所需的最小分钟数，若永远无法腐烂所有橘子则返回 -1。

示例：输入 grid = [[2,1,1],[1,1,0],[0,1,1]]，输出 4。

思路解析：

本题的关键在于”同时扩散”——所有腐烂橘子在同一分钟内同步向四周蔓延，这正是多源 BFS 的场景。初始化时，把所有腐烂橘子（值为 2）全部加入队列，同时统计新鲜橘子总数 fresh。BFS 每一轮（一分钟）从队列中取出所有当前腐烂橘子，尝试感染四邻，每成功感染一个就将 fresh 减一并把新腐烂橘子入队，轮数加一。BFS 结束后若 fresh > 0，说明存在被孤立的新鲜橘子，返回 -1；否则返回总轮数（注意空队列也会走一轮，需减去最后那次空轮）。

复杂度：时间 O(mn)，空间 O(mn)。

3. 课程表

难度：Medium | 标签：拓扑排序/BFS判环 | 🔗 LeetCode 第 207 题

题目描述：你需要修完 numCourses 门课（编号 0 到 numCourses-1），prerequisites[i] = [a, b] 表示修课 a 前必须先修课 b。判断是否可以完成所有课程的学习。

示例：输入 numCourses = 2, prerequisites = [[1,0]]，输出 true（先修课 0，再修课 1 即可）。

思路解析：

课程依赖关系构成有向图：prerequisites[i] = [a, b] 表示必须先修 b 才能修 a，即有向边 b → a。能否修完所有课程等价于：有向图中是否存在环。存在环则某些课程永远无法开始，返回 False。

使用 Kahn 算法（BFS 拓扑排序） 判环：

  1. 建图（邻接表）并统计每个节点的入度。
  2. 将所有入度为 0 的节点（无前置依赖）加入队列——这些课可以直接开始修。
  3. 每次从队列取出一个节点，将其所有后继节点的入度减一；若某后继入度降为 0，加入队列。
  4. 统计被处理的节点数，若等于总课程数则无环，返回 True；否则说明剩余节点都在环里，返回 False。

直觉上，拓扑排序就是不断”剥掉”没有依赖的节点，若最终所有节点都能被剥掉，则图是 DAG（有向无环图）。

复杂度：时间 O(V + E)，空间 O(V + E)（V 为课程数，E 为先修关系数）。

4. 实现 Trie（前缀树）

难度：Medium | 标签：Trie/多叉树 | 🔗 LeetCode 第 208 题

题目描述：实现一个前缀树（Trie），支持三个操作：insert(word) 插入一个单词；search(word) 返回该完整单词是否存在；startsWith(prefix) 返回是否存在以 prefix 为前缀的单词。

示例：依次调用 insert("apple")，search("apple") 返回 true，search("app") 返回 false，startsWith("app") 返回 true。

思路解析：

Trie 是一棵多叉树，每个节点代表一个字符，从根到某节点的路径拼接起来就是一个字符串前缀。每个节点维护两个信息：

  • children：一个长度 26 的数组（或字典），分别对应 26 个小写字母。
  • is_end：布尔值，标记该节点是否是某个完整单词的结尾。

insert：按字符逐层往下走，若子节点不存在则新建，走完所有字符后将最后节点的 is_end 置为 True。

search：同样逐层走，若中途遇到不存在的子节点则返回 False；走完后检查 is_end 是否为 True——必须是完整单词，不能只是前缀。

startsWith：与 search 逻辑相同，但最后不需要检查 is_end，只要路径存在就返回 True。

三个操作的时间复杂度均为 O(L)，L 为字符串长度；空间复杂度为 O(总字符数 × 26)。

复杂度：时间 O(L)（每次操作），空间 O(N × L × 26)（N 为插入单词数，L 为平均长度）。
