LeetCode Hot100-10：二分查找

二分查找：每次砍掉一半

二分查找的核心在于两点：一是明确”搜索区间”的定义（左闭右闭 [l, r] 还是左闭右开 [l, r)），并在整个循环中严格维持这个”循环不变量”；二是根据区间定义来决定 mid 的计算方式和边界的更新逻辑，稍有不一致就会导致死循环或漏解。面对旋转排序数组，关键在于每次先判断哪一半是有序的，再决定目标在哪一侧；找左右边界则需要在找到目标值后不急于返回，而是继续收缩区间以逼近边界。

1. 搜索插入位置

难度：Easy | 标签：二分查找 | 🔗 LeetCode 第 35 题

题目描述：给定一个升序排列的不含重复元素的整数数组 nums 和一个目标值 target，若 target 存在则返回其下标，否则返回它应被插入的位置（使数组仍保持有序）。

示例：nums = [1,3,5,6]，target = 5 → 2（nums[2] == 5）；target = 2 → 1（2 应插在下标 1）。

思路解析：使用左闭右闭区间 [l, r]，循环条件为 l <= r。每次取 mid = l + (r - l) // 2，若 nums[mid] == target 直接返回 mid；若 nums[mid] < target，说明插入位置在右半，令 l = mid + 1；否则令 r = mid - 1。循环结束时 l > r，此时 l 就是目标应插入的位置——它始终指向”第一个大于等于 target 的位置”，恰好满足题意。

复杂度：时间 O(log n)，空间 O(1)。

2. 搜索二维矩阵

难度：Medium | 标签：二分查找、矩阵 | 🔗 LeetCode 第 74 题

题目描述：给定一个 m x n 的整数矩阵 matrix，每行从左到右有序，且每行第一个元素大于上一行最后一个元素。给定整数 target，判断其是否存在于矩阵中。

示例：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]]，target = 3 → true。

思路解析：矩阵每行从左到右有序，且每行首元素大于上一行尾元素，因此整个矩阵按行展开后是一个严格有序的一维数组，长度为 m * n。对这个虚拟数组做一次标准二分：将下标 mid 映射回矩阵坐标 (mid // n, mid % n)，按普通二分流程比较即可。这样只需一次 O(log(mn)) 的二分，无需先找行再找列。

复杂度：时间 O(log(mn))，空间 O(1)。

3. 在排序数组中查找元素的第一个和最后一个位置

难度：Medium | 标签：二分查找 | 🔗 LeetCode 第 34 题

题目描述：给定升序整数数组 nums 和目标值 target，返回 target 在数组中出现的第一个和最后一个位置；若不存在则返回 [-1, -1]。要求时间复杂度 O(log n)。

示例：nums = [5,7,7,8,8,10]，target = 8 → [3, 4]。

思路解析：分别用两次独立的二分查找左边界和右边界。找左边界时，当 nums[mid] == target 不立即返回，而是令 r = mid - 1 继续向左收缩，循环结束后检查 l 是否越界且 nums[l] == target；找右边界时，命中时令 l = mid + 1 向右收缩，循环结束后 r 即为右边界。两次二分模板高度对称，差异只在命中时的收缩方向以及最终取 l 还是 r。

复杂度：时间 O(log n)，空间 O(1)。

4. 搜索旋转排序数组

难度：Medium | 标签：二分查找 | 🔗 LeetCode 第 33 题

题目描述：整数数组 nums 原本升序排列，在某个未知下标处发生了旋转（如 [0,1,2,4,5,6,7] 变为 [4,5,6,7,0,1,2]）。给定 target，在数组中搜索并返回其下标，不存在返回 -1。要求 O(log n) 时间复杂度。

示例：nums = [4,5,6,7,0,1,2]，target = 0 → 4。

思路解析：旋转后的数组每次二分都能保证至少有一半是严格有序的。先比较 nums[mid] 与 nums[l]：若 nums[l] <= nums[mid]，左半 [l, mid] 有序；否则右半 [mid, r] 有序。确定有序的那一侧后，判断 target 是否落在该有序区间内：若是，就收缩到那一侧；否则收缩到另一侧。这样每次仍能砍掉一半，时间复杂度不变。注意用 <= 而非 < 来比较 nums[l] 和 nums[mid]，防止 l == mid 时误判。

复杂度：时间 O(log n)，空间 O(1)。

5. 寻找旋转排序数组中的最小值

难度：Medium | 标签：二分查找 | 🔗 LeetCode 第 153 题

题目描述：给定一个元素互不相同的升序整数数组，在某个位置发生了旋转，找出其中的最小值。要求时间复杂度 O(log n)。

示例：nums = [3,4,5,1,2] → 1。

思路解析：最小值一定在旋转点处，它是数组中唯一”前一个元素比自己大”的位置（或者是 nums[0]，即未旋转的情况）。比较 nums[mid] 与 nums[r]：若 nums[mid] > nums[r]，说明最小值在 mid 的右侧，令 l = mid + 1；若 nums[mid] <= nums[r]，最小值在 mid 处或其左侧，令 r = mid（注意不是 mid - 1，因为 mid 本身可能就是最小值）。循环终止条件为 l < r，结束时 l == r 即为最小值位置。

复杂度：时间 O(log n)，空间 O(1)。

6. 寻找两个正序数组的中位数

难度：Hard | 标签：二分查找、分治 | 🔗 LeetCode 第 4 题

题目描述：给定两个升序整数数组 nums1（长度 m）和 nums2（长度 n），找出两数组合并后的中位数。要求时间复杂度 O(log(m+n))。

示例：nums1 = [1,3]，nums2 = [2] → 2.0（合并为 [1,2,3]，中位数为 2）。

思路解析：要在 O(log(m+n)) 内完成，不能合并后排序，需对”分割线”做二分。核心思路是在较短数组 A 上二分一个分割点 i，使得 A[:i] 和 B[:j]（j = half - i，其中 half = (m+n+1)//2）合在一起恰好构成左半部分，且满足交叉不等式 A[i-1] <= B[j] 且 B[j-1] <= A[i]。找到合法分割线后，奇偶总长决定中位数取法：总长为奇数时中位数是左半最大值 max(A[i-1], B[j-1])；总长为偶数时是左半最大值与右半最小值的均值。边界处理用 -inf 和 inf 代替越界的虚拟元素，使逻辑统一。

复杂度：时间 O(log(min(m,n)))，空间 O(1)。
