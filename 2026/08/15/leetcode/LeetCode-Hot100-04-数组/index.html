LeetCode Hot100-04：普通数组技巧

普通数组：前缀、差分与原地技巧

这类题不靠固定框架，靠的是对数组结构的巧妙观察：用前缀积消除冗余除法、用原地标记把数组自身当哈希表、用三次反转代替额外空间。掌握这些技巧，能在 O(n) 时间、O(1) 空间内解决看似复杂的问题。

1. 最大子数组和

难度：Medium | 标签：动态规划/贪心 | 🔗 LeetCode 第 53 题

题目描述：给定整数数组 nums，找出具有最大和的连续子数组（子数组至少含一个元素），返回其最大和。

示例：nums = [-2,1,-3,4,-1,2,1,-5,4] → 6（子数组 [4,-1,2,1] 的和最大）

思路解析：Kadane 算法的核心观察是：若当前的连续子数组之和已经为负，那么从下一个元素重新开始一定更优——负数只会拖累后续元素。因此定义 cur 为以当前元素结尾的子数组最大和，状态转移为 cur = max(nums[i], cur + nums[i])，即”要么把当前元素接在前面的子数组后面，要么丢掉之前的一切从当前元素重新出发”，全程维护全局最大值即可。

复杂度：时间 O(n)，空间 O(1)。

2. 合并区间

难度：Medium | 标签：数组/排序 | 🔗 LeetCode 第 56 题

题目描述：以数组 intervals 表示若干区间的集合，其中 intervals[i] = [start_i, end_i]，合并所有重叠区间，返回不重叠的区间数组。

示例：intervals = [[1,3],[2,6],[8,10],[15,18]] → [[1,6],[8,10],[15,18]]（区间 [1,3] 和 [2,6] 重叠，合并为 [1,6]）

思路解析：将所有区间按起点升序排序后，只需线性扫描一次即可完成合并。维护一个结果列表，每次取当前区间与结果列表末尾区间比较：若当前区间起点 ≤ 末尾区间终点，说明二者重叠，将末尾区间的终点更新为两者终点的最大值；否则直接追加当前区间。排序保证了只需向后看，不必回头处理。

复杂度：时间 O(n log n)，空间 O(n)。

3. 轮转数组

难度：Medium | 标签：数组/双指针 | 🔗 LeetCode 第 189 题

题目描述：给定整数数组 nums，将数组中的元素向右轮转 k 个位置（k 为非负数），要求原地修改。

示例：nums = [1,2,3,4,5,6,7]，k = 3 → [5,6,7,1,2,3,4]

思路解析：将数组向右轮转 k 步，等价于把整个数组反转，再把前 k 个元素反转，最后把后 n-k 个元素反转。以 [1,2,3,4,5,6,7]，k=3 为例：全部反转得 [7,6,5,4,3,2,1]，前 3 个反转得 [5,6,7,4,3,2,1]，后 4 个反转得 [5,6,7,1,2,3,4]，正好是目标结果。注意 k 需要对 n 取模，避免 k≥n 的情况。

复杂度：时间 O(n)，空间 O(1)。

4. 除自身以外数组的乘积

难度：Medium | 标签：数组/前缀积 | 🔗 LeetCode 第 238 题

题目描述：给定整数数组 nums，返回数组 answer，其中 answer[i] 等于 nums 中除 nums[i] 之外其余各元素的乘积，不得使用除法，且要求 O(n) 时间。

示例：nums = [1,2,3,4] → [24,12,8,6]

思路解析：题目要求不使用除法，且 O(n) 时间、O(1) 额外空间（输出数组不计入）。关键观察是：answer[i] = nums[0..i-1] 的乘积 × nums[i+1..n-1] 的乘积，即左侧前缀积与右侧后缀积之积。第一遍从左向右扫描，令 answer[i] 先存储 i 左侧所有元素的乘积（answer[0]=1，因为 0 左侧没有元素）；第二遍从右向左扫描，用变量 right 累积右侧后缀积，并直接乘入 answer[i]，两遍扫描完毕即得最终结果，全程只用了输出数组和一个 right 变量。

复杂度：时间 O(n)，空间 O(1)（输出数组不计）。

5. 缺失的第一个正数

难度：Hard | 标签：数组/原地哈希 | 🔗 LeetCode 第 41 题

题目描述：给定未排序的整数数组 nums，找出其中没有出现的最小正整数，要求时间复杂度 O(n)，空间复杂度 O(1)。

示例：nums = [3,4,-1,1] → 2（正整数 1 存在，2 缺失）

思路解析：题目要求 O(n) 时间、O(1) 空间，不能用额外哈希表。核心思路是把数组本身当哈希表：对于长度为 n 的数组，答案必然落在 [1, n+1] 范围内（最好情况是 1n 全部出现，答案就是 n+1）。因此只需关心 1n 范围内的数。遍历数组，对每个满足 1 <= nums[i] <= n 的数，将它放到下标 nums[i]-1 的位置上（即让 nums[nums[i]-1] == nums[i]），通过不断交换来归位，直到当前位置的数无法继续归位为止（目标位置已经有正确的数，或数值越界）。归位完成后，再次遍历，第一个不满足 nums[i] == i+1 的下标 i，答案就是 i+1；若全部满足则答案是 n+1。

复杂度：时间 O(n)，空间 O(1)。
