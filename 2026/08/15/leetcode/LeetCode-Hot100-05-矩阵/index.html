LeetCode Hot100-05：矩阵

矩阵：方向控制与原地操作

矩阵题的核心难点在于二维遍历的边界管理——螺旋遍历、旋转等操作稍有疏漏就会越界或重复访问。原地修改类题目（置零、旋转）要求在 O(1) 额外空间内完成，通常需要借用矩阵自身的某一行/列或利用数学变换（转置+翻转）来规避额外存储。对于有序矩阵的查找，利用行递增、列递增的有序性，从右上角出发做 Z 字路径搜索，可以将朴素 O(mn) 降到 O(m+n)。

1. 矩阵置零

难度：Medium | 标签：矩阵 | 🔗 LeetCode 第 73 题

题目描述：给定一个 m × n 的整数矩阵 matrix，如果某个元素为 0，则将其所在行和列的所有元素置为 0，要求原地修改，尽量使用 O(1) 的额外空间。

示例：输入 matrix = [[1,1,1],[1,0,1],[1,1,1]]，输出 [[1,0,1],[0,0,0],[1,0,1]]。

思路解析：朴素做法是用两个集合分别记录含零的行和列，但需要 O(m+n) 额外空间。原地技巧的关键观察是：可以直接用首行和首列充当这两个集合——先用两个布尔变量记录首行、首列自身是否含零，然后遍历矩阵主体（从 matrix[1][1] 开始），遇到零就在对应的 matrix[0][j] 和 matrix[i][0] 打标记；第二轮根据标记将对应行列置零；最后按原先记录的布尔值决定是否清空首行和首列。整个流程只借用了两个变量，空间降到 O(1)。

复杂度：时间 O(mn)，空间 O(1)。

2. 螺旋矩阵

难度：Medium | 标签：矩阵 | 🔗 LeetCode 第 54 题

题目描述：给定一个 m × n 的矩阵 matrix，按螺旋顺序（从外圈到内圈，顺时针方向）返回矩阵中的所有元素。

示例：输入 matrix = [[1,2,3],[4,5,6],[7,8,9]]，输出 [1,2,3,6,9,8,7,4,5]。

思路解析：维护四个边界 top、bottom、left、right，每次沿一个方向遍历完一条边后就将该边界向内收缩一格，依次按”左→右、上→下、右→左、下→上”循环推进，直到 top > bottom 或 left > right 为止。每次向内收缩前需要检查边界是否仍然有效，避免单行/单列时重复采集。这种边界收缩方式比层层剥皮更直观，也更容易控制终止条件。

复杂度：时间 O(mn)，空间 O(1)（结果数组不计）。

3. 旋转图像

难度：Medium | 标签：矩阵 | 🔗 LeetCode 第 48 题

题目描述：给定一个 n × n 的二维矩阵 matrix，将其原地顺时针旋转 90°，不能使用额外的矩阵空间。

示例：输入 matrix = [[1,2,3],[4,5,6],[7,8,9]]，输出 [[7,4,1],[8,5,2],[9,6,3]]。

思路解析：顺时针旋转 90° 的数学等价是：先沿主对角线转置，再水平翻转（左右镜像）。转置的效果是 matrix[i][j] 与 matrix[j][i] 互换，完成后行列身份互换；水平翻转则把每行的第 j 列和第 n-1-j 列对调，恰好补全了旋转所需的列序颠倒。两步合起来精确对应”顺时针 90°”的坐标变换 (i, j) → (j, n-1-i)，全程原地操作，无需额外矩阵。逆时针 90° 则是先水平翻转再转置，或者先转置再垂直翻转，原理相同。

复杂度：时间 O(n²)，空间 O(1)。

4. 搜索二维矩阵 II

难度：Medium | 标签：矩阵、二分查找 | 🔗 LeetCode 第 240 题

题目描述：编写一个高效算法在 m × n 矩阵 matrix 中搜索目标值 target，矩阵每行从左到右递增，每列从上到下递增。

示例：输入 matrix = [[1,4,7,11],[2,5,8,12],[3,6,9,16],[10,13,14,17]]，target = 5，输出 true。

思路解析：矩阵每行从左到右递增、每列从上到下递增，这种有序性决定了右上角是一个天然的”分叉点”：当前值比 target 大时，该列所有更大的值都在下方（向左移动一列可以缩小当前值）；比 target 小时，该行所有更小的值都在左方（向下移动一行可以增大当前值）。每次比较都能排除一整行或一整列，路径呈 Z 字形从右上走向左下，最多走 m+n 步即可确定目标是否存在，比暴力搜索快一个数量级。

复杂度：时间 O(m+n)，空间 O(1)。
