CodeGen: An Open Large Language Model for Code with Multi-Turn Program Synthesis

核心信息

  • 标题: CodeGen: An Open Large Language Model for Code with Multi-Turn Program Synthesis
  • 作者: Erik Nijkamp et al. (Salesforce Research)
  • 发表时间: 2022年3月
  • arXiv: 2203.13474
  • 论文类型: 模型发布论文

原文摘要翻译

CodeGen 是一系列开源的大规模代码语言模型，参数规模从 350M 到 16B。通过多步程序合成（multi-step program synthesis）——将复杂编程任务分解为多个子任务，模型通过与用户的多轮对话逐步构建完整程序。模型在多轮程序合成基准上展现了强大能力。

创新点

1. 多步程序合成范式

将复杂编程任务分解为多个子步骤逐步完成，模型在每步基于前面步骤的输出继续编码，实现更可控的代码生成。

2. 开源代码模型系列

从 350M 到 16B 的多尺度发布，特别覆盖了小模型的部署场景。是 Codex 之外最早的开源代码模型之一。

3. 多轮对话式编程

将程序合成定义为多轮交互过程，为后续的交互式编程助手奠定了基础。

一句话总结

CodeGen 是最早的开源代码模型系列之一，提出多步程序合成范式实现交互式编程。

关键要点

  • 多步程序合成：分解复杂任务
  • 多尺度开源（350M-16B）
  • 交互式编程的早期探索
