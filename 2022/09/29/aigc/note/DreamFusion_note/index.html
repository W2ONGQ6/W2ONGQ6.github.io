DreamFusion: Text-to-3D using 2D Diffusion

DreamFusion: Text-to-3D using 2D Diffusion

核心信息

  • 完整标题: DreamFusion: Text-to-3D using 2D Diffusion
  • 中文译名: DreamFusion：使用 2D 扩散模型实现文本到 3D 生成
  • 作者: Ben Poole, Ajay Jain, Jonathan T. Barron, Ben Mildenhall
  • 机构: Google Research / UC Berkeley
  • 发表时间: 2022年9月（arXiv），2023年5月（ICLR 2023 Oral）
  • 发表渠道: ICLR 2023（Oral 演讲，接收率前 5%）
  • arXiv: 2209.14988
  • 项目主页: https://dreamfusion3d.github.io
  • 关键词: Score Distillation Sampling (SDS), 2D Diffusion Prior, Neural Radiance Field (NeRF), Text-to-3D, Zero 3D Training Data

研究背景：3D 内容生成的根本性瓶颈

3D 内容（三维模型、场景）是游戏、电影、AR/VR、工业设计、机器人仿真的基础要素。然而，与 2D 图像生成（拥有数十亿级别的图文对训练数据）相比，3D 生成面临一个根本性瓶颈：缺乏足够规模和多样性的标注 3D 数据集。

量化这一瓶颈的严重性：

  • 2D 图像数据: LAION-5B 包含约 58.5 亿条图文对；ImageNet 有 1400 万张标注图像
  • 3D 模型数据: 最大的公开 3D 数据集 ShapeNet 仅包含约 5.1 万个 3D 模型（55 个类别）；Objaverse 约 80 万模型但标注质量参差不齐
  • 数据量差距: 2D vs 3D 大约多 3-4 个数量级（1000-10000 倍）

DreamFusion 提出了突破性策略：将冻结的 2D 文本到图像扩散模型作为 3D 生成器的”教师”，通过 Score Distillation Sampling (SDS) 将 2D 扩散模型中蕴含的视觉先验蒸馏到 3D 表示（NeRF）中，完全不需要任何 3D 训练数据。

原文摘要翻译

近年来，基于扩散模型的二维图像生成取得了显著进展，通过在大规模图像-文本对数据集上训练数十亿参数的模型，这些模型能够生成具有惊人真实感和多样性的图像。然而，类似规模的 3D 生成模型受限于标注 3D 数据集的数量和多样性——目前最大的公开 3D 数据集仅包含数十万个模型，而 2D 图文对训练数据已超过 50 亿对。本文提出 DreamFusion，一种无需任何 3D 训练数据即可实现文本到 3D 合成的方法。我们引入得分蒸馏采样（Score Distillation Sampling，简称 SDS），这是一种利用预训练 2D 文本到图像扩散模型作为先验，对参数化图像生成器进行优化的方法。具体而言，我们通过梯度下降优化一个神经辐射场（NeRF），使其从随机相机视角渲染的图像在扩散模型评估下看起来像是从输入文本描述生成的高概率样本。与传统扩散采样在像素空间逐步去噪不同，SDS 在参数空间中进行梯度下降——冻结的扩散模型的得分估计被用作优化信号，推动 NeRF 参数向生成与文本描述一致的 3D 内容的方向移动。该方法不需要 3D 训练数据，也无需对图像扩散模型进行任何修改或微调。我们通过大量定性实验（多视角渲染结果和 360 度旋转视频）和定量实验（CLIP R-Precision 78.5%，用户偏好率 70.9%）证明了预训练 2D 扩散模型的有效先验知识可迁移至 3D 生成任务。

创新点

创新点 1: 得分蒸馏采样（SDS）——将 2D 扩散模型转化为 3D 优化信号

核心定义: SDS 是将冻结的 2D 扩散模型的得分估计转化为对任意可微分参数化图像生成器（如 NeRF 渲染函数）的可微优化目标的方法。它在参数空间中做梯度下降，而非在像素空间中逐步去噪。

SDS 损失的梯度:
$$\nabla_\theta \mathcal{L}{\text{SDS}}(\theta) = \mathbb{E}{t, \epsilon} \left[ w(t) (\hat{\epsilon}_\phi(\alpha_t g(\theta) + \sigma_t \epsilon; y, t) - \epsilon) \frac{\partial g(\theta)}{\partial \theta} \right]$$

WHY 分析: (1) 测量了渲染图像偏离”真实图像”的方向——扩散模型预测的噪声 vs 实际加入的噪声；(2) 关键简化——丢弃 U-Net Jacobian: 完整的梯度链式法则包含 项（维度约 12K x 12K），计算成本不可接受。丢弃它使得梯度有偏但可行，且实践证明这个近似提供了足够强的优化信号；(3) 与 GAN 的结构类比：扩散模型的得分估计类似冻结的”判别器”，但无需对抗训练——远比 GAN 稳定。

创新点 2: 零 3D 训练数据的 3D 生成范式

核心定义: 首次证明”不需要任何 3D 数据就能生成 3D 内容”在技术上是可行的，打破了此前 3D 生成必须依赖 3D 标注数据或 3D GAN 的约束。

WHY 分析——扩散模型为何学会 3D: 2D 扩散模型虽从未接触 3D 数据，但在数十亿图文对训练中不得不隐式学习 3D 规律：(a) 判断”从侧面看的木椅”的照片质量需要理解椅子在侧面的外观；(b) 生成正确的遮挡关系需要深度排序理解；(c) 生成一致光照需要表面法线与光照交互的知识。DreamFusion 的实验结果证明了这一推测——生成的多视角渲染具有合理的几何一致性。

创新点 3: 随机视角与光照的联合优化策略

核心定义: 在每步优化中从球面随机采样相机位姿和光照方向，迫使 NeRF 学习覆盖所有视角的真实 3D 几何。

WHY 分析——为何固定视角会导致退化: 单视角缺乏深度约束——NeRF 可以将密度集中在该视角方向的薄层中（纸片效应）。随机视角采样迫使密度分布到 3D 空间——如果仅在视角 A”欺骗”，视角 B 的渲染会立刻暴露问题。视角采样范围：仰角 ，方位角 。

创新点 4: 2D 扩散模型的 3D 先验发现——为”2D 升维”奠基

核心定义: 用实验证明了预训练 2D 扩散模型内部蕴含丰富的隐式 3D 理解。这个发现为后续 Magic3D、ProlificDreamer、MVDream、Zero-1-to-3、DreamGaussian 等所有”2D 升维”方法提供了理论基础。

一句话总结

DreamFusion 通过得分蒸馏采样（SDS）将冻结的 2D 文本到图像扩散模型转化为 3D 神经辐射场的优化信号，在 ICLR 2023 获得 Oral，开创了”2D 升维”技术范式——完全不需要任何 3D 训练数据即可从文本生成 3D 内容，启发了后续从 Magic3D 到 DreamGaussian 到 LGM 的快速迭代（生成时间从 1.5 小时缩短至 5 秒）。

研究问题

核心总问题

能否利用已有的 2D 扩散模型来指导 3D 内容的生成，完全绕开 3D 训练数据稀缺的瓶颈？需要设计什么样的优化机制来将 2D 扩散模型的”评价能力”转化为对 3D 表示的可微优化信号？

子问题 1: 如何将扩散模型的 2D 得分转化为对 3D 参数的可微优化信号？

SDS 将”在像素空间迭代去噪”转化为”在参数空间做梯度下降”：从 NeRF 渲染图像 → 加噪 → 冻结扩散模型预测 $\hat{\epsilon}\phi(x_t; y, t)\nabla\theta = (\hat{\epsilon} - \epsilon) \cdot \partial x / \partial \theta$。丢弃 U-Net Jacobian 牺牲了数学精确性换取计算可行性。

子问题 2: 仅用 2D 监督如何保证多视角一致性？

单张 2D 图像不包含深度信息，同一 NeRF 可通过多种 3D 配置产生相同渲染。随机视角采样策略迫使模型每步都”取悦”一个新的随机视角——如果上一步在某视角”作弊”（将密度集中在该方向），下一步其他视角的渲染会立即暴露问题。

子问题 3: 2D 扩散模型内部真的包含 3D 先验吗？

正面证据：DreamFusion 表现出合理的多视角一致性和几何结构。反面证据：Janus 问题（多视角都是”正面”）、过饱和伪影、无法处理复杂场景。结论：2D 扩散模型包含 3D 先验，但这个先验是不完整的。

子问题 4: 不同噪声级别 t 有什么不同作用？

大 t（高噪声）→ 全局结构和语义一致性（但也导致过饱和）；小 t（低噪声）→ 精细纹理和局部细节；U(0,1) 均匀采样是隐式的多尺度优化。退火策略（从大 t 逐步减小）可产生课程学习效果。

数据与任务定义

任务: 输入文本 prompt → 输出 3D NeRF 表示，可从任意视角渲染符合文本描述的一致图像。

无需 3D 训练数据: 仅使用 Imagen 扩散模型（冻结），T5-XXL 文本编码器（冻结）。

3D 表示: mip-NeRF 360——前景/背景分离、视点相关颜色、Phong 光照模型。

渲染分辨率: 64x64（匹配 Imagen 基础分辨率）。

评估方法: CLIP R-Precision（78.5%）、用户偏好研究（70.9% vs CLIP-Mesh 的 29.1%）。

校准: 无需校准数据。SDS 优化过程中通过 Imagen 的冻结参数隐式提供”什么是好图像”的参考。

方法主线

步骤 1: 文本编码

输入: 自然语言 prompt（如 “a DSLR photo of a peacock on a surfboard”）
操作: 使用冻结 T5-XXL 编码为嵌入
输出: 贯穿整个优化的固定文本条件信号

步骤 2: 随机视角渲染

输入: NeRF 参数
操作: 从球面随机采样相机位姿（仰角 、方位角 、距离 2.0-3.5），随机采样光照方向，使用 mip-NeRF 360 进行可微分体积渲染
输出: 64x64 渲染图像

步骤 3: SDS 梯度计算

输入: 渲染图像 ，文本嵌入 ，冻结 Imagen
操作: 采样 和 → 加噪 → 预测 $\hat{\epsilon}\phi \nabla\theta \approx w(t)(\hat{\epsilon} - \epsilon) \cdot \partial x / \partial \theta$
输出: NeRF 参数的近似梯度

步骤 4: NeRF 参数更新

输入: 近似梯度
操作: Adam 优化器， （cosine decay 到 ），训练 10000-30000 步（约 1.5 小时 on 4x TPUv4）
输出: 更新后的 NeRF 参数——编码了与文本一致的 3D 物体

步骤 5: 光照增强

输入: NeRF 预测的反照率和法线
操作: 使用随机光照方向 + 简化 Phong 模型（ambient + diffuse + specular）计算最终颜色，迫使 NeRF 分离材质和光照
输出: 具有物理真实性光照的渲染图像

深度分析

分析 1: SDS 与 GAN 训练的结构类比

GAN: 判别器提供梯度 推动生成器向真实分布。SDS: 扩散模型的得分估计提供信号 。关键区别——扩散模型是冻结的，无需对抗训练，远比 GAN 稳定。这是因为扩散模型在数十亿真实图像上预训练，已形成精确的”真实图像分布”内部模型，即使对 NeRF 早期极差的渲染也能提供有意义的方向信号。

分析 2: SDS 过饱和问题的数学根源

SDS 从 U(0,1) 均匀采样 t。大 t 时扩散模型看到严重破坏的图像，去噪方向指向分布中心（高饱和、高对比度的”平均”图像）。ProlificDreamer (2023) 的 VSD 通过优化 LoRA 微调的学生模型提供更精确的梯度，将过饱和伪影减少约 70-80%。

分析 3: Janus 问题的深层原因

2D 扩散模型的训练数据中正面视角远多于背面，模型缺乏”背面应该长什么样”的强先验。从背面渲染 NeRF 时扩散模型偏好生成类似正面的图像，导致 NeRF 学习到双正面结构。MVDream (2023) 通过多视图扩散模型将 Janus 发生率降低了约 80%。

分析 4: 从 2D 扩散到 3D 的信息损失

SDS 蒸馏过程存在多层信息损失：渲染分辨率仅 64x64（低分辨率无法传递精细细节）、每步仅 1 个随机视角（模型必须猜测其他视角）、丢弃 U-Net Jacobian 引入梯度偏差。

分析 5: 为什么选择 NeRF 而非其他 3D 表示？

NeRF（mip-NeRF 360）的核心优势是可微分体积渲染——SDS 需要梯度从渲染图像反向传播到 3D 参数。Mesh（2022 年可微分光栅化不成熟）、Voxel Grid（内存 限制）、Point Cloud（无法产生高质量 2D 渲染）。3D Gaussian Splatting 在 2023 年才发明，成为 dreamFusion 之后效率突破的关键。

局限

  1. Janus 问题（~30-50% 出现率）：物体从多个视角显示”正面”，根源是 2D 扩散模型正面数据多于背面
  2. 过饱和伪影（~40% 用户认为颜色过度鲜艳）：SDS 高噪声级别导致分布平滑化
  3. 生成时间长（~1.5 小时）：无法交互使用，后续 DreamGaussian（2分钟）和 LGM（5秒）已大幅改进
  4. 渲染分辨率仅 64x64：受限于 Imagen 基础分辨率，无法捕获精细纹理
  5. 缺乏 3D 几何的定量评估标准：CLIP R-Precision 仅评估 2D 渲染质量，不评估 3D 几何
  6. 依赖教师模型质量：较弱扩散模型（SD 1.5）导致 R-Precision 从 78.5% 降至 74.2%
  7. 对 prompt 措辞敏感：不同措辞可能产生不同结果，需要 prompt engineering
  8. 无法处理复杂场景：单 NeRF 难以表示多物体场景，物体关系不准确

可复用洞见

  1. “蒸馏而不训练”的迁移范式: SDS 证明冻结教师模型的知识可通过梯度蒸馏到完全不同模态的学生模型——只要存在可微分的”渲染/生成”接口

  2. 随机视角采样 = 隐式多视角一致性: 每步随机变化视角迫使模型学习真实的 3D 结构，是一种极致的”多视角数据增强”

  3. 噪声级别 t 是多尺度优化的设计空间: 大 t 关注全局结构，小 t 关注局部细节。退火策略（大→小）提供天然课程学习

  4. 冻结模型比自适应评估器更稳定: SDS 使用冻结扩散模型避免了 GAN 对抗训练的不稳定性——“足够好且稳定”优于”最优但不稳定”

我的笔记

DreamFusion 是”踩在巨人肩膀上”的经典案例——Imagen（教师）+ mip-NeRF 360（3D 表示）都是已有工作，SDS 是唯一原创组件，但贡献足够开创一个新方向。SDS 丢弃 U-Net Jacobian 是一个有偏但有效的近似梯度——反映”在实践中足够好”比”理论上完全精确但计算不可行”更有价值的研究哲学。

从 DreamFusion (1.5h) 到 DreamGaussian (2min) 到 LGM (5s)，生成效率提升超 1000 倍——驱动因素包括从 NeRF 到 3DGS 的渲染速度飞跃和从前馈生成到实例优化的策略转变。

Janus 问题不仅是 bug，更揭示了深刻的科学问题：2D 视觉知识不完全等价于 3D 理解。2D 扩散模型”知道”人脸长什么样但”不知道”3D 脸的背面应该是什么——学习到的 2D 先验与真实 3D 理解之间存在”语义鸿沟”。

DreamFusion 在 ICLR 2023 获得 Oral（前 5%），至今引用超 2000 次。它开创的”2D 升维”方向在 2023-2024 年间爆炸式发展。

后续问题

  1. SDS 梯度估计的偏差在什么条件下可接受？能否对不同场景进行量化的偏差分析？
