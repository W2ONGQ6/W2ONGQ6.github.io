ZeRO: Memory Optimizations Toward Training Trillion Parameter Models

ZeRO: Memory Optimizations Toward Training Trillion Parameter Models

核心信息

  • 标题: ZeRO: Memory Optimizations Toward Training Trillion Parameter Models
  • 标题翻译: ZeRO：面向万亿参数模型训练的内存优化
  • 作者: Samyam Rajbhandari, Jeff Rasley, Olatunji Ruwase, Yuxiong He
  • 机构: Microsoft
  • 发表时间: 2019年10月
  • 发表渠道: SC 2020
  • arXiv: 1910.02054
  • 论文链接: https://arxiv.org/abs/1910.02054

原文摘要翻译

训练大型深度学习模型是一项挑战，因为传统的训练方法需要模型参数、梯度、优化器状态三者在训练过程中全部驻留在 GPU 内存中。我们开发了 ZeRO（Zero Redundancy Optimizer），一种新颖的内存优化技术，大幅降低了训练大型模型所需的内存占用，同时保持了极高的计算效率。与现有的数据并行和模型并行方法不同，ZeRO 通过对优化器状态、梯度和参数进行分区（partitioning）来消除数据并行进程间的内存冗余，同时保持计算粒度和通信效率。ZeRO 的 Stage 1 将优化器状态分区，减少 4 倍内存；Stage 2 额外将梯度分区，减少 8 倍；Stage 3 再将参数分区，内存减少与数据并行度 N 线性相关。ZeRO 为训练万亿参数模型铺平了道路。

创新点

1. 内存冗余的系统性消除

数据并行训练中，每个 GPU 都保存了完整的优化器状态、梯度和模型参数——这些在 N 个 GPU 间是 100% 冗余的。ZeRO 通过对这些状态进行分区消除冗余，将每个 GPU 的内存占用从 O(模型大小) 降为 O(模型大小/N)。

2. ZeRO 的三阶段渐进优化

  • ZeRO-1 (Pos): 仅分区优化器状态，减少 4x 内存，无额外通信
  • ZeRO-2 (Pos+g): 分区优化器状态 + 梯度，减少 8x 内存
  • ZeRO-3 (Pos+g+p): 分区所有状态，内存线性随 N 减少，需额外通信收集参数

3. 与模型并行的正交互补

ZeRO 可以与模型并行（MP）组合使用：ZeRO 处理数据并行维度的内存冗余，MP 切分模型本身。ZeRO-3 + MP 可以训练任意大小的模型。

一句话总结

ZeRO 通过系统性消除数据并行训练中的优化器状态、梯度和参数的内存冗余，使训练万亿参数模型变得可行，是 DeepSpeed 框架的核心技术和现代大模型训练的基石。

方法主线

三阶段内存优化

  1. ZeRO-1 (Pos): 将优化器状态（Adam 的 m 和 v）在所有数据并行的 GPU 间均匀分区，每 GPU 只保存 1/N 的优化器状态
  2. ZeRO-2 (Pos+g): 在 ZeRO-1 基础上额外分区梯度。每 GPU 只负责更新其拥有的参数分区对应的梯度
  3. ZeRO-3 (Pos+g+p): 在 ZeRO-2 基础上分区模型参数本身。每 GPU 只保存 1/N 的参数，需要时通过 allgather 通信收集完整参数

通信分析

  • ZeRO-1: 通信量与标准数据并行相同（仅 allreduce 梯度）
  • ZeRO-2: 增加 reduce-scatter（替代 allreduce），通信量不变
  • ZeRO-3: 增加前向/反向的 allgather 参数收集，通信量为标准数据并行的 1.5x

核心实验

  • 在 1024 个 V100 GPU 上训练 170B 参数的 GPT-2 风格模型
  • ZeRO-1 将最大可训练模型规模从 1.4B 扩展到 6B（同 GPU 数）
  • ZeRO-3 实现接近线性的扩展效率（>90% 的弱扩展效率）
  • 吞吐量接近标准数据并行（计算效率损失 <10%）

局限性与批判

  • ZeRO-3 的通信开销在跨节点场景下更明显（带宽 vs 计算比下降）
  • 对模型架构有一定要求（需要支持分片参数收集）
  • 与某些模型并行方案的集成较复杂（如 pipeline parallelism 的参数分片策略）

关键要点

  • 数据并行中的内存冗余是巨大且可消除的——优化器状态占 12x 参数大小的内存
  • ZeRO 的渐进式设计允许用户根据硬件选择合适阶段
  • DeepSpeed 已成为 LLM 训练的事实标准框架
  • ZeRO 思想被后续的 FSDP（PyTorch）等方案吸收和推广
