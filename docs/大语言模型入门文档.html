表面上，模型只是在预测下一个词；但为了做好预测，它必须逐渐学会：

  • 语法；
  • 事实关联；
  • 上下文指代；
  • 代码结构；
  • 常识模式；
  • 不同任务的表达方式。

因此，“预测下一个 token”是训练目标，不等于模型最终表现出来的全部能力。

2.2 Token：模型真正看到的单位

模型并不直接读取汉字、单词或句子，而是读取 token。Token 可以是：

  • 一个汉字；
  • 一个英文单词的一部分；
  • 一个标点；
  • 一个代码片段；
  • 一组常见字符。

2.3 预训练、后训练与推理

现代 LLM 通常经历三个阶段：

  1. 预训练：在海量文本上学习语言规律和世界知识；
  2. 后训练：通过指令微调、偏好优化和强化学习，让模型更会遵循人类意图；
  3. 推理：给定上下文，逐 token 生成答案。

可以把它理解为：

预训练：学会“语言世界的统计规律”
后训练：学会“应该怎样与人协作”
推理：在当前上下文中生成行动结果

三、Transformer：LLM 的核心架构

3.1 为什么需要上下文建模

同一个词的含义取决于上下文。例如“苹果”可能指水果，也可能指公司。模型不能只看当前 token，必须让每个位置访问上下文中的相关信息。

Transformer 的核心机制是自注意力（Self-Attention）。

四、规模定律：为什么模型变大后能力会提升

4.1 三个主要变量

预训练效果主要受三类资源影响：

  • 模型参数量 ；
  • 训练 token 数 ；
  • 训练计算量 。

4.2 Chinchilla 的重要修正

早期实践常常把大量算力用来训练更大的模型，但数据量不足。Chinchilla 一类研究指出：在固定计算预算下，较小模型配合更多训练数据，可能优于更大的欠训练模型。

核心问题从：

模型能做多大？

转向：

参数、数据和训练步数如何匹配？

4.3 涌现能力

当模型规模、数据和训练充分增加时，一些能力可能表现出明显跃迁：

  • 少样本学习；
  • 多步推理；
  • 代码生成；
  • 复杂指令遵循。

需要注意：能力是否“突然出现”还与评测指标、提示方式和任务难度有关。更稳妥的理解是：规模让模型内部表示变得足够丰富，某些能力在特定任务上跨过了可观察的门槛。

五、从预训练模型到助手

5.1 为什么预训练模型不会自动听指令

预训练目标是预测网页、书籍或代码中的下一个 token，不是回答用户问题。模型可能会：

  • 继续补写问题；
  • 输出多个角色的对话；
  • 不遵守格式；
  • 给出与用户意图不符的续写。

因此需要后训练。

例如，预训练模型可能把“请把这句话翻译成英文”继续补写成一篇文章， 而不是直接给出翻译。后训练的作用，就是把“像文本一样续写”变成“按 用户任务完成回答”。

5.2 指令微调

  • 如何理解任务；
  • 如何组织回答；

  • 如何完成对话。

一个直观对比是：同一个预训练模型可能继续写一篇关于煮咖啡的文章； 经过指令微调后，它更可能直接按要求列出材料、步骤和注意事项。这主要 是响应行为发生了变化，而不是凭空增加了一个知识模块。

六、推理能力：模型如何一步步思考

6.1 Chain-of-Thought

复杂问题可以拆成中间步骤：

CoT 提示让模型显式生成中间推理过程，使每一步成为下一步的上下文。

例如“商品原价 80 元，打八折后再减 5 元是多少？”可以拆成：

先算打折价：80 × 0.8 = 64
再减去 5 元：64 - 5 = 59

分步过程给模型提供了检查中间结果的机会；但它也可能把错误一步步展开， 所以复杂任务仍需要计算器、代码执行或最终答案校验。

6.3 推理时计算

传统模型主要通过增加训练计算提升能力；推理模型还会在回答前生成更长的中间过程，相当于增加推理时计算：

9.3 KV Cache

自回归生成时，历史 token 的 Key、Value 可以缓存，避免每次重复计算：

第一次生成：计算全部上下文
后续生成：只计算新 token，复用历史 KV

例如上下文已有 1000 个 token，模型正在生成第 1001 个 token。没有缓存 时，前面的 token 可能被反复处理；有 KV Cache 时，历史 token 的 Key 和 Value 可以直接复用，只为新 token 计算新的表示。缓存只服务于当前一次 生成，并不等同于跨会话记忆。

长上下文推理的瓶颈，往往从算力转向 KV Cache 的显存和带宽管理。

十、总结

大语言模型的技术史可以浓缩为：

Transformer 解决上下文建模
规模化预训练获得通用表示
指令微调让模型学会协作
偏好优化让模型更符合人类目标
CoT 和 RLVR 提升复杂推理
多模态和工具使用让模型连接外部世界
高效训练和推理让模型真正可部署

最后记住五句话：

  1. LLM 的训练目标是预测下一个 token，但能力来自对大量模式的压缩和组合。
  2. Transformer 的核心是让每个位置有选择地读取上下文。
  3. 规模、数据和计算共同决定预训练能力。
  4. 后训练把“会续写”变成“会回答、会推理、会协作”。
  5. Agent 和具身智能是 LLM 从符号空间走向外部世界的两条重要路径。
