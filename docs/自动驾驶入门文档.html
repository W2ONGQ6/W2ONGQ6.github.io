  4. 为什么自动驾驶必须从开环评测走向闭环评测？

核心闭环是：

传感器 → 场景表示 → 他车预测 → 自车规划 → 控制执行

二、自动驾驶系统在解决什么问题

2.1 从 A 点到 B 点

自动驾驶不是单一模型，而是一套层级系统：

层级 问题 时间尺度
路由 从哪里到哪里 分钟级
行为决策 跟车、变道、让行还是停车 秒级
运动规划 未来几秒走哪条轨迹 毫秒到秒级
控制 方向盘、油门、刹车怎么执行 高频

本文重点关注感知、预测和规划。

BEV 的价值：

3.3 占据：不只问“是什么”

边界框适合车辆和行人，但无法准确描述：

  • 掉落物；
  • 施工区域；
  • 不规则障碍物；
  • 被遮挡的几何结构。

占据表示对空间体素预测：

它不要求每个物体都有清晰类别，而是先回答：

这个空间位置能不能被车辆占用？

例如施工锥、掉落的纸箱可能很难被稳定归类为某个目标类别，但只要占据 预测指出行驶区域中存在障碍，规划器就可以减速或绕行。

四、他车预测：别人会怎么动

4.1 为什么不能只规划自车

道路是多智能体环境。自车动作会受到：

  • 行人横穿；
  • 邻车变道；
  • 对向车辆转弯；
  • 交通规则和社会交互。

五、规划：我应该怎么开

5.1 规则式规划

优点是可解释、易调试；缺点是场景越复杂，规则越容易爆炸。

六、模仿学习与端到端驾驶

6.1 行为克隆

将人类驾驶数据作为专家示范：

问题是协变量偏移：训练时车辆位于专家轨迹上，部署时模型自己的小误差会把车辆带到训练分布之外。

例如专家驾驶时车辆始终位于车道中央，模型部署后第一次转向偏左一点。 此时相机画面和车辆状态已经不同于训练样本，模型可能继续输出错误转向， 车辆进一步偏离车道，形成误差累积的闭环问题。

七、生成式规划：从一条轨迹到轨迹分布

如果一个场景存在“左绕”和“右绕”两种合理选择，均值回归可能得到一条撞向障碍物的中间轨迹。

生成式规划学习：

扩散模型从噪声逐步生成轨迹：

模型预测噪声并完成反向去噪。

生成式规划的核心价值是：

  • 表达多种驾驶意图；
  • 生成平滑轨迹；
  • 把不确定性纳入规划；
  • 为后续安全筛选提供多个候选。

例如障碍物挡住道路时，“左绕”和“右绕”都可能成功。若用单一均值轨迹 训练，两个方向可能被平均成一条直穿障碍物的轨迹；生成模型则可以产生 两组候选，再由安全层结合道路边界和碰撞检查进行筛选。

八、大模型驾驶

8.1 为什么需要 VLM/LLM

道路中有大量语义和常识：

  • 施工人员手势；
  • 临时交通标志；
  • 学校、医院等场景；
  • 交警指挥；
  • 非标准障碍物。

VLM/LLM 可以提供视觉语义理解和常识推理。

8.2 双系统架构

一种实际折中是：

慢系统：VLM/LLM 做场景理解、解释和高层决策
快系统：传统规划器做实时轨迹和控制

慢系统不必每个控制周期运行，快系统负责安全执行。

例如 VLM 可以每隔较长时间判断“前方是临时施工改道”，而快系统每几十 毫秒继续完成车辆跟踪和制动。这样语义理解不必承担高频控制，也不会因 一次较慢的语言推理直接阻塞车辆执行。

8.3 大模型的边界

  • 空间坐标精度有限；
  • 推理延迟较高；
  • 可能出现幻觉；
  • 长尾常识不等于动力学理解；
  • 语言解释不等于安全保证。

因此大模型更适合作为高层认知模块，或者与几何规划器联合使用。

9.3 评测：开环与闭环

开环评测把模型预测和专家轨迹比较：

但它不真正执行模型动作，因此看不到误差累积。

闭环评测让模型输出驱动车辆继续运行：

模型动作 → 环境更新 → 新观测 → 模型再次决策

闭环更接近真实任务，也更容易暴露规划失败和安全问题。

一个模型可能在日志数据上有很小的平均轨迹误差，因为它预测的是专家当时 已经走过的道路；但一旦真实执行中出现一次小偏差，后续观测就不再像日志 里的专家轨迹，模型可能进入未见过的状态。因此不能只看开环 L2，还要观 察闭环中的碰撞、接管、舒适性和任务完成率。

十、自动驾驶技术演进

前视像素 → BEV 几何表示 → 占据/向量表示
    ↓
规则规划 → 搜索/优化 → 模仿学习
    ↓
端到端全栈 → 生成式规划 → VLM/LLM 驾驶
    ↓
开环指标 → 闭环评测 → 世界模型与闭环训练

每一代方法都在回应上一代的缺陷：

  • 像素难以规划，于是出现 BEV；
  • 边界框描述不了任意障碍，于是出现占据；
  • 单条轨迹表达不了多种决策，于是出现生成式规划；
  • 模块误差传播，于是出现端到端；
  • 端到端缺乏常识，于是引入 VLM/LLM；
  • 开环指标不可信，于是转向闭环评测。

十一、总结

  1. 自动驾驶是感知、预测、规划和控制组成的闭环系统。
  2. BEV 把视觉信息放到适合决策的车辆坐标系。
  3. 占据表示从“识别物体”扩展到“理解空间是否可占用”。
  4. 预测需要表达其他交通参与者的多种可能行为。
  5. 规划正在从规则和单点回归走向生成式、多模态和认知推理。
  6. VLM/LLM 可以增强语义理解，但不能替代几何、动力学和安全约束。
  7. 自动驾驶最终必须在闭环中被检验，而不能只看开环误差。
