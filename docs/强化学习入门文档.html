强化学习：从试错决策到大模型推理

面向了解机器学习基本概念、但没有系统学习过强化学习的读者。

一、阅读目标

阅读本文后，希望能够回答四个问题：

  1. 强化学习和监督学习、无监督学习有什么不同？
  2. 智能体如何知道一个动作是好是坏？
  3. DQN、PPO 等经典算法分别解决了什么问题？
  4. 强化学习为什么能够应用到 AlphaGo、RLHF 和大模型推理？

本文不追求记住所有算法名字，而是希望建立一条主线：

智能体与环境交互
    ↓
用奖励评价结果
    ↓
学习状态和动作的价值
    ↓
改进策略
    ↓
解决高维、连续、稀疏奖励和样本效率问题
    ↓
进入游戏、机器人和大模型

二、什么是强化学习

2.1 从“预测”到“行动”

监督学习通常是：

输入一张图片 → 预测它是什么
输入一封邮件 → 判断它是不是垃圾邮件
输入一句话 → 预测下一个词

强化学习则是：

观察当前环境 → 选择一个动作 → 获得反馈 → 继续行动

强化学习的输出不是一个标签，而是一个会改变未来的动作。

例如机器人要把杯子放入柜子：

  • 观察：杯子在哪里、柜子在哪里、机械臂当前姿态是什么；
  • 行动：移动、抓取、抬升、转向、释放；
  • 反馈：是否抓稳、是否碰撞、是否成功放入；
  • 目标：让整个任务最终成功。

2.2 强化学习的三个角色

角色 含义 机器人例子
Agent 做决策的智能体 机械臂、游戏角色、语言模型
Environment 智能体所在的环境 游戏、房间、网页、对话环境
Reward 环境对动作的评价 得分、任务成功、人工偏好

最重要的区别是：监督学习直接告诉模型“正确答案是什么”，强化学习通常只告诉它“结果好不好”。

2.3 一句话定义

强化学习是在环境反馈下，通过试错学习一个策略，使长期累计奖励最大化。

过渡：

既然强化学习的核心是“长期变好”，我们就需要先定义：什么叫长期收益？环境又应该怎样被数学化？

五、DQN：把 Q-Learning 接上神经网络

5.1 为什么表格 Q-Learning 不够

Q-Learning 假设可以保存每个 的 Q 值。但 Atari 游戏的状态是图像，状态空间极其庞大，无法为每个状态建立表格。

DQN 用神经网络近似：

输入图像，输出每个离散动作的 Q 值。

5.2 神经网络带来的致命三要素

把神经网络接入 Q-Learning 会同时遇到：

  1. 函数逼近：改一个状态会影响相似状态；
  2. Bootstrapping：用估计值训练估计值；
  3. Off-policy：训练数据和目标策略不一致。

这三者叠加，训练很容易发散。

5.3 经验回放

把交互数据存入回放池：

训练时随机采样，而不是按时间顺序使用。

作用：

  • 打破连续帧之间的强相关；
  • 让旧经验被重复利用；
  • 让每个 batch 更接近独立同分布。

如果目标和被训练网络使用同一套参数，网络每次更新都会改变目标，形成“追着自己移动的靶子”。目标网络通过周期性复制参数，把目标暂时固定住。

5.5 DQN 的历史意义

DQN 证明了：

神经网络可以直接从高维感知输入中学习动作价值。

它开启了深度强化学习，但也有一个明确边界：

对离散动作容易，对机器人关节力矩这类连续动作却很困难。于是下一条主线转向策略梯度。

六、策略梯度、Actor-Critic 与 PPO

6.1 为什么要直接优化策略

策略梯度不再先学习 Q 再取最大动作，而是直接参数化策略：

目标是最大化：

策略梯度定理：

直觉：

  • 高回报动作：提高被选中的概率；
  • 低回报动作：降低被选中的概率。

只有一个状态、两个动作：

  • 平均奖励为 1；
  • 平均奖励为 0。

6.3 Actor-Critic：降低策略梯度方差

REINFORCE 使用整条轨迹的回报 ，方差很高。

Actor-Critic 将系统拆成：

  • Actor：负责选择动作；
  • Critic：负责估计状态价值。

优势函数：

它回答的不是“这个动作好不好”，而是：

这个动作比当前状态下的平均水平好多少？

这样可以减少无意义的更新。

6.4 PPO：不要一次更新太远

策略梯度的另一个问题是步长敏感。策略一旦更新过猛，后续采样分布也会变坏。

6.5 PPO 为什么重要

PPO 的代表性在于“简单、稳健、通用”：

  • 游戏中使用；
  • 机器人控制中使用；
  • RLHF 中使用；
  • 后来的 GRPO 也继承了它的裁剪思想。

七、强化学习的三类核心困难

这一部分不展开算法细节，只建立地图。

7.1 探索：奖励太稀疏怎么办

如果只有完成任务才奖励，随机探索几乎不可能撞到成功路径。

解决思路：

  • Count-based：访问越少，探索奖励越高；
  • ICM/RND：预测越不准，越值得探索；
  • Go-Explore：记住有希望的状态，并可靠地返回。

7.2 样本效率：真实环境太贵怎么办

模型型 RL 学习环境模型：

再在模型中进行规划和想象。

关键矛盾：

模型越长程，想象越丰富；
但预测误差也会不断累积。

Dreamer 选择在潜空间中想象，MuZero 则只学习与决策相关的隐式模型。

7.3 不能在线试错怎么办

离线 RL 只使用固定数据集。它必须防止策略选择数据集中没有出现过的 OOD 动作。

代表方法：

  • BCQ：限制策略在数据分布附近；
  • CQL：压低 OOD 动作的 Q 值；
  • IQL：训练中避免直接查询 OOD 动作；
  • Decision Transformer：把 RL 改写为条件序列建模。

八、AlphaGo：强化学习如何形成系统突破

8.1 AlphaGo 的三个部件

  • 策略网络：预测哪些动作值得搜索；
  • 价值网络：估计当前局面的胜率；
  • MCTS：在有限计算预算下重点搜索有希望的分支。

可以把它理解为：

策略网络减少搜索宽度
价值网络减少搜索深度
MCTS 负责在候选空间中进一步规划

8.2 AlphaZero：自我博弈

AlphaZero 去掉人类棋谱，从随机初始化开始：

  1. 当前网络引导 MCTS；
  2. MCTS 产生比网络更强的搜索策略；
  3. 用搜索结果训练网络；
  4. 更强的网络再次引导搜索。

形成自我提升循环：

8.3 这一阶段带来的启发

AlphaGo 系统说明：

  • 学习和搜索可以互相增强；
  • 自我博弈可以生成无限训练数据；
  • 简单的奖励信号也可能产生复杂能力；
  • 大规模并行本身就是算法能力的一部分。

这条“可验证奖励 + 自我改进”的思路，后来会在大模型推理中再次出现。

九、RLHF 与大模型推理

9.1 RLHF：从人类偏好学习奖励

语言任务很难手写奖励：

什么是有帮助？
什么是诚实？
什么是安全？

RLHF 的经典三阶段：

  1. SFT：用高质量示范让模型先学会回答；
  2. 奖励模型：让人类比较多个回答，学习偏好分数；
  3. PPO：优化语言模型，同时用 KL 惩罚防止模型偏离参考模型。

9.2 DPO：把偏好优化改写成监督学习

DPO 从带 KL 的 RLHF 目标出发，推导出：

直觉：

提高好回答相对参考模型的概率，
降低差回答相对参考模型的概率。

DPO 更简单，但主要依赖已有的离线偏好数据。

9.3 GRPO：去掉昂贵的 Critic

对同一个问题采样一组回答：

根据组内奖励计算相对优势：

比组平均好的回答被强化，差的被抑制。组内平均值替代了 Critic 的一部分作用。

9.4 RLVR：用可验证奖励训练推理

数学、代码等任务可以使用客观验证器：

奖励目标：

如果更长的推理链能提高答对概率，强化学习就会自然增加这类轨迹的概率。于是反思、验证、回溯等行为可能从“优化结果正确”中涌现出来。

9.5 这条线和 AlphaZero 的关系

AlphaZero 大模型 RL
胜负 答案是否正确
自我博弈 多次采样和自我探索
MCTS 改进策略 RL 优化回答概率
棋力提升 推理能力提升

共同内核是：

用客观结果作为反馈，让系统通过试错发现人类没有逐步指定的行为。

10.2 最后用五句话带走

  1. 强化学习学习的不是“标准答案”，而是如何行动。
  2. 奖励告诉智能体结果好不好，但不直接告诉它每一步怎么做。
  3. 价值函数回答“从这里继续走，未来能得到多少”。
  4. 策略优化回答“下一步应该更倾向于做什么”。
  5. DQN、PPO、RLHF 和 GRPO 都是在解决同一个大问题：如何让行动策略在反馈中稳定变好。
